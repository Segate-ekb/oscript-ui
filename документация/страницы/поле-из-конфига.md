# Поле из конфига

Поле из конфига показывает настройку, значение которой задано снаружи — файлом свойств или переменной окружения. Конфиг — эталон, интерфейс — зеркало: значение видно, но не правится, а рядом сказано, где его поменять.

## Когда использовать

- Настройка приходит из `autumn-properties.json` или из переменной окружения, и правка в интерфейсе откатилась бы на перезапуске.
- Администратору нужно увидеть действующее значение и понять, откуда оно взялось.

Не берите его для значения, которое правится в интерфейсе, — это [поле формы](поле). Если значение просто нельзя менять и источника у него нет, хватит заблокированного поля формы. Команду, которую надо выполнить, показывает [блок команды](блок-команды).

В дереве холста метку, значение, подсказку и секретность пишут слова (см. [Язык узлов](язык-узлов)). Источник — `Деталька` и `Переменная` — слов не имеет и задаётся структурой модели.

```живой Узлом холста — словами
HTML = Кит.ПолеИзКонфига(Новый Структура("Деталька, Переменная",
	"app.storage.root", "APP_STORAGE_ROOT"))
	.Метка("Каталог данных").Значение("/var/lib/приложение").Рендер();
```

## Значение из детальки

Компонент печатает заблокированное [поле формы](поле) со значением, под ним — источник с замком (`Деталька`, имя детальки-источника), а ниже — строку для переменной окружения с кнопкой копирования (`Переменная`). Всё вместе обведено пунктирной рамкой: это не обычная часть формы.

```живой Значение из детальки
HTML = Набор.ПолеИзКонфига().Отрисовать(
	Новый Структура("Метка, Значение, Деталька, Переменная",
		"Каталог данных", "/var/lib/приложение",
		"app.storage.root", "APP_STORAGE_ROOT"));
```

Поле заблокировано и не отправляется с формой: сервер не получит значение, которое всё равно не может принять. `Подсказка` печатается под полем, как у обычного поля формы.

```живой С подсказкой — без переменной окружения
HTML = Набор.ПолеИзКонфига().Отрисовать(
	Новый Структура("Метка, Значение, Деталька, Подсказка",
		"Порт", "8080", "app.http.port", "меняется в файле свойств, вступает в силу после перезапуска"));
```

## Секрет

`Секрет` прячет значение: в поле его нет, вместо него плейсхолдер «значение скрыто», а в строке переменной стоит `<значение>`. Значения нет и в разметке страницы, поэтому оно не утечёт через «просмотр кода» или кэш.

```живой Секрет
HTML = Набор.ПолеИзКонфига().Отрисовать(
	Новый Структура("Метка, Значение, Деталька, Переменная, Секрет",
		"Пароль админа", "s3cret",
		"app.admin.password", "APP_ADMIN_PASSWORD", Истина));
```

## Гайдлайны

```делайте Пароли и ключи — с флагом Секрет
HTML = Набор.ПолеИзКонфига().Отрисовать(
	Новый Структура("Метка, Значение, Переменная, Секрет",
		"Ключ API", "sk-12345", "APP_API_KEY", Истина));
```

```не-делайте Секрет без флага: ключ виден на экране и в коде страницы
HTML = Набор.ПолеИзКонфига().Отрисовать(
	Новый Структура("Метка, Значение, Переменная",
		"Ключ API", "sk-12345", "APP_API_KEY"));
```

```делайте Назовите источник: человек видит, где поменять
HTML = Набор.ПолеИзКонфига().Отрисовать(
	Новый Структура("Метка, Значение, Деталька, Переменная",
		"Каталог данных", "/var/lib/приложение",
		"app.storage.root", "APP_STORAGE_ROOT"));
```

```не-делайте Заблокированное поле без источника: непонятно, почему не правится
HTML = Набор.Поле().Отрисовать(Новый Структура("Метка, Значение, Заблокировано",
	"Каталог данных", "/var/lib/приложение", Истина));
```

## Доступность

- Значок замка у источника несёт подпись «значение задано конфигурацией»: скринридер читает, почему поле не правится.
- Поле заблокировано атрибутом `disabled`: оно не берёт фокус и не отправляется.
- Кнопка копирования переменной — `<button type="button">` с видимой надписью «Копировать»; её оживляет скрипт страницы по `data-copy`. Без скрипта строку можно выделить мышью.

## Узлом холста

```живой Поле из конфига узлом дерева
HTML = Кит.ПолеИзКонфига(Новый Структура("Деталька", "app.storage.root"))
	.Метка("Каталог данных").Значение("/var/lib/приложение").Рендер();
```

## Модель

Поля модели — из комментария в исходнике компонента. Структура — прежний вид модели: в дереве холста `Метка`, `Значение`, `Подсказка` и `Секрет` пишут слова `Кит.ПолеИзКонфига`, а источник остаётся в структуре.

```справка Кит.ПолеИзКонфига
```

```справка ПолеИзКонфига
```

```словарь компонент:поле-конфига
```
