# Текст и значения

Листья дерева — то, что человек читает: заголовки, надписи, абзацы, ссылки, машинные значения, картинки. Текст из данных кладут узлом `Кит.Текст()`, и он экранируется всегда.

## Какой род взять

- **Заголовок** — место в оглавлении страницы, уровень от 1 до 6.
- **Надпись** — кусок строки со своей ролью: название, пояснение, приглушённое.
- **Примечание** — абзац мелким шрифтом: описание, источник значения, «ничего не найдено».
- **Ссылка** — переход; внутрь кладут текст, значок, картинку.
- **Текст** — сама строка. Экранируется по своей природе.
- **Код** — машинное значение моноширинным: имя, адрес, ключ, команда.
- **Шаблон** — фраза для перевода с местами `%1…%N`, которые занимают узлы.
- **Картинка** — внешний рисунок. Значок из набора — компонент [«Иконка»](иконки).
- **Готовое** — костыль перехода: строка разметки, собранная не деревом.

## Заголовок

Уровень заголовка — не оформление, а место в оглавлении страницы. Поэтому он задаётся числом, а не видом. Вид «имя» — имя объекта в его карточке.

```живой Заголовки — уровень числом, а не тегом
Холст = Кит.Холст();
Холст.Добавить(Кит.Заголовок(2, "имя")).Добавить(Кит.Текст("Документы проекта"));
Холст.Добавить(Кит.Заголовок(3)).Добавить(Кит.Текст("Редакции"));

HTML = Холст.Рендер();
```

Уровня вне 1–6 кит не соберёт. Заголовок без содержимого не печатается: в оглавлении страницы он остался бы дырой.

```живой Уровень 7 — исключение
Попытка
	Кит.Заголовок(7);
Исключение
	HTML = Кит.Примечание(КраткоеПредставлениеОшибки(ИнформацияОбОшибке())).Рендер();
КонецПопытки;
```

## Надпись

Надпись — `span` с ролью в строке. «Название» — главное слово строки, «пояснение» — подсказка рядом, «приглушённая» — второстепенное, «приписка» — мелкая строка под значением, «ключ» — имя настройки.

```живой Надписи — кусок строки со своей ролью
Ряд = Кит.Ряд("строкой");
Ряд.Добавить(Кит.Надпись("название")).Добавить(Кит.Текст("отчёт"));
Ряд.Добавить(Кит.Надпись("пояснение")).Добавить(Кит.Текст("обновлён вчера"));
Ряд.Добавить(Кит.Надпись("приглушённая")).Добавить(Кит.Текст("черновик"));

HTML = Ряд.Рендер();
```

## Примечание

Примечание — абзац мелким шрифтом. Текст можно передать сразу, а можно собрать детьми: примечание — холст, в нём бывают ссылка и код. Пустое примечание не печатается.

```живой Примечание — абзац мелким шрифтом
HTML = Кит.Примечание("Ключ показывается один раз.", "описание").Рендер();
```

Вид «источник» говорит, откуда взято значение. Вид «пусто» — ответ списка, который ничего не нашёл.

```живой Источник значения и пустая выдача
Холст = Кит.Холст();

Источник = Холст.Добавить(Кит.Примечание("", "источник"));
Источник.Добавить(Кит.Текст("задано в конфигурации: "));
Источник.Добавить(Кит.Код("hub.quota"));

Холст.Добавить(Кит.Примечание("По запросу «бета» ничего не найдено", "пусто"));

HTML = Холст.Рендер();
```

## Ссылка

Ссылка — холст: внутрь кладут текст, машинное значение, значок. Вид «пилюля» — ссылка в ряду взаимоисключающих, «пилюля-текущая» — она же выбранная.

```живой Ссылка — холст, а не только текст
Ссылка = Кит.Ссылка("/документы", "пилюля");
Ссылка.Добавить(Кит.Иконка("куб"));
Ссылка.Добавить(Кит.Текст(" Документы"));

HTML = Ссылка.Рендер();
```

Адрес недопустимой схемы ссылкой не станет: содержимое останется видимым, но кликабельным не будет. Ссылка без содержимого не печатается вовсе.

```разметкой Адрес javascript: снимает ссылку
Ссылка = Кит.Ссылка("javascript:alert(1)");
Ссылка.Добавить(Кит.Текст("открыть"));

HTML = Ссылка.Рендер();
```

## Текст

Текстовый узел иначе как экранированным печатать не умеет. Чужая строка разметкой не станет, даже если в ней тег.

```живой Текст экранируется по своей природе
HTML = Кит.Примечание().Добавить(
	Кит.Текст("<script>alert(1)</script> — и это видно как текст")).Родитель().Рендер();
```

## Код

Код — машинное значение моноширинным шрифтом. Без вида он стоит внутри строки текста. «Блочный» — образец в несколько строк, переносы и отступы сохраняются. «Приглушённый» — значение, которое не спорит с соседним текстом.

```живой Код — машинное значение моноширинным
Холст = Кит.Холст();
Холст.Добавить(Кит.Код("приложение установить отчёт"));
Холст.Добавить(Кит.Код("Холст = Кит.Холст();", "блочный"));

HTML = Холст.Рендер();
```

## Шаблон

Шаблон держит фразу цельной строкой для перевода, а вставки собирает деревом. Места `%1…%N` занимают дети в порядке добавления. Сам текст экранируется, дети печатаются разметкой.

```живой Шаблон — фраза цельная, вставки собираются деревом
Шаблон = Кит.Шаблон("Проект %1 обновлён %2");
Шаблон.Добавить(Кит.Код("main"));
Шаблон.Добавить(Кит.Надпись("приглушённая").Добавить(Кит.Текст("вчера")).Родитель());

HTML = Кит.Примечание().Добавить(Шаблон).Родитель().Рендер();
```

Число мест и детей обязано совпасть. Лишний ребёнок не напечатался бы, недостающий оставил бы дыру, поэтому кит останавливает сборку.

## Картинка

Картинка — внешний рисунок по адресу. Подпись становится `alt`, высота и ширина — атрибутами: место под картинку занято до того, как приедет лист стилей. Пустой адрес не даёт битого изображения — узел печатается пустой строкой.

```разметкой Картинка — внешний рисунок, Подпись() даёт alt
Знак = Кит.Картинка("/static/знак.svg", "значок");
Знак.Подпись("Знак проекта");
Знак.Высота(32);

HTML = Знак.Рендер();
```

## Готовое

Готовое — костыль перехода. Узел печатает строку как есть и ничего не экранирует. Он нужен, чтобы переводить экраны на дерево по одному, и стоит на виду у ревью.

```живой Готовое — ⚠ костыль перехода: узел ничего не экранирует
HTML = Кит.Готовое(Набор.Тег().Отрисовать("собрано строкой")).Рендер();
```

> **Совет.** Почти у каждого компонента есть узел в ките: вместо `Кит.Готовое(Набор.Тег().Отрисовать(…))` пишите `Кит.Плашка(…)`. Компонент в дереве виден по имени — об этом страница [Компонент в дереве](компонент-в-дереве).

## Гайдлайны

```делайте Значение из данных — узлом Текст() или Код()
Имя = "<b>отчёт</b>";
HTML = Кит.Примечание().Добавить(Кит.Код(Имя)).Родитель().Рендер();
```

```не-делайте Значение из данных — в Готовое(): оно станет разметкой
Имя = "<b>отчёт</b>";
HTML = Кит.Примечание().Добавить(Кит.Готовое(Имя)).Родитель().Рендер();
```

```делайте Фраза со вставками — шаблоном: переводчик видит её целиком
Шаблон = Кит.Шаблон("Проект %1 обновлён %2");
Шаблон.Добавить(Кит.Код("main"));
Шаблон.Добавить(Кит.Текст("вчера"));
HTML = Кит.Примечание().Добавить(Шаблон).Родитель().Рендер();
```

```не-делайте Фраза из кусков: порядок слов не переведёшь

Абзац.Добавить(Кит.Текст("Проект "));
Абзац.Добавить(Кит.Код("main"));
Абзац.Добавить(Кит.Текст(" обновлён "));
Абзац.Добавить(Кит.Текст("вчера"));
HTML = Абзац.Рендер();
```

```делайте Заголовки по порядку уровней
Холст = Кит.Холст();
Холст.Добавить(Кит.Заголовок(2)).Добавить(Кит.Текст("Проект"));
Холст.Добавить(Кит.Заголовок(3)).Добавить(Кит.Текст("Редакции"));
HTML = Холст.Рендер();
```

```не-делайте Уровень выбран по размеру шрифта: оглавление с пропуском

Холст.Добавить(Кит.Заголовок(2)).Добавить(Кит.Текст("Проект"));
Холст.Добавить(Кит.Заголовок(5)).Добавить(Кит.Текст("Редакции"));
HTML = Холст.Рендер();
```

## Доступность

- Картинке, которая что-то сообщает, дайте подпись: она станет `alt`. Картинка без подписи печатается с пустым `alt`, и скринридер её пропускает.
- Значок внутри ссылки декоративен, если рядом есть текст. Значок без текста подпишите — подпись станет его доступным именем.
- Пустые заголовок, ссылка и примечание не печатаются: скринридер не встретит безымянный элемент.
- Ссылка с адресом недопустимой схемы (`javascript:`) печатается одним содержимым.
