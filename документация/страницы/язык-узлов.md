# Язык узлов

Шесть правил, по которым пишется экран на ките: по коду видно, что встанет на экран, а структур-моделей и склейки строк в нём нет. Разметка на выходе та же, что у сборки по одному узлу.

## Как читается экран

Позицией — то, без чего узел бессмыслен: текст заголовка и кнопки, адрес ссылки, имя и метка поля, вид ряда. Дальше — дети узла. Всё остальное — слова: методы узла, которые возвращают тот же узел и ставятся цепочкой.

```живой Список проектов: заголовок, таблица из данных, форма
Проекты = Новый ТаблицаЗначений;
Проекты.Колонки.Добавить("Имя");
Проекты.Колонки.Добавить("Участников");
Проекты.Колонки.Добавить("Действие");
Проект = Проекты.Добавить();
Проект.Имя = Кит.Ссылка("/проекты/альфа", "альфа");
Проект.Участников = 3;
Проект.Действие = Кит.Кнопка("Открыть").Вторичная().Малая().Адрес("/проекты/альфа");

HTML = Кит.Холст(
	Кит.Заголовок(2, "Проекты"),
	Кит.Таблица(Проекты).Пусто("Проектов пока нет."),
	Кит.ФормаБезТокена("/проекты/новый",
		Кит.Поле("имя", "Имя проекта").Пример("например альфа").Обязательное(),
		Кит.Кнопка("Создать").Основная()).Вид("столбик")).Рендер();
```

## 1. Строка на месте узла — текст

Любая строка там, где ждут ребёнка, — позиционно или в `Добавить`, — становится узлом `Кит.Текст` и экранируется. Сырая разметка — по-прежнему только узлом `Кит.Готовое()`, он на виду у ревью.

```разметкой Строка экранируется, как Кит.Текст
HTML = Кит.Примечание("Имя ", Кит.Код("<main>"), " уже занято.").Рендер();
```

Два исключения. В форму строка не кладётся вовсе: прежде вторым аргументом формы шёл CSRF-токен, и строкой-ребёнком он напечатался бы на экране. Токен задаётся словом `.Токен(…)`, текст в форме — узлом `Кит.Текст()`. В строгих родах — таблице, записи, списке, свойствах, документе, голове — строка отвергается проверкой вложения: текст в записи не печатается, его кладут в ячейку.

```живой Строка в форме — исключение с подсказкой
Попытка
	Кит.Форма("/выход", "т0кен-сессии");
Исключение
	HTML = Кит.Примечание(КраткоеПредставлениеОшибки(ИнформацияОбОшибке())).Рендер();
КонецПопытки;
```

## 2. Позицией обязательное, словом остальное

Первый аргумент узла — то, без чего он бессмыслен. Всё прочее задают слова с именами полей модели. У кнопки единственный сахар: `.Основная() .Вторичная() .Опасная() .Ссылкой() .Малая() .Большая()`.

```живой Кнопки словами
HTML = Кит.Ряд("действия",
	Кит.Кнопка("Сохранить").Основная().Иконка("сохранить"),
	Кит.Кнопка("Отмена").Вторичная().Адрес("/проекты"),
	Кит.Кнопка("Удалить").Опасная().Малая().Имя("операция", "удалить")).Рендер();
```

Слово, которого компонент не знает, останавливает сборку и перечисляет его слова: опечатка не даст молча кнопку не того вида.

```живой Неизвестное слово — исключение с перечнем слов
Попытка
	Кит.Плашка("готов").Основная();
Исключение
	HTML = Кит.Примечание(КраткоеПредставлениеОшибки(ИнформацияОбОшибке())).Рендер();
КонецПопытки;
```

Прежний вход компонента структурой-моделью — `Кит.Кнопка(Новый Структура("Подпись, Вариант", …))` — работает как раньше и печатает то же самое; слова дописывают и такую модель. На страницах компонентов модель описана как «прежний вид модели».

## 3. Дети аргументами

Каждая фабрика контейнера принимает до восьми детей позиционно; `Неопределено` пропускается, поэтому условный ребёнок пишется прямо в списке. Девятый и дальше кладутся `Добавить`, который по-прежнему возвращает ребёнка.

```разметкой Дети по порядку аргументов
HTML = Кит.Ряд("справа", Кит.Плашка("черновик"), Неопределено, "3 участника").Рендер();
```

Второй холст с аргументами наполняется и возвращает владельца — цепочка продолжается: `Раскрывашка.Шапка(…)`, `Запись.Разворот(…)`, `Таблица.Пусто(…)`, `Карточка.Действия(…)`. Без аргументов второй холст отдаётся сам, как прежде.

```живой Шапка раскрывашки аргументами
HTML = Кит.Раскрывашка(Кит.Примечание("Ключ создан вчера."))
	.Шапка("Подробности").Вид("врезка").Рендер();
```

## 4. Условие словом

`.Когда(Условие)` есть у любого узла: ложь печатает пустую строку. Узел остаётся в дереве, и `Дерево()` показывает его пометкой `[скрыт]`. У колонки таблицы ложь снимает и заголовок, и ячейки под ним.

```живой Когда: узел есть в дереве, на экране его нет
Холст = Кит.Холст(
	Кит.Примечание("Новый ключ показан один раз.").Когда(Истина),
	Кит.Примечание("Ключей пока нет.").Когда(Ложь));

HTML = Холст.Рендер() + Кит.Код(Холст.Дерево()).Вид("блочный").Рендер();
```

Условие вычисляется всегда. Там, где вычислять дорого, остаётся `Если` и [`Кит.Ничего()`](холст).

## 5. Таблица из данных, как в 1С

`Кит.Таблица(Данные)` собирает таблицу из таблицы значений или массива структур. Подробно — на странице [Таблица деревом](таблица-деревом).

- Таблица значений даёт колонки (заголовок колонки, по умолчанию имя) и записи — её строки; ячейка — свойство строки по имени колонки.
- Массив структур или соответствий даёт записи, а колонки объявляются словом `.Колонка(Ключ, Заголовок)` в порядке вызовов.
- Значение ячейки: строка — текст, узел — узел (несколько узлов кладут `Кит.Холст(…)`), число — без разделителя групп, `Неопределено` и `""` — пустая ячейка. Дату и Булево форматирует экран: кит остановит печать и назовёт колонку.

```живой Таблица из массива структур
Участники = Новый Массив();
Участники.Добавить(Новый Структура("Имя, Роль", "анна", Кит.Плашка("владелец").Вид("accent")));
Участники.Добавить(Новый Структура("Имя, Роль", "борис", "участник"));

Таблица = Кит.Таблица(Участники);
Таблица.Колонка("Имя", "Участник");
Таблица.Колонка("Роль", "Роль");

HTML = Таблица.Рендер();
```

## 6. Секция и дом — тоже узлы

Дом настроек и его секции — узлы `Кит.ДомНастроек` и `Кит.Секция`. Адрес раздела и CSRF-токен задаются один раз у дома; форма внутри берёт их у ближайшего предка: `Кит.Форма("", …)` уходит на адрес текущего раздела, `Кит.Форма("revoke", …)` — на `раздел/revoke`, `Кит.Форма("/x", …)` — на свой адрес. Форма без токена ни у себя, ни у предков не печатается. Подробно — на странице [Дом настроек](дом-настроек).

```живой Форма берёт адрес и токен у дома
Дом = Кит.ДомНастроек("Настройки", "/проекты/альфа/настройки", "т0кен",
	Кит.Секция("Ключи доступа",
		Кит.Форма("", Кит.Кнопка("Выпустить ключ").Основная()),
		Кит.Форма("7/revoke", Кит.Кнопка("Отозвать").Опасная().Малая())));
Дом.Раздел("Общее", "");
Дом.Раздел("Ключи", "ключи").Текущий();

HTML = Дом.Рендер();
```

## Тип поля — системой типов

Тип поля задаётся словом `.ТипЗначения(…)` значением системы типов OneScript: `Тип("Число")` печатается полем `type=number`, `Тип("Булево")` — флажком, `Тип("Дата")` — полем даты. `ОписаниеТипов` с квалификаторами даёт пределы ввода. Строка — прежний тип модели: «email», «url», «пароль», «файл», «многострочное», «выбор». Без явного типа он выводится из значения. Слово называется `ТипЗначения`, а не `Тип`: имя «Тип» в OneScript занято самой системой типов. Подробно — на странице [Формы деревом](формы-деревом).

```разметкой Тип из описания типов и из значения
HTML = Кит.Холст(
	Кит.Поле("сумма", "Сумма").ТипЗначения(
		Новый ОписаниеТипов("Число", Новый КвалификаторыЧисла(7, 2))),
	Кит.Поле("с", "Начало").Значение(Дата(2024, 3, 5)),
	Кит.Поле("уведомлять", "Присылать письма").Значение(Истина)).Рендер();
```

## Словарь

Общие слова любого узла: `Вид`, `Подпись`, `Подсказка` (атрибут `title`), `Якорь` (атрибут `id`), `Признак`, `Роль`, `Отключить`, `Скрыть`, `Когда`, `Токен`; у своих родов — `Открыть` (раскрывашка), `Высота` и `Ширина` (картинка), `СФайлами` и `БезПерезагрузки` (форма), `БезПодписиВЗаписи` (колонка). У компонента общие слова с именем поля его модели пишут это поле.

## Прежний вид — подсказкой

Где второй аргумент прежде был видом, а теперь там ребёнок-текст, строка-вид стала бы видимым словом на экране. Поэтому строка, совпавшая с видом рода, при рождении узла останавливает сборку подсказкой: «вид теперь задаётся словом .Вид(…)».

```живой Кит.Область("полоса") — прежний вызов, исключение с подсказкой
Попытка
	Кит.Область("полоса");
Исключение
	HTML = Кит.Примечание(КраткоеПредставлениеОшибки(ИнформацияОбОшибке())).Рендер();
КонецПопытки;
```

## Гайдлайны

```делайте Дети аргументами, настройка словами: экран читается сверху вниз
HTML = Кит.Группа("Срок действия",
	Кит.Поле("срок", "Дней").ТипЗначения("число").Значение(30).Обязательное(),
	Кит.Примечание("От 1 до 90 дней.")).Рендер();
```

```не-делайте Структура-модель и Добавить по одному: что на экране, видно не сразу
Группа = Кит.Группа("Срок действия");
```
