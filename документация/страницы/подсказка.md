# Подсказка

Подсказка — значок «?», по нажатию на который рядом открывается поповер с пояснением. Длинное пояснение уходит с экрана, но не теряется: оно в одном нажатии, а у поля скринридер слышит его описанием самого поля. Скрипта нет: поповер открывает и закрывает браузер.

## Когда использовать

- Пояснение к полю длиннее строки: зачем оно, что будет потом, откуда взять значение. Три строки мелкого текста под каждым полем делают форму стеной — их место в справке.
- Термин в заголовке или в тексте, который знают не все: «ключ доступа», «пресет».

Короткое пояснение, которое нужно каждому, остаётся строкой под полем — словом `Подсказка`. Отказ сервера — словом `Ошибка`: его не прячут. Всё, без чего форму не заполнить, видно сразу.

## У поля

У поля справку печатает слово `Справка(Текст)` самого поля: значок «?» встаёт в строку подписи у правого края поля, поповер — под ним, а поле ссылается на текст поповера из `aria-describedby`. Короткая `Подсказка` остаётся строкой под полем. У выпадающего списка значок стоит левее шеврона, у флажка — сразу за подписью.

```живой Длинное пояснение — справкой
HTML = Кит.Форма("/проекты",
	Кит.Поле("key", "Ключ проекта").Подсказка("латиницей, без пробелов")
		.Справка("Ключ входит в адрес проекта и в имена его файлов. Сменить его потом нельзя: старые ссылки перестанут работать."),
	Кит.Поле("visibility", "Видимость").Вариант("private", "Только участники").Вариант("public", "Все")
		.Справка("Открытый проект видят все, кто вошёл, но менять его могут только участники."),
	Кит.Поле("archive", "Архивировать через год без изменений").ТипЗначения(Тип("Булево"))
		.Справка("Архивный проект не удаляется: его можно вернуть из списка архива."),
	Кит.Кнопка("Создать").Основная()).Токен("т0кен-сессии").Рендер();
```

Значок называет себя скринридеру «Справка: Ключ проекта» — шаблон словаря `help.field`. Идентификатор поповера — `Ид` поля с хвостом `-help`, а без `Ид` кит выдаёт свой из имени и места поля: постоянный для того же дерева.

## Отдельно

`Кит.Подсказка(Текст)` — тот же значок с поповером где угодно: в строке текста, рядом с подписью группы. Имя значка для скринридера — слово `Подпись`, без него — текст словаря `help.open` («Справка»).

```живой Термин в тексте
HTML = Кит.Примечание("Ключи доступа живут 90 дней",
	Кит.Подсказка("Через 90 дней ключ перестаёт работать. Выпустите новый заранее и замените его в настройках сборки.")
		.Подпись("Почему 90 дней")).Рендер();
```

## Без скрипта

Всё работает без скрипта: значок — кнопка с атрибутом `popovertarget`, поповер — атрибут `popover`. Esc и щелчок мимо закрывают его, фокус возвращается на значок — это делает браузер. Движок, который не знает `popover`, печатает текст пояснения сразу за значком: он остаётся на странице.

## Где встаёт поповер

Поповер встаёт под значком; не хватит места справа или снизу — браузер отзеркалит его. Движок без привязки к якорю ставит его по центру экрана. На телефоне (до 640 px) поповер шириной в экран с полями 16 px, под значком или над ним: за край он не уходит, где бы значок ни стоял.

## Гайдлайны

```делайте Под полем — строка, остальное — в справке
HTML = Кит.Поле("key", "Ключ проекта").Подсказка("латиницей, без пробелов")
	.Справка("Ключ входит в адрес проекта и в имена его файлов. Сменить его потом нельзя.").Рендер();
```

```не-делайте Три строки под каждым полем
HTML = Кит.Поле("key", "Ключ проекта").Подсказка("Латиницей, без пробелов. Ключ входит в адрес проекта"
	+ " и в имена его файлов. Сменить его потом нельзя: старые ссылки перестанут работать.").Рендер();
```

```делайте У поля — слово Справка: поле связано с текстом
HTML = Кит.Поле("owner", "Владелец").Справка("Владелец получает письма о сбоях сборки.").Рендер();
```

```не-делайте Кит.Подсказка рядом с полем: скринридер не свяжет её с полем
HTML = Кит.Холст(Кит.Поле("owner", "Владелец"),
	Кит.Подсказка("Владелец получает письма о сбоях сборки.")).Рендер();
```

```не-делайте Обязательное условие — в справке: его не увидят
HTML = Кит.Поле("email", "Почта").Справка("Обязательно рабочая почта, иначе приглашение не дойдёт.").Рендер();
```

Условие, без которого форму не заполнить, пишут подсказкой под полем, а проверяет его форма.

## Доступность

- Значок — кнопка `type="button"`: форму не отправляет. Имя у неё своё — «Справка: Ключ проекта» (`aria-label`), знак «?» скрыт от скринридера. Открыт ли поповер, браузер сообщает сам (`aria-expanded` у кнопки с `popovertarget`).
- Поле ссылается на текст поповера из `aria-describedby`: скринридер читает пояснение, когда фокус приходит в поле, и открывать поповер ему не нужно. У отбитого поля описание — отказ, потом справка.
- Значок стоит вне `<label>` поля: кнопка внутри метки стала бы её полем.
- Значок 24 px, а зона нажатия — 48 px. Esc закрывает поповер, фокус возвращается на значок.
- Настройка «меньше движения» гасит проявление поповера.
