# Слот картинки

Слот картинки — загрузка одной картинки: логотипа, значка вкладки, обложки. Вместо системного поля «Выберите файл», таблицы «что стоит сейчас» и отдельной кнопки — один слот: видно, что стоит, и одна кнопка, чтобы заменить. Выбор файла отправляет его сразу.

## Когда использовать

- Картинка одна и заменяется целиком: логотип инсталляции, аватар проекта, значок вкладки.
- Человеку важно видеть, что стоит сейчас, прежде чем менять.
- У картинки есть стандартная, к которой можно вернуться.

Не берите слот для вложений к записи и для нескольких файлов сразу: там нужен список файлов, а не одна рамка. Для файла, который уходит вместе с остальной формой (договор к заявке), хватит [поля](поле) словом `Файл()`.

## Слот

`Кит.СлотКартинки(Имя, Подпись)` — узел рода «слот-картинки»: предпросмотр на шахматке, подпись и строка состояния, кнопка «Загрузить» или «Заменить». Имя — имя файлового поля, под ним сервер получит файл; подпись называет картинку. Слот — своя форма (`multipart/form-data`, тихая отправка): адрес загрузки — слово `Форма(Хвост)`, как у [секции](дом-настроек), токен — у предков. Имя `Кит.Картинка` занято картинкой-`<img>`, поэтому узел назван слотом.

```живой Стандартный и свой — выберите файл
HTML = Кит.Холст(
	Кит.СлотКартинки("logo", "Логотип").Адрес("/static/знак.svg")
		.Форма("/образец-картинки").Якорь("slot-standart"),
	Кит.СлотКартинки("logo", "Логотип").Адрес("/static/знак.svg")
		.Состояние("logo.png · 12 КБ · 3 октября").Принимает("image/png,image/svg+xml")
		.Форма("/образец-картинки").Сброс("/образец-картинки/сброс").Якорь("slot-svoi"))
	.Токен("т0кен-сессии").Рендер();
```

Оба слота уходят на [образец с сервером](/образец-картинки): там видно, как сервер отвечает на загрузку и на сброс.

- `Адрес(ТекущаяКартинка)` — что стоит сейчас. Без адреса слот пуст: одна шахматка и кнопка «Загрузить». Годится адрес http(s), путь своего приложения или встроенная картинка `data:image/…`.
- `Состояние(Текст)` — строка под подписью: имя файла, размер, дата. Без неё — «Стандартная» (ключ `imgslot.default`), а у слота со сбросом — «Своя картинка» (`imgslot.custom`).
- `Принимает(Типы)` — атрибут `accept`, по умолчанию `image/*`. Это подсказка окну выбора файла, а не проверка: тип и размер присланного сверяет сервер.
- `КнопкаЗагрузки(Подпись)` — своя подпись кнопки вместо «Заменить» (`imgslot.replace`) и «Загрузить» (`imgslot.upload`).

Пока файл в пути, предпросмотр приглушён (форма слота помечена `aria-busy`), а выбранная картинка сразу встаёт в рамку — скрипт показывает её из памяти браузера. Ответ сервера ложится на страницу на место: удача приносит новый адрес и состояние, отказ — прежнюю картинку.

## Вернуть стандартную

Слово `Сброс(Адрес)` добавляет меню ⚙ с пунктом «Вернуть стандартную». Пункт отправляет отдельную форму сброса, а её отправку перехватывает [подтверждение](подтверждение): то же окно, что `Кит.Подтверждение`, с вопросом о картинке и кнопкой цвета ошибки. Уходит форма кнопкой окна — с полем `confirmed=1` (`Подтверждение.ИмяПоляПодтверждения()`).

Без скрипта форма сброса уходит без поля подтверждения. Сервер отвечает перенаправлением на страницу, где тот же слот напечатан словом `Открыто()`: окно сброса стоит на странице, и человек подтверждает там.

```разметкой Сервер спрашивает подтверждение страницей
HTML = Кит.Холст(Кит.СлотКартинки("logo", "Логотип").Адрес("/static/знак.svg")
		.Состояние("logo.png · 12 КБ").Форма("/образец-картинки")
		.Сброс("/образец-картинки/сброс").Открыто().Якорь("slot-sbros"))
	.Токен("т0кен-сессии").Рендер();
```

## Без скрипта

Без скрипта слот показывает системное файловое поле и кнопку «Отправить файл» (`imgslot.send`) — форма уходит обычной навигацией, а сервер отвечает перенаправлением обратно на страницу. Со скриптом поле уходит из вида под кнопку «Заменить», кнопка отправки прячется, и выбор файла отправляет форму сам: на файловом поле стоит признак `data-autosubmit` — тот же, что у [тумблера](тумблер) со словом `СохранятьСразу`.

Слот — своя форма, поэтому внутрь другой формы он не кладётся: браузер выбросил бы вложенный `<form>`, и файл ушёл бы не туда. Кит останавливает такую сборку. В [доме настроек](дом-настроек) положите слоты в секцию без `.Форма()`, а поля, которые сохраняются кнопкой, — в соседнюю секцию-форму.

```разметкой Что печатает сервер
HTML = Кит.Холст(Кит.СлотКартинки("icon", "Значок вкладки")
		.Форма("/образец-картинки").Якорь("slot-razmetka"))
	.Токен("т0кен-сессии").Рендер();
```

## Гайдлайны

```делайте Подпись называет картинку, состояние — что стоит
HTML = Кит.Холст(Кит.СлотКартинки("icon", "Значок вкладки").Адрес("/static/знак.svg")
		.Состояние("icon.png · 2 КБ").Форма("/образец-картинки").Якорь("delat-podpis"))
	.Токен("т0кен-сессии").Рендер();
```

```не-делайте «Файл» без имени: на странице с двумя слотами не понять, какой что меняет
HTML = Кит.Холст(Кит.СлотКартинки("icon", "Файл").Адрес("/static/знак.svg")
		.Форма("/образец-картинки").Якорь("ne-delat-fail"))
	.Токен("т0кен-сессии").Рендер();
```

```делайте Сброс — только когда стоит своя картинка
HTML = Кит.Холст(Кит.СлотКартинки("logo", "Логотип").Адрес("/static/знак.svg")
		.Форма("/образец-картинки").Якорь("delat-bez-sbrosa"))
	.Токен("т0кен-сессии").Рендер();
```

```не-делайте «Вернуть стандартную» у стандартной: пункт, который ничего не меняет
HTML = Кит.Холст(Кит.СлотКартинки("logo", "Логотип").Адрес("/static/знак.svg")
		.Состояние("Стандартная").Форма("/образец-картинки")
		.Сброс("/образец-картинки/сброс").Якорь("ne-delat-sbros"))
	.Токен("т0кен-сессии").Рендер();
```

## Доступность

- Картинка в рамке декоративна (`alt=""`): что это, говорит подпись рядом, а что нарисовано на логотипе, словами не пересказать.
- Файловое поле названо кнопкой и подписью (`aria-labelledby`: «Заменить Логотип»), а строка состояния — его описание (`aria-describedby`): скринридер слышит, что стоит сейчас.
- Со скриптом поле уходит из вида, но не из порядка обхода: фокус с клавиатуры встаёт на него, обводку рисует кнопка над ним, Enter и пробел открывают выбор файла.
- Меню ⚙ названо «Действия: Логотип». Окно сброса названо вопросом и описано последствиями; закрыли его — фокус возвращается на кнопку ⚙.
