# Образец

Образец — рамка предпросмотра: подпись, переключатель темы и рамка, в которой лежит любое дерево. Рядом с полями настройки он показывает, как выйдет результат, и меняется по мере ввода — без запроса к серверу. Что показывать в образце, решает приложение.

## Когда использовать

- Настройка меняет вид: название и акцент сайта, подпись письма, карточка проекта.
- Человеку нужно увидеть результат до сохранения, а не после.
- Результат выглядит по-разному в светлой и тёмной теме, и это стоит проверить.

Не делайте образцом то, что и так видно на странице: правку записи в таблице показывает сама таблица. Образец — не форма: поля стоят рядом, в обычной форме.

## Рамка и зеркало

`Кит.Образец(Подпись, д…)` — узел рода «образец»: фигура с подписью, переключатель «Светлая / Тёмная» и рамка с детьми узла. Слово `Зеркало(ИмяПоля)` у любого узла внутри — признак `data-mirror`: скрипт кита пишет в узел текущее значение поля с этим именем при каждом вводе. Текст узла — то, что напечатал сервер, и он же возвращается, когда поле опустело.

```живой Название и акцент — наберите название, выберите цвет
Форма = Кит.Форма("/образец-картинки/шапка",
		Кит.Поле("title", "Название сайта").Значение("Ромашка").Ид("obrazec-title"),
		Кит.Поле("accent", "Акцент").Ид("obrazec-accent").Значение("#6750a4")
			.Образец("#6750a4", "Фиолетовый").Образец("#1a73e8", "Синий")
			.Образец("#188038", "Зелёный").Образец("#b3261e", "Красный"),
		Кит.Кнопка("Сохранить").Основная())
	.Вид("столбик").БезПерезагрузки();
Образец = Кит.Образец("Шапка сайта",
		Кит.Область(
			Кит.Заголовок(3, "Ромашка").Зеркало("title"),
			Кит.Примечание("Проекты, участники, сборки")).Зеркало("accent", "#6750a4"))
	.Тема("светлая").Якорь("obrazec-shapki");
HTML = Кит.Область(Кит.Область(Форма).Вид("работа"), Образец).Вид("студия")
	.Токен("т0кен-сессии").Рендер();
```

Форма уходит на [образец с сервером](/образец-картинки): там сохранённые название и акцент печатает сервер. Раскладка «поля слева, образец справа» — область вида `студия`: на узком экране образец уезжает под поля.

Поле цвета — [поле вида «цвет»](поле#цвет) с образцами-кружками, как здесь, или системный выбор цвета — пишет не текст, а пользовательское свойство CSS `--mirror-<имя>` на узле. Его берёт лист приложения: у этого сайта акцент — полоса слева у шапки (`border-left: 6px solid var(--mirror-accent, var(--md-sys-color-primary))`). Пустое значение («по умолчанию») свойство снимает, и лист берёт своё. Вторым аргументом `Зеркало(ИмяПоля, Цвет)` сервер печатает то же свойство с сохранённым цветом — образец верен и без скрипта. Цвет — только `#rgb`, `#rrggbb` или `#rrggbbaa`: он печатается в атрибут `style`, в CSS-контекст.

Имя поля зеркала — буквы (латиница и кириллица), цифры, «-» и «_», **без точки**: оно становится признаком `data-mirror` и частью имени свойства CSS `--mirror-<имя>`, а точка в имени свойства его ломает. Ключ настройки вида `ui.brand` зеркалить нельзя — назовите поле формы без точек (`brand`) и сопоставьте с ключом на сервере. Имя с точкой кит не пропускает: сборка останавливается с этим объяснением.

### Акцент в образце

Зеркало поля с именем `accent` кит понимает сам: узел образца, на котором стоит `--mirror-accent`, пересобирает свою палитру акцента из этого цвета. Основная кнопка, плашка вида `accent`, ссылка и контурная кнопка внутри него берут выбранный цвет так, как возьмут его на сайте; текст на акценте — белый или чёрный по светлоте цвета, контейнер плашки — тот же цвет поверх поверхности рамки. Листа приложения не нужно. Пустое поле («по умолчанию») возвращает узлу акцент рамки.

```живой Акцент перекрашивает кнопку и плашку образца
Форма = Кит.Форма("/образец-картинки/шапка",
		Кит.Поле("accent", "Акцент").Ид("obrazec-akcent-pole").ОбразцыТемы().Значение("#e5484d"),
		Кит.Кнопка("Сохранить").Основная())
	.Вид("столбик").БезПерезагрузки();
Образец = Кит.Образец("Акцент на сайте",
		Кит.Область(
			Кит.Кнопка("Создать проект").Основная().Иконка("плюс").БезОтправки(),
			Кит.Плашка("новое").Вид("accent"),
			Кит.Ссылка("#obrazec-akcenta", "Все проекты"))
			.Вид("полоса").Зеркало("accent", "#e5484d"))
	.Якорь("obrazec-akcenta");
HTML = Кит.Область(Кит.Область(Форма).Вид("работа"), Образец).Вид("студия")
	.Токен("т0кен-сессии").Рендер();
```

Перекрашивается только узел с зеркалом и то, что внутри него, и только в образце: страница вокруг остаётся в своём акценте. Зеркало на самой рамке (`Кит.Образец(…).Зеркало("accent", …)`) перекрашивает рамку целиком. Поле с другим именем перекрашивает только то, что возьмёт его свойство в листе приложения.

Зеркало вешается на узел со своим тегом — надпись, заголовок, примечание, область, саму рамку образца. Компонент (кнопка, плашка) рисует себя сам, и текст поверх стёр бы его разметку, поэтому кит останавливает такую сборку: положите рядом `Кит.Надпись(…).Зеркало(…)`.

### Зеркало признаком

Текстом вид не поменять: выбор сегмента «Устаревший» должен перекрасить плашку, а не вписать в неё слово `deprecated`. Слово `ЗеркалоПризнаком(ИмяПоля, Значение)` пишет значение поля — выбранного сегмента, радиокнопки, варианта списка, набранного текста — в признак `data-mirror-<имя>` узла, и вид по нему задаёт лист приложения: `[data-mirror-стиль="deprecated"] .tag { … }`. Вторым аргументом сервер печатает текущее значение тем же признаком — без скрипта образец показывает сохранённый вид; скрипт кита переписывает признак при каждом выборе. Текст узла и свойство `--mirror-*` слово не трогает.

Зеркало признаком годится и для компонента — плашки, значка, кнопки: разметку компонента кит не переписывает, а только кладёт признак на его первый тег. У одного узла может быть несколько зеркал признаком, по одному на поле: узел несёт их список признаком `data-mirrors`, по нему скрипт его и находит. Имя поля — по тем же правилам, что у `Зеркало`; в признаке оно печатается строчными.

```живой Плашка меняет вид по сегменту, а значок — по списку
Форма = Кит.Форма("/проекты/альфа/тег",
		Кит.Сегменты("стиль",
			Кит.Сегмент("plain", "Обычный"),
			Кит.Сегмент("stable", "Стабильный"),
			Кит.Сегмент("deprecated", "Устаревший")).Подпись("Стиль плашки").Выбрано("stable"),
		Кит.Поле("значок", "Значок").Вариант("тег", "Тег").Вариант("ключ", "Ключ")
			.Вариант("пакет", "Пакет").Значение("ключ"),
		Кит.Кнопка("Сохранить").Основная())
	.Вид("столбик").БезПерезагрузки();
Плашка = Кит.Плашка(
		Кит.Надпись(Кит.Иконка("тег")).Признак("glyph", "тег"),
		Кит.Надпись(Кит.Иконка("ключ")).Признак("glyph", "ключ"),
		Кит.Надпись(Кит.Иконка("пакет")).Признак("glyph", "пакет"),
		"v2.4")
	.ЗеркалоПризнаком("стиль", "stable").ЗеркалоПризнаком("значок", "ключ");
Образец = Кит.Образец("Так будет выглядеть плашка", Плашка).Якорь("obrazec-plashki");
HTML = Кит.Область(Кит.Область(Форма).Вид("работа"), Образец).Вид("студия")
	.Токен("т0кен-сессии").Рендер();
```

Лист этого сайта — то, что напишет приложение: вид плашки по признаку стиля и один глиф из трёх по признаку значка. Кит здесь ничего не знает ни о стилях, ни о глифах.

## Тема рамки

Тема рамки — атрибут `data-theme` на ней: словом `Тема("светлая" | "тёмная")` сервер печатает её сразу, переключатель меняет её скриптом, повторное нажатие возвращает рамку к теме страницы. Обе палитры уже лежат в голове страницы, но привязаны к `<html>`, поэтому для рамки скрипт собирает палитру из того же блока токенов и подключает листом без разметки. Сменился акцент страницы — палитра рамки пересобирается.

Без скрипта рамка показана в теме страницы, а переключатель лист прячет: кнопка, которая ничего не меняет, хуже, чем никакой. Зеркала без скрипта показывают то, что напечатал сервер, — сохранённое значение.

```разметкой Что печатает сервер
HTML = Кит.Образец("Карточка проекта",
		Кит.Заголовок(3, "Альфа").Зеркало("name"),
		Кит.Примечание("Сборка каждую ночь"))
	.Тема("тёмная").Якорь("obrazec-razmetka").Рендер();
```

## Гайдлайны

```делайте Образец показывает то, что меняют поля рядом
Образец = Кит.Образец("Карточка проекта",
	Кит.Заголовок(3, "Альфа").Зеркало("name"),
	Кит.Примечание("Сборка каждую ночь").Зеркало("about"));
HTML = Образец.Якорь("delat-obrazec").Рендер();
```

```не-делайте Образец без связи с полями: картинка, которая не отвечает на ввод
Образец = Кит.Образец("Образец",
	Кит.Заголовок(3, "Пример заголовка"),
	Кит.Примечание("Пример текста"));
HTML = Образец.Якорь("ne-delat-obrazec").Рендер();
```

## Доступность

- Образец — фигура (`<figure>`): подпись первой (`<figcaption>`), ею фигура и названа.
- Переключатель — группа «Тема образца» из двух кнопок-тумблеров с `aria-pressed`: скринридер говорит, какая тема нажата.
- Зеркало пишет текст, а не разметку: набранное в поле не исполняется.
- Текст на акценте в образце — белый или чёрный, что контрастнее к выбранному цвету: кнопка образца читается при любом акценте палитры.
- Смена текста в зеркале не объявляется скринридеру: человек и так слышит, что набирает. Если образец важен для решения, пусть сервер повторит его словами после сохранения — [тостом](тост).
