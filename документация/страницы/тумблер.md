# Тумблер

Тумблер — поле формы из двух состояний: включено или выключено. Внешне это переключатель Material 3 — дорожка-пилюля с бегунком, который при включении растёт и уезжает вправо.

## Когда использовать

- Настройка, у которой ровно два состояния, и одно из них — «выключено»: видимость, уведомления, внешний доступ.
- Серверу нужно явное значение в обоих положениях, а не только «отмечено».

Не берите тумблер для выбора из двух равноправных вариантов («локальный» или «внешний»): там нет «выключенного», и для этого есть [поле выбора](поле). Согласие и признаки в длинной форме ставьте [флажком](поле).

В дереве холста тумблер собирается словами: имя и метка позицией, состояние и подписи — цепочкой (см. [Язык узлов](язык-узлов)).

```живой Узлом холста — словами
HTML = Кит.Тумблер("видимость", "Видимость проекта").Включено()
	.Подписи("публичный", "приватный").Рендер();
```

## Состояния

`Метка` называет настройку. `ПодписьВкл` и `ПодписьВыкл` печатаются под ней приглушённой строкой и говорят, что значит текущее положение. Подписи состояний необязательны, но с ними человеку не надо гадать, что значит «бегунок справа».

```живой Включён
HTML = Набор.Тумблер().Отрисовать(
	Новый Структура("Имя, Метка, Включено, ПодписьВкл, ПодписьВыкл",
		"видимость", "Видимость проекта", Истина, "публичный", "приватный"));
```

```живой Выключен
HTML = Набор.Тумблер().Отрисовать(
	Новый Структура("Имя, Метка, Включено, ПодписьВкл, ПодписьВыкл",
		"видимость", "Видимость проекта", Ложь, "публичный", "приватный"));
```

Подпись состояния печатает сервер по текущему значению. Без скрипта она не меняется до отправки формы: вид меняет только бегунок.

`Подсказка` — строка под тумблером о последствиях.

```живой С подсказкой
HTML = Набор.Тумблер().Отрисовать(Новый Структура("Имя, Метка, Включено, Подсказка",
	"уведомления", "Письма о сбоях", Истина, "уходят владельцам проекта"));
```

`Источник` — откуда взялось значение: «по умолчанию · ключ конфигурации». Он стоит мелко справа в строке подсказки, как у [поля](поле), и на телефоне уходит под подсказку. `Справка` — длинное пояснение за значком «?» рядом с тумблером: поповер открывается щелчком, тумблер ссылается на него для скринридера (`aria-describedby`).

```живой Источник значения и справка
HTML = Кит.Тумблер("mail_enabled", "Письма о сбоях").Включено()
	.Подсказка("уходят владельцам проекта")
	.Источник("по умолчанию · mail.enabled")
	.Справка("Письмо уходит после трёх неудачных сборок подряд, не чаще раза в час.").Рендер();
```

Заблокированный тумблер показывает состояние и не переключается. Он не отправляется, поэтому `Имя` ему не нужно.

```живой Заблокирован
HTML = Набор.Тумблер().Отрисовать(Новый Структура("Метка, Включено, Заблокировано",
	"Внешние источники", Ложь, Истина));
```

## Что уходит на сервер

Браузер не отправляет снятый флажок вовсе. Поэтому тумблер печатает пару: флажок со значением `ЗначениеВкл` («1») и сразу за ним скрытое поле с `ЗначениеВыкл` («0»). Включённый отправляет «1» и «0», и сервер берёт первое; выключенный — только «0».

```разметкой Пара флажка и скрытого поля
HTML = Набор.Тумблер().Отрисовать(Новый Структура("Имя, Метка, Включено, ЗначениеВкл, ЗначениеВыкл",
	"режим", "Тёмная тема", Истина, "тёмная", "светлая"));
```

Читайте тумблер на сервере сравнением со `ЗначениеВкл`. Проверка `ЗначениеЗаполнено` не годится: выключенный тумблер присылает явное «0», а строка «0» заполнена.

Тумблер — поле формы: новое состояние вступает в силу, когда форму отправят. В доме настроек сохранение берёт на себя [панель сохранения](панель-сохранения).

## Сохранять сразу

Настройка, которую ждут применённой в момент щелчка, — уведомления, видимость, тема, — помечается `СохранятьСразу`. Переключение само отправляет форму тумблера. Если форма собрана с `БезПерезагрузки()`, отправка уходит в фоне: страница не перезагружается, бегунок доезжает своей анимацией, а подпись состояния обновляет ответ сервера.

```разметкой Флажок с признаком отправки по изменению
HTML = Набор.Тумблер().Отрисовать(Новый Структура("Имя, Метка, Включено, ПодписьВкл, ПодписьВыкл, СохранятьСразу",
	"сбои", "Письма о сбоях", Истина, "приходят", "не приходят", Истина));
```

Без скрипта переключение никуда не уходит, и форме нужна кнопка отправки. Если у формы тумблера своей кнопки нет, кит печатает её сам: рядом с первым тумблером `СохранятьСразу` — малую кнопку-значок «сохранить» (имя — словарь `toggle.save`), а где скрипт работает, лист её прячет. Своя кнопка формы — кнопка отправки (не ссылка, не `БезОтправки`), панель сохранения, шаги, панель секции-формы; с ней запасной кнопки нет и разметка прежняя. Тумблер вне формы и тумблер, напечатанный строкой (`Набор.Тумблер()`), кнопки не получают.

```живой Тумблер без своей кнопки: запасную «сохранить» кит печатает сам, видна она только без скрипта
HTML = Кит.Форма("/проект/почта",
	Кит.Тумблер("почта", "Письма о сборках").Включено().СохранятьСразу())
	.БезПерезагрузки().Токен("т0кен-сессии").Рендер();
```

Свою кнопку можно поставить и самому — так было до 0.13.0-dev.7. Где скрипт работает, лист её прячет — в любой форме, где кроме тумблеров с `СохранятьСразу` полей нет: в теле секции, в карточке, в действиях записи [реестра](реестр). Форма, в которой есть и другое поле, свою кнопку показывает: другое поле иначе не отправить. Отправку по изменению делает скрипт кита, поэтому её можно повесить и на другое поле узлом холста: `Поле.Признак("autosubmit", "")`.

```живой Тумблер в своей форме: кнопка «Сохранить» видна только без скрипта
HTML = Кит.Форма("/проект/каталог",
	Кит.Тумблер("скрыт", "Скрыт из каталога").СохранятьСразу(),
	Кит.Кнопка("Сохранить").Иконка("сохранить").ТолькоИконка().Малая())
	.БезПерезагрузки().Токен("т0кен-сессии").Рендер();
```

## Гайдлайны

```делайте Метка называет настройку, подпись состояния — её значение
HTML = Набор.Тумблер().Отрисовать(
	Новый Структура("Имя, Метка, Включено, ПодписьВкл, ПодписьВыкл",
		"видимость", "Видимость проекта", Истина, "публичный", "приватный"));
```

```не-делайте Метка-вопрос без состояния: непонятно, что сейчас включено
HTML = Набор.Тумблер().Отрисовать(Новый Структура("Имя, Метка, Включено",
	"видимость", "Сделать проект приватным?", Истина));
```

```делайте Два равноправных варианта — выбором
Варианты = Новый Массив();
Варианты.Добавить(Новый Структура("Значение, Подпись", "локальный", "Локальный"));
Варианты.Добавить(Новый Структура("Значение, Подпись", "внешний", "Внешний"));

HTML = Набор.Поле().Отрисовать(Новый Структура("Имя, Метка, Тип, Значение, Варианты",
	"тип", "Тип проекта", "выбор", "внешний", Варианты));
```

```не-делайте Тумблер без «выключенного» положения
HTML = Набор.Тумблер().Отрисовать(
	Новый Структура("Имя, Метка, Включено, ПодписьВкл, ПодписьВыкл",
		"тип", "Тип проекта", Истина, "внешний", "локальный"));
```

## Доступность

- В основе — настоящий `<input type="checkbox">`. Он не скрыт через `display: none`, а прозрачен и лежит поверх дорожки: тумблер берёт фокус и переключается пробелом.
- Метка и подпись состояния лежат в том же `<label>`, что и флажок: щелчок по тексту переключает, скринридер читает название.
- Дорожка помечена `aria-hidden`: состояние сообщает сам флажок.
- Фокус с клавиатуры виден обводкой цветом secondary вокруг дорожки.
- Активный тумблер без `Имени` кит не соберёт: браузер не отправил бы его состояние.

## Узлом холста

Поля модели пишут слова: `Включено`, `Подсказка`, `Заблокировано`, `СохранятьСразу`, пары — `Значения(Вкл, Выкл)` и `Подписи(Вкл, Выкл)`.

```живой Тумблер узлом дерева
HTML = Кит.Тумблер("видимость", "Видимость проекта").Включено().Рендер();
```

## Модель

Поля модели — из комментария в исходнике компонента. Структура с этими полями — прежний вид модели: в дереве холста те же поля пишут слова `Кит.Тумблер`.

```справка Кит.Тумблер
```

```справка Тумблер
```

```словарь компонент:тумблер
```
