# Панель сохранения

Панель сохранения — полоса внизу формы с кнопкой «Сохранить», а при нужде и с «Отменить» и строкой пояснения слева. Она прилипает к нижнему краю окна, пока форма на экране, поэтому сохранить длинную секцию настроек можно, не прокручивая её до конца.

## Когда использовать

- Форма длинная, и кнопка сохранения в самом низу ушла бы за край экрана.
- Секция [дома настроек](дом-настроек) отправляет свою форму: там панель печатает сам каркас.
- Правку можно отменить возвратом на страницу секции, и это нужно показать рядом с сохранением.

Не берите панель для короткой формы из двух полей — там хватит [кнопки](кнопка) под полями. Необратимое действие с подтверждением — это [опасная зона](опасная-зона), а не панель с красной кнопкой.

## Сохранение

Основная кнопка с дискетой отправляет форму, в которой стоит панель. `АдресОтмены` добавляет перед ней вторичную ссылку-кнопку «Отменить», а `Пояснение` — приглушённую строку слева.

```живой Сохранение с отменой и пояснением
HTML = Набор.ПанельСохранения().Отрисовать(
	Новый Структура("Подпись, Пояснение, АдресОтмены",
		"Сохранить", "Есть несохранённые изменения", "/настройки"));
```

Без модели панель печатает одну кнопку «Сохранить».

```живой Панель без модели
HTML = Набор.ПанельСохранения().Отрисовать();
```

Панель работает без скрипта: кнопка — `submit` внутри формы, липкость даёт лист. Это поверхность Material на уровне возвышения 2 со скруглением large.

Со скриптом кита панель подсвечивается цветом secondary container на первом же вводе в её форму: так видно, что есть несохранённые правки. Подсветку снимает ответ сервера. Если форма собрана с `БезПерезагрузки()`, сохранение проходит без перезагрузки страницы, см. [Формы деревом](формы-деревом).

## Опасное действие

`Опасное` перекрашивает кнопку в цвет ошибки и меняет дискету на корзину. Так выглядит панель секции, чьё действие разрушает данные.

```живой Опасное действие
HTML = Набор.ПанельСохранения().Отрисовать(
	Новый Структура("Подпись, Опасное", "Удалить проект", Истина));
```

Опасная панель не спрашивает подтверждения. Если действие необратимо, положите в ту же форму [опасную зону](опасная-зона) с полем подтверждения.

## Своя иконка

Не всякое действие секции — сохранение, и дискета на «Доверить конвейеру» читается неверно. Иконку называет секция полем `Иконка`.

```живой Иконка под действие
HTML = Набор.ПанельСохранения().Отрисовать(
	Новый Структура("Подпись, Иконка", "Доверить конвейеру", "ключ"));
```

## Заблокирована

Заблокированная кнопка остаётся на месте и не отвечает: например, у человека нет прав на правку секции. Решает это сервер при печати страницы — скрипта, который включит кнопку после первой правки, в ките нет.

```живой Заблокирована
HTML = Набор.ПанельСохранения().Отрисовать(
	Новый Структура("Подпись, Заблокирована", "Сохранить", Истина));
```

## Какая кнопка нажата

`Имя` и `Значение` печатаются атрибутами `name` и `value` кнопки. Форма, в которой две кнопки отправки, по ним узнаёт, какую нажали.

```живой Кнопка с именем и значением
HTML = Набор.ПанельСохранения().Отрисовать(
	Новый Структура("Подпись, Имя, Значение, АдресОтмены",
		"Сохранить черновик", "действие", "черновик", "/статьи"));
```

## Гайдлайны

```делайте Разрушающее действие — опасной панелью с корзиной
HTML = Набор.ПанельСохранения().Отрисовать(
	Новый Структура("Подпись, Опасное", "Удалить проект", Истина));
```

```не-делайте Удаление синей кнопкой с дискетой: выглядит как сохранение
HTML = Набор.ПанельСохранения().Отрисовать(
	Новый Структура("Подпись", "Удалить проект"));
```

```делайте Иконка повторяет действие
HTML = Набор.ПанельСохранения().Отрисовать(
	Новый Структура("Подпись, Иконка", "Доверить конвейеру", "ключ"));
```

```не-делайте Дискета на действии, которое не сохраняет
HTML = Набор.ПанельСохранения().Отрисовать(
	Новый Структура("Подпись", "Доверить конвейеру"));
```

```делайте Пояснение говорит, что будет сохранено или что мешает
HTML = Набор.ПанельСохранения().Отрисовать(
	Новый Структура("Подпись, Пояснение, АдресОтмены",
		"Сохранить", "Изменены 2 поля", "/настройки"));
```

```не-делайте Пояснение повторяет кнопку
HTML = Набор.ПанельСохранения().Отрисовать(
	Новый Структура("Подпись, Пояснение",
		"Сохранить", "Нажмите «Сохранить», чтобы сохранить"));
```

## Доступность

- Кнопки панели — [кнопки](кнопка) кита: подпись, иконка как украшение, фокус виден.
- «Отменить» — ссылка-кнопка: она уводит на адрес секции, а не сбрасывает поля скриптом, поэтому работает и без него.
- Пояснение — обычный текст рядом с кнопками. Со скринридером его слышно только при чтении подряд, поэтому то, без чего нельзя нажать «Сохранить», пишите и у самих полей.
- Липкая панель закрывает низ окна только на время прокрутки: в конце формы она встаёт на своё место после полей и ничего не прячет. Но поле, на которое ушёл фокус с клавиатуры, может оказаться под ней: прокручивая к полю, браузер липкую полосу не учитывает. В длинной форме задайте своим листом `scroll-padding-bottom` на высоту панели.

## Узлом холста

На [холсте](холст) панель — узел рода «панель». Кладите её последним ребёнком формы.

```живой Панель узлом дерева
HTML = Кит.ПанельСохранения(Новый Структура("Подпись", "Сохранить")).Рендер();
```
