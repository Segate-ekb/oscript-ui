# Сводка

Сводка показывает запись списка одним взглядом: название первым и крупно, знаки состояния рядом с ним, подпись под ним и подписанные строки «подпись — значение» ниже. Разметка у неё строчная, поэтому сводка ложится и в свёрнутую строку раскрывашки.

## Когда использовать

- Список записей, у каждой из которых имя, состояние и два-три сведения: рассылки, расписания, подключения.
- Запись разворачивается на месте, и её свёрнутая строка должна сразу ответить «что это».
- Сведений у записи разное число, и колонки таблицы стояли бы полупустыми.

Не берите сводку, когда записи сравнивают по одним и тем же колонкам — для этого есть [таблица](таблица). Первый экран одного объекта — это [шапка объекта](шапка-объекта).

## Название, подпись и сведения

`Название` обязательно: им запись называют — именем, адресом, номером. `Подпись` — приглушённая строка под названием. `Сведения` — строки «подпись — значение»: на широком экране подпись и значение стоят колонками, на узком подпись встаёт над значением.

```живой Название, подпись и сведения
Сведения = Новый Массив();
Сведения.Добавить(Новый Структура("Подпись, Значение", "Когда", "по будням в 9:00"));
Сведения.Добавить(Новый Структура("Подпись, Значение", "Кому", "всем участникам"));

HTML = Набор.Сводка().Отрисовать(Новый Структура("Название, Подпись, Сведения",
	"Утренняя рассылка", "почта · общий ящик", Сведения));
```

## Знаки состояния и предупреждение

`Знаки` — модели [плашек](плашка) сразу за названием: их читают вторыми, но видят сразу. `Подпись` можно передать массивом частей — кит соединит их через « · » и пропустит пустые. Строка сведений с видом «warn» красится цветом предупреждения. Длинный перечень переносится внутри своей колонки значения.

```живой Знак у названия, подпись частями, длинный перечень и предупреждение
Знаки = Новый Массив();
Знаки.Добавить(Новый Структура("Текст, Вид", "выключена", "warn"));

Подпись = Новый Массив();
Подпись.Добавить("почта");
Подпись.Добавить("отдел продаж");

Сведения = Новый Массив();
Сведения.Добавить(Новый Структура("Подпись, Значение", "Темы",
	"Новые заказы, Отмены заказов, Возвраты, Жалобы клиентов, Отзывы, Сбои оплаты"));
Сведения.Добавить(Новый Структура("Подпись, Значение, Вид", "Пропало", "Опросы", "warn"));

HTML = Кит.Сводка(Новый Структура("Название, Знаки, Подпись, Сведения",
	"Вечерний отчёт", Знаки, Подпись, Сведения)).Рендер();
```

## Пустые сведения

Строка с пустым значением не печатается. Поэтому сведения собирают как есть, без проверок: незаполненное поле просто не появится.

```живой Пустое «Кому» пропущено
Сведения = Новый Массив();
Сведения.Добавить(Новый Структура("Подпись, Значение", "Когда", "раз в месяц"));
Сведения.Добавить(Новый Структура("Подпись, Значение", "Кому", ""));

HTML = Набор.Сводка().Отрисовать(Новый Структура("Название, Сведения",
	"Ежемесячный итог", Сведения));
```

## В свёрнутой строке раскрывашки

Сводка — сплошь `<span>`, поэтому её можно положить в `<summary>`, куда блочные теги класть нельзя. Свёрнутая строка отвечает «что это», развёрнутая отдаёт подробности.

```живой Сводка в шапке раскрывашки
Сведения = Новый Массив();
Сведения.Добавить(Новый Структура("Подпись, Значение", "Темы", "Новые заказы, Отмены, Возвраты"));

Карточка = Кит.Раскрывашка();
Карточка.Шапка().Добавить(Кит.Сводка(Новый Структура("Название, Подпись, Сведения",
	"Вечерний отчёт", "почта · отдел продаж", Сведения)));
Карточка.Добавить(Кит.Примечание("Отправляется в 19:00 по рабочим дням."));

HTML = Карточка.Рендер();
```

## Гайдлайны

```делайте Название — имя самой записи
HTML = Набор.Сводка().Отрисовать(Новый Структура("Название, Подпись",
	"Вечерний отчёт", "рассылка · отдел продаж"));
```

```не-делайте Название — тип записи: все строки списка назовутся одинаково
HTML = Набор.Сводка().Отрисовать(Новый Структура("Название, Подпись",
	"Рассылка", "Вечерний отчёт · отдел продаж"));
```

```делайте Состояние — знаком у названия
Знаки = Новый Массив();
Знаки.Добавить(Новый Структура("Текст, Вид", "выключена", "warn"));

HTML = Набор.Сводка().Отрисовать(Новый Структура("Название, Знаки",
	"Вечерний отчёт", Знаки));
```

```не-делайте Состояние строкой сведений: его не видно с первого взгляда
Сведения = Новый Массив();
Сведения.Добавить(Новый Структура("Подпись, Значение", "Когда", "в 19:00"));
Сведения.Добавить(Новый Структура("Подпись, Значение", "Состояние", "выключена"));

HTML = Набор.Сводка().Отрисовать(Новый Структура("Название, Сведения",
	"Вечерний отчёт", Сведения));
```

## Доступность

- Без `Названия` кит сводку не соберёт и бросит исключение: запись без имени скринридер не назовёт.
- Знаки — обычные плашки с текстом. Их смысл читается словами, а не цветом.
- Подпись строки сведений печатается текстом рядом со значением, поэтому скринридер читает пару целиком: «Темы — Новые заказы…».
- Предупреждение в сведениях выделено только цветом. Пусть его несёт и само значение или подпись: «Пропало — Опросы».

## Узлом холста

`Кит.Сводка` — узел [холста](холст): его кладут в пункт списка, в ячейку таблицы или в шапку раскрывашки, как в образце выше.

```живой Сводка узлом дерева
HTML = Кит.Сводка(Новый Структура("Название, Подпись", "Утренняя рассылка", "почта")).Рендер();
```
