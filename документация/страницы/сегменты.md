# Сегменты

Сегменты — выбор одного из немногих вариантов рядом кнопок в одной пилюле: тема, режим, пресет. Все варианты видны сразу, выбранный залит цветом и отмечен галкой. Под капотом — радиокнопки одного имени: выбор уходит с формой без скрипта, стрелки меняют его, а наборы полей под сегментами переключает лист.

## Когда использовать

- Вариантов два–четыре, подписи короткие, и человеку полезно видеть их все сразу: «Светлая / Тёмная / Авто».
- От выбора зависит, какие поля заполнять дальше: «Ключ / Пароль» — у каждого способа свои поля.
- Выбор в строке списка, который сохраняется сам: роль участника, режим уведомлений.

Вариантов больше пяти или подписи длинные — это [поле выбора](поле) (`Кит.Поле(…).Вариант(…)`). Два состояния «включено / выключено» — [тумблер](тумблер). Соседние виды одного объекта со своими адресами — [вкладки](табы): сегменты ничего не открывают, они выбирают значение.

## Выбор

Сегменты — `Кит.Сегменты(Имя, …)` из `Кит.Сегмент(Значение, Подпись)`. Имя — имя поля формы: под ним уходит значение выбранного сегмента. Отмечен ровно один: сегмент со словом `Выбран()`, иначе тот, чьё значение назвало слово `Выбрано(Значение)`, иначе первый. `Подпись` — имя группы для скринридера.

```живой Тема интерфейса
HTML = Кит.Форма("/настройки/тема",
	Кит.Сегменты("theme",
		Кит.Сегмент("light", "Светлая"),
		Кит.Сегмент("dark", "Тёмная"),
		Кит.Сегмент("auto", "Авто")).Подпись("Тема").Выбрано("auto"),
	Кит.Кнопка("Сохранить").Основная()).Токен("т0кен-сессии").Рендер();
```

Значение, которого нет среди сегментов, отмечает первый — так же браузер показывает выпадающий список, чьё значение не нашлось. Два сегмента с одним значением сборка не пускает: сервер получил бы одно и то же, какой ни выбери.

## Наборы полей

Дети сегмента — его набор полей: под группой виден набор отмеченного сегмента, остальные спрятаны. Переключает их лист кита (`:has(:checked)`), без скрипта и без запроса на сервер. Сегмент без детей — без набора: под ним пусто.

```живой Способ входа — у каждого свои поля
HTML = Кит.Форма("/подключения",
	Кит.Сегменты("auth",
		Кит.Сегмент("key", "Ключ",
			Кит.Поле("token", "Ключ доступа").Подсказка("выдаёт владелец проекта")),
		Кит.Сегмент("password", "Пароль",
			Кит.Поле("login", "Логин"),
			Кит.Поле("secret", "Пароль").Секрет()),
		Кит.Сегмент("none", "Без входа")).Подпись("Способ входа"),
	Кит.Кнопка("Подключить").Основная()).Токен("т0кен-сессии").Рендер();
```

Как это связано. Сегменты печатают под группой по панели на каждый сегмент, в том же порядке, — `<div class="segments__panel" data-segment="значение">` с его набором внутри. Лист показывает панель номер N, пока отмечен сегмент номер N; правила перечислены до восьми сегментов, и девятый набор сборка не пускает. Признак `data-segment` несёт значение сегмента: по нему свой CSS или скрипт страницы находит набор, не считая номеров.

Спрятанный набор не отключён: его поля уходят с формой вместе с выбранным, и сервер берёт поля того способа, который пришёл в имени сегментов. Движок без `:has()` показывает все наборы сразу — поля не теряются.

## Сохранять сразу

Слово `СохранятьСразу` — как у тумблера: выбор сам отправляет форму, а с `БезПерезагрузки()` у формы — в фоне, без перезагрузки страницы. Кнопку сохранения форме всё равно оставьте: без скрипта отправить выбор больше нечем.

```живой Режим уведомлений сохраняется сам
HTML = Кит.Форма("/уведомления",
	Кит.Сегменты("notify",
		Кит.Сегмент("all", "Все"),
		Кит.Сегмент("mentions", "Упоминания"),
		Кит.Сегмент("none", "Никаких")).Подпись("Уведомления").Выбрано("mentions").СохранятьСразу(),
	Кит.Кнопка("Сохранить").Вторичная()).БезПерезагрузки().Токен("т0кен-сессии").Рендер();
```

## Малые

`Малые()` — та же пилюля ниже и плотнее: для строки списка, записи реестра, ячейки таблицы, где обычные сегменты выше соседей.

```живой Роль участника в строке таблицы
Участники = Новый Массив();
Для Каждого Пара Из СтрРазделить("anna:write,boris:read", ",") Цикл
	Имя = СтрРазделить(Пара, ":")[0];
	Участники.Добавить(Новый Структура("name, role", Имя,
		Кит.Форма("/участники/" + Имя,
			Кит.Сегменты("role",
				Кит.Сегмент("read", "Чтение"),
				Кит.Сегмент("write", "Запись")).Подпись("Роль: " + Имя)
				.Выбрано(СтрРазделить(Пара, ":")[1]).Малые().СохранятьСразу())
			.БезПерезагрузки().Токен("т0кен-сессии")));
КонецЦикла;
Таблица = Кит.Таблица(Участники);
Таблица.Колонка("name", "Участник");
Таблица.Колонка("role", "Роль");
HTML = Таблица.Рендер();
```

## Без скрипта

Сегменты — радиокнопки: выбор, стрелки и отправка с формой работают без скрипта, наборы переключает лист. Скрипт нужен только слову `СохранятьСразу` — без него выбор уходит кнопкой сохранения, как любое поле.

## Гайдлайны

```делайте Два–четыре варианта, подпись — одно-два слова
HTML = Кит.Сегменты("view",
	Кит.Сегмент("list", "Списком"),
	Кит.Сегмент("cards", "Карточками")).Подпись("Вид списка").Рендер();
```

```не-делайте Семь вариантов сегментами: подписи сжимаются до многоточий
HTML = Кит.Сегменты("day",
	Кит.Сегмент("1", "Понедельник"), Кит.Сегмент("2", "Вторник"), Кит.Сегмент("3", "Среда"),
	Кит.Сегмент("4", "Четверг"), Кит.Сегмент("5", "Пятница"), Кит.Сегмент("6", "Суббота"),
	Кит.Сегмент("7", "Воскресенье")).Подпись("День").Рендер();
```

Длинный перечень — это поле выбора: `Кит.Поле("day", "День").Вариант(…)`.

```делайте Обязательность наборов проверяет сервер
HTML = Кит.Сегменты("auth",
	Кит.Сегмент("key", "Ключ", Кит.Поле("token", "Ключ доступа")),
	Кит.Сегмент("password", "Пароль", Кит.Поле("secret", "Пароль").Секрет())).Подпись("Способ входа").Рендер();
```

```не-делайте Обязательное поле в наборе: спрятанное, оно не пустит форму
HTML = Кит.Сегменты("auth",
	Кит.Сегмент("key", "Ключ", Кит.Поле("token", "Ключ доступа").Обязательное()),
	Кит.Сегмент("password", "Пароль", Кит.Поле("secret", "Пароль").Секрет().Обязательное()))
	.Подпись("Способ входа").Рендер();
```

Браузер не отправит форму, пока пусто обязательное поле, — даже спрятанное в невыбранном наборе, и показать отказ ему негде. Поле набора, без которого нельзя, проверяет сервер для того способа, что пришёл в имени сегментов.

```не-делайте Сегменты вместо вкладок: у каждого вида объекта свой адрес
HTML = Кит.Сегменты("tab",
	Кит.Сегмент("overview", "Обзор", Кит.Примечание("Сводка проекта.")),
	Кит.Сегмент("history", "История", Кит.Примечание("Изменения проекта."))).Рендер();
```

## Доступность

- Группа — `role="radiogroup"` с именем из слова `Подпись` (`aria-label`): скринридер читает «Тема, группа переключателей, Тёмная, 2 из 3». Без подписи группу называет только соседний текст — дайте её всегда, когда сегменты стоят без видимого заголовка.
- Сегмент — настоящая радиокнопка внутри своей метки: Tab приходит в группу один раз, стрелки меняют выбор, пробел отмечает. Фокус виден обводкой сегмента.
- Галка выбранного — оформление (`aria-hidden`): что отмечено, скринридер узнаёт от радиокнопки.
- Спрятанный набор — `display: none`: его поля уходят из порядка Tab и из речи скринридера.
- Настройка «меньше движения» гасит переходы заливки и въезд галки.
