# Карточка

Карточка — поверхность для законченного куска содержимого: заголовок, пояснение, тело и полоса действий внизу. В Material это приподнятая карточка: фон surface-container-low, тень первого уровня, среднее скругление.

## Когда использовать

- Экран делится на самостоятельные блоки, и каждый можно читать отдельно: «Доступ», «Источники», «Ключи».
- У блока есть свои действия, и они относятся только к нему.
- Несколько однородных объектов выкладываются колонкой или [сеткой](сетка).

Не берите карточку ради рамки вокруг одной строки — хватит [заголовка](заголовок-страницы) и абзаца. Необратимые действия собирает [опасная зона](опасная-зона), а не красная карточка.

В дереве холста карточка собирается словами: заголовок позицией, тело — детьми, описание словом, кнопки — в `.Действия(…)` (см. [Язык узлов](язык-узлов)).

```живой Узлом холста — словами
HTML = Кит.Карточка("Ключи доступа", Кит.Примечание("Активных ключей: 2"))
	.Описание("Ключ показывается один раз")
	.Действия(Кит.Кнопка("Выпустить ключ").Вторичная()).Рендер();
```

## Заголовок, описание, тело

Заголовок называет блок и печатается `<h2>`, иконка стоит перед ним. Описание — одна приглушённая строка под заголовком. Тело — доверенная разметка, собранная компонентами кита.

```живой Заголовок, описание, тело
HTML = Набор.Карточка().Отрисовать(Новый Структура("Заголовок, Описание, Тело, Иконка",
	"Проект «Альфа»", "Проект по умолчанию", "<p>тело карточки</p>", "куб"));
```

## Действия

`Действия` печатаются отдельной полосой под телом. Кладите туда кнопки, которые относятся к этой карточке и ни к чему больше.

```живой С полосой действий
HTML = Набор.Карточка().Отрисовать(Новый Структура("Заголовок, Тело, Действия",
	"С действиями", "<p>тело</p>", Набор.Кнопка().Отрисовать("Применить")));
```

## Без заголовка

Карточка без заголовка — просто поверхность. Она годится, когда заголовок уже стоит над ней или содержимое называет себя само.

```живой Без заголовка
HTML = Набор.Карточка().Отрисовать(Новый Структура("Тело", "<p>только тело</p>"));
```

## Заголовок ссылкой, уровень и якорь

С `Адресом` заголовок становится ссылкой — так карточка в списке ведёт на страницу объекта. `Уровень` меняет тег заголовка (от 1 до 6, по умолчанию 2): карточка внутри раздела с `<h2>` получает `<h3>`. `Якорь` печатается атрибутом `id`, и на карточку можно сослаться из оглавления.

```живой Заголовок-ссылка третьего уровня с якорем
HTML = Набор.Карточка().Отрисовать(Новый Структура("Заголовок, Адрес, Описание, Уровень, Якорь, Иконка",
	"Проект «Альфа»", "/проекты/альфа", "18 документов, 3 участника", 3, "альфа", "куб"));
```

## Гайдлайны

```делайте Заголовок называет содержимое
HTML = Набор.Карточка().Отрисовать(Новый Структура("Заголовок, Описание, Тело",
	"Ключи доступа", "Ключ показывается один раз", "<p>Активных ключей: 2</p>"));
```

```не-делайте Заголовок, который ничего не говорит
HTML = Набор.Карточка().Отрисовать(Новый Структура("Заголовок, Тело",
	"Информация", "<p>Активных ключей: 2</p>"));
```

```делайте Действия карточки — в её полосе действий
HTML = Набор.Карточка().Отрисовать(Новый Структура("Заголовок, Тело, Действия",
	"Источники", "<p>Подключено источников: 3</p>",
	Набор.Кнопка().Отрисовать(Новый Структура("Подпись, Вариант", "Подключить", "вторичная"))));
```

```не-делайте Карточка в карточке: тени и рамки множатся, иерархия теряется
Внутренняя = Набор.Карточка().Отрисовать(Новый Структура("Заголовок, Тело",
	"Подробности", "<p>Подключено источников: 3</p>"));

HTML = Набор.Карточка().Отрисовать(Новый Структура("Заголовок, Тело",
	"Источники", Внутренняя));
```

## Доступность

- Карточка печатается `<section>`, а заголовок — настоящим `<h1>`–`<h6>`. Скринридер находит блок по заголовкам.
- Выбирайте `Уровень` по месту в оглавлении страницы, а не по размеру шрифта: пропуск уровня ломает навигацию по заголовкам.
- Иконка заголовка декоративна (`aria-hidden`): смысл несёт текст.
- Заголовок со ссылкой — обычная ссылка с текстом заголовка. Отдельная кнопка «Открыть» рядом не нужна.

## Узлом холста

На [холсте](холст) тело карточки не передают строкой, а кладут детьми узла; полоса действий — второй холст `.Действия(д…)`.

```живой Узлом дерева — тело кладут детьми
HTML = Кит.Карточка("Проекты", Кит.Примечание("две штуки")).Рендер();
```

## Модель

Структура с этими полями — прежний вид модели: в дереве холста `Адрес`, `Описание`, `Иконка`, `Уровень` и `Якорь` пишут слова `Кит.Карточка`, а тело и действия — дети узла.

```справка Карточка
```

```справка Кит.Карточка
```

```словарь компонент:карточка
```
