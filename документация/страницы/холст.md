# Холст и узлы

Холст — способ собрать экран деревом узлов: берёте у кита узел, кладёте в него другие и печатаете корень одним вызовом. Тегов, имён классов и склейки строк в коде экрана при этом нет.

## Модель

В модели три участника.

- **Кит** — фабрика узлов. Каждая функция кита (`Кит.Ряд`, `Кит.Таблица`, `Кит.Кнопка`) возвращает новый узел.
- **Элемент экрана** — сам узел. У него есть род, вид, родитель и дети. Детей передают фабрике аргументами или кладут методом `Добавить`, печатают методом `Рендер`.
- **Холст** — корень куска экрана. Своего тега не печатает: он только держит детей и печатает их подряд.

Порядок детей и есть порядок на экране. Печать идёт один раз, с корня: каждый узел печатает себя и всё, что внутри него. Правила, по которым пишется код экрана, собраны на странице [Язык узлов](язык-узлов).

```живой Список объектов: шапка, таблица, карточки, действие
HTML = Кит.Холст(
	Кит.Ряд("выбор",
		Кит.Надпись("Витрина").Вид("название"),
		Кит.Надпись("холст, ряд, надпись, текст").Вид("пояснение")),
	Кит.Таблица(
		Кит.Колонка("Имя"),
		Кит.Запись(Кит.Ячейка(Кит.Код("отчёт")))),
	Кит.Область(
		Кит.Статья(
			Кит.Заголовок(3, "объект").Вид("имя"),
			Кит.Примечание("описание объекта").Вид("описание")).Вид("карточка")).Вид("карточки"),
	Кит.Кнопка("Действие").Основная()).Рендер();
```

## Дети аргументами

Фабрика контейнера принимает до восьми детей позиционно, по порядку на экране. `Неопределено` пропускается: ребёнок, которого может не быть, пишется прямо в списке. Девятый и дальше кладутся методом `Добавить`.

Строка на месте узла — текст: она становится узлом `Кит.Текст` и экранируется, разметкой не станет никогда.

```разметкой Строки — текст, узлы — узлы
HTML = Кит.Примечание("Ключ ", Кит.Код("api-7f2c"), " показывается один раз.").Рендер();
```

## Добавить возвращает положенное

`Добавить` возвращает не родителя, а ребёнка — тот узел, который только что положили. Поэтому цепочка `Холст.Добавить(Кит.Ряд(...)).Добавить(...)` спускается вглубь дерева, а не наполняет один уровень. Строку `Добавить` тоже принимает и отдаёт её текстовый узел.

Нужен родитель — возьмите его методом `Родитель()`. Так узел, собранный в одну строку, отдают целиком.

```живой Цепочка вглубь и возврат к родителю
Абзац = Кит.Примечание().Добавить("Ключ показывается один раз.").Родитель();

HTML = Абзац.Рендер();
```

Список, который собирается циклом, наполняют `Добавить`:

```живой Дети из цикла — Добавить
Ряд = Кит.Ряд("признаки");
Для Каждого Имя Из СтрРазделить("свежий,проверен,открытый", ",") Цикл
	Ряд.Добавить(Кит.Плашка(Имя));
КонецЦикла;

HTML = Ряд.Рендер();
```

## Род и вид

Род — что это за узел: ряд, таблица, ссылка, текст. Род определяет тег и то, что можно положить внутрь. Вид — оформление узла из закрытого набора его рода. Вид задают словом `.Вид(…)`: `Кит.Таблица(…).Вид("карточками")`. У ряда вид — его смысл, поэтому он первым аргументом: `Кит.Ряд("выбор", …)`.

Вид — не имя CSS-класса. Его проверяют сразу: опечатка останавливает сборку, а не даёт молча голый экран. Все роды и их виды собраны в [словаре родов](словарь-родов).

```живой Неизвестный вид — исключение
Попытка
	Кит.Ряд("кнопки");
Исключение
	HTML = Кит.Примечание(КраткоеПредставлениеОшибки(ИнформацияОбОшибке())).Рендер();
КонецПопытки;
```

Прежде вид шёл вторым аргументом: `Кит.Примечание("Ничего", "пусто")`. Теперь там ребёнок-текст, и слово «пусто» напечаталось бы на экране. Строку, совпавшую с видом рода, кит ловит при рождении узла и подсказывает слово `.Вид(…)`.

## Условие словом

`.Когда(Условие)` есть у любого узла: ложь печатает пустую строку, а узел остаётся в дереве — `Дерево()` показывает его пометкой `[скрыт]`. Условие вычисляется всегда; там, где вычислять дорого, пишите `Если` и `Кит.Ничего()`.

```живой Когда — узел на месте, на экране его нет
ЕстьКлючи = Ложь;

HTML = Кит.Холст(
	Кит.Заголовок(3, "Ключи доступа"),
	Кит.Примечание("Ключей пока нет.").Вид("пусто").Когда(НЕ ЕстьКлючи),
	Кит.Кнопка("Отозвать все").Опасная().Когда(ЕстьКлючи)).Рендер();
```

## Правила вложения

Дерево проверяет себя на каждом ребёнке. Ошибку видно сразу, в строке, где её сделали, а не на экране, с которого содержимое молча пропало.

- Внутрь кладут узел или строку текста. Готовую разметку, которую пока некому собрать деревом, заворачивают в `Кит.Готовое()`.
- Лист дерева (текст, картинка, мета, компонент без слота) детей не принимает.
- Один узел — одно место на экране. Для второго места возьмите у кита новый узел.
- Узел нельзя положить в самого себя или в своего потомка.
- Некоторые роды принимают только своих детей: в таблицу кладут колонки и записи, в запись — ячейки, в список — пункты, в свойства — свойства, в документ — голову и тело. Строка в таком роде — тоже чужой ребёнок.
- В форму строка не кладётся вовсе: токен задаётся словом `.Токен(…)`, текст — узлом `Кит.Текст()`.

```живой Чужой ребёнок — исключение
Попытка
	Кит.Список(Кит.Примечание("абзац вместо пункта"));
Исключение
	HTML = Кит.Примечание(КраткоеПредставлениеОшибки(ИнформацияОбОшибке())).Рендер();
КонецПопытки;
```

```живой Строка в записи таблицы — исключение
Попытка
	Кит.Запись("значение без ячейки");
Исключение
	HTML = Кит.Примечание(КраткоеПредставлениеОшибки(ИнформацияОбОшибке())).Рендер();
КонецПопытки;
```

## Холст и Ничего

`Кит.Холст()` и `Кит.Ничего()` возвращают одинаковый узел и печатаются одинаково — пустой строкой, пока в них ничего не положили. Разница видна только тому, кто читает код экрана, и в ней весь смысл.

- `Кит.Холст(…)` — корень куска экрана: его наполняют и печатают целиком.
- `Кит.Ничего()` — место, где показывать нечего: его не наполняют, он и есть ответ.

```живой Ничего печатается пустой строкой
HTML = Кит.Ничего().Рендер();
```

Ничего ложится всюду, где принимают холст, но не в обход правил вложения: внутрь записи по-прежнему кладут ячейку, внутрь таблицы — запись, внутрь списка — пункт.

```bsl
Функция БлокЧерновика(Знач Статья)

	Если Статья.Черновик Тогда
		Возврат Кит.Ничего();   // на странице этого места просто не будет
	КонецЕсли;

	Возврат Кит.Холст(          // а здесь собираем кусок экрана
		Кит.Заголовок(3, "Как читать"),
		Кит.Примечание(Статья.Пояснение).Вид("описание"));

КонецФункции
```

На `Возврат Кит.Ничего();` читатель останавливается: элемента здесь нет. На `Возврат Кит.Холст();` он идёт вверх по функции искать, чем холст наполнили, и не находит ничего.

Слово «пусто» в ките уже занято видимым смыслом: компонент [«Пустое состояние»](пустое-состояние), вид примечания «пусто» и `Таблица.Пусто()`. Все три что-то показывают человеку, поэтому место без содержимого называется иначе.

## Дерево узла

`Дерево()` печатает, из чего собран кусок экрана: род и вид каждого узла, вложенность отступом, снятые словом `Когда` — пометкой `[скрыт]`. Это ответ на вопрос «что здесь напечатано» без чтения функций, которые экран собирали.

```живой Из чего собран экран
Холст = Кит.Холст(
	Кит.Ряд("выбор", Кит.Кнопка("Все").Вторичная()),
	Кит.Таблица(
		Кит.Колонка("Имя"),
		Кит.Запись(Кит.Ячейка(Кит.Код("отчёт")))).Пусто("Ничего не найдено"),
	Кит.Примечание("Фильтр не задан.").Когда(Ложь));

HTML = Кит.Код(Холст.Дерево()).Вид("блочный").Рендер();
```

## Свойства узла

Атрибуты узла задаются словами, а не строкой. Каждое слово возвращает тот же узел, поэтому их ставят цепочкой.

- `Подпись` — доступное имя ряда, легенда группы, заголовок таблицы, имя свойства, текст `alt` картинки.
- `Якорь` — атрибут `id`: на него ссылаются адрес с решёткой и кнопка вне своей формы.
- `Признак` — атрибут `data-*` для скрипта страницы. Печатается даже пустым. Имя — латиницей, цифрами и дефисом: признак с другим именем молча не печатается.
- `Роль` — роль для скринридера из набора кита: «группа», «состояние», «тревога».
- `Подсказка` — атрибут `title`.
- `Отключить` и `Скрыть` — атрибуты `disabled` и `hidden`.
- `Вид`, `Когда`, `Токен` — вид узла, условие показа и CSRF-токен для форм внутри.

У компонента те же слова пишут поля его модели — подробно на странице [Компонент в дереве](компонент-в-дереве).

```разметкой Свойства печатаются атрибутами
HTML = Кит.Область(Кит.Примечание("Ключ создан"))
	.Вид("вставка").Якорь("шаг-2").Роль("состояние").Подсказка("Шаг второй")
	.Признак("step", "2").Рендер();
```

```разметкой Отключённая и скрытая группа полей
HTML = Кит.Группа("Расписание", Кит.Поле("время", "Время"))
	.Вид("простая").Отключить().Скрыть().Рендер();
```

## Гайдлайны

```делайте Ничего() там, где показывать нечего: отсутствие видно в коде сразу
Черновик = Истина;
Холст = Кит.Холст(Кит.Заголовок(3, "Отчёт за март"));
Если Черновик Тогда
	Холст.Добавить(Кит.Ничего());
Иначе
	Холст.Добавить(Кит.Примечание("Как читать отчёт").Вид("описание"));
КонецЕсли;
HTML = Холст.Рендер();
```

```не-делайте Пустой Холст() вместо Ничего(): читатель ищет, чем его наполнили
Черновик = Истина;
Холст = Кит.Холст(Кит.Заголовок(3, "Отчёт за март"));
Если Черновик Тогда
	Холст.Добавить(Кит.Холст());
Иначе
	Холст.Добавить(Кит.Примечание("Как читать отчёт").Вид("описание"));
КонецЕсли;
HTML = Холст.Рендер();
```

```делайте Один корень и один Рендер() в конце
HTML = Кит.Холст(
	Кит.Заголовок(3, "Ключи доступа"),
	Кит.Примечание("Ключ показывается один раз.")).Рендер();
```

```не-делайте Склейка напечатанных кусков: дерево экрана теряется
HTML = Кит.Заголовок(3, "Ключи доступа").Рендер()
	+ Кит.Примечание("Ключ показывается один раз.").Рендер();
```

```делайте Текст — строкой-ребёнком: она экранируется сама
HTML = Кит.Примечание("Имя ", Кит.Код("<main>"), " уже занято.").Рендер();
```

```не-делайте Разметка строкой через Готовое(): экранировать её некому
HTML = Кит.Примечание(Кит.Готовое("Имя <code>&lt;main&gt;</code> уже занято.")).Рендер();
```

## Доступность

- Текст из данных печатается текстом — строкой-ребёнком или узлом `Кит.Текст()` — и экранируется всегда: разметкой он не станет.
- Уровень заголовка — число от 1 до 6, другой кит не соберёт. Не пропускайте уровни: скринридер строит по ним оглавление страницы.
- Ряд с подписью получает `aria-label` (ставьте ему и роль «группа», иначе имя у `div` не прочтут), группа — видимую легенду, картинка — `alt`. Картинка без подписи декоративна, скринридер её пропускает.
- Роль ставится только из набора кита, произвольную строку кит отвергнет.
- Пустые ссылка, заголовок и примечание не печатаются вовсе: безымянная ссылка и пустой заголовок для скринридера — дыра.
