# Холст и узлы

Холст — способ собрать экран деревом узлов: берёте у кита узел, кладёте в него другие и печатаете корень одним вызовом. Тегов, имён классов и склейки строк в коде экрана при этом нет.

## Модель

В модели три участника.

- **Кит** — фабрика узлов. Каждая функция кита (`Кит.Ряд`, `Кит.Таблица`, `Кит.Кнопка`) возвращает новый узел.
- **Элемент экрана** — сам узел. У него есть род, вид, родитель и дети. Кладут его методом `Добавить`, печатают методом `Рендер`.
- **Холст** — корень куска экрана. Своего тега не печатает: он только держит детей и печатает их подряд.

Порядок детей и есть порядок на экране. Печать идёт один раз, с корня: каждый узел печатает себя и всё, что внутри него.

```живой Список объектов: шапка, таблица, карточки, действие
Холст = Кит.Холст();

Шапка = Холст.Добавить(Кит.Ряд("выбор"));
Шапка.Добавить(Кит.Надпись("название")).Добавить(Кит.Текст("Витрина"));
Шапка.Добавить(Кит.Надпись("пояснение")).Добавить(
	Кит.Текст("холст, ряд, надпись, текст"));

Таблица = Холст.Добавить(Кит.Таблица());
Таблица.Добавить(Кит.Колонка("Имя"));
Таблица.Добавить(Кит.Запись()).Добавить(Кит.Ячейка()).Добавить(Кит.Код("отчёт"));

Карточка = Холст.Добавить(Кит.Область("карточки")).Добавить(Кит.Статья("карточка"));
Карточка.Добавить(Кит.Заголовок(3, "имя")).Добавить(Кит.Текст("объект"));
Карточка.Добавить(Кит.Примечание("описание объекта", "описание"));

Холст.Добавить(Кит.Кнопка(Новый Структура("Подпись, Вариант",
	"Действие", "основная")));

HTML = Холст.Рендер();
```

## Добавить возвращает положенное

`Добавить` возвращает не родителя, а ребёнка — тот узел, который только что положили. Поэтому цепочка `Холст.Добавить(Кит.Ряд(...)).Добавить(...)` спускается вглубь дерева, а не наполняет один уровень.

Нужен родитель — возьмите его методом `Родитель()`. Так узел, собранный в одну строку, отдают целиком.

```живой Цепочка вглубь и возврат к родителю
Абзац = Кит.Примечание().Добавить(Кит.Текст("Ключ показывается один раз.")).Родитель();

HTML = Абзац.Рендер();
```

## Род и вид

Род — что это за узел: ряд, таблица, ссылка, текст. Род определяет тег и то, что можно положить внутрь. Вид — оформление узла из закрытого набора его рода: `Кит.Ряд("выбор")`, `Кит.Таблица("карточками")`.

Вид — не имя CSS-класса. Его проверяют при рождении узла: опечатка останавливает сборку, а не даёт молча голый экран. Все роды и их виды собраны в [словаре родов](словарь-родов).

```живой Неизвестный вид — исключение при рождении узла
Попытка
	Кит.Ряд("кнопки");
Исключение
	HTML = Кит.Примечание(КраткоеПредставлениеОшибки(ИнформацияОбОшибке())).Рендер();
КонецПопытки;
```

## Правила вложения

Дерево проверяет себя на каждом `Добавить`. Ошибку видно сразу, в строке, где её сделали, а не на экране, с которого содержимое молча пропало.

- Внутрь кладут узел, а не строку. Готовую разметку, которую пока некому собрать деревом, заворачивают в `Кит.Готовое()`.
- Лист дерева (текст, картинка, мета, компонент без слота) детей не принимает.
- Один узел — одно место на экране. Для второго места возьмите у кита новый узел.
- Узел нельзя положить в самого себя или в своего потомка.
- Некоторые роды принимают только своих детей: в таблицу кладут колонки и записи, в запись — ячейки, в список — пункты, в свойства — свойства, в документ — голову и тело.

```живой Чужой ребёнок — исключение на Добавить
Попытка
	Кит.Список().Добавить(Кит.Примечание("абзац вместо пункта"));
Исключение
	HTML = Кит.Примечание(КраткоеПредставлениеОшибки(ИнформацияОбОшибке())).Рендер();
КонецПопытки;
```

```живой Строка вместо узла — исключение на Добавить
Попытка
	Кит.Холст().Добавить("<b>жирно</b>");
Исключение
	HTML = Кит.Примечание(КраткоеПредставлениеОшибки(ИнформацияОбОшибке())).Рендер();
КонецПопытки;
```

## Холст и Ничего

`Кит.Холст()` и `Кит.Ничего()` возвращают одинаковый узел и печатаются одинаково — пустой строкой, пока в них ничего не положили. Разница видна только тому, кто читает код экрана, и в ней весь смысл.

- `Кит.Холст()` — корень куска экрана: его наполняют и печатают целиком.
- `Кит.Ничего()` — место, где показывать нечего: его не наполняют, он и есть ответ.

```живой Ничего печатается пустой строкой
HTML = Кит.Ничего().Рендер();
```

Ничего ложится всюду, где принимают холст, но не в обход правил вложения: внутрь записи по-прежнему кладут ячейку, внутрь таблицы — запись, внутрь списка — пункт.

```bsl
Функция БлокЧерновика(Знач Статья)

	Если Статья.Черновик Тогда
		Возврат Кит.Ничего();   // на странице этого места просто не будет
	КонецЕсли;

	Блок = Кит.Холст();         // а здесь собираем кусок экрана
	Блок.Добавить(Кит.Заголовок(3)).Добавить(Кит.Текст("Как читать"));
	Блок.Добавить(Кит.Примечание(Статья.Пояснение, "описание"));
	Возврат Блок;

КонецФункции
```

На `Возврат Кит.Ничего();` читатель останавливается: элемента здесь нет. На `Возврат Кит.Холст();` он идёт вверх по функции искать, чем холст наполнили, и не находит ничего.

Слово «пусто» в ките уже занято видимым смыслом: компонент [«Пустое состояние»](пустое-состояние), вид примечания «пусто» и `Таблица.Пусто()`. Все три что-то показывают человеку, поэтому место без содержимого называется иначе.

## Дерево узла

`Дерево()` печатает, из чего собран кусок экрана: род и вид каждого узла, вложенность отступом. Это ответ на вопрос «что здесь напечатано» без чтения функций, которые экран собирали.

```живой Из чего собран экран
Холст = Кит.Холст();
Ряд = Холст.Добавить(Кит.Ряд("выбор"));
Ряд.Добавить(Кит.Кнопка(Новый Структура("Подпись, Вариант", "Все", "вторичная")));

Таблица = Холст.Добавить(Кит.Таблица());
Таблица.Добавить(Кит.Колонка("Имя"));
Таблица.Добавить(Кит.Запись()).Добавить(Кит.Ячейка()).Добавить(Кит.Код("отчёт"));
Таблица.Пусто().Добавить(Кит.Примечание("Ничего не найдено"));

HTML = Кит.Код(Холст.Дерево(), "блочный").Рендер();
```

## Свойства узла

Атрибуты узла задаются методами, а не строкой. Каждый метод возвращает тот же узел, поэтому их ставят цепочкой.

- `Подпись` — доступное имя ряда, легенда группы, заголовок таблицы, имя свойства, текст `alt` картинки.
- `Якорь` — атрибут `id`: на него ссылаются адрес с решёткой и кнопка вне своей формы.
- `Признак` — атрибут `data-*` для скрипта страницы. Печатается даже пустым. Имя — латиницей, цифрами и дефисом: признак с другим именем молча не печатается.
- `Роль` — роль для скринридера из набора кита: «группа», «состояние», «тревога».
- `Подсказка` — атрибут `title`.
- `Отключить` и `Скрыть` — атрибуты `disabled` и `hidden`.

```разметкой Свойства печатаются атрибутами
Область = Кит.Область("вставка").Якорь("шаг-2").Роль("состояние").Подсказка("Шаг второй");
Область.Признак("step", "2");
Область.Добавить(Кит.Примечание("Ключ создан"));

HTML = Область.Рендер();
```

```разметкой Отключённая и скрытая группа полей
Группа = Кит.Группа("Расписание", "простая").Отключить().Скрыть();
Группа.Добавить(Кит.Поле(Новый Структура("Имя, Метка", "время", "Время")));

HTML = Группа.Рендер();
```

## Гайдлайны

```делайте Ничего() там, где показывать нечего: отсутствие видно в коде сразу
Черновик = Истина;
Холст = Кит.Холст();
Холст.Добавить(Кит.Заголовок(3)).Добавить(Кит.Текст("Отчёт за март"));
Если Черновик Тогда
	Холст.Добавить(Кит.Ничего());
Иначе
	Холст.Добавить(Кит.Примечание("Как читать отчёт", "описание"));
КонецЕсли;
HTML = Холст.Рендер();
```

```не-делайте Пустой Холст() вместо Ничего(): читатель ищет, чем его наполнили
Черновик = Истина;
Холст = Кит.Холст();
Холст.Добавить(Кит.Заголовок(3)).Добавить(Кит.Текст("Отчёт за март"));
Если Черновик Тогда
	Холст.Добавить(Кит.Холст());
Иначе
	Холст.Добавить(Кит.Примечание("Как читать отчёт", "описание"));
КонецЕсли;
HTML = Холст.Рендер();
```

```делайте Один корень и один Рендер() в конце
Холст = Кит.Холст();
Холст.Добавить(Кит.Заголовок(3)).Добавить(Кит.Текст("Ключи доступа"));
Холст.Добавить(Кит.Примечание("Ключ показывается один раз."));
HTML = Холст.Рендер();
```

```не-делайте Склейка напечатанных кусков: дерево экрана теряется
HTML = Кит.Заголовок(3).Добавить(Кит.Текст("Ключи доступа")).Родитель().Рендер()
	+ Кит.Примечание("Ключ показывается один раз.").Рендер();
```

```делайте Текст — узлом Текст(): он экранируется сам
Абзац = Кит.Примечание();
Абзац.Добавить(Кит.Текст("Имя "));
Абзац.Добавить(Кит.Код("<main>"));
Абзац.Добавить(Кит.Текст(" уже занято."));
HTML = Абзац.Рендер();
```

```не-делайте Разметка строкой через Готовое(): экранировать её некому
HTML = Кит.Примечание().Добавить(
	Кит.Готовое("Имя <code>&lt;main&gt;</code> уже занято.")).Родитель().Рендер();
```

## Доступность

- Текст из данных печатается узлом `Кит.Текст()` и экранируется всегда: разметкой он не станет.
- Уровень заголовка — число от 1 до 6, другой кит не соберёт. Не пропускайте уровни: скринридер строит по ним оглавление страницы.
- Ряд с подписью получает `aria-label` (ставьте ему и роль «группа», иначе имя у `div` не прочтут), группа — видимую легенду, картинка — `alt`. Картинка без подписи декоративна, скринридер её пропускает.
- Роль ставится только из набора кита, произвольную строку кит отвергнет.
- Пустые ссылка, заголовок и примечание не печатаются вовсе: безымянная ссылка и пустой заголовок для скринридера — дыра.
