# Окно

Окно — модальный диалог поверх экрана: короткая задача, которую человек решает, не уходя со страницы. Новая запись, правка одного поля, выбор из небольшого списка. Это нативный `<dialog>`: открывает его кнопка командой браузера, Esc и крестик закрывают, фокус держится внутри и возвращается на кнопку, с которой окно открыли.

## Когда использовать

- Задача короткая и не уводит со страницы: завести проект, переименовать запись, пригласить участника.
- После неё человек возвращается к тому же списку и видит результат на месте.
- Нужен ответ сейчас, прежде чем идти дальше, — для необратимого действия есть [подтверждение](подтверждение).

Не открывайте окном длинную форму с разделами и не открывайте окно из окна: длинной задаче место на своей странице, а второе окно поверх первого прячет, откуда человек пришёл. Сообщение об итоге — не окно, а [тост](тост).

## Окно и кнопка

Окно — узел `Кит.Окно(Заголовок, тело…)`: дети узла — тело окна, кнопки внизу — второй холст `Действия(…)`. Кнопка открывает его словом `Открывает(Окно)`: кит печатает команду браузера `command="show-modal"` и `commandfor` с идентификатором окна. Скрипт для этого не нужен — движок знает команду сам, а движку постарше её доучивает скрипт кита.

```живой Кнопка и окно — нажмите «Новый проект»
Окно = Кит.Окно("Новый проект",
		Кит.Поле("name", "Название").Обязательное())
	.Лид("Проект появится в списке сразу.")
	.Действия(Кит.Кнопка("Отмена").Вторичная().Команда("закрыть", "novyi-proekt-obrazec"),
		Кит.Кнопка("Создать").Основная())
	.Форма("/образец-окон").Якорь("novyi-proekt-obrazec");
HTML = Кит.Холст(Кит.Кнопка("Новый проект").Иконка("плюс").Открывает(Окно), Окно)
	.Токен("т0кен-сессии").Рендер();
```

Форма этого окна уходит на [образец с сервером](/образец-окон): созданный проект появится в его списке.

Открытое окно стоит по центру экрана, где бы его ни напечатали: в теле карточки, секции или записи реестра ритм контейнера его не сдвигает.

Окно печатается слотами в одном порядке: шапка — заголовок и крестик, под ней лид (что это окно делает), тело, ряд действий. Порядок задаёт кит, а не порядок слов в коде.

Словом `Форма(Адрес)` окно целиком становится формой: шапка, тело и действия лежат внутри `<form>`, поэтому кнопка «Создать» отправляет её сама, а крестик и «Отмена» — кнопки-команды, они форму не шлют. Адрес и токен окно берёт у контекста, как [любая форма холста](формы-деревом): относительный адрес — от дома настроек вокруг, токен — у ближайшего предка. Как форма в окне уходит без перезагрузки и закрывает окно — раздел «В окне» страницы [Формы деревом](формы-деревом).

## Вид

| Вид | Для чего |
|---|---|
| `обычное` (или без вида) | короткая форма, выбор, сведения |
| `опасное` | заголовок цветом ошибки: необратимое действие. Готовое окно такого рода — [подтверждение](подтверждение) |
| `широкое` | шаги мастера, таблица или две колонки, которым тесно в обычной ширине; слово `Широкое()` — то же |

```живой Широкое окно со сведениями
Окно = Кит.Окно("Ключи проекта",
		Кит.Таблица(Кит.Колонка("Ключ"), Кит.Колонка("Создан"),
			Кит.Запись(Кит.Ячейка("ноутбук"), Кит.Ячейка("12 марта")),
			Кит.Запись(Кит.Ячейка("сервер сборки"), Кит.Ячейка("2 апреля"))))
	.Вид("широкое").Якорь("klyuchi");
HTML = Кит.Холст(Кит.Кнопка("Все ключи").Вторичная().Открывает(Окно), Окно).Рендер();
```

Ширина окна — базового диалога Material: 560 пикселей, у широкого — 640. Шире окна не бывают: то, чему тесно в 640, просится на свою страницу.

## Идентификатор

На окно ссылаются кнопка (`commandfor`), заголовок (`aria-labelledby`) и форма с подтверждением. Слово `Якорь(Ид)` задаёт его явно. Без якоря кит выдаёт идентификатор сам — из заголовка и места окна в дереве: ответ на тот же запрос повторяется байт в байт, а два окна с одним заголовком в разных местах страницы получают разные идентификаторы. Кнопке узел окна передают словом `Открывает(Окно)`; строкой — идентификатор окна этой же страницы.

## Окно открытым с сервера

Без скрипта и в движке, который не знает команд, кнопка окна не сработает. Поэтому у экрана должна оставаться серверная дорога: адрес, по которому страница приходит с уже открытым окном, обычно тот же адрес с `?окно=…`. Слово `Открыто()` печатает окно открытым. Скрипт кита поднимает такое окно модальным — с фоном и удержанием фокуса; без скрипта оно работает как обычная форма. Тем же словом возвращают человеку отбитую форму вместе с набранным.

Без скрипта окно не модальное — в верхний слой браузера его поднимает только скрипт, — но выглядит и ведёт себя как модальное: стоит по центру экрана поверх шапки и секций ниже, страницу под ним гасит подложка, а щелчок мимо окна страницу не нажимает. Сама страница под окном прокручивается, длинное окно прокручивается само. Закрывает такое окно крестик там, где движок знает команду `close`, а в любом браузере — ссылка на адрес страницы без `?окно`: дайте её окну в действиях, `Кит.Кнопка("Закрыть").Вторичная().Адрес("/проекты")`. Так устроено [окно правки образца](/образец-окон?окно=правка&project=Альфа): секция с записями реестра ниже окна его не перекрывает.

```разметкой Окно, напечатанное открытым
Окно = Кит.Окно("Переименовать проект",
		Кит.Поле("name", "Название").Значение("альфа").Ошибка("Такой проект уже есть"))
	.Форма("/проекты/альфа").Открыто().Якорь("pereimenovat")
	.Действия(Кит.Кнопка("Сохранить").Основная());
HTML = Кит.Холст(Окно).Токен("т0кен-сессии").Рендер();
```

## Кнопка, которая работает без скрипта

Команда `show-modal` есть не в каждом движке, и без скрипта кита кнопка окна в старом браузере молчит. Дайте окну адрес его серверной дороги словом `Адрес("?окно=…")` — страницу, где сервер печатает это окно открытым, — и кнопка `Открывает(Окно)` печатается ссылкой на неё с признаком `data-opens`. Без скрипта ссылка ведёт на страницу с открытым окном в любом браузере. Со скриптом кит открывает окно этой страницы на месте: без запроса и без перехода, фокус возвращается на кнопку. Свой `Адрес` у кнопки главнее адреса окна. Адрес — своего приложения: чужой останавливает сборку. Без адреса кнопка — прежняя команда браузера.

```живой Ссылка на окно — со скриптом окно открывается на месте
Окно = Кит.Окно("Новый проект",
		Кит.Поле("name", "Название").Обязательное())
	.Лид("Проект появится в списке сразу.")
	.Действия(Кит.Кнопка("Создать").Основная())
	.Форма("/образец-окон").Адрес("/образец-окон?окно=новый").Якорь("novyi-proekt-ssylkoi");
HTML = Кит.Холст(Кит.Кнопка("Новый проект").Иконка("плюс").Открывает(Окно), Окно)
	.Токен("т0кен-сессии").Рендер();
```

Так же открывается и [подтверждение](подтверждение): у него та же серверная дорога.

## Окно по адресу

У таблицы на сотню строк сотню окон правки заранее не печатают. `Кит.ОкноПоАдресу(Адрес, Подпись)` — кнопка окна, которое приходит с сервера, когда его открывают. Без скрипта это ссылка на страницу с `?окно=…`, где сервер печатает окно открытым. Со скриптом кит берёт ту же страницу запросом в фоне, вынимает из неё окно, кладёт в оболочку и открывает. Форма такого окна уходит и закрывается так же, как у окна на странице.

```живой Кнопка окна по адресу
HTML = Кит.Ряд("действия",
	Кит.ОкноПоАдресу("/образец-окон?окно=правка&project=Альфа", "Переименовать").Малая().Иконка("карандаш"),
	Кит.ОкноПоАдресу("/образец-окон?окно=правка&project=Бета", "Переименовать бету")
		.ТолькоИконка().Иконка("карандаш")).Рендер();
```

Оболочка — одна пустая `<dialog>` на страницу и рядом скрытый тост «не удалось открыть окно». Её печатает [каркас страницы](каркас-страницы), и только там, где на странице есть хоть одна кнопка окна по адресу: страница без них остаётся той же байт в байт. Кто собирает документ без каркаса, ставит её узлом `Кит.ОболочкаОкна()` в конец тела.

Адрес окна — адрес своего приложения: окно берётся запросом с куками сессии, поэтому чужой хост и чужая схема останавливают сборку.

Образец с настоящим сервером — [список проектов с окнами](/образец-окон): новый проект, правка по адресу и удаление с подтверждением.

## На телефоне

До 640 px окно остаётся базовым диалогом: по центру экрана, шириной в экран без полей по 16 пикселей, действия — под телом. Подтверждение из пары строк и двух кнопок так и выглядит окном, а не пустым листом с кнопками внизу.

```живой Короткое окно на телефоне — базовое
Окно = Кит.Окно("Переименовать проект", Кит.Поле("name", "Название").Значение("альфа"))
	.Действия(Кит.Кнопка("Отмена").Вторичная().Команда("закрыть", "pereimenovat-telefon"),
		Кит.Кнопка("Сохранить").Основная())
	.Якорь("pereimenovat-telefon");
HTML = Кит.Холст(Кит.Кнопка("Переименовать").Вторичная().Открывает(Окно), Окно).Рендер();
```

Сложная задача — мастер с шагами, длинный выбор — на телефоне встаёт листом во весь экран, как полноэкранный диалог Material: прокручивается само окно, а ряд действий прилипает к низу и всегда под пальцем. Такое окно называют словом `ВоВесьЭкран()`; окно с [шагами](шаги) встаёт листом и без него. На широком экране слово ничего не меняет.

```живой Мастер на телефоне — во весь экран
Окно = Кит.Окно("Подключить источник",
		Кит.Поле("url", "Адрес источника"),
		Кит.Поле("branch", "Ветка").Значение("main"),
		Кит.Поле("token", "Токен доступа").Секрет())
	.Действия(Кит.Кнопка("Подключить").Основная())
	.ВоВесьЭкран().Широкое().Якорь("istochnik-telefon");
HTML = Кит.Холст(Кит.Кнопка("Подключить источник").Вторичная().Открывает(Окно), Окно).Рендер();
```

Окно, напечатанное открытым без скрипта, листом не становится — оно базовое по центру экрана и прокручивается само.

## Доступность

- Окно — нативный `<dialog>`, открытый `showModal`: фон недоступен, Tab ходит только внутри окна, Esc закрывает. Это делает браузер, а не скрипт.
- Окно названо заголовком (`aria-labelledby`), лид — его описание (`aria-describedby`): скринридер слышит «Новый проект, диалог» и следом, о чём оно. Окно без заголовка не собирается.
- Крестик — кнопка-значок с именем из словаря интерфейса (ключ `window.close`).
- Закрытое окно возвращает фокус на кнопку, которой его открыли. Когда форма окна ушла удачно и окно закрылось, фокус встаёт на то, что сервер пометил словом `Фокус()`, — обычно новую запись.
- Движение окна — проявление с небольшим ростом; при «меньше движения» оно мгновенное.
