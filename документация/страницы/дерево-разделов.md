# Дерево разделов

Дерево разделов — навигация внутри объекта или приложения: список ссылок на разделы, при необходимости с вложенными. Колонкой оно стоит слева в доме настроек, рядом — в шапке страницы. Текущий раздел подсвечен индикатором Material, и подсвечивает его сервер.

## Когда использовать

- У объекта или приложения больше пяти-шести разделов, и вкладками их уже не уместить.
- Разделы группируются: «Доступ» и под ним «Метки», «Ключи».
- Навигация должна стоять на каждой странице одинаково — в боковой колонке или в шапке.

Не берите дерево для двух-трёх видов одного объекта — им место во [вкладках](табы). Для выбора значений в иерархии есть [дерево галок](дерево-галок): там пункты отмечают, а здесь по ним переходят.

## Колонкой

Вертикаль — вид по умолчанию: пункты идут колонкой, каждый ростом 48 пикселей, вложенные сдвинуты вправо. Так выглядит колонка разделов в [доме настроек](дом-настроек) и оглавление слева на этом сайте.

```живой Вертикаль — дом настроек
Дети = Новый Массив();
Дети.Добавить(Новый Структура("Подпись, Адрес", "Метки", "/настройки/метки"));

Разделы = Новый Массив();
Разделы.Добавить(Новый Структура("Подпись, Адрес, Активен, Иконка",
	"Общие", "/настройки", Истина, "шестерёнка"));
Разделы.Добавить(Новый Структура("Подпись, Адрес, Дети",
	"Доступ", "/настройки/доступ", Дети));

HTML = Набор.ДеревоРазделов().Отрисовать(Новый Структура("Заголовок, Разделы",
	"Настройки проекта", Разделы));
```

В дереве холста имя дерева задаёт слово `Заголовок`, а разделы приходят прежним списком структур: слов для пунктов у дерева нет (см. [Язык узлов](язык-узлов)).

```живой Узлом холста — словами
Дети = Новый Массив();
Дети.Добавить(Новый Структура("Подпись, Адрес", "Метки", "/настройки/метки"));

Разделы = Новый Массив();
Разделы.Добавить(Новый Структура("Подпись, Адрес, Активен, Иконка",
	"Общие", "/настройки", Истина, "шестерёнка"));
Разделы.Добавить(Новый Структура("Подпись, Адрес, Дети",
	"Доступ", "/настройки/доступ", Дети));

HTML = Кит.ДеревоРазделов(Новый Структура("Разделы", Разделы))
	.Заголовок("Настройки проекта").Рендер();
```

Пункт — пилюля ящика навигации Material. Текущий раздел залит цветом secondary-container; на наведении пункт проявляется слоем состояния.

## Рубрики и опасный раздел

Десять и больше разделов плоским списком не читаются. Поле раздела `Рубрика` группирует их: подпись рубрики печатается над первым разделом с этим именем — мелкими прописными, приглушённо и с воздухом сверху. Разделы не переставляются: порядок остаётся тот, что пришёл, поэтому разделы одной рубрики кладите подряд.

Поле `Опасный` помечает раздел необратимого. Он печатается цветом ошибки, значок тоже, и стоит последним и без рубрики, где бы ни пришёл в списке. Открытый опасный раздел залит цветом error-container и несёт `aria-current`, как любой текущий.

```живой Три рубрики и опасный раздел
Разделы = Новый Массив();
Разделы.Добавить(Настройки.Раздел("Удаление проекта", "/настройки/удаление", "корзина",
	Ложь, "", Истина));
Разделы.Добавить(Настройки.Раздел("Общие", "/настройки", "шестерёнка", Истина));
Разделы.Добавить(Настройки.Раздел("Участники", "/настройки/участники", "аккаунт",
	Ложь, "Доступ"));
Разделы.Добавить(Настройки.Раздел("Ключи", "/настройки/ключи", "ключ", Ложь, "Доступ"));
Разделы.Добавить(Настройки.Раздел("Почта", "/настройки/почта", "конверт",
	Ложь, "Оповещения"));
Разделы.Добавить(Настройки.Раздел("Метки", "/настройки/метки", "тег", Ложь, "Оповещения"));
Разделы.Добавить(Настройки.Раздел("История", "/настройки/история", "история",
	Ложь, "Журнал"));

HTML = Кит.ДеревоРазделов(Новый Структура("Разделы", Разделы))
	.Заголовок("Настройки проекта").Рендер();
```

В [доме настроек](дом-настроек) рубрики и опасный раздел задаются словами: `Рубрика(Подпись)` у дома и `Опасный()` у раздела. В ряду шапки рубрики не печатаются — подпись между ходами читалась бы ещё одним ходом, по которому нельзя перейти. В группе разделов [единого меню](единое-меню) на телефоне — печатаются, в том же порядке.

## Рядом

`Ориентация` = «горизонталь» ставит пункты в ряд. Так [каркас страницы](каркас-страницы) печатает дороги приложения в шапке — тем же компонентом, с классом `tree--top`, который раздвигает пункты пошире.

```живой Горизонталь — шапка
Дети = Новый Массив();
Дети.Добавить(Новый Структура("Подпись, Адрес", "Метки", "/настройки/метки"));

Разделы = Новый Массив();
Разделы.Добавить(Новый Структура("Подпись, Адрес, Активен, Иконка",
	"Общие", "/настройки", Истина, "шестерёнка"));
Разделы.Добавить(Новый Структура("Подпись, Адрес, Дети",
	"Доступ", "/настройки/доступ", Дети));

HTML = Набор.ДеревоРазделов().Отрисовать(
	Новый Структура("Заголовок, Разделы, Ориентация",
		"Основная навигация", Разделы, "горизонталь"));
```

В ряду вложенный список встаёт под своим пунктом и разрывает строку. Держите горизонталь в один уровень — как в гайдлайнах ниже.

```живой Ряд дорог шапки
Дороги = Новый Массив();
Дороги.Добавить(Новый Структура("Подпись, Адрес, Иконка, Активен",
	"Проекты", "/проекты", "куб", Истина));
Дороги.Добавить(Новый Структура("Подпись, Адрес, Иконка", "Команды", "/команды", "стопка"));
Дороги.Добавить(Новый Структура("Подпись, Адрес, Иконка", "Настройки", "/настройки", "шестерёнка"));

HTML = Набор.ДеревоРазделов().Отрисовать(
	Новый Структура("Заголовок, Разделы, Ориентация, Класс",
		"Дороги приложения", Дороги, "горизонталь", "tree--top"));
```

## Вложенность

Дети раздела — массив той же формы, что и разделы. Компонент печатает всё, что пришло: свернуть ветку в браузере нельзя. Хотите показать подразделы только у текущего раздела — кладите `Дети` только ему, это решает сервер.

```живой Ветка открыта у текущего раздела
Ключи = Новый Массив();
Ключи.Добавить(Новый Структура("Подпись, Адрес, Активен",
	"Ключи доступа", "/настройки/доступ/ключи", Истина));
Ключи.Добавить(Новый Структура("Подпись, Адрес", "Участники", "/настройки/доступ/участники"));

Разделы = Новый Массив();
Разделы.Добавить(Новый Структура("Подпись, Адрес, Иконка",
	"Общие", "/настройки", "шестерёнка"));
Разделы.Добавить(Новый Структура("Подпись, Адрес, Иконка, Дети",
	"Доступ", "/настройки/доступ", "замок", Ключи));
Разделы.Добавить(Новый Структура("Подпись, Адрес, Иконка",
	"Уведомления", "/настройки/уведомления", "конверт"));

HTML = Набор.ДеревоРазделов().Отрисовать(Новый Структура("Заголовок, Разделы",
	"Настройки проекта", Разделы));
```

Глубина ограничена четырьмя уровнями: модель приходит извне, и раздел может оказаться в собственных детях. Всё, что глубже, не печатается.

Раздел без адреса или с опасной схемой адреса остаётся в списке подписью, но перестаёт быть ссылкой. Пустой список разделов не печатает ничего.

## Доступность

- Дерево печатается `<nav>` с `aria-label`: по умолчанию «Разделы», своё имя — поле `Заголовок`. На странице с несколькими навигациями имена обязаны различаться, иначе скринридер покажет два одинаковых «Разделы».
- Текущий раздел-ссылка несёт `aria-current="page"`; цвет индикатора — только второй носитель этого смысла.
- Вложенность выражена вложенными списками `<ul>`, поэтому скринридер называет уровень и число пунктов в нём.
- Иконка пункта декоративна, имя пункта — его подпись. Пункт без подписи не называется ничем: подпись обязательна.
- Рубрика — элемент списка с текстом, не ссылка: скринридер читает её на своём месте, перед разделами её группы.
- Опасный раздел отличается не только цветом: он всегда последний, и подпись называет необратимое словами («Удаление проекта»).
