# Подтверждение

Подтверждение — окно перед необратимым действием. Вместо `window.confirm` браузера, где только «ОК» и «Отмена», оно называет последствия, просит набрать имя того, что пропадёт, и держит кнопку цвета ошибки недоступной, пока имя не совпало.

## Когда использовать

- Действие нельзя отменить: удалить проект, отозвать все ключи, передать владение.
- Ошибка дорогая, и одного щелчка мало: эхо-поле заставляет прочитать, что именно удаляется.

Не спрашивайте подтверждения на обратимом: архивировать, скрыть, переименовать. Лишний вопрос приучает жать «Подтвердить» не читая. Если действие обратимо, сделайте его сразу и дайте [тост](тост) с отменой. Целый раздел опасных действий в настройках — [опасная зона](опасная-зона).

## Форма спрашивает подтверждение

`Кит.Подтверждение(Заголовок, Последствия)` — [окно](окно) вида «опасное». Форма называет его словом `СПодтверждением(Подтверждение)`: она получает признак `data-confirm`, и скрипт кита, поймав её отправку, открывает окно вместо того, чтобы отправить форму. Уходит форма кнопкой окна — та ссылается на неё атрибутом `form`.

```живой Удаление проекта — нажмите «Удалить»
Подтверждение = Кит.Подтверждение("Удалить проект «альфа»?",
		"Проект, его ключи и история сборок пропадут навсегда. Вернуть их будет нельзя.")
	.Эхо("name", "альфа").Кнопка("Удалить проект").Якорь("udalit-alfa");
HTML = Кит.Холст(
	Кит.Форма("/проекты/альфа/удалить", Кит.Кнопка("Удалить").Опасная())
		.СПодтверждением(Подтверждение),
	Подтверждение).Токен("т0кен-сессии").Рендер();
```

Слово `Эхо(Имя, Образец)` добавляет поле, в которое человек набирает образец. Поле несёт `pattern` (образец буквально: точка — точка, а не «любой символ») и `required`, поэтому браузер не отправит форму с несовпавшим образцом даже без скрипта, а лист рисует кнопку недоступной, пока поле не совпало. Скрипт ещё и ставит кнопке `disabled`. Подпись поля по умолчанию — из словаря интерфейса (`confirm.echo`), своя — третьим аргументом.

Кнопка подтверждения отправляет поле `confirmed=1`: по нему сервер отличает подтверждённую отправку от первой. Подпись кнопки — словом `Кнопка(Подпись)`, по умолчанию `confirm.ok`; отмена — `confirm.cancel`.

## Без скрипта

Без скрипта форма уходит сразу, без поля `confirmed`. Сервер на это отвечает перенаправлением на GET того же адреса, и там печатает страницу с этим же окном открытым — `Открыто()`. Человек набирает образец, жмёт кнопку, форма уходит уже с подтверждением.

```разметкой Сервер спрашивает подтверждение страницей
Подтверждение = Кит.Подтверждение("Удалить проект «альфа»?", "Вернуть его будет нельзя.")
	.Эхо("name", "альфа").Кнопка("Удалить проект").Якорь("udalit-alfa")
	.Открыто();
HTML = Кит.Холст(
	Кит.Форма("/проекты/альфа/удалить", Кит.Кнопка("Удалить").Опасная())
		.СПодтверждением(Подтверждение),
	Подтверждение).Токен("т0кен-сессии").Рендер();
```

Проверка на клиенте — удобство, гарантия — серверная: сервер сам сверяет эхо-поле с именем и, если не совпало, отвечает 400 той же страницей с окном открытым и отказом под полем — словом `Ошибка(Текст)`.

Эхо-поле закрытого окна печатается заблокированным: оно приписано к форме страницы, и обязательное пустое поле в закрытом окне не дало бы форме уйти вовсе. Открывая окно, скрипт поле открывает, закрывая — блокирует снова.

## Своя форма и кнопка

Подтверждение со своей формой открывает кнопка или пункт меню словом `Открывает(Подтверждение)`, а адрес задаёт слово `Форма(Адрес)`. Подтверждение может лежать и внутри формы — тогда оно отправляет её. Подтверждению без формы нечего отправлять: оно не собирается.

```живой Отзыв ключей — кнопкой
Подтверждение = Кит.Подтверждение("Отозвать все ключи?",
		"Сборки и скрипты, которые входят по этим ключам, перестанут работать сразу.")
	.Кнопка("Отозвать").Форма("/проекты/альфа/ключи/отозвать").Якорь("otozvat");
HTML = Кит.Холст(Кит.Кнопка("Отозвать все ключи").Опасная().Открывает(Подтверждение),
	Подтверждение).Токен("т0кен-сессии").Рендер();
```

Тот же поток с настоящим сервером — в [образце со списком проектов](/образец-окон): удаление спрашивает имя проекта, отказ сервера остаётся в окне, удача закрывает окно и убирает строку.

## Гайдлайны

```делайте Последствия — что пропадёт и что нельзя вернуть
Подтверждение = Кит.Подтверждение("Удалить проект «альфа»?",
		"Проект, его ключи и история сборок пропадут навсегда.")
	.Кнопка("Удалить проект").Форма("/проекты/альфа/удалить").Якорь("delat-posledstviya");
HTML = Кит.Холст(Подтверждение).Токен("т0кен-сессии").Рендер();
```

```не-делайте «Вы уверены?» без последствий: человек не знает, на что соглашается
Подтверждение = Кит.Подтверждение("Вы уверены?", "Продолжить?")
	.Форма("/проекты/альфа/удалить").Якорь("ne-delat-uvereny");
HTML = Кит.Холст(Подтверждение).Токен("т0кен-сессии").Рендер();
```

```делайте Кнопка называет действие
Подтверждение = Кит.Подтверждение("Отозвать ключ «ноутбук»?", "Вход по этому ключу перестанет работать.")
	.Кнопка("Отозвать ключ").Форма("/ключи/ноутбук/отозвать").Якорь("delat-knopka");
HTML = Кит.Холст(Подтверждение).Токен("т0кен-сессии").Рендер();
```

```не-делайте Подтверждение обратимого: приучает жать не читая
Подтверждение = Кит.Подтверждение("Перенести проект в архив?", "Проект можно вернуть из архива.")
	.Форма("/проекты/альфа/архив").Якорь("ne-delat-arhiv");
HTML = Кит.Холст(Подтверждение).Токен("т0кен-сессии").Рендер();
```

## Доступность

- Окно названо вопросом-заголовком, последствия — его описание (`aria-describedby`): скринридер читает их сразу за заголовком.
- Заголовок и кнопка — цветом ошибки, но смысл несут слова, а не цвет: «Удалить проект», а не красный «ОК».
- Эхо-поле подписано, что набрать; отказ сервера — под полем с `role="alert"`, поле помечено `aria-invalid`.
- Отмена — первой и вторичной: Esc и «Отмена» закрывают окно, ничего не отправив, и фокус возвращается туда, откуда открыли.
