# Плитка показателя

Плитка показывает одно число крупно: сколько документов, проектов, ошибок за сутки. Под числом — подпись, что именно посчитано. С адресом плитка целиком ведёт к списку, который стоит за числом.

## Когда использовать

- На обзорном экране нужно ответить «сколько» раньше, чем человек откроет список.
- Несколько сводных показателей стоят рядом и сравниваются между собой.
- За числом есть список, и в него хочется провалиться одним нажатием.

Не берите плитку для доли от предела — для этого есть [полоса заполнения](полоса-заполнения). Сведения об одной записи показывает [сводка](сводка) или [ряд меты](ряд-меты).

## Ссылка на список

Плитка с `Адресом` печатается ссылкой целиком: нажать можно в любое место. На наведении она приподнимается тенью второго уровня. Число, от которого нельзя перейти к данным за ним, — украшение, поэтому давайте адрес, когда список есть.

```живой Кликабельная с пояснением
HTML = Набор.Плитка().Отрисовать(
	Новый Структура("Значение, Подпись, Пояснение, Адрес, Иконка",
		"1 204", "документов", "во всех открытых проектах", "/документы", "куб"));
```

`Пояснение` — мелкая строка под подписью: в каком срезе посчитано число.

В дереве холста плитка собирается словами: значение и подпись позицией, остальное — словами (см. [Язык узлов](язык-узлов)).

```живой Узлом холста — словами
HTML = Кит.Плитка("1 204", "документов")
	.Пояснение("во всех открытых проектах").Адрес("/документы").Иконка("куб").Рендер();
```

## Без ссылки

Без адреса плитка печатается простым блоком. Так показывают число, за которым нет отдельного списка.

```живой Без ссылки
HTML = Набор.Плитка().Отрисовать(Новый Структура("Значение, Подпись",
	"18", "проектов"));
```

## Виды

Вид красит число цветом роли. Ставьте его, когда число само по себе оценка: ноль ошибок — хорошо, семь сбоев — плохо.

```живой Вид ok — всё в порядке
HTML = Набор.Плитка().Отрисовать(Новый Структура("Значение, Подпись, Вид",
	"7", "проектов с источниками", "ok"));
```

```живой Вид warn — стоит взглянуть
HTML = Набор.Плитка().Отрисовать(Новый Структура("Значение, Подпись, Вид",
	"7", "проектов с источниками", "warn"));
```

```живой Вид err — нужна помощь
HTML = Набор.Плитка().Отрисовать(Новый Структура("Значение, Подпись, Вид",
	"7", "проектов с источниками", "err"));
```

```живой Вид accent — главный показатель экрана
HTML = Набор.Плитка().Отрисовать(Новый Структура("Значение, Подпись, Вид",
	"7", "проектов с источниками", "accent"));
```

## Ряд плиток

Плитки ставят рядом [сеткой](сетка): ячейки равной ширины, на узком экране переносятся.

```живой Три показателя сеткой
Ячейки = Новый Массив();
Ячейки.Добавить(Набор.Плитка().Отрисовать(Новый Структура("Значение, Подпись, Адрес",
	"18", "проектов", "/проекты")));
Ячейки.Добавить(Набор.Плитка().Отрисовать(Новый Структура("Значение, Подпись, Адрес",
	"1 204", "документов", "/документы")));
Ячейки.Добавить(Набор.Плитка().Отрисовать(Новый Структура("Значение, Подпись, Вид, Адрес",
	"0", "сбоев за сутки", "ok", "/журнал")));

HTML = Набор.Сетка().Отрисовать(Новый Структура("Ячейки, Колонки, Заголовок",
	Ячейки, 3, "Сводка инсталляции"));
```

## Гайдлайны

```делайте Число отформатировано для человека
HTML = Набор.Плитка().Отрисовать(Новый Структура("Значение, Подпись",
	"1 204", "документов"));
```

```не-делайте Машинное число: разряды не разделены, хвост нулей
HTML = Набор.Плитка().Отрисовать(Новый Структура("Значение, Подпись",
	"1204.00", "документов"));
```

```делайте Подпись говорит, что посчитано
HTML = Набор.Плитка().Отрисовать(Новый Структура("Значение, Подпись, Пояснение",
	"3", "сбоя синхронизации", "за последние сутки"));
```

```не-делайте Подпись «Всего»: неясно, чего и за какой срок
HTML = Набор.Плитка().Отрисовать(Новый Структура("Значение, Подпись",
	"3", "Всего"));
```

```делайте Цвет — у одного числа, которое требует внимания
Ячейки = Новый Массив();
Ячейки.Добавить(Набор.Плитка().Отрисовать(Новый Структура("Значение, Подпись", "18", "проектов")));
Ячейки.Добавить(Набор.Плитка().Отрисовать(Новый Структура("Значение, Подпись, Вид", "3", "сбоя", "err")));

HTML = Набор.Сетка().Отрисовать(Новый Структура("Ячейки, Колонки", Ячейки, 2));
```

```не-делайте Все плитки цветные: глазу не за что зацепиться
Ячейки = Новый Массив();
Ячейки.Добавить(Набор.Плитка().Отрисовать(Новый Структура("Значение, Подпись, Вид", "18", "проектов", "accent")));
Ячейки.Добавить(Набор.Плитка().Отрисовать(Новый Структура("Значение, Подпись, Вид", "3", "сбоя", "warn")));

HTML = Набор.Сетка().Отрисовать(Новый Структура("Ячейки, Колонки", Ячейки, 2));
```

## Доступность

- `Значение` и `Подпись` обязательны: без них кит бросает исключение. Число без подписи не скажет скринридеру, что посчитано.
- Плитка-ссылка — одна ссылка с числом, подписью и пояснением внутри. Скринридер читает её целиком, как фразу.
- Цвет вида — второй носитель смысла. Оценку должна нести и подпись: «сбоя», «ошибок».
- Неверный адрес (чужая схема) кит в ссылку не превращает: плитка остаётся плиткой.

## Узлом холста

```живой Плитка узлом дерева
HTML = Кит.Плитка("18", "проектов").Рендер();
```
