# Движение

Движение в ките — кривые и длительности Material Design 3, а поведение — как у MUI. Почти всё делает CSS. Скрипт кита добавляет четыре вещи, без которых страница всё равно работает целиком.

## Кривые

Кривая задаёт характер движения. Стандартная — для мелких переходов внутри экрана, выразительная — для того, что входит на экран или покидает его.

```директива движение
```

Наведите указатель на строку или встаньте на неё клавишей Tab — точка проедет дорожку с этой кривой за одинаковое время.

| Токен | Значение | Где в ките |
| --- | --- | --- |
| `standard` | `cubic-bezier(.2, 0, 0, 1)` | Слой состояния, подпись поля, цвет шапки, рябь |
| `standard-decelerate` | `cubic-bezier(0, 0, 0, 1)` | — |
| `standard-accelerate` | `cubic-bezier(.3, 0, 1, 1)` | — |
| `emphasized` | `cubic-bezier(.2, 0, 0, 1)` | Раскрывашка, индикатор вкладок, поворот шеврона |
| `emphasized-decelerate` | `cubic-bezier(.05, .7, .1, 1)` | Появление: меню, шторка, лист, диалог, тост, ползунок тумблера |
| `emphasized-accelerate` | `cubic-bezier(.3, 0, .8, .15)` | — |
| `legacy` | `cubic-bezier(.4, 0, .2, 1)` | — |
| `linear` | `cubic-bezier(0, 0, 1, 1)` | — |

Токен кривой — `--md-sys-motion-easing-<кривая>`. Выразительная кривая Material составная, одной `cubic-bezier` её не записать, поэтому `emphasized` в CSS совпадает со стандартной — так же её записывает и сама Material.

## Длительности

Шкала длительностей Material 3 — четыре ступени по четыре шага.

| Ступень | 1 | 2 | 3 | 4 |
| --- | --- | --- | --- | --- |
| `short` | 50 | 100 | 150 | 200 |
| `medium` | 250 | 300 | 350 | 400 |
| `long` | 450 | 500 | 550 | 600 |
| `extra-long` | 700 | 800 | 900 | 1000 |

Токен длительности — `--md-sys-motion-duration-<ступень><шаг>`, значения в миллисекундах. Чем больше путь и площадь элемента, тем длиннее его движение: слой наведения — 150, шторка — 300.

Прежние имена остались псевдонимами:

| Прежнее имя | Значение | Для чего |
| --- | --- | --- |
| `--motion-fast` | `short3`, 150 | Наведение, фокус, переключатель |
| `--motion-medium` | `medium1`, 250 | Раскрытие секции, поворот шеврона |
| `--motion-slow` | `medium2`, 300 | Смена раздела настроек |
| `--motion-ease` | `standard` | Кривая по умолчанию |
| `--motion-pulse` | 1600 | Оборот индикатора занятой кнопки |

## Что делает CSS

Всё движение, которому хватает состояния разметки, лист кита делает сам — без единой строки скрипта.

| Что | Как |
| --- | --- |
| Слой состояния | Фон за `short3`, кнопка на наведении приподнимается тенью за `short4` |
| Подпись поля | Уменьшается до 4/5 (12 пикселей) и поднимается к верхнему краю за `short4`; путь короче прежнего — поле 44 пикселя, а не 56; у поля со `СкрытаяМетка` метки на экране нет — нечему и плыть, пример виден всегда |
| Рамка поля в фокусе | Из `outline` (в покое, не меньше 3:1 к заливке поля и карточке) становится 2 пикселя цветом primary за `short3`; содержимое поля не сдвигается — второй пиксель рисует кольцо внутрь |
| Тумблер | Ползунок едет за `medium1`; поповер справки «?» рядом с ним проявляется, как у поля |
| Выпадающее меню | Растёт из угла у кнопки, как Grow у MUI: проявление за `short4`, размер за `medium1`; кольцо-контур растёт вместе с ним |
| Шторка единого меню | Выезжает из-за левого края за `medium2`; заголовки групп и рубрики в ней — одним стилем, title-small обычным регистром |
| Лист меню на телефоне | Выезжает снизу за `medium2` |
| Окно на телефоне | Базовое окно проявляется по центру, как на широком экране; листом во весь экран встаёт только окно `ВоВесьЭкран` и окно с шагами — без своего движения, тем же проявлением |
| Диалог | Проявляется и чуть вырастает, скрим набирает плотность вместе с ним — `medium2`; растёт из центра экрана, в каком бы контейнере его ни напечатали |
| Раскрывашка | Высота содержимого едет от нуля до своей за `medium2`, как аккордеон MUI |
| Тост | Въезжает снизу на 8 пикселей и проявляется за `medium2` |
| Шапка | Меняет цвет и даёт тень за `medium1`, когда страница прокручена; линия `outline-variant` под ней стоит всегда и не анимируется |
| Сегменты | Заливка выбранного за `short3`, галка въезжает за `short4`; набор полей отмеченного сегмента показывает `:has(:checked)`; на телефоне группа — во всю ширину равными колонками, подпись переносится, а не обрезается; источник значения (`Источник`) стоит справа на строке подписи группы и не движется |
| Подсказка | Поповер проявляется за `short4`; открывает и закрывает его движок (`popover`) |
| Сетка | Не движется: число колонок меняют точки перелома листа, ряд перестраивается сразу, без анимации и без скрипта; у сеток в 3 и 4 колонки число — потолок; у сетки `ПолныеРяды` на смене точки перелома хвост неполного ряда сразу пропадает или возвращается — лист, без скрипта |
| Шапка карточки объекта | Не движется: имя сжимается последним и не уже девяти знаков, в узкой карточке плашки сразу встают строкой под имя — по ширине самой карточки (`@container`), а не окна |
| Блок команды | Не движется: длинная строка переносится у края блока, кнопка «Копировать» держит ширину; на телефоне она сразу встаёт под код, если рядом не помещается |
| Окно без скрипта | Окно, напечатанное открытым (`?окно=…`, отбитая форма), без скрипта не модальное, но стоит, как модальное: закреплено по центру экрана выше шапки и секций, подложка гасит страницу (тень со спредом во весь экран) и ловит щелчок мимо окна, страница под ним прокручивается; появление то же — проявление с небольшим ростом, и доходит до конца без `:modal` |
| Секция со списком карточек | Не движется: на телефоне (до 600 px) карточка или секция с сеткой карточек объектов становится плоской — без кольца, заливки и боковых полей, — а карточки объектов в ней остаются карточками во всю ширину экрана без полей страницы (на 390 — 358 px), без черты между ними; без `:has()` — прежний вид |
| Карточка в карточке | Не движется: на телефоне (до 600 px) вложенная карточка, секция и таблица сразу становятся частью родителя — без тени, кольца и боковых полей, с чертой между соседями; поля страницы и карточки — 16 px |
| Ссылка в тексте | Не движется: подчёркнута всегда, а не только под указателем; ссылка навигации, кнопки, ячейки таблицы и имя карточки подчёркиваются только под указателем, как прежде |
| Строка поиска со значком | Не движется: значок «поиск» стоит внутри рамки поля справа на любой ширине, на телефоне ничего не переносится; на нажатии — рябь и слой состояния кнопки-значка. Поиск дерева галок (дев-сборка 8) — той же строкой |
| Кнопка без отправки | Не движется: кнопка `БезОтправки` в форме — `type="button"`, на нажатии та же рябь и слой состояния, что у любой кнопки, а форма не уходит |
| Плашка с крестиком формой | Не движется: плашка со словом `Снять` печатается внутри своей тихой формы (`tag-form`) — строчным блоком, и в ряду плашек форма встаёт, как сама плашка; крестик — кнопка отправки, ответ ложится на страницу тихой отправкой |
| Цели касания | Не движутся: на касании (`pointer: coarse`) область нажатия кнопки-значка, крестика плашки, кружка акцента и «?» — 48 × 48 при прежнем видимом размере; слой состояния и рябь — в видимых границах |
| Шапка врезки | Маркер раскрытия впереди поворачивается на четверть оборота у открытой врезки и подробности (короткая стандартная кривая); дети шапки — значок, подпись, плашки — стоят в строку с зазором 8 px и переносятся вместе |
| Панель сегмента | Не движется: панель вне набора (`ПанельСегмента`) появляется сразу, как только в форме отмечен её сегмент, — лист по месту группы и номеру сегмента, без скрипта; без `:has()` видны все панели |
| Подпись сегмента на телефоне | Не движется: подпись переносится только между словами; колонка сегмента не уже самого длинного слова своей подписи, остаток ширины — поровну, и однословная подпись делает свою колонку шире соседей, а не рвётся посреди слова |
| Колонка чисел | Не движется: число и заголовок над ним — по правому краю, цифры одной ширины; в таблице карточками на телефоне число сразу встаёт слева под подписью — лист, без скрипта |
| Прочерк пустой ячейки | Не движется: печатает сервер — прочерк таблицы, у колонки свой поверх него (`Колонка(…).Пустое(…)`), у колонки действий его можно снять |

Меню, шторка и диалог открываются движком браузера по атрибутам `popover` и `<dialog>`. Их выход тоже анимирован: `display` и верхний слой снимаются дискретно, после движения. Движок, который так не умеет, открывает и закрывает их мгновенно — поведение то же, только без анимации.

Раскрывашка анимируется там, где движок знает `interpolate-size` и `::details-content`. Остальные открывают её сразу, как раньше.

```живой Подпись поля плавает, рамка в фокусе становится primary

	"название", "Название проекта", "Видно всем участникам."));
```

```живой Ползунок тумблера
HTML = Набор.Тумблер().Отрисовать(
	Новый Структура("Имя, Метка, Включено, ПодписьВкл, ПодписьВыкл",
		"видимость", "Видимость проекта", Ложь, "публичный", "приватный"));
```

```живой Раскрывашка — высота едет до своей

	.Шапка("Подробности сборки").Рендер();
```


## Что делает скрипт

Скрипт кита `oscript-ui.js` делает то, чего одним CSS не сделать. Каркас страницы подключает его сам, перед скриптом инсталляции. Глобальных имён скрипт не заводит и разметку не печатает — только атрибуты, рябь и текст отказа под полем (тот же `field__error`, что печатает сервер); новую плашку списка он клонирует из шаблона, который напечатал сервер.

1. **Рябь.** Круг расходится от точки нажатия и гаснет, как в MUI. С клавиатуры, на Enter и пробеле, рябь идёт из середины. Даже от короткого касания она успевает показаться — живёт не меньше 225 миллисекунд. Рябь есть у кнопки, чипа, вкладки, пункта дерева, страницы пагинации, хода в шапке, плашки-ссылки, плитки-ссылки и кнопок копирования.
2. **Пустота поля.** Атрибут `data-empty` у пустого текстового поля опускает подпись на место значения. Скрипт следит за вводом, сбросом формы и автозаполнением браузера. У выбора, даты, цвета и файла подпись всегда наверху: они всегда что-то показывают.
3. **Шапка при прокрутке.** Атрибут `data-scrolled` у шапки, когда страница сдвинута вниз. По нему шапка берёт цвет контейнера и тень второго уровня.
4. **Индикатор вкладок.** При переходе по вкладке того же ряда скрипт даёт активной вкладке имя перехода (`data-vt`), и движок везёт индикатор со старой страницы на новую (View Transitions между документами). Сама страница меняется сразу — двигается только индикатор, как у Tabs в MUI.
5. **Закрываемый тост.** Крестик `data-close` гасит тост и убирает его со страницы.
6. **Тихая отправка.** Форма с `БезПерезагрузки()` уходит в фоне, и ответ сервера ложится на страницу на место, без перезагрузки. Подробно — в разделе [Формы деревом](формы-деревом).
7. **Тема сразу.** Переключатель темы (форма с `data-theme-toggle`) перекрашивает страницу, не дожидаясь сервера: обе палитры уже лежат в голове страницы, и смена темы — один атрибут. Где движок умеет View Transitions, старая тема растворяется в новой. Сервер узнаёт о смене тем же запросом, что и без скрипта, только в фоне, и его ответ страницу не трогает: куку ставит ответ, а из него скрипт берёт только сам переключатель — значок и подсказку. Куда бы сервер ни перенаправил ответ, хоть на главную, человек остаётся на своей странице, с прокруткой и введённым; сбой сети тоже ничего не меняет.
8. **Отправка по изменению и несохранённое.** Тумблер с `СохранятьСразу` отправляет форму сам; запасную кнопку отправки его формы, где других полей нет, лист при работающем скрипте прячет, а у формы без своей кнопки её печатает сам кит (`toggle__save`, словарь `toggle.save`) и при скрипте тоже прячет (`@media (scripting: enabled)`) — в любом месте страницы, а не только в записи реестра. Панель сохранения `data-savebar` подсвечивается на первом же вводе в её форму, и подсветку снимает ответ сервера после сохранения. Форму, в которой правили, пока шёл запрос, скрипт помечает `data-edited`, и ответ её введённое не сбрасывает.
9. **Окна.** Команды кнопки `show-modal` и `close` (`command` и `commandfor`) исполняет движок; движку, который их ещё не знает, их доучивает скрипт. Ссылка-кнопка с `data-opens` (кнопка `Открывает(Окно)`, когда у окна или у кнопки есть `Адрес`) не уводит со страницы: скрипт открывает окно с этим идентификатором на месте, без запроса; без скрипта она ведёт на страницу, где сервер печатает окно открытым. Окна и подтверждения из записей [реестра](реестр) сервер печатает после списка, а не в теле записи: скрипт открывает их на виду, даже когда запись свёрнута. Окно, которое сервер напечатал открытым, скрипт поднимает модальным. Форма в окне после удачной тихой отправки закрывает окно и ставит фокус на элемент с `data-focus` (слово `Фокус()`), после отказа (4xx) остаётся в окне с отказами у полей; ответ 2xx, который сам печатает другое окно открытым, закрывает окно формы и поднимает окно ответа модальным, а открытое окно, которого в ответе нет, закрывает — раздел «В окне» страницы [Формы деревом](формы-деревом).
10. **Окно по адресу.** Кнопка с `data-window-link` (`Кит.ОкноПоАдресу`) не уводит на страницу с окном: скрипт берёт её запросом в фоне, кладёт окно в одну на страницу оболочку `data-window-shell` и открывает. Не вышло — показывает тост `data-window-error`, напечатанный сервером рядом с оболочкой. Подробно — [Окно](окно).
11. **Подтверждение.** Форма с `data-confirm` (`СПодтверждением`) не уходит сразу: скрипт открывает окно [подтверждения](подтверждение), а уходит форма его кнопкой. Значение признака — идентификатор окна, и обслуживает его скрипт кита: свой `window.confirm` на `data-confirm` приложение не вешает. Эхо-поле держит эту кнопку недоступной (`disabled`), пока набранное не совпало с образцом. Форма из набора записи [реестра](реестр) печатается дважды — пунктом меню ⚙ и кнопкой внизу, — но `id` несёт только пункт меню: копия внизу без `id` тоже открывает подтверждение своим `data-confirm`, а кнопка окна шлёт форму меню.
12. **Шаги.** У [шагов](шаги) видна одна панель, над ней полоса номеров, под ней «Назад / Дальше». «Дальше» и Enter в поле пускают на следующий шаг, только когда поля текущего годны: первому негодному браузер показывает свой отказ (`reportValidity`). Признаки: `data-steps` (корень, номер шага, с которого начать), `data-steps-bar`, `data-steps-go`, `data-steps-panel`, `data-steps-back`, `data-steps-next`, `data-steps-submit` печатает сервер; `data-steps-live` у корня и `data-steps-done` у пройденного шага ставит скрипт. Без скрипта шаги — панели подряд, и форма отправляется целиком.
13. **Сегменты и подсказка (0.12).** Своего раздела в скрипте у них нет. [Сегменты](сегменты) со словом `СохранятьСразу` печатают у каждой радиокнопки `data-autosubmit` — тот же признак, что у тумблера, его исполняет пункт 8. Признак `data-segment` (значение сегмента) у панели набора полей печатает сервер для своего CSS и скрипта страницы; наборы переключает лист. Панель вне набора (`ПанельСегмента`) и её группа несут `data-segments-slot` (место группы в форме), панель — ещё `data-segments-number`; её тоже переключает лист. [Подсказка](подсказка) открывается движком по `popovertarget`.
14. **Поле-список.** У [списка](поле#список) скрипт показывает плашки, напечатанные сервером, отдаёт имя поля скрытому полю `data-chips-value` и пишет в него строку через запятую при каждой правке. Enter, запятая и уход из строки делают из набранного плашку — её скрипт клонирует из шаблона `data-chips-chip`, напечатанного сервером; крестик `data-chips-remove` и Backspace в пустой строке плашку снимают. Признаки: `data-chips`, `data-chips-value`, `data-chips-chip`, `data-chips-remove` печатает сервер; `data-chips-live` у корня ставит скрипт. Без скрипта это обычное текстовое поле со строкой.
15. **Поле цвета.** У [поля цвета](поле#цвет) скрипт показывает ряд образцов `data-swatches-row` и держит его в согласии с полем кода: кружок пишет свой код, набранный код отмечает свой кружок, палитра `data-swatches-own` — «свой»; имя выбранного пишет в `data-swatches-name`. Корень — `data-swatches`. Палитра кита (`ОбразцыТемы`) — те же кружки, своего поведения у неё нет. Без скрипта ряд спрятан, и код набирают руками.
16. **Проверка до отправки.** Поле с текстами отказов (`data-error-required`, `-type`, `-number`, `-pattern`, `-minlength`, `-maxlength`, `-min`, `-max` — их печатает [поле](поле) из слов `Длина`, `Шаблон`, `ПроверкаДоОтправки`) не показывает пузырь браузера: на попытке отправить и на уходе из поля скрипт пишет текст отказа (уход в кнопку отправки своей формы отказ не печатает — его напечатает проверка отправки на том же щелчке, и строка отказа не сдвигает кнопку из-под отпускаемой мыши) в его `field__error`, ставит `aria-invalid` и ссылку из `aria-describedby`, фокус — на первое негодное поле; исправленное поле снимает отказ на вводе. Поле с `data-check` (`ПроверкаНаСервере`) спрашивает адрес, свободно ли значение: `200` — свободно, `409` с текстом — занято.
17. **Тост из ответа.** Новые тосты из ответа тихой отправки скрипт поднимает вниз экрана и показывает по одному, каждый 5 секунд (`data-toast-live`: `wait`, `show`, `gone`); пока на тосте мышь или фокус, время стоит. Тост с ролью `alert` остаётся на своём месте — подробно на странице [Тост](тост).
18. **Слот картинки.** На файловом поле [слота картинки](картинка) признак `data-autosubmit`: выбор файла отправляет форму слота сам, тихой отправкой (multipart), а выбранная картинка сразу встаёт в предпросмотр из памяти браузера. Отказ (4xx) ложится на страницу, как любой ответ тихой отправки: под слотом встаёт напечатанный сервером отказ (`Ошибка`), в рамке — прежняя картинка. Меню ⚙ «Вернуть стандартную» отправляет форму сброса с `data-confirm` — через подтверждение. Закрытое окно сброса возвращает фокус на кнопку ⚙.
19. **Зеркало и образец.** Узел с `data-mirror="имя"` (слово `Зеркало`) показывает текущее значение поля с этим именем при каждом вводе; поле цвета пишет свойство CSS `--mirror-<имя>`; узел с `data-mirrors="имя …"` (слово `ЗеркалоПризнаком`) получает значение поля в признак `data-mirror-<имя>`, вид по нему задаёт лист приложения; свойство `--mirror-accent` в образце лист сразу превращает в акцент узла — основная кнопка, плашка и ссылка внутри перекрашиваются без своего движения. Кнопки `data-preview-theme` [образца](образец) меняют `data-theme` его рамки (`aria-pressed`), а палитру для рамки скрипт собирает из блока токенов страницы и подключает листом без разметки (`adoptedStyleSheets`).
20. **Таблица карточками и свойства (0.13).** Своего поведения у них нет. Запись-карточку раскладывает лист: заглавная ячейка `cell-title` — первой строкой, ячейка меню `cell-menu` — в правом верхнем углу. Секрет [свойства](списки) открывает лист по галке «Показать». Кнопку копирования свойства с `data-copy` — тот же признак, что у [блока команды](блок-команды) и поля из конфига, — оживляет скрипт инсталляции. Скрипт кита даёт этой кнопке и кнопке «Показать» только рябь.
21. **Страницы и отбор без перезагрузки.** Ссылка с `data-quiet` — шаг [пагинации](пагинация) и ссылка [сортировки колонки](таблица-деревом) со словом `БезПерезагрузки` — не уводит со страницы: скрипт берёт её адрес запросом в фоне и кладёт ответ на место тем же морфингом, что ответ тихой формы, прокрутка и фокус остаются, адрес уходит в историю вкладки (`pushState`). Пока переход в пути, навигация или таблица помечены `aria-busy`. Тихая GET-форма — [строка поиска и форма отбора](форма-отбора) — ещё и уходит сама по изменению поля: через 0,4 с после последней буквы, выбор — почти сразу; тот же отбор дважды не уходит, и форма после ответа не сбрасывается. «Назад» и «Вперёд» по записям истории, которые пометил скрипт, тоже берутся тихо и возвращают прокрутку и значения полей отбора. Щелчок с Ctrl/Cmd, Shift или средней кнопкой — по-прежнему браузеру. Без скрипта это обычные ссылки и обычная GET-форма.
22. **Дерево галок (0.13).** Щелчок по галке ветки (`data-checktree-box`) [дерева галок](дерево-галок) раздаёт её состояние детям, а ветки выше пересчитывают «частично» по детям (`indeterminate`; напечатанное сервером `data-checktree-state` скрипт не переписывает). «Показать ещё» (`data-checktree-more`) и раскрытие пустой ветки берут страницу детей запросом в фоне и дописывают её в список `data-checktree-page` с тем же ключом. «Найти» в поиске `data-checktree-search` берёт ответ `data-checktree-found` с адреса поиска и кладёт его на место веток. У дерева `data-checktree-edits-only` правки галок и режимов (`data-checktree-modes`) копятся плашками в `data-checktree-edits` — плашку скрипт клонирует из шаблона `data-checktree-chip` с текстами `data-checktree-text-on`, `-off`, `-mode`, крестик `data-checktree-undo` снимает правку, — и форма отдаёт только их: `правки=1`, `включить`, `снять`, `режим`. Обёртка — `data-checktree-set`. Режим ветки скрипт узнаёт по значению радиокнопки: в «все» и «никакие» дети заперты (`inert`), в «выбранные» и «кроме» (дев-сборка 8) правятся; переход «все» → «кроме» оживляет детей отмеченными, «кроме» → «все» возвращает их галкам напечатанное. Скрытое поле показанного `data-checktree-shown` (слово `ПравкиБезСкрипта`) при отправке без правок скрипт пересчитывает по всем галкам обёртки. Крестик плашки отмеченного вне показанного (ряд `data-checktree-picked`, плашка `data-checktree-pick`) у дерева с правками становится правкой того же узла в общем ряду, и ряд правок держит плашку зачёркнутой, пока правка стоит; без скрипта он — галка формы, и зачёркивает плашку лист. Строку сводки правок `data-checktree-changes` (слово `СводкаПравок`) скрипт пишет по плашкам ряда: «Изменений: 3 (+2 −1)», тексты — `data-checktree-text-changes` и `-split`; без правок она спрятана. Без скрипта ветка показывает первые 50, ссылка и кнопка поиска ведут на свои адреса, и форма отдаёт галки.
23. **Подсказка обрезанного имени (0.13).** Имя [карточки объекта](раскладка#статья), которое лист обрезал многоточием, на наведении получает `title` с именем целиком; у целого имени подсказки нет, свой `title` от сервера скрипт не трогает. Без скрипта имя так же обрезано, а целиком его читает скринридер и видно по ссылке.

Без скрипта страница работает и выглядит законченной: подпись поля просто стоит наверху, ряби нет, шапка без тени, индикатор появляется на новом месте, а формы и переключатель темы отправляются обычной навигацией с перезагрузкой. Окно открывает движок, а где он команд не знает — сервер печатает его открытым по адресу с `?окно=…`; подтверждение спрашивает сервер страницей. Негодное поле не пускает браузер своим пузырём, а то, что знает только сервер, он отбивает отказом под полем; тост стоит на странице, где его напечатал сервер. Слот картинки показывает системное файловое поле и кнопку отправки, образец — в теме страницы, а зеркала — то, что напечатал сервер. Секрет свойства открывается и без скрипта, а значение для копирования выделяют мышью.

```живой Рябь — нажмите на кнопку
HTML = Набор.Кнопка().Отрисовать(Новый Структура("Подпись, Иконка", "Сохранить", "сохранить"))
	+ Набор.Кнопка().Отрисовать(Новый Структура("Подпись, Вариант", "Отмена", "вторичная"))
	+ Набор.Кнопка().Отрисовать(Новый Структура("Подпись, Вариант, Иконка, ТолькоИконка",
		"Настройки", "ссылка", "шестерёнка", Истина));
```

## Меньше движения

Человек может попросить систему убрать движение — настройка `prefers-reduced-motion`. Кит её слушает:

- лист сводит длительность всех анимаций и переходов почти к нулю, повторы — к одному, плавную прокрутку отключает;
- скрипт перестаёт рождать рябь.

Состояния при этом меняются как прежде — пропадает только путь между ними.

## Гайдлайны

```делайте Длительность и кривая — токенами шкалы
HTML = Набор.Кнопка().Отрисовать(Новый Структура("Подпись, Вариант", "Наведите", "вторичная"));
```

```не-делайте Своя секунда по прямой: наведение тянется, интерфейс кажется вязким
HTML = "<button class=""button button--ghost"" type=""button"" "
	+ "style=""transition:background-color 1200ms linear"">Наведите</button>";
```

```делайте Занятость — индикатором внутри кнопки
HTML = Набор.Кнопка().Отрисовать(Новый Структура("Подпись, Занята", "Сохраняется", Истина));
```

```не-делайте Элемент прыгает ради внимания: бесконечное движение отвлекает и укачивает
HTML = "<button class=""button"" type=""button"" "
	+ "style=""animation:ui-toast 600ms ease-in-out infinite alternate"">Сохраняется</button>";
```

## Доступность

- Настройка «меньше движения» гасит анимации кита целиком. Своё движение в листе инсталляции тоже оборачивайте в `@media (prefers-reduced-motion: reduce)`.
- Движение ничего не сообщает в одиночку: занятая кнопка несёт `aria-busy`, тост — роль `status` или `alert`.
- Рябь — декорация: её контейнер скрыт от скринридера (`aria-hidden`) и не ловит указатель.
