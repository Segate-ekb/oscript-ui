# Ряд меты

Ряд меты — сведения об объекте одной строкой: автор, число открытий, дата обновления. Каждый пункт — значок и значение. Подпись пункта видят мышью во всплывающей подсказке, а скринридер слышит её текстом.

## Когда использовать

- Под именем объекта нужно коротко сказать, чей он, когда обновлён и сколько им пользуются.
- Сведений немного, два-четыре, и каждое понятно по значку.
- Одно из сведений ведёт дальше: автор — на страницу автора.

Не берите ряд меты для сведений, которые сравнивают между записями, — для этого есть [таблица](таблица). Подписанные строки «подпись — значение» в записи списка печатает [сводка](сводка). Ряд меты уже встроен в [шапку объекта](шапка-объекта) — её поле `Мета`.

## Значок и значение

У пункта есть `Подпись`, `Значение` и `Значок`. Со значком на экране видны значок и значение, а подпись уходит в подсказку и в скрытый текст для скринридера. С `Адресом` значение становится ссылкой.

```живой Со значками, второй пункт — ссылка
Элементы = Новый Массив();
Элементы.Добавить(Новый Структура("Подпись, Значение, Значок",
	"Открытий", "1 204", "скачать"));
Элементы.Добавить(Новый Структура("Подпись, Значение, Значок, Адрес",
	"Автор", "а.иванова", "аккаунт", "/люди/а.иванова"));

HTML = Набор.РядМеты().Отрисовать(Элементы, "objhead__meta", "objhead__meta-item");
```

Пункты разделяет точка «·». Классы ряда и пункта передаёт вызывающий: оформление у ряда в шапке и в карточке объекта разное.

## Без значка

Пункт без значка печатается текстом «подпись: значение». Так пишут сведения, для которых нет понятного значка.

```живой Без значка — пара «подпись: значение»
Элементы = Новый Массив();
Элементы.Добавить(Новый Структура("Подпись, Значение", "Обновлено", "вчера"));

HTML = Набор.РядМеты().Отрисовать(Элементы, "objhead__meta", "objhead__meta-item");
```

Пункт только с подписью или только со значением печатается тем, что есть. Пункт, где нет ни того, ни другого, пропускается.

## Пустой ряд

Ряд без пунктов не печатается вовсе — ни пустой строки, ни отступа. Поэтому сведения передают как есть, без проверки на пустоту.

```живой Пустой ряд не печатается вовсе
HTML = Набор.РядМеты().Отрисовать(Новый Массив(),
	"objhead__meta", "objhead__meta-item");
```

## Доступность

- Значок декоративен (`aria-hidden`). Подпись печатается рядом скрытым текстом, и скринридер читает «Автор: а.иванова».
- Та же подпись стоит в `title` пункта — подсказка для мыши. С клавиатуры и на телефоне её не видно, поэтому значение должно быть понятно и без неё.
- Значение со ссылкой — обычная ссылка с текстом значения.

## Узлом холста

На [холсте](холст) классы даёт не вызывающий, а вид ряда: «шапка» — ряд в шапке объекта, «карточка» — ряд в карточке объекта. Другого вида не бывает, и кит бросит исключение.

```живой Узлом дерева — классы даёт вид, а не вызывающий
Элементы = Новый Массив();
Элементы.Добавить(Новый Структура("Подпись, Значение", "Обновлён", "вчера"));

HTML = Кит.РядМеты(Элементы, "карточка").Рендер();
```
