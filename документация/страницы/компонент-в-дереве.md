# Компонент в дереве

Компонент кита входит в дерево узлом рода «компонент»: `Кит.Кнопка(...)`, `Кит.Карточка(...)`, `Кит.Плашка(...)`. Он печатает себя целиком по своей модели, а тот, у кого есть слот, принимает детей — они становятся его телом.

## Как компонент живёт в дереве

Компонент можно позвать двумя путями. Через `Набор` он сразу возвращает строку. Через `Кит` — узел, который кладут в дерево и печатают вместе со всем экраном. Модель одна и та же.

- **Компонент без слота** — лист дерева: кнопка, поле, иконка, плитка, пагинация. Разметка собирается сразу, детей он не принимает.
- **Компонент со слотом** — карточка и опасная зона (дети — тело), шапка объекта (дети — действия), плашка (дети — содержимое вместо значка и текста). Рисуется на печати, когда дети уже собраны.
- **Компонент со списком** — сетка: каждый ребёнок становится своей ячейкой.

От узла `Готовое` компонент отличается тем, что назван. В дереве экрана видно `компонент[карточка]`, а не безымянный кусок HTML.

## Слот: дети становятся телом

У карточки слот — тело. Всё, что кладут в узел карточки, печатается внутри неё.

```живой Компонент печатает себя целиком и принимает детей
Карточка = Кит.Карточка(Новый Структура("Заголовок", "Проекты"));
Карточка.Добавить(Кит.Кнопка(Новый Структура("Подпись, Вариант",
	"Создать", "основная")));

HTML = Карточка.Рендер();
```

У шапки объекта дети становятся действиями — кнопками справа от имени.

```живой Шапка объекта: дети — её действия
Шапка = Кит.ШапкаОбъекта(Новый Структура("Имя, Иконка, Описание",
	"отчёт", "куб", "Отчёт о продажах за квартал"));
Шапка.Добавить(Кит.Кнопка(Новый Структура("Подпись, Вариант, Иконка",
	"Скачать", "вторичная", "скачать")));

HTML = Шапка.Рендер();
```

У плашки дети печатаются вместо значка и текста модели. Так плашку собирают из своих узлов — например, с машинным значением внутри.

```живой Плашка, собранная детьми
Плашка = Кит.Плашка(Новый Структура("Вид", "accent"));
Плашка.Добавить(Кит.Текст("ветка "));
Плашка.Добавить(Кит.Код("main"));

HTML = Плашка.Рендер();
```

## Список: каждый ребёнок — ячейка

Сетка раскладывает детей сама, поэтому получает их по одному, а не склеенной строкой.

```живой Сетка из карточек
Сетка = Кит.Сетка(Новый Структура("Колонки", 2));
Для Каждого Имя Из СтрРазделить("альфа,бета", ",") Цикл
	Карточка = Сетка.Добавить(Кит.Карточка(Новый Структура("Заголовок", Имя)));
	Карточка.Добавить(Кит.Примечание("проект команды", "описание"));
КонецЦикла;

HTML = Сетка.Рендер();
```

## Компонент виден по имени

`Дерево()` показывает компонент его видом: `компонент[карточка]`, `компонент[кнопка]`. По дереву видно, из чего собран экран, не открывая разметку.

```живой В дереве компонент виден по имени, а не куском HTML
Карточка = Кит.Карточка(Новый Структура("Заголовок", "Проекты"));
Карточка.Добавить(Кит.Кнопка(Новый Структура("Подпись", "Создать")));

HTML = Кит.Код(Карточка.Дерево(), "блочный").Рендер();
```

Компонент без слота детей не принимает: внутрь него не кладут, и кит скажет об этом на `Добавить`.

```живой Кнопка не холст — исключение
Попытка
	Кит.Кнопка(Новый Структура("Подпись", "Создать")).Добавить(Кит.Текст("ещё"));
Исключение
	HTML = Кит.Примечание(КраткоеПредставлениеОшибки(ИнформацияОбОшибке())).Рендер();
КонецПопытки;
```

## Гайдлайны

```делайте Тело карточки — детьми узла
Карточка = Кит.Карточка(Новый Структура("Заголовок", "Ключи доступа"));
Карточка.Добавить(Кит.Примечание("Ключ показывается один раз."));
Карточка.Добавить(Кит.Кнопка(Новый Структура("Подпись, Вариант", "Создать ключ", "вторичная")));
HTML = Карточка.Рендер();
```

```не-делайте Тело строкой через Набор и Готовое: в дереве — безымянный HTML
Тело = Набор.Кнопка().Отрисовать(Новый Структура("Подпись, Вариант", "Создать ключ", "вторичная"));
HTML = Кит.Готовое(Набор.Карточка().Отрисовать(
	Новый Структура("Заголовок, Тело", "Ключи доступа", Тело))).Рендер();
```

```делайте Компонент узлом кита — Кит.Плашка(…)
Ряд = Кит.Ряд("признаки");
Ряд.Добавить(Кит.Плашка(Новый Структура("Текст, Вид", "открытый", "ok")));
Ряд.Добавить(Кит.Плашка(Новый Структура("Текст", "команда")));
HTML = Ряд.Рендер();
```

```не-делайте Компонент строкой в Готовое(): дерево его не видит
Ряд = Кит.Ряд("признаки");
Ряд.Добавить(Кит.Готовое(Набор.Тег().Отрисовать(Новый Структура("Текст, Вид", "открытый", "ok"))));
Ряд.Добавить(Кит.Готовое(Набор.Тег().Отрисовать("команда")));
HTML = Ряд.Рендер();
```

## Доступность

Компонент в дереве печатает ровно ту же разметку, что через `Набор`. Всё, что он делает для скринридера, описано на его странице: [кнопка](кнопка), [карточка](карточка), [шапка объекта](шапка-объекта), [плашка](плашка). Слот добавляет только то, что вы положили в него сами — подписывайте значки и называйте кнопки.
