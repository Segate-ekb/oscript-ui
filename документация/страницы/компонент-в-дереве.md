# Компонент в дереве

Компонент кита входит в дерево узлом рода «компонент»: `Кит.Кнопка(...)`, `Кит.Карточка(...)`, `Кит.Плашка(...)`. Первым аргументом — то, без чего он бессмыслен, остальное — слова, которые пишут поля его модели. Он печатает себя целиком, а тот, у кого есть слот, принимает детей — они становятся его телом.

## Как компонент живёт в дереве

Компонент можно позвать двумя путями. Через `Набор` он сразу возвращает строку — это «компонент строкой». Через `Кит` — узел, который кладут в дерево и печатают вместе со всем экраном. Разметка у обоих одна, байт в байт.

- **Компонент без слота** — лист дерева: кнопка, поле, иконка, плитка, пагинация. Детей он не принимает.
- **Компонент со слотом** — карточка и опасная зона (дети — тело), шапка объекта (дети — действия), плашка (дети — содержимое вместо значка и текста).
- **Компонент со списком** — сетка (каждый ребёнок — своя ячейка), табы (дети — вкладки `Кит.Вкладка`), меню (дети — пункты `Кит.ПунктМеню` и формы).

Компонент рисуется на печати: слова дописывают его модель до самого `Рендер()`, а содержимое слота — это дети, которых к моменту рождения ещё нет. От узла `Готовое` компонент отличается тем, что назван: в дереве экрана видно `компонент[карточка]`, а не безымянный кусок HTML.

## Слова — поля модели

Слово компонента пишет поле его модели и возвращает тот же узел. Булево поле — слово без аргумента (`.Обязательное()`, `.ТолькоИконка()`), поле-список — слово, которое добавляет один элемент (`.Мета(…)`, `.Вариант(…)`, `.Параметры(…)`). Общие слова узла — `Подпись`, `Подсказка`, `Вид`, `Якорь`, `Иконка` — у компонента значат то, что значат в его модели. У кнопки есть сахар варианта и размера: `.Основная() .Вторичная() .Опасная() .Ссылкой() .Малая() .Большая()`.

```живой Компонент словами печатает то же, что структурой
Словами = Кит.Кнопка("Отозвать").Опасная().Малая().Иконка("корзина").Имя("операция", "отзыв");

Структурой = Кит.Кнопка(Новый Структура("Подпись, Вариант, Размер, Иконка, Имя, Значение",
	"Отозвать", "опасная", "малый", "корзина", "операция", "отзыв"));

HTML = Кит.Ряд("действия", Словами, Структурой).Рендер();
```

Структура-модель — прежний вид модели: `Кит.Кнопка(Новый Структура(…))` работает как раньше, и слова дописывают её. Полный список слов каждого компонента — на странице [Язык узлов](язык-узлов) и в справке его функции кита.

Слово, которого компонент не знает, останавливает сборку и перечисляет его слова: опечатка не даст молча компонент не того вида.

```живой Неизвестное слово — исключение со словами компонента
Попытка
	Кит.Карточка("Проекты").Опасная();
Исключение
	HTML = Кит.Примечание(КраткоеПредставлениеОшибки(ИнформацияОбОшибке())).Рендер();
КонецПопытки;
```

Компонент, которого ждёт слово другого компонента, кладут узлом: кнопку — в действие пустого состояния, поле — в строку поиска, плашку — в шапку объекта или знак сводки.

```живой Узел компонента — в слово другого
HTML = Кит.ПустоеСостояние("Создайте первый проект — он появится здесь.")
	.Заголовок("Проектов пока нет")
	.Действие(Кит.Кнопка("Создать проект").Адрес("/проекты/новый").Иконка("плюс"))
	.Рендер();
```

## Слот: дети становятся телом

У карточки слот — тело. Дети узла карточки печатаются внутри неё; второй холст — действия, слово `Действия(…)`.

```живой Компонент печатает себя целиком и принимает детей
HTML = Кит.Карточка("Проекты", Кит.Примечание("Три проекта, два открытых."))
	.Описание("Проекты команды")
	.Действия(Кит.Кнопка("Создать").Основная())
	.Рендер();
```

У шапки объекта дети становятся действиями — кнопками справа от имени.

```живой Шапка объекта: дети — её действия
HTML = Кит.ШапкаОбъекта("отчёт",
	Кит.Кнопка("Скачать").Вторичная().Иконка("скачать"))
	.Иконка("куб").Описание("Отчёт о продажах за квартал")
	.Рендер();
```

У плашки дети печатаются вместо значка и текста модели. Так плашку собирают из своих узлов — например, с машинным значением внутри.

```живой Плашка, собранная детьми
HTML = Кит.Плашка("ветка ", Кит.Код("main")).Вид("accent").Рендер();
```

## Список: каждый ребёнок — ячейка

Сетка раскладывает детей сама, поэтому получает их по одному, а не склеенной строкой. Табы и меню собираются из своих узлов: вкладка и пункт меню печатаются только внутри них.

```живой Сетка из карточек
Сетка = Кит.Сетка().Колонки(2);
Для Каждого Имя Из СтрРазделить("альфа,бета", ",") Цикл
	Сетка.Добавить(Кит.Карточка(Имя, Кит.Примечание("проект команды").Вид("описание")));
КонецЦикла;

HTML = Сетка.Рендер();
```

```живой Табы из вкладок
HTML = Кит.Табы(
	Кит.Вкладка("Обзор", "/проекты/альфа").Активна(),
	Кит.Вкладка("Участники", "/проекты/альфа/участники").Счётчик(3),
	Кит.Вкладка("Настройки", "/проекты/альфа/настройки").Иконка("шестерёнка"))
	.Заголовок("Разделы проекта").Рендер();
```

## Компонент виден по имени

`Дерево()` показывает компонент его видом: `компонент[карточка]`, `компонент[кнопка]`. По дереву видно, из чего собран экран, не открывая разметку.

```живой В дереве компонент виден по имени, а не куском HTML
Карточка = Кит.Карточка("Проекты", Кит.Кнопка("Создать"));

HTML = Кит.Код(Карточка.Дерево()).Вид("блочный").Рендер();
```

Компонент без слота детей не принимает: внутрь него не кладут, и кит скажет об этом на `Добавить`.

```живой Кнопка не холст — исключение
Попытка
	Кит.Кнопка("Создать").Добавить("ещё");
Исключение
	HTML = Кит.Примечание(КраткоеПредставлениеОшибки(ИнформацияОбОшибке())).Рендер();
КонецПопытки;
```

## Гайдлайны

```делайте Тело карточки — детьми узла, настройка — словами
HTML = Кит.Карточка("Ключи доступа",
	Кит.Примечание("Ключ показывается один раз."),
	Кит.Кнопка("Создать ключ").Вторичная()).Рендер();
```

```не-делайте Тело строкой через Набор и Готовое: в дереве — безымянный HTML
Тело = Набор.Кнопка().Отрисовать(Новый Структура("Подпись, Вариант", "Создать ключ", "вторичная"));
HTML = Кит.Готовое(Набор.Карточка().Отрисовать(
	Новый Структура("Заголовок, Тело", "Ключи доступа", Тело))).Рендер();
```

```делайте Компонент узлом кита — Кит.Плашка(…)
HTML = Кит.Ряд("признаки",
	Кит.Плашка("открытый").Вид("ok"),
	Кит.Плашка("команда")).Рендер();
```

```не-делайте Компонент строкой в Готовое(): дерево его не видит
HTML = Кит.Ряд("признаки",
	Кит.Готовое(Набор.Тег().Отрисовать(Новый Структура("Текст, Вид", "открытый", "ok"))),
	Кит.Готовое(Набор.Тег().Отрисовать("команда"))).Рендер();
```

## Доступность

Компонент в дереве печатает ровно ту же разметку, что через `Набор`. Всё, что он делает для скринридера, описано на его странице: [кнопка](кнопка), [карточка](карточка), [шапка объекта](шапка-объекта), [плашка](плашка). Слот добавляет только то, что вы положили в него сами — подписывайте значки и называйте кнопки.
