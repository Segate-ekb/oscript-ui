# Типографика

Шрифт кита — типографическая шкала Material Design 3: пятнадцать стилей, по три размера в пяти ролях. Стиль задаёт гарнитуру, начертание, кегль, интерлиньяж и трекинг сразу, поэтому текст на любом экране выглядит одной системой.

## Шкала

Роли шкалы — по назначению текста:

- **display** — самый крупный текст: число или фраза заставки. Сам кит его не берёт.
- **headline** — заголовок страницы и окна.
- **title** — заголовок раздела, карточки, колонки; имя записи.
- **body** — основной текст и значения.
- **label** — подписи управления: кнопка, вкладка, плашка.

## Токены

У каждого стиля пять токенов Material: `--md-sys-typescale-<стиль>-font`, `-weight`, `-size`, `-line-height` и `-tracking`. Шестой — сокращение кита `--type-<стиль>`: вся запись `font` одним значением, чтобы правило не собирало её из пяти переменных.

Трекинг в запись `font` не входит. Ставьте его рядом отдельным `letter-spacing`:

```css
.report__title {
	font: var(--type-title-medium);
	letter-spacing: var(--md-sys-typescale-title-medium-tracking);
}
```

Гарнитуры тоже токены. `--md-ref-typeface-brand` — для display, headline и `title-large`, `--md-ref-typeface-plain` — для остального. Сегодня это одна гарнитура, но место для фирменной у заголовков уже есть. Код и машинные значения идут гарнитурой `--md-ref-typeface-mono`.

Прежние имена `--font-heading`, `--font-body`, `--font-mono`, `--font-size-body`, `--font-size-small`, `--font-size-h1` и `--font-size-h2` остались псевдонимами этих токенов.

## Шрифт Roboto

Шрифт Material — Roboto. Кит его не везёт, как не везёт и MUI. Где Roboto установлен (Android, ChromeOS) или подключён инсталляцией, страница говорит им. Остальные видят системный гротеск: `system-ui`, San Francisco, Segoe UI.

Чтобы все видели Roboto, подключите его в листе своей инсталляции через `@font-face` и положите файлы шрифта в её статику. Шкала от этого не меняется: она описана кеглями, а не гарнитурой.

## Где какой стиль в ките

Компоненты уже выбрали стиль по своей роли. Своему экрану берите стиль по той же логике, а не по нужному размеру.

| Где | Стиль |
| --- | --- |
| Текст страницы, значение поля | `body-large` |
| `h1` — заголовок страницы | `headline-medium` |
| `h2` — раздел, заголовок карточки, знак в шапке | `title-large` |
| `h3` — подраздел, имя записи в сводке | `title-medium` |
| Заголовок окна | `headline-small` |
| Значение плитки показателя | `headline-medium` |
| Шапка таблицы, вкладка, заголовок тоста | `title-small` |
| Ячейка таблицы, лид карточки, текст тоста | `body-medium` |
| Пояснение и ошибка под полем | `body-small` |
| Подпись кнопки, ход в шапке | `label-large` |
| Малая кнопка, плашка | `label-medium` |
| Счётчик на вкладке и кнопке | `label-small` |
| Большая кнопка | `title-medium` |

```живой Заголовки страницы — h1, h2 и h3 по шкале
HTML = Кит.Холст(
	Кит.Заголовок(1, "Отчёты"),
	Кит.Заголовок(2, "Расписание"),
	Кит.Заголовок(3, "Еженедельные"),
	Кит.Примечание("Отчёт уходит в понедельник в девять утра.")).Рендер();
```

```живой Карточка — заголовок title-large, лид body-medium, текст body-large
HTML = Набор.Карточка().Отрисовать(Новый Структура("Заголовок, Описание, Иконка, Тело",
	"Хранилище", "Общий объём файлов проекта", "пакет",
	"<p>Занято 12 из 100 ГБ.</p>"));
```

```живой Плитка — одно число стилем headline-medium
HTML = Набор.Плитка().Отрисовать(Новый Структура("Значение, Подпись",
	"1 204", "документов"));
```

## Гайдлайны

```делайте Уровень заголовка — по структуре: подраздел мельче раздела
HTML = Кит.Холст(
	Кит.Заголовок(2, "Доступ"),
	Кит.Заголовок(3, "Ключи")).Рендер();
```

```не-делайте Уровень по нужному размеру: подраздел крупнее раздела
HTML = Кит.Холст(
	Кит.Заголовок(3, "Доступ"),
	Кит.Заголовок(2, "Ключи")).Рендер();
```

```делайте Размер текста — стилем шкалы
HTML = "<p style=""margin:0;font:var(--type-title-medium);"
	+ "letter-spacing:var(--md-sys-typescale-title-medium-tracking)"">Сводка за неделю</p>";
```

```не-делайте Размер и гарнитура литералом: текст выпадает из системы
HTML = "<p style=""margin:0;font:bold 19px Georgia,serif"">Сводка за неделю</p>";
```

```делайте Подпись кнопки — обычным регистром, как в Material 3
HTML = Набор.Кнопка().Отрисовать(Новый Структура("Подпись, Иконка", "Сохранить", "сохранить"));
```

```не-делайте Подпись прописными: её труднее читать, и она кричит
HTML = Набор.Кнопка().Отрисовать(Новый Структура("Подпись, Иконка", "СОХРАНИТЬ", "сохранить"));
```

## Доступность

- Кегли заданы в пикселях, но масштаб страницы браузера увеличивает их вместе с остальной вёрсткой.
- Заголовки — настоящие `h1`–`h3`: по ним скринридер строит оглавление страницы. Не пропускайте уровни и не берите заголовок ради размера.
- Основной текст — `body-large`, 16 пикселей. Мельче `body-small` (12) текст, который человек должен прочитать, не делайте.
