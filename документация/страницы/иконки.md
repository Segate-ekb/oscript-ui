# Иконки

Глифы интерфейса — набор Material Symbols Outlined. Кит вставляет иконку в страницу инлайновым `<svg>` по русскому имени, а цвет и размер она берёт у текста вокруг.

## Набор

Сейчас в ките столько глифов, сколько нужно его компонентам и типовым экранам. Каждый глиф — отдельный файл, и набор ниже собран прямо из этого каталога.

```директива иконки
```

Имена русские и называют смысл в интерфейсе, а не рисунок: «куб» — это `deployed_code`, «палочка» — `wand_stars`, «аккаунт» — один человек (`account_circle`), «группа» — несколько (`group`): значок раздела групп рядом с разделом людей. «Отправить» (`send`) — канал доставки сообщений, например чат-бот; «вебхук» (`webhook`) — вызов адреса приложения по событию. Исходное имя Material записано комментарием в файле глифа. Регистр имени не важен.

## Как вставить

Компоненты принимают иконку полем модели `Иконка` — у кнопки, карточки, плашки, пункта меню; в дереве холста это слово `.Иконка(…)`: `Кит.Кнопка("Создать").Иконка("плюс")`. Отдельно иконку печатает компонент «Иконка».

Без подписи иконка декоративна: она скрыта от скринридера, потому что смысл несёт текст рядом.

```живой Декоративная — смысл несёт текст рядом
HTML = Набор.Иконка().Отрисовать("куб");
```

Если иконка стоит одна и что-то значит, дайте ей подпись. Подпись печатается `<title>`, и иконка получает роль изображения.

```живой С подписью для скринридера
HTML = Набор.Иконка().Отрисовать(Новый Структура("Имя, Подпись",
	"ключ", "ключ подписи"));
```

Неизвестное имя не роняет страницу: иконка просто не печатается. Компоненты пропускают её так же — кнопка с опечаткой в имени иконки останется кнопкой с подписью.

```живой Неизвестное имя — пусто
HTML = Набор.Иконка().Отрисовать("такой-иконки-нет");
```

На [холсте](холст) иконка — узел, как остальные: имя позицией, подпись для скринридера — словом `.Подпись(…)`.

```живой Узлом дерева
HTML = Кит.Иконка("куб").Рендер();
```

## Размер и цвет

Иконка — квадрат `1em` на `1em`, опущенный на 1/8 кегля к базовой линии, и залита `currentColor`. Поэтому она растёт вместе с кеглем строки и красится цветом текста — в любой теме и при любом акценте.

```живой Иконка берёт кегль и цвет строки
HTML = "<span style=""font:var(--type-headline-small);color:var(--md-sys-color-primary)"">"
	+ Набор.Иконка().Отрисовать("пакет") + " Пакеты</span>";
```

```живой В компонентах — по их правилам
HTML = Набор.Кнопка().Отрисовать(Новый Структура("Подпись, Иконка", "Скачать", "скачать"))
	+ Набор.Тег().Отрисовать(Новый Структура("Текст, Вид, Иконка", "проверен", "ok", "успех"));
```

## Свой глиф

Глиф — файл `.svg` в каталоге глифов кита `src/статика/иконки`. Имя файла без расширения — имя иконки. Каталог читается целиком при запуске, поэтому новый файл появляется в наборе и на этой странице сам.

1. Возьмите глиф в [Material Symbols](https://fonts.google.com/icons), стиль Outlined, — так он совпадёт по толщине с остальными.
2. Назовите файл по-русски, по смыслу: `архив.svg`.
3. Оставьте у `<svg>` атрибут `viewBox`: по нему рисунок вписывается в строку. У глифов Material это `0 -960 960 960`, но годится любой.
4. Не задавайте заливку контуру — её даёт `fill="currentColor"` самой иконки.
5. Запишите комментарием исходное имя и лицензию, как в соседних файлах.

Комментарии, `<title>` и служебные элементы редактора кит при чтении отбрасывает, в страницу уходит только рисунок. Файл без `<svg>`, без `viewBox` или пустой роняет запуск с понятной ошибкой — значок не пропадёт со страницы молча. Тест `ГрафикаКита` сверяет каталог с набором в обе стороны.

> **Совет.** Файлы, которые кит отдаёт по `/static` — базовый лист, скрипт, значки провайдеров, тексты лицензий, — инсталляция подменяет своими: файл, объявленный ею под тем же именем, вытесняет китовый целиком. Глифы так не подменяются: они не отдаются файлами, а вставляются в разметку, и набор читает только каталог кита. Новый глиф кладут в сам кит.

## Значки провайдеров

Фирменных знаков в Material Symbols нет, поэтому значки брендов — официальные логотипы из набора [Simple Icons](https://simpleicons.org) (дев-сборка 8; прежде — рисунки Phosphor). Набор распространяется по лицензии CC0-1.0, но сами логотипы — товарные знаки их владельцев и используются по их правилам: значок называет сервис, через который человек входит или куда уходит событие, и не перекрашивается и не искажается. Цвет — цвет бренда из данных набора; тёмные логотипы (GitHub, Keycloak, Mattermost) в тёмной теме рисуются цветом текста — иначе их не видно на тёмной поверхности. Общий вход по ключу — глиф Material «key».

Значки лежат в каталоге `src/статика/провайдеры` по файлу на ключ, сетка 24 px, и отдаются файлами — для `<img>` на странице входа. Список ключей закрытый: `authentik`, `discord`, `gitea`, `github`, `gitlab`, `google`, `key`, `keycloak`, `mattermost`, `okta`, `telegram`. Логотипов Microsoft, Slack и Яндекса в Simple Icons нет — их владельцы попросили убрать; свой файл такого значка инсталляция кладёт в свою статику.

В узлах холста бренд печатается иконкой с приставкой: `Кит.Иконка("бренд:telegram")` — инлайн-`<svg>` цветом бренда, стоящий один называет бренд скринридеру. То же имя принимает слово `Иконка` у кнопки, плашки и пункта меню и слово `Значок` у записи реестра — там логотип рядом с текстом декоративен. Неизвестный бренд останавливает сборку с перечнем известных.

```живой Все бренды строкой
Ключи = СтрРазделить("telegram,github,gitlab,gitea,google,authentik,keycloak,okta,discord,mattermost,key", ",");
Ряд = Кит.Ряд("признаки");
Для Каждого Ключ Из Ключи Цикл
	Ряд.Добавить(Кит.Иконка("бренд:" + Ключ));
КонецЦикла;
HTML = Ряд.Рендер();
```

```живой Бренд в плашке, кнопке и записи реестра
HTML = Кит.Холст(
	Кит.РядПлашек(Кит.Плашка("Telegram").Иконка("бренд:telegram"), Кит.Плашка("GitHub").Иконка("бренд:github")),
	Кит.Кнопка("Войти через GitLab").Вторичная().Иконка("бренд:gitlab"),
	Кит.Реестр(Кит.ЗаписьРеестра("Канал «Сборки»").Значок("бренд:telegram")
		.Подпись("Сообщает о сбоях сборки"))).Рендер();
```

```bsl
// адрес значка с отпечатком содержимого — для <img> на странице входа
Адрес = Активы.Адрес("telegram.svg");
```

Свой значок провайдера инсталляция кладёт в свою статику под тем же именем — он вытеснит китовый.

## Гайдлайны

```делайте Значки одного набора: одна толщина и один стиль
HTML = Набор.Кнопка().Отрисовать(Новый Структура("Подпись, Вариант, Иконка", "Настройки", "вторичная", "шестерёнка"))
	+ Набор.Кнопка().Отрисовать(Новый Структура("Подпись, Вариант, Иконка", "История", "вторичная", "история"));
```

```не-делайте Значки из разных источников: эмодзи рядом с глифом выглядит чужим
HTML = "<button class=""button button--ghost"" type=""button"">⚙️ Настройки</button>"
	+ Набор.Кнопка().Отрисовать(Новый Структура("Подпись, Вариант, Иконка", "История", "вторичная", "история"));
```

```делайте Иконка цветом текста или роли
HTML = "<p style=""margin:0;color:var(--md-sys-color-on-surface-variant)"">"
	+ Набор.Иконка().Отрисовать("часы") + " обновлён вчера</p>";
```

```не-делайте Иконка своим цветом: в другой теме она пропадает или режет глаз
HTML = "<p style=""margin:0;color:var(--md-sys-color-on-surface-variant)"">"
	+ "<span style=""color:#ffeb3b"">" + Набор.Иконка().Отрисовать("часы") + "</span> обновлён вчера</p>";
```

```делайте Иконка размером с букву строки
HTML = "<p style=""margin:0"">" + Набор.Иконка().Отрисовать("замок") + " Доступ только участникам</p>";
```

```не-делайте Иконка крупнее текста: строка разъезжается
HTML = "<p style=""margin:0""><span style=""font-size:40px"">" + Набор.Иконка().Отрисовать("замок")
	+ "</span> Доступ только участникам</p>";
```

## Доступность

- Иконка без подписи печатается с `aria-hidden="true"` и `focusable="false"`: скринридер её пропускает, клавиатура на ней не останавливается.
- Иконка с подписью получает `role="img"` и `<title>` — это и доступное имя, и всплывающая подсказка.
- Кнопка из одной иконки берёт подпись в `aria-label`, и кит не соберёт её без подписи.
- Признак у имени в [шапке объекта](шапка-объекта) без подписи отвергается исключением.

## Лицензии

Глифы Material Symbols распространяются по лицензии Apache 2.0. Её текст лежит рядом с глифами, `material-symbols-LICENSE.txt`, и отдаётся по `/static` вместе с остальной статикой. Значки брендов — из набора Simple Icons по лицензии CC0-1.0, текст — `simple-icons-LICENSE.txt` в каталоге значков; логотипы остаются товарными знаками владельцев.
