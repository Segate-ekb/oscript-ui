# Скрытое поле

Скрытое поле везёт с формой значение, которого человек не видит и не правит: идентификатор записи, текущий отбор, токен. На экране его нет, поэтому здесь показана разметка, которую печатает кит.

## Когда использовать

- Форма должна вернуть серверу то, что он сам отдал: идентификатор записи, номер шага, текущий отбор.
- Поиск должен сохранить остальные параметры адреса: [форма отбора](форма-отбора) везёт их скрытыми полями.
- Нужен явный «сброс» признака: пустое значение тоже отправляется.

Не прячьте значение, которое человек должен видеть, — покажите его заблокированным [полем формы](поле) или [полем из конфига](поле-из-конфига). Не доверяйте скрытому полю права и цены: его правит кто угодно в инструментах браузера, и сервер обязан проверять всё заново.

## Имя и значение

`Имя` обязательно: поле без `name` формой не отправляется, и такая разметка молча теряет данные. `Значение` приводится к строке; имя и значение экранируются.

```разметкой Имя и значение
HTML = Набор.СкрытоеПоле().Отрисовать(
	Новый Структура("Имя, Значение", "проект", "main"));
```

## Пустое значение

Атрибут `value` печатается и для пустого значения. Пустое значение законно: так форма сообщает серверу «признак снят», а не «признака не было».

```разметкой Пустое значение — сброс признака
HTML = Набор.СкрытоеПоле().Отрисовать(Новый Структура("Имя", "включить"));
```

> **Совет.** Скрытое поле — единственный источник разметки `<input type="hidden">` в ките. Его печатают и [тумблер](тумблер) (выключенное значение), и форма с токеном CSRF, и форма отбора. Свою разметку скрытого поля строкой не собирайте.

## Гайдлайны

```делайте Служебный параметр — скрытым полем: поиск помнит выбранный проект
Скрытые = Новый Массив();
Скрытые.Добавить(Новый Структура("Имя, Значение", "проект", "main"));

HTML = Набор.ФормаОтбора().Отрисовать(Новый Структура("Действие, Метка, Кнопка, СкрытыеПоля",
	"/документы", "Имя документа", "Найти", Скрытые));
```

```не-делайте Служебный параметр видимым полем: человек правит то, чего не выбирал
Поля = Новый Массив();
Поля.Добавить(Новый Структура("Имя, Метка", "q", "Имя документа"));
Поля.Добавить(Новый Структура("Имя, Метка, Значение", "проект", "проект", "main"));

HTML = Набор.ФормаОтбора().Отрисовать(Новый Структура("Действие, Кнопка, Поля",
	"/документы", "Найти", Поля));
```

```делайте Значение, которое человек должен видеть, — заблокированным полем
HTML = Набор.Поле().Отрисовать(Новый Структура("Метка, Значение, Заблокировано",
	"Каталог данных", "/var/lib/приложение", Истина))
	+ Набор.Кнопка().Отрисовать("Создать проект");
```

```не-делайте То же значение скрытым: форма отправит то, чего человек не видел
HTML = Набор.СкрытоеПоле().Отрисовать(
		Новый Структура("Имя, Значение", "каталог", "/var/lib/приложение"))
	+ Набор.Кнопка().Отрисовать("Создать проект");
```

## Доступность

- Скрытое поле не видно никому — ни глазу, ни скринридеру, ни клавиатуре. Всё, что человеку нужно знать, должно быть на экране отдельно.

## Узлом холста

На [холсте](холст) скрытое поле — `Кит.СкрытоеПоле(Имя, Значение)`: два параметра вместо структуры. Кладите его в форму.

```разметкой Скрытое поле узлом дерева
HTML = Кит.СкрытоеПоле("проект", "main").Рендер();
```

## Модель

Поля модели — из комментария в исходнике компонента.

```справка СкрытоеПоле
```

```справка Кит.СкрытоеПоле
```

```словарь компонент:скрытое
```
