# Дерево галок

Дерево галок — выбор в иерархии: края и города, разделы и страницы, группы и права. У ветки трёхпозиционная галка — «включено», «снято» или «частично», — а сама ветка сворачивается.

## Когда использовать

- Человек отмечает часть большого перечня, который естественно делится на группы.
- По ветке нужно видеть сразу, выбрана ли она целиком, частично или нет.

Не берите дерево для плоского списка из нескольких пунктов — хватит [флажков](поле). Для перехода по разделам объекта есть [дерево разделов](дерево-разделов), а для иерархии записей с колонками — [таблица деревом](таблица-деревом).

## Три состояния ветки

`Состояние` узла — «вкл» (по умолчанию), «выкл» или «частично». Все три печатает сервер, и «частично» видно без скрипта: отмеченной галкой со знаком «—» вместо галочки.

Ветка — узел с ключом `Дети`. Она сворачивается нативной раскрывашкой с шевроном слева; `Открыт` присылает её раскрытой. Вложенность показывают отступ и линия слева.

`Пояснение` — приглушённая приписка после подписи: сколько внутри, что снято. `Примечание` — строка в конце ветки, например «показан 1 из 40». `Отключён` — галка видна, но не правится и не отправляется.

```живой Три состояния ветки: включена, частично, снята
Север = Новый Массив();
Север.Добавить(Новый Структура("Имя, Подпись", "город_1", "Архангельск"));
Север.Добавить(Новый Структура("Имя, Подпись, Состояние", "город_2", "Мурманск", "выкл"));

Юг = Новый Массив();
Юг.Добавить(Новый Структура("Имя, Подпись", "город_3", "Краснодар"));

Восток = Новый Массив();
Восток.Добавить(Новый Структура("Имя, Подпись, Состояние, Отключён", "город_4", "Владивосток", "выкл", Истина));

Узлы = Новый Массив();
Узлы.Добавить(Новый Структура("Имя, Подпись, Пояснение, Состояние, Дети, Открыт",
	"край_1", "Север", "2 города, снят 1", "частично", Север, Истина));
Узлы.Добавить(Новый Структура("Имя, Подпись, Пояснение, Дети", "край_2", "Юг", "1 город", Юг));
Узлы.Добавить(Новый Структура("Имя, Подпись, Состояние, Дети, Открыт, Примечание",
	"край_3", "Восток", "выкл", Восток, Истина, "Показан 1 из 40"));

HTML = Набор.ДеревоГалок().Отрисовать(Новый Структура("Подпись, Узлы", "Где работаем", Узлы));
```

Состояние ветки считает сервер по детям: кит его не выводит, а печатает то, что пришло в модели.

## Что уходит на сервер

Каждая галка — флажок формы с `Имя` и `Значение` («1» по умолчанию). Отмеченная отправляет значение, снятая — ничего. «Частично» отправляется отмеченной галкой.

Без скрипта щелчок по частичной галке снимает узел целиком, повторный возвращает прежнюю частичную отметку. Дети при этом не трогаются: пересчёт на лету — дело скрипта страницы.

## Данные для скрипта страницы

Скрипт находит дерево по `data-checktree`, галку — по `data-checktree-box`, а состояние читает и пишет в `data-checktree-state` (`on`, `off`, `mixed`). Свои признаки галки приходят полем `Данные`: соответствие, имена без приставки `data-`.

`Признаки` — массив моделей [плашек](плашка) после подписи. Одноуровневое дерево — тоже дерево: просто узлы без `Детей`.

```живой Один уровень с плашками и данными для скрипта
Данные = Новый Соответствие();
Данные.Вставить("key", "город_1");

Признаки = Новый Массив();
Признаки.Добавить("столица");

Узлы = Новый Массив();
Узлы.Добавить(Новый Структура("Имя, Подпись, Признаки, Данные", "город_1", "Москва", Признаки, Данные));
Узлы.Добавить(Новый Структура("Имя, Подпись, Состояние", "город_2", "Тверь", "выкл"));

HTML = Кит.ДеревоГалок(Новый Структура("Узлы", Узлы)).Рендер();
```

Глубина дерева ограничена четырьмя уровнями: модель приходит извне, и узел мог бы оказаться в собственных детях. Ветки глубже предела не печатаются.

## Доступность

- `Подпись` дерева уходит в `aria-label` списка: скринридер называет, что это за выбор.
- Галка — настоящий флажок в `<label>` с подписью узла: щелчок по тексту отмечает, пробел переключает.
- «Частично» сервер печатает как `aria-checked="mixed"` на отмеченной галке. Это осознанное отступление от ARIA in HTML: свойство `indeterminate` ставит только скрипт, а другого способа сказать «частично» у разметки нет.
- Строка узла стоит в разметке после ветки, а на экране — первой. Так шеврон раскрытия идёт в порядке фокуса раньше галки, а галка не вложена в кнопку раскрытия. У шеврона скрытая подпись — имя ветки.
- Узел без `Имени` и неизвестное `Состояние` кит не соберёт: выбор пропал бы молча.

## Узлом холста

На [холсте](холст) дерево кладут в форму — `Кит.ДеревоГалок(Модель)`, модель та же. Пример узлом — выше, в разделе о данных для скрипта.

## Модель

Поля модели — из комментария в исходнике компонента.

```справка ДеревоГалок
```
