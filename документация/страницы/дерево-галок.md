# Дерево галок

Дерево галок — выбор в иерархии: края и города, разделы и страницы, группы и права. У ветки трёхпозиционная галка — «включено», «снято» или «частично», — а сама ветка сворачивается.

## Когда использовать

- Человек отмечает часть большого перечня, который естественно делится на группы.
- По ветке нужно видеть сразу, выбрана ли она целиком, частично или нет.
- Пунктов тысяча и больше: ветки грузятся страницами по адресу, поиск спрашивает сервер, а форма отдаёт только правки — см. раздел «Тысяча пунктов» ниже.

Не берите дерево для плоского списка из нескольких пунктов — хватит [флажков](поле). Для перехода по разделам объекта есть [дерево разделов](дерево-разделов), а для иерархии записей с колонками — [таблица деревом](таблица-деревом).

В дереве холста узлы приходят первым аргументом — массивом структур узлов, а подпись дерева задаёт слово `.Подпись(…)` (см. [Язык узлов](язык-узлов)); узел по одному добавляет слово `.Узел(Модель)`.

```живой Узлом холста — словами
Узлы = Новый Массив();
Узлы.Добавить(Новый Структура("Имя, Подпись", "город_1", "Архангельск"));
Узлы.Добавить(Новый Структура("Имя, Подпись, Состояние", "город_2", "Мурманск", "выкл"));

HTML = Кит.ДеревоГалок(Новый Структура("Узлы", Узлы)).Подпись("Где работаем").Рендер();
```

## Три состояния ветки

`Состояние` узла — «вкл» (по умолчанию), «выкл» или «частично». Все три печатает сервер, и «частично» видно без скрипта: отмеченной галкой со знаком «—» вместо галочки.

Ветка — узел с ключом `Дети`. Она сворачивается нативной раскрывашкой с шевроном слева; `Открыт` присылает её раскрытой. Вложенность показывают отступ и линия слева.

`Пояснение` — приглушённая приписка после подписи: сколько внутри, что снято. `Примечание` — строка в конце ветки, например «показан 1 из 40». `Отключён` — галка видна, но не правится и не отправляется.

```живой Три состояния ветки: включена, частично, снята
Север = Новый Массив();
Север.Добавить(Новый Структура("Имя, Подпись", "город_1", "Архангельск"));
Север.Добавить(Новый Структура("Имя, Подпись, Состояние", "город_2", "Мурманск", "выкл"));

Юг = Новый Массив();
Юг.Добавить(Новый Структура("Имя, Подпись", "город_3", "Краснодар"));

Восток = Новый Массив();
Восток.Добавить(Новый Структура("Имя, Подпись, Состояние, Отключён", "город_4", "Владивосток", "выкл", Истина));

Узлы = Новый Массив();
Узлы.Добавить(Новый Структура("Имя, Подпись, Пояснение, Состояние, Дети, Открыт",
	"край_1", "Север", "2 города, снят 1", "частично", Север, Истина));
Узлы.Добавить(Новый Структура("Имя, Подпись, Пояснение, Дети", "край_2", "Юг", "1 город", Юг));
Узлы.Добавить(Новый Структура("Имя, Подпись, Состояние, Дети, Открыт, Примечание",
	"край_3", "Восток", "выкл", Восток, Истина, "Показан 1 из 40"));

HTML = Набор.ДеревоГалок().Отрисовать(Новый Структура("Подпись, Узлы", "Где работаем", Узлы));
```

Состояние ветки считает сервер по детям: кит его не выводит, а печатает то, что пришло в модели.

## Что уходит на сервер

Каждая галка — флажок формы с `Имя` и `Значение` («1» по умолчанию). Отмеченная отправляет значение, снятая — ничего. «Частично» отправляется отмеченной галкой.

Без скрипта щелчок по частичной галке снимает узел целиком, повторный возвращает прежнюю частичную отметку. Дети при этом не трогаются.

Со скриптом кита (выпуск 0.13) щелчок по галке ветки раздаёт её состояние детям, а ветки выше пересчитывают «частично» по детям. «Частично» щелчком становится «включено», как у трёхпозиционного флажка ARIA. Ветка, у которой загружены не все дети, «целиком» становится, только если так её напечатал сервер или человек сам отметил её целиком: чего на странице нет, того скрипт не знает. Дети, которые приедут в отмеченную целиком ветку, приходят её состоянием. Напечатанное сервером скрипт при загрузке не пересчитывает — состояние ветки по-прежнему считает сервер.

## Данные для скрипта страницы

Скрипт находит дерево по `data-checktree`, галку — по `data-checktree-box`, а в `data-checktree-state` (`on`, `off`, `mixed`) лежит состояние, которое напечатал сервер: скрипт кита сверяет с ним правки и его не переписывает, а текущее состояние — сама галка (`checked`, `indeterminate`). Свои признаки галки приходят полем `Данные`: соответствие, имена без приставки `data-`.

`Признаки` — массив моделей [плашек](плашка) после подписи. Одноуровневое дерево — тоже дерево: просто узлы без `Детей`.

```живой Один уровень с плашками и данными для скрипта
Данные = Новый Соответствие();
Данные.Вставить("key", "город_1");

Признаки = Новый Массив();
Признаки.Добавить("столица");

Узлы = Новый Массив();
Узлы.Добавить(Новый Структура("Имя, Подпись, Признаки, Данные", "город_1", "Москва", Признаки, Данные));
Узлы.Добавить(Новый Структура("Имя, Подпись, Состояние", "город_2", "Тверь", "выкл"));

HTML = Кит.ДеревоГалок(Новый Структура("Узлы", Узлы)).Рендер();
```

Глубина дерева ограничена четырьмя уровнями: модель приходит извне, и узел мог бы оказаться в собственных детях. Ветки глубже предела не печатаются.

## Доступность

- `Подпись` дерева уходит в `aria-label` списка: скринридер называет, что это за выбор.
- Галка — настоящий флажок в `<label>` с подписью узла: щелчок по тексту отмечает, пробел переключает.
- «Частично» сервер печатает как `aria-checked="mixed"` на отмеченной галке. Это осознанное отступление от ARIA in HTML: свойство `indeterminate` ставит только скрипт, а другого способа сказать «частично» у разметки нет.
- Строка узла стоит в разметке после ветки, а на экране — первой. Так шеврон раскрытия идёт в порядке фокуса раньше галки, а галка не вложена в кнопку раскрытия. У шеврона скрытая подпись — имя ветки.
- Узел без `Имени` и неизвестное `Состояние` кит не соберёт: выбор пропал бы молча.
- Режим ветки — группа радиокнопок (`role="radiogroup"`) с именем «Режим ветки «…»»: стрелки двигают выбор движком браузера. Дети ветки в режиме «все» или «никакие» напечатаны запертыми (`disabled`) — скринридер слышит их состояние и «недоступно», а скрипт ещё и выводит их из порядка фокуса (`inert`); дети ветки «выбранные» правятся с клавиатуры.
- Поле поиска стоит в области `role="search"` и подписано скрытой меткой; у значка-кнопки имя «Найти». Число найденного печатается с `role="status"`.
- «Показать ещё» — ссылка и без скрипта. Со скриптом фокус со ссылки переходит на первую новую галку, а не теряется вместе со ссылкой.
- Сводка правок печатается с `role="status"`: число правок скринридер слышит, не перечитывая плашки.
- Плашка правки — пункт списка с крестиком «Отменить правку «…»»; когда правку сняли, фокус встаёт на соседнюю плашку, а без них — на сам узел (или на крестик его плашки в ряду отмеченного).
- Ряд отмеченного — список плашек; крестик — флажок с именем «Снять «…»» («Вернуть «…»» у снятого узла), фокус с клавиатуры виден кольцом вокруг значка, а отмеченное снятие — зачёркнутой подписью, не одним цветом.

## Тысяча пунктов

Когда пунктов тысяча, все ветки в разметке — тяжёлая страница, а форма, которая отдаёт каждую галку, — тяжёлый запрос. Четыре слова выпуска 0.13 разгружают и то, и другое; дерево без них печатается как прежде, байт в байт.

| Слово | Что делает |
| --- | --- |
| `Адрес(Адрес)` | Ветка печатает первые 50 детей (`РазмерСтраницы`), под ними «Показать ещё» и «Показано 50 из N»; остальные приезжают по адресу страницами по 50. Узел с `Всего` и без `Детей` — ветка, чьи дети приедут при раскрытии |
| `Поиск(Адрес)` | Над деревом поле «Найти в дереве» со значком-лупой внутри, как у [строки поиска](форма-отбора); ответ сервера ложится на место веток. Прежний вид — поле и кнопка рядом — словом `Кнопка("Найти")` |
| `Режимы()` | У каждой ветки вместо галки сегменты «Все / Выбранные / Никакие» |
| `Режимы("все", "выбранные", …)` | Набор допустимых режимов: сегменты только у них и в их порядке |
| `ТолькоПравки()` | Со скриптом форма отдаёт не все галки, а только правки; правки видны плашками под деревом — над кнопками формы |
| `ПравкиБезСкрипта()` | И без скрипта форма отдаёт правки: кит печатает скрытое поле показанного, `РазобратьПравки` считает правки против него |
| `Отмеченные(Узлы)` | Над деревом ряд «Выбрано: …» — плашки отмеченных узлов вне показанного с крестиком |
| `СводкаПравок()` | Под деревом, у кнопок формы, строка «Изменений: 3 (+2 −1)» по ряду правок |

У каждого узла есть ключ — по нему сервер узнаёт узел в адресе ветки и в правках. Ключ — `Значение` галки, если оно своё (не «1»), иначе её `Имя`.

### Страницы ветки

`Всего` у ветки — сколько у неё детей на сервере; без него — сколько их пришло в `Детях`. Детей больше 50 — кит печатает первые 50 и ссылку на вторую страницу. Ссылка настоящая: без скрипта она ведёт на страницу ветки, со скриптом страница приезжает запросом в фоне и дописывается в ветку, а ссылка ведёт уже на следующую. Нажмите «Показать ещё» — ответит [образец с сервером](/образец-дерева).

```живой Ветка печатает первые 50 — остальное по «Показать ещё»
Дети = Новый Массив();
Для Номер = 1 По 60 Цикл
	Дети.Добавить(Новый Структура("Имя, Подпись, Состояние", "alpha-" + Формат(Номер, "ЧЦ=3; ЧВН=; ЧГ=0"),
		"Участник " + Формат(Номер, "ЧГ=0"), ?(Номер % 3 = 0, "выкл", "вкл")));
КонецЦикла;

Узлы = Новый Массив();
Узлы.Добавить(Новый Структура("Имя, Подпись, Состояние, Дети, Всего, Открыт",
	"alpha", "Альфа", "частично", Дети, 140, Истина));
Узлы.Добавить(Новый Структура("Имя, Подпись, Пояснение, Всего", "gamma", "Гамма", "75 участников", 75));

HTML = Кит.ДеревоГалок(Узлы).Подпись("Участники проектов").Адрес("/образец-дерева/ветка").Рендер();
```

Ветка «Гамма» пришла без детей: со скриптом они приезжают, когда её раскрывают, без скрипта под ней ссылка на первую страницу.

### Режим ветки

`Режимы()` ставит у ветки малые [сегменты](сегменты) «Все / Выбранные / Никакие» — радиокнопки `режим:<ключ ветки>`. «Все» — вся ветка целиком, вместе с детьми, которых на странице нет: галкой ветки этого не сказать, пока загружена только часть детей. «Выбранные» — только отмеченные дети, «Никакие» — никто.

Режим берётся из поля `Режим` узла, а без него — из `Состояния`: «вкл» — «все», «выкл» — «никакие», «частично» — «выбранные».

Режим — ещё и массовая отметка (дев-сборка 10). «Все» — все дети ветки отмечены и заперты; «Никакие» — все сняты и заперты; «Выбранные» — дети отперты и начинаются с того, что было видно: переключили из «Все» — все отмечены, снимите лишних; из «Никакие» — все сняты, отметьте нужных; из «Выбранных» — как были. Ручные отметки внутри «Выбранных» живут, пока не нажато «Все» или «Никакие». Сервер печатает детей ветки «все» отмеченными, «никакие» — снятыми, и тех и других запертыми (`disabled`, признак `data-checktree-locked`): что видно, то и сохранится, и без скрипта тоже. Со скриптом переключение — на месте, и дети, которые приедут страницей позже, встают по режиму, отмеченному сейчас.

Массовая отметка — основа «выбранных»: правки детей считаются против неё, и с формой уходит `основа=<ключ>:все` или `:никакие` — сервер строит набор заново: «выбранные» после «все» — вся ветка минус снятые, после «никакие» — только отмеченные. Разложить правки одной ветки помогает `ПравкиВетки` (см. [контракт сервера](#контракт-сервера)).

Сегменты режима у строки ветки — малая пилюля своей ширины и одной строкой на любой ширине, в окне и на телефоне тоже (дев-сборка 10): не помещаются рядом с подписью — строка переносит пилюлю под подпись целиком, а подписи сегментов не переносятся. Правила «во всю ширину» и «столбиком в окне» — для [сегментов](сегменты) выбора в форме, а не для строки дерева: столбиком сегменты удлиняли бы каждую ветку втрое.


### Набор режимов

Режимы строками — набор допустимых режимов дерева: сегменты печатаются только у них и в их порядке. Своё у отдельной ветки — поле узла `Режимы` (массив). Ветка, чей режим в набор не входит, и неизвестный режим в наборе останавливают сборку: ни один сегмент не был бы отмечен. `Режимы()` без набора и набор из трёх прежних печатают одно и то же — прежнюю разметку.

```живой Своя ветка не бывает «никакой»: набор «все / выбранные»
Альфа = Новый Массив();
Альфа.Добавить(Новый Структура("Имя, Подпись", "alpha-001", "Анна Белых"));

Узлы = Новый Массив();
Узлы.Добавить(Новый Структура("Имя, Подпись, Режим, Дети, Открыт", "alpha", "Альфа", "все", Альфа, Истина));

HTML = Кит.ДеревоГалок(Узлы).Подпись("Свой проект").Режимы("все", "выбранные").Рендер();
```

### Поиск через сервер

`Поиск(Адрес)` ставит над деревом поле поиска той же разметкой, что [строка поиска](форма-отбора) кита без кнопки (дев-сборка 8): значок-лупа — кнопка отправки внутри рамки поля, подпись поля «Найти в дереве» — скрытой меткой, а в пустом поле видна подсказка. Поиск дерева и поиск реестра на одном экране выглядят одинаково. Со скриптом значок, Enter и пауза в наборе берут ответ по адресу `Адрес?найти=<строка>`, и он ложится на место веток; пустое поле возвращает ветки. Без скрипта Enter и значок отправляют форму дерева на адрес поиска, не проверяя полей, и сервер отвечает страницей с ответом.

Прежний вид — поле с меткой и кнопка рядом — словом `Кнопка(Подпись)`:

### Только правки

`ТолькоПравки()` — форма отдаёт не все галки, а только то, что человек поменял против напечатанного сервером. Скрипт копит правки и показывает их плашками под деревом («+ Анна Белых», «− Борис Седых», «Альфа: Все»); любую можно снять крестиком — узел вернётся к тому, что напечатал сервер. Правка ветки покрывает правки её детей того же рода: «+ Альфа» уже говорит, что включены и все её участники. Без скрипта ряд правок спрятан, и форма отдаёт галки, как обычно.

### Отмеченное вне показанного

Без скрипта форма знает только показанные галки: первые 50 ветки или найденное. Отмеченный участник на третьей странице ветки не виден и не снимается, пока его не найдёшь. Слово `Отмеченные(Узлы)` — модели узлов (`Имя`, `Значение`, `Подпись`), которых на странице нет, — печатает над деревом ряд «Выбрано: …»: плашка на узел с крестиком. ### Правки без скрипта

Без скрипта форма знает только показанные галки и отдаёт их как есть: отмеченные — значением, снятые — ничем. Чтобы понять, что человек поменял, приложению пришлось бы сравнивать форму с тем, что оно напечатало. Слово `ПравкиБезСкрипта()` делает это за него: кит печатает в конце дерева скрытое поле `показано` (`data-checktree-shown`) — какие галки и режимы он показал и в каком состоянии, — и `РазобратьПравки` без скрипта отдаёт правки против него, как со скриптом: снятую показанную галку — в `Снять`, отмеченную снятую — в `Включить`, сменённый режим — в `Режимы` (несменённых там нет). Закрытая галка (`Отключён`) в форму не уходит и в показанное не входит. «Частично», оставленное отмеченным, правкой не считается.

Со скриптом поле пересчитывается при отправке — по всем галкам обёртки: страницы веток и найденное, приехавшие запросом, в нём тоже есть. У дерева `ТолькоПравки()` скрипт шлёт правки сам, и поле не уходит.

```живой Поле показанного — в конце дерева

Альфа.Добавить(Новый Структура("Имя, Подпись, Состояние", "alpha-002", "Борис Седых", "выкл"));

Узлы = Новый Массив();
Узлы.Добавить(Новый Структура("Имя, Подпись, Режим, Дети, Открыт", "alpha", "Альфа", "выбранные", Альфа, Истина));

HTML = Кит.ДеревоГалок(Узлы).Подпись("Участники проектов").Режимы()
	.ТолькоПравки().ПравкиБезСкрипта().Рендер();
```

### Без скрипта

- Каждая ветка печатает первые 50 детей, «Показать ещё» — обычная ссылка на страницу ветки.
- Значок поиска (и Enter в поле) — кнопка отправки формы на адрес поиска; ответ поиска — страница, где на месте веток совпадения.
- Крестик плашки отмеченного — галка `снять=<ключ>` (`включить=<ключ>` у снятого узла): уходит с формой.
- Режим ветки — радиокнопки `режим:<ключ>` со значением `все`, `выбранные` или `никакие` (`кроме` — если назван в наборе). Дети ветки «все» и «никакие» напечатаны состоянием режима и заперты: смена сегмента уходит с формой, и сервер печатает ветку заново — «выбранные» после «все» засеяны отмеченными, после «никакие» — снятыми (основу кит выводит из показанного режима, см. `ПравкиВетки`).
- Форма уходит обычной отправкой галок: каждая показанная отмеченная галка — `Имя=Значение`. Чего на странице не было, того в форме нет: сервер знает, что показывал, — первые 50 каждой ветки или совпадения поиска (строка поиска приходит полем `найти`).

## Контракт сервера

Скрипт ничего не решает за сервер: он берёт те же адреса, что ссылки и кнопки без скрипта, и ищет в ответе признаки кита. Ответ может быть страницей целиком — скрипт возьмёт из неё нужный кусок, а без скрипта человек увидит эту страницу.

**Страница ветки.** Запрос — `GET Адрес?ветка=<ключ ветки>&страница=<N>` (у корня дерева — без `ветка`), `N` с единицы. Ответ — HTML (`text/html`, код 200), в котором есть список `data-checktree-page="<ключ ветки>"`: его узлы `li.checktree__node` скрипт дописывает в ветку, пропуская те, чей ключ в ветке уже есть. Строка `data-checktree-more="<ключ ветки>"` из ответа встаёт на место прежней «Показать ещё»; нет её — показано всё. Напечатать такой ответ — то же дерево со словом `Ветка(Ключ, Страница, Всего)`: узлы — дети ветки на этой странице.

```bsl
// GET /образец-дерева/ветка?ветка=alpha&страница=2
Страница = Кит.ДеревоГалок(УчастникиСтраницы(Проект, Номер))
	.Подпись(Проект.Подпись).Адрес("/образец-дерева/ветка")
	.Ветка(Проект.Ключ, Номер, Проект.Всего);
Ответ.ТелоТекст = Каркас.Страница("Участники проекта", Страница, Контекст);
```

```живой Страница ветки — ответ адреса веток

	Дети.Добавить(Новый Структура("Имя, Подпись", "alpha-" + Формат(Номер, "ЧЦ=3; ЧВН=; ЧГ=0"),
		"Участник " + Формат(Номер, "ЧГ=0")));

```

**Страница ветки без скрипта** (дев-сборка 10). Без скрипта человек видит ответ адреса веток страницей — вместо дерева. У дерева с режимами назовите режим ветки четвёртым аргументом: `Ветка(Ключ, Страница, Всего, Режим)`. Тогда страница печатается целиком: строка ветки с её сегментами режима (те же радиокнопки `режим:<ключ>`, что в дереве), дети «все» и «никакие» — запертыми его состоянием, над ними ряд отмеченного (`Отмеченные`), под ними ряд и сводка правок и поле `показано` — в той же обёртке `data-checktree-set`. Положите её в ту же форму, что дерево: смена режима и галки уйдут, как из дерева. Скрипт, когда берёт страницу запросом, по-прежнему забирает из неё только список детей. Ответит [образец получателей](/образец-получателей/ветка?ветка=epsilon&страница=1).

```живой Страница ветки с режимом — и без скрипта
Дети = Новый Массив();
Для Номер = 51 По 53 Цикл
	Дети.Добавить(Новый Структура("Имя, Подпись", "epsilon-" + Формат(Номер, "ЧЦ=3; ЧВН=; ЧГ=0"),
		"Участник " + Формат(Номер, "ЧГ=0")));
КонецЦикла;

HTML = Кит.ДеревоГалок(Дети).Подпись("Эпсилон").Адрес("/образец-получателей/ветка").Режимы()
	.Ветка("epsilon", 2, 120, "никакие").ТолькоПравки().ПравкиБезСкрипта().СводкаПравок().Рендер();
```

**Ответ поиска.** Запрос со скриптом — `GET Поиск?найти=<строка>`; без скрипта — отправка формы дерева на адрес поиска (`POST`, строка поиска — полем `найти`, остальные поля формы рядом). Ответ — HTML, в котором есть блок `data-checktree-found`: скрипт кладёт его на место веток. Напечатать — дерево совпадений со словом `Найдено(Запрос, Всего)` и словом `Поиск`, чтобы без скрипта поле помнило строку; ничего не нашлось — то же слово и пустой массив узлов.

**Отправка формы.** Со скриптом и `ТолькоПравки()` галки и радиокнопки режимов дерева в форму не уходят; вместо них приходят поля:

| Поле | Значение |
| --- | --- |
| `правки` | `1` — форма прислала правки, а не галки; приходит и тогда, когда правок нет |
| `включить` | ключ узла, который включили; по полю на узел |
| `снять` | ключ узла, который сняли; по полю на узел |
| `режим` | `<ключ ветки>:<режим>` — режим, который сменили |
| `основа` | `<ключ ветки>:все` или `:никакие` — «выбранные» начаты массовой отметкой (дев-сборка 10): набор ветки — основа плюс `включить` и минус `снять` |

Без скрипта приходят галки (`Имя=Значение` показанных отмеченных), радиокнопки режимов `режим:<ключ>=<режим>`, строка поиска `найти` и, если нажали, `найденные=вкл` или `выкл`; со словом `ПравкиБезСкрипта()` — и поле `показано`: перечень через запятую, `+ключ`, `-ключ`, `~ключ` — галка, напечатанная включённой, снятой или «частично», `=ключ:режим` — режим ветки (запятая и процент в ключе — `%2C` и `%25`). Ветка, которую включили или сняли целиком, приходит своей правкой и правками загруженных детей; детей, которых скрипт не загружал, в правках нет — «всю ветку» говорит режим «все».

Правок одного имени приходит несколько, поэтому тело разбирают строкой: `Кит.РазобратьПравкиДерева(Тело)` (то же, что `ДеревоГалок.РазобратьПравки`; словами кита с дев-сборки 10 — прежний вход `НаборКомпонентов` для этого не нужен, как и для `Кит.РазмерСтраницыДерева()`) отдаёт `Правки` (Булево), `Включить` и `Снять` (массивы ключей), `Режимы` (соответствие: ключ ветки — режим) — режимы в обоих видах, со скриптом и без, — `Показанные` (ключи из поля `показано`; пришло оно без `правки=1` — `Включить`, `Снять` и `Режимы` посчитаны против него) и `Основы` (ключ ветки — «все» | «никакие»: от чего начались «выбранные»; без скрипта кит выводит основу из показанного режима). `Кит.ПравкиВеткиДерева(Разбор, КлючВетки, КлючиДетей)` (`ДеревоГалок.ПравкиВетки`) раскладывает правки одной ветки: `Режим` (новый, "" — не меняли), `БылРежим` (основа), `Включённые`, `Снятые` — только её детей; у режима «все» и «никакие» правок детей нет.

```bsl
Итог = Кит.РазобратьПравкиДерева(ТелоЗапроса);
Если Итог.Правки ИЛИ Итог.Показанные.Количество() > 0 Тогда
	// поменять только то, что пришло: Итог.Включить, Итог.Снять, Итог.Режимы
	Ветка = Кит.ПравкиВеткиДерева(Итог, "alpha", КлючиУчастников("alpha"));
	Если Ветка.Режим = "все" ИЛИ Ветка.Режим = "никакие" Тогда
		// весь проект | никого
	ИначеЕсли Ветка.БылРежим = "все" Тогда
		// все участники минус Ветка.Снятые
	ИначеЕсли Ветка.БылРежим = "никакие" Тогда
		// только Ветка.Включённые
	Иначе
		// хранимый выбор плюс Ветка.Включённые минус Ветка.Снятые
	КонецЕсли;
Иначе
	// без скрипта: показанные галки целиком, режимы — в Итог.Режимы
КонецЕсли;
```

## Узлом холста

На [холсте](холст) дерево кладут в форму — `Кит.ДеревоГалок(Узлы)`: узлы массивом первым аргументом, подпись — словом `.Подпись(…)`, узел по одному — словом `.Узел(…)`. Прежний вход со структурой-моделью (`Кит.ДеревоГалок(Новый Структура("Узлы", …))`) работает как раньше. Примеры узлом — выше на странице.
