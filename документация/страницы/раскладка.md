# Раскладка

Роды раскладки решают, где узлы стоят на экране: подряд, в строку, в коробке, под свёрнутой строкой или одной группой полей. Содержимого у них нет — его кладут внутрь.

## Какой род взять

- **Холст** — подряд без своего тега. Нужен корень куска экрана или функция, которая возвращает несколько узлов.
- **Область** — блок со своим тегом и видом. На неё вешают признак, роль, якорь.
- **Ряд** — узлы в строку с переносом: кнопки выбора, плашки, действия записи.
- **Статья** — самостоятельный кусок, который можно вынуть из списка: карточка объекта.
- **Раскрывашка** — свёрнутая строка отвечает «что это», развёрнутая отдаёт содержимое.
- **Группа** — поля, которые браузер и скринридер считают одним целым.

Не берите область там, где хватает холста: обёртка, которой никто не просил, ломает вертикальный ритм соседей. Равнозначные блоки в колонки раскладывает компонент «Сетка» — о нём ниже, а о колонках и шаге интервалов — на странице [Сетка и интервалы](сетка).

## Холст и Ничего

Холст печатает детей подряд и не добавляет ни одного тега. Подробно о нём — на странице [Холст и узлы](холст).

```живой Холст — группировка без своего тега
HTML = Кит.Холст(
	Кит.Примечание("первый абзац"),
	Кит.Примечание("второй абзац")).Рендер();
```

Ничего — тот же узел, но для места, где показывать нечего. Его не наполняют.

```живой Ничего — место, где показывать нечего
HTML = Кит.Ничего().Рендер();
```

## Область

Область — коробка с тегом `div`. Слово `.Вид(…)` задаёт её роль на экране: «вставка» — врезка пунктиром внутри формы, «карточки» — колонка карточек, «проза» — чужой документ, набранный типографски, «полоса» — колонка содержимого по центру.

```живой Область — блок со своим тегом, видом и признаком
HTML = Кит.Область(Кит.Примечание("врезка пунктиром внутри формы"))
	.Вид("вставка").Признак("step", "1").Рендер();
```

Вставка нужна там, где шаг формы надо выделить, но своя секция для него — слишком много.

```живой Вставка с заголовком и лидом
HTML = Кит.Область(
	Кит.Надпись("Шаг 2. Ключ доступа").Вид("заголовок"),
	Кит.Надпись("Скопируйте ключ: второй раз его не покажут.").Вид("лид"),
	Кит.БлокКоманды("ключ-7f3a-91c2")).Вид("вставка").Рендер();
```

## Ряд

Ряд ставит узлы в строку и переносит их, когда строка кончается. Вид у ряда обязателен и идёт первым аргументом, дети — за ним: «выбор» — взаимоисключающие кнопки, «признаки» — плашки, «действия» — кнопки записи, «справа» — ряд у правого края, «строкой» — значок и значение без переноса.

```живой Ряд — элементы в строку с переносом
HTML = Кит.Ряд("выбор",
	Кит.Кнопка("Все").Вторичная(),
	Кит.Кнопка("Мои").Вторичная()).Рендер();
```

Подпись ряда человеку не видна: она уходит в `aria-label`. Имя у простого `div` скринридер не читает, поэтому ряду с подписью ставьте ещё и роль «группа».

```живой Ряд у правого края, с доступным именем
HTML = Кит.Ряд("справа", Кит.Кнопка("Создать проект").Основная().Иконка("плюс"))
	.Подпись("Действия списка").Роль("группа").Рендер();
```

## Статья

Статья — лендмарк `article`: её можно вынуть из списка, и она останется понятной. Этим она и отличается от области.

```живой Статья — кусок, который можно вынуть из списка
HTML = Кит.Статья(
	Кит.Заголовок(3, "Проект «Альфа»"),
	Кит.Примечание("Проект по умолчанию").Вид("описание")).Вид("карточка").Рендер();
```

## Раскрывашка

Раскрывашка — нативный `details`: раскрывается без единой строки скрипта. У неё два холста. Тело — дети узла, свёрнутую строку наполняет слово `Шапка(…)`: с аргументами оно кладёт их в шапку и возвращает саму раскрывашку, без аргументов отдаёт холст шапки.

```живой Раскрывашка — свёрнутая строка наполняется словом Шапка(…)
HTML = Кит.Раскрывашка(Кит.Примечание("содержимое видно после раскрытия"))
	.Шапка("Ещё три источника").Вид("врезка").Рендер();
```

Без слова `.Вид(…)` раскрывашка печатается панелью с рамкой. `Открыть()` печатает её сразу развёрнутой: так открывают подробность, которую человек пришёл прочесть.

```живой Раскрывашка, открытая сразу
HTML = Кит.Раскрывашка(Кит.Примечание("открыта по умолчанию"))
	.Шапка("Подробности").Открыть().Рендер();
```

## Группа

Группа — `fieldset`. Подпись группы — первый аргумент, дети — за ней; подпись видима и печатается легендой первой строкой. Слово `.Вид(…)`: «набор» — группа-переключатель, «простая» — без оформления (существует, чтобы отключать и прятать поля вместе), «раздел» — часть длинной формы.

```живой Группа — набор полей со своей легендой
HTML = Кит.Группа("Видимость",
	Кит.Поле("публичный", "Показывать всем").Значение(Истина)).Вид("набор").Рендер();
```

Длинную форму делят разделы. Подпись раздела печатается заголовком, раздел от раздела отделяет черта, вложенные группы внутри раздела — без рамок. Действия собираются одним рядом вне формы: кнопка называет свою форму по якорю (слово `ВФорме(…)`, атрибут `form`).

```живой Разделы длинной формы и действия одним рядом
Форма = Кит.ФормаБезТокена("/рассылки",
	Кит.Группа("Куда отправлять",
		Кит.Поле("адрес", "Адрес")).Вид("раздел"),
	Кит.Группа("О чём сообщать",
		Кит.Группа("Темы",
			Кит.Поле("заказы", "Новые заказы").Значение(Истина)
				.Подсказка("как только заказ оформлен"))).Вид("раздел"))
	.Вид("столбик").Якорь("рассылка-правка");

HTML = Кит.Холст(Форма,
	Кит.Ряд("действия",
		Кит.Кнопка("Сохранить").Основная().ВФорме("рассылка-правка"),
		Кит.Кнопка("Отмена").Вторичная().Адрес("/рассылки"))).Рендер();
```

## Сетка

Сетка — компонент, а не род, но в дереве она ведёт себя как раскладка: каждый ребёнок узла становится своей ячейкой. Число колонок задаёт слово `Колонки(…)`: «авто» или от 1 до 4. Подпись сетки — слово `Заголовок(…)` — уходит в `aria-label`.

```живой Сетка: каждый ребёнок — своя ячейка
HTML = Кит.Сетка(
	Кит.Плитка("12", "Проектов"),
	Кит.Плитка("340", "Ключей"),
	Кит.Плитка("4,2 ГБ", "Занято")).Колонки(3).Заголовок("Показатели").Рендер();
```

## Доступность

- Раскрывашка — нативный `details`: клавиатура, фокус и состояние «свёрнуто/развёрнуто» работают без скрипта. Подпись раскрывашки кит вешает `aria-label` на свёрнутую строку.
- Легенда группы печатается первым ребёнком `fieldset`, как требует HTML: скринридер читает её перед каждым полем группы.
- Ряд без видимого заголовка назовите подписью и дайте ему роль «группа»: подпись станет `aria-label`, роль — `role="group"`.
- Признак (`data-*`) — для скрипта, а не для скринридера. Имя признака — латиницей, цифрами и дефисом, иначе он молча не печатается.
