# Раскладка

Роды раскладки решают, где узлы стоят на экране: подряд, в строку, в коробке, под свёрнутой строкой или одной группой полей. Содержимого у них нет — его кладут внутрь.

## Какой род взять

- **Холст** — подряд без своего тега. Нужен корень куска экрана или функция, которая возвращает несколько узлов.
- **Область** — блок со своим тегом и видом. На неё вешают признак, роль, якорь.
- **Ряд** — узлы в строку с переносом: кнопки выбора, плашки, действия записи.
- **Статья** — самостоятельный кусок, который можно вынуть из списка: карточка объекта.
- **Раскрывашка** — свёрнутая строка отвечает «что это», развёрнутая отдаёт содержимое.
- **Группа** — поля, которые браузер и скринридер считают одним целым.

Не берите область там, где хватает холста: обёртка, которой никто не просил, ломает вертикальный ритм соседей. Равнозначные блоки в колонки раскладывает компонент «Сетка» — о нём ниже, а о колонках и шаге интервалов — на странице [Сетка и интервалы](сетка).

## Холст и Ничего

Холст печатает детей подряд и не добавляет ни одного тега. Подробно о нём — на странице [Холст и узлы](холст).

```живой Холст — группировка без своего тега
Холст = Кит.Холст();
Холст.Добавить(Кит.Примечание("первый абзац"));
Холст.Добавить(Кит.Примечание("второй абзац"));

HTML = Холст.Рендер();
```

Ничего — тот же узел, но для места, где показывать нечего. Его не наполняют.

```живой Ничего — место, где показывать нечего
HTML = Кит.Ничего().Рендер();
```

## Область

Область — коробка с тегом `div`. Вид задаёт её роль на экране: «вставка» — врезка пунктиром внутри формы, «карточки» — колонка карточек, «проза» — чужой документ, набранный типографски, «полоса» — колонка содержимого по центру.

```живой Область — блок со своим тегом, видом и признаком
Область = Кит.Область("вставка");
Область.Признак("step", "1");
Область.Добавить(Кит.Примечание("врезка пунктиром внутри формы"));

HTML = Область.Рендер();
```

Вставка нужна там, где шаг формы надо выделить, но своя секция для него — слишком много.

```живой Вставка с заголовком и лидом
Область = Кит.Область("вставка");
Область.Добавить(Кит.Надпись("заголовок")).Добавить(Кит.Текст("Шаг 2. Ключ доступа"));
Область.Добавить(Кит.Надпись("лид")).Добавить(Кит.Текст("Скопируйте ключ: второй раз его не покажут."));
Область.Добавить(Кит.БлокКоманды(Новый Структура("Команда", "ключ-7f3a-91c2")));

HTML = Область.Рендер();
```

## Ряд

Ряд ставит узлы в строку и переносит их, когда строка кончается. Вид у ряда обязателен: «выбор» — взаимоисключающие кнопки, «признаки» — плашки, «действия» — кнопки записи, «справа» — ряд у правого края, «строкой» — значок и значение без переноса.

```живой Ряд — элементы в строку с переносом
Ряд = Кит.Ряд("выбор");
Ряд.Добавить(Кит.Кнопка(Новый Структура("Подпись, Вариант", "Все", "вторичная")));
Ряд.Добавить(Кит.Кнопка(Новый Структура("Подпись, Вариант", "Мои", "вторичная")));

HTML = Ряд.Рендер();
```

Подпись ряда человеку не видна: она уходит в `aria-label`. Имя у простого `div` скринридер не читает, поэтому ряду с подписью ставьте ещё и роль «группа».

```живой Ряд у правого края, с доступным именем
Ряд = Кит.Ряд("справа").Подпись("Действия списка").Роль("группа");
Ряд.Добавить(Кит.Кнопка(Новый Структура("Подпись, Вариант, Иконка",
	"Создать проект", "основная", "плюс")));

HTML = Ряд.Рендер();
```

## Статья

Статья — лендмарк `article`: её можно вынуть из списка, и она останется понятной. Этим она и отличается от области.

```живой Статья — кусок, который можно вынуть из списка
Статья = Кит.Статья("карточка");
Статья.Добавить(Кит.Заголовок(3)).Добавить(Кит.Текст("Проект «Альфа»"));
Статья.Добавить(Кит.Примечание("Проект по умолчанию", "описание"));

HTML = Статья.Рендер();
```

## Раскрывашка

Раскрывашка — нативный `details`: раскрывается без единой строки скрипта. У неё два холста. Свёрнутую строку наполняют через `Шапка()`, тело — обычным `Добавить()`.

```живой Раскрывашка — свёрнутая строка наполняется через Шапка()
Раскрывашка = Кит.Раскрывашка("врезка");
Раскрывашка.Шапка().Добавить(Кит.Текст("Ещё три источника"));
Раскрывашка.Добавить(Кит.Примечание("содержимое видно после раскрытия"));

HTML = Раскрывашка.Рендер();
```

Без вида раскрывашка печатается панелью с рамкой. `Открыть()` печатает её сразу развёрнутой: так открывают подробность, которую человек пришёл прочесть.

```живой Раскрывашка, открытая сразу
Раскрывашка = Кит.Раскрывашка();
Раскрывашка.Открыть();
Раскрывашка.Шапка().Добавить(Кит.Текст("Подробности"));
Раскрывашка.Добавить(Кит.Примечание("открыта по умолчанию"));

HTML = Раскрывашка.Рендер();
```

## Группа

Группа — `fieldset`. Подпись группы видима и печатается легендой первой строкой. Вид «набор» — группа-переключатель, «простая» — без оформления (существует, чтобы отключать и прятать поля вместе), «раздел» — часть длинной формы.

```живой Группа — набор полей со своей легендой
Группа = Кит.Группа("Видимость", "набор");
Группа.Добавить(Кит.Поле(Новый Структура("Имя, Метка, Тип, Отмечено",
	"публичный", "Показывать всем", "флажок", Истина)));

HTML = Группа.Рендер();
```

Длинную форму делят разделы. Подпись раздела печатается заголовком, раздел от раздела отделяет черта, вложенные группы внутри раздела — без рамок. Действия собираются одним рядом вне формы: кнопка называет свою форму по якорю (поле `Форма`, атрибут `form`).

```живой Разделы длинной формы и действия одним рядом
Форма = Кит.ФормаБезТокена("/рассылки", "столбик").Якорь("рассылка-правка");
Куда = Форма.Добавить(Кит.Группа("Куда отправлять", "раздел"));
Куда.Добавить(Кит.Поле(Новый Структура("Имя, Метка", "адрес", "Адрес")));

Что = Форма.Добавить(Кит.Группа("О чём сообщать", "раздел"));
Темы = Что.Добавить(Кит.Группа("Темы"));
Темы.Добавить(Кит.Поле(Новый Структура("Имя, Метка, Тип, Отмечено, Подсказка",
	"заказы", "Новые заказы", "флажок", Истина, "как только заказ оформлен")));

Действия = Кит.Ряд("действия");
Действия.Добавить(Кит.Кнопка(Новый Структура("Подпись, Вариант, Форма",
	"Сохранить", "основная", "рассылка-правка")));
Действия.Добавить(Кит.Кнопка(Новый Структура("Подпись, Адрес, Вариант", "Отмена", "/рассылки", "вторичная")));

Страница = Кит.Холст();
Страница.Добавить(Форма);
Страница.Добавить(Действия);
HTML = Страница.Рендер();
```

## Сетка

Сетка — компонент, а не род, но в дереве она ведёт себя как раскладка: каждый ребёнок узла становится своей ячейкой. Число колонок задаёт модель: «авто» или от 1 до 4. Подпись сетки (`Заголовок`) уходит в `aria-label`.

```живой Сетка: каждый ребёнок — своя ячейка
Сетка = Кит.Сетка(Новый Структура("Колонки, Заголовок", 3, "Показатели"));
Сетка.Добавить(Кит.Плитка(Новый Структура("Подпись, Значение", "Проектов", "12")));
Сетка.Добавить(Кит.Плитка(Новый Структура("Подпись, Значение", "Пакетов", "340")));
Сетка.Добавить(Кит.Плитка(Новый Структура("Подпись, Значение", "Занято", "4,2 ГБ")));

HTML = Сетка.Рендер();
```

## Доступность

- Раскрывашка — нативный `details`: клавиатура, фокус и состояние «свёрнуто/развёрнуто» работают без скрипта. Подпись раскрывашки кит вешает `aria-label` на свёрнутую строку.
- Легенда группы печатается первым ребёнком `fieldset`, как требует HTML: скринридер читает её перед каждым полем группы.
- Ряд без видимого заголовка назовите подписью и дайте ему роль «группа»: подпись станет `aria-label`, роль — `role="group"`.
- Признак (`data-*`) — для скрипта, а не для скринридера. Имя признака — латиницей, цифрами и дефисом, иначе он молча не печатается.
