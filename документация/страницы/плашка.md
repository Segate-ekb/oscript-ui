# Плашка

Плашка — короткая метка у объекта: его состояние, тип или источник одним-двумя словами. В Material это малый чип высотой 24 пикселя; цвет состояния он несёт тональным контейнером своей роли.

## Когда использовать

- Нужно показать состояние записи: «черновик», «готово», «отозвано».
- У объекта есть признак, по которому его отличают от соседей: «внешний», «основное».
- Человек снимает применённую метку или отбор — плашка с крестиком.

Не берите плашку для действия — для этого есть [кнопка](кнопка). Для фразы о результате действия подойдёт [тост](тост). Признак, который принадлежит самому имени объекта (подписан, закреплён), ставят значком у имени в [шапке объекта](шапка-объекта).

## Виды

Нейтральная плашка — признак без оценки. Её заливка — surface-container-highest, текст — приглушённый.

```живой Нейтральная
HTML = Набор.Тег().Отрисовать("черновик");
```

Статусные виды берут тональные контейнеры Material: заливка — контейнер роли, текст — цвет «на контейнере». Цвет узнаётся издалека, а текст на нём остаётся читаемым в обеих темах.

```живой Вид ok — успех, всё в порядке
HTML = Набор.Тег().Отрисовать(Новый Структура("Текст, Вид", "готово", "ok"));
```

```живой Вид warn — внимание, но не авария
HTML = Набор.Тег().Отрисовать(Новый Структура("Текст, Вид", "устаревший", "warn"));
```

```живой Вид err — ошибка или отказ
HTML = Набор.Тег().Отрисовать(Новый Структура("Текст, Вид", "отозвано", "err"));
```

```живой Вид accent — выделенное, текущее
HTML = Набор.Тег().Отрисовать(Новый Структура("Текст, Вид", "текущее", "accent"));
```

Вид можно назвать и по-русски: «успех», «предупреждение», «ошибка», «акцент». Неизвестный вид даёт нейтральную плашку: в CSS-класс попадает только значение из списка.

## Ссылка и подсказка

С `Адресом` плашка становится ссылкой: на наведении её заливку накрывает слой состояния. Так плашка «внешний» ведёт к списку всех внешних объектов.

```живой Ссылка с иконкой
HTML = Набор.Тег().Отрисовать(Новый Структура("Текст, Адрес, Иконка",
	"внешний", "/проекты", "тег"));
```

`Подсказка` печатается атрибутом `title` — всплывающей подсказкой мыши. Она поясняет, но не заменяет текст плашки.

```живой С подсказкой
HTML = Набор.Тег().Отрисовать(Новый Структура("Текст, Вид, Подсказка",
	"устаревший", "warn", "Есть редакция новее — 1.1.0"));
```

## Крестик снятия

`Действие` — разметка управления, которая печатается ВНУТРИ плашки. Поэтому перенос строки не отрывает крестик от подписи. Крестик — обычная [кнопка](кнопка)-значок с подписью.

```живой С крестиком снятия — кнопка живёт внутри плашки
Крестик = Набор.Кнопка().Отрисовать(
	Новый Структура("Подпись, Вариант, Размер, Иконка, ТолькоИконка",
		"Снять метку", "ссылка", "малый", "закрыть", Истина));

HTML = Набор.Тег().Отрисовать(Новый Структура("Текст, Вид, Действие",
	"избранное", "accent", Крестик));
```

`Действие` вместе с `Адресом` кит не соберёт: кнопка внутри ссылки не нажимается, и компонент бросает исключение.

## Ряд плашек

Несколько плашек печатаются одним элементом `Ряд`: они стоят в строку и переносятся вместе. Соседними детьми контейнера их не ставят — вертикальный отступ контейнера достался бы каждой и опустил бы строку.

```живой Ряд плашек — один элемент разметки
Плашки = Новый Массив();
Плашки.Добавить(Новый Структура("Текст, Вид", "Основное", "accent"));
Плашки.Добавить(Новый Структура("Текст, Вид", "Открытое", "ok"));

HTML = Набор.Тег().Ряд(Плашки);
```

`Неопределено` вместо модели — признака нет, и плашка не печатается. Это правило живёт в компоненте, поэтому в ряд можно класть признаки как есть, без проверок.

```живой Неопределено в ряду пропускается
Плашки = Новый Массив();
Плашки.Добавить(Новый Структура("Текст, Вид", "Основное", "accent"));
Плашки.Добавить(Неопределено);
Плашки.Добавить("Открытое");

HTML = Набор.Тег().Ряд(Плашки);
```

## Гайдлайны

```делайте Одно-два слова: состояние читается с одного взгляда
HTML = Набор.Тег().Отрисовать(Новый Структура("Текст, Вид", "устаревший", "warn"));
```

```не-делайте Фраза в плашке: это уже сообщение, а не метка
HTML = Набор.Тег().Отрисовать(Новый Структура("Текст, Вид",
	"Эта редакция устарела, обновитесь до 1.1.0 как можно скорее", "warn"));
```

```делайте Цвет по смыслу, нейтральное — без цвета
Плашки = Новый Массив();
Плашки.Добавить("черновик");
Плашки.Добавить(Новый Структура("Текст, Вид", "отозвано", "err"));

HTML = Набор.Тег().Ряд(Плашки);
```

```не-делайте Цвет для красоты: красный «черновик» пугает зря
Плашки = Новый Массив();
Плашки.Добавить(Новый Структура("Текст, Вид", "черновик", "err"));
Плашки.Добавить(Новый Структура("Текст, Вид", "отозвано", "accent"));

HTML = Набор.Тег().Ряд(Плашки);
```

```делайте Крестик — внутри плашки, через Действие
Крестик = Набор.Кнопка().Отрисовать(
	Новый Структура("Подпись, Вариант, Размер, Иконка, ТолькоИконка",
		"Снять отбор «внешний»", "ссылка", "малый", "закрыть", Истина));

HTML = Набор.Тег().Отрисовать(Новый Структура("Текст, Действие", "внешний", Крестик));
```

```не-делайте Крестик отдельной кнопкой рядом: при переносе он уедет от подписи
HTML = Набор.Тег().Отрисовать("внешний")
	+ Набор.Кнопка().Отрисовать(
		Новый Структура("Подпись, Вариант, Размер, Иконка, ТолькоИконка",
			"Снять", "ссылка", "малый", "закрыть", Истина));
```

## Доступность

- Смысл плашки несёт её текст, а цвет только повторяет его. Плашку без слов не ставьте: скринридер прочтёт пустоту. Нет признака — передайте `Неопределено`, и плашки не будет.
- Подпись крестика уходит в `aria-label`. Называйте в ней, что снимается: «Снять отбор «внешний»», а не «Закрыть».
- `Подсказка` в `title` не видна с клавиатуры и на телефоне. Не кладите туда то, без чего плашку не понять.
- Плашка-ссылка — обычная ссылка с текстом: её находит обход по Tab и список ссылок скринридера.

## Узлом холста

На [холсте](холст) плашка и ряд плашек — узлы. Их кладут в ячейку таблицы, в ряд шапки, в [сводку](сводка).

```живой Плашка узлом дерева
HTML = Кит.Плашка(Новый Структура("Текст, Вид", "свежий", "ok")).Рендер();
```

```живой Ряд плашек узлом дерева
Плашки = Новый Массив();
Плашки.Добавить(Новый Структура("Текст, Вид", "Основное", "accent"));
Плашки.Добавить(Новый Структура("Текст", "Открытое"));

HTML = Кит.РядПлашек(Плашки).Рендер();
```

Дети узла-плашки печатаются ВМЕСТО значка и текста модели. Так плашку собирают из своих узлов — например, с кодом версии внутри.

```живой Плашка, собранная из узлов
Плашка = Кит.Плашка(Новый Структура("Текст, Вид", "обновите до 1.1.0", "warn"));
Плашка.Добавить(Кит.Текст("обновите до "));
Плашка.Добавить(Кит.Код("1.1.0"));

HTML = Плашка.Рендер();
```

## Модель

В наборе компонентов плашка зовётся `Набор.Тег()`, а класс компонента — `Плашка`: имя `Тег` в OneScript занято.

```справка Плашка
```

```справка Плашка.Ряд
```

```справка Кит.Плашка
```

```справка Кит.РядПлашек
```

```словарь компонент:плашка, компонент:плашки
```
