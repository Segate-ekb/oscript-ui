# Таблица

Таблица показывает записи строками, а их признаки колонками: версия, дата, состояние. Кит печатает настоящую `<table>` в обёртке с прокруткой. На телефоне такая таблица умеет перестраиваться в стопку карточек.

## Когда использовать

- Записей много, и их сравнивают по одним и тем же признакам.
- Человек ищет нужную строку глазами, пробегая по колонке.
- У каждой записи есть свои действия, и место им — в её строке.

Не берите таблицу для одной записи: её покажут [сводка](сводка) или пары «подпись — значение» из [списков](списки). Одно число, ради которого открыли экран, — это [плитка](плитка).

## Шапка и строки

Колонки — массив заголовков, строки — массивы ячеек. Ячейка-строка экранируется, поэтому значения из базы кладут в таблицу как есть.

```живой Шапка и строки
Колонки = Новый Массив();
Колонки.Добавить("Редакция");
Колонки.Добавить("Дата");

Первая = Новый Массив();
Первая.Добавить("1.0.0");
Первая.Добавить("2026-07-29");

Строки = Новый Массив();
Строки.Добавить(Первая);

HTML = Набор.Таблица().Отрисовать(Новый Структура("Колонки, Строки", Колонки, Строки));
```

Ячейка-структура с полем `HTML` несёт готовую разметку кита: плашку, кнопку, ссылку. Эта разметка доверенная и не экранируется — собирайте её только компонентами. `Подпись` печатается тегом `<caption>`: она называет таблицу и для глаза, и для скринридера.

```живой Подпись таблицы и плашка в ячейке
Колонки = Новый Массив();
Колонки.Добавить("Редакция");
Колонки.Добавить("Состояние");

Первая = Новый Массив();
Первая.Добавить("1.1.0");
Первая.Добавить(Новый Структура("HTML",
	Набор.Тег().Отрисовать(Новый Структура("Текст, Вид", "действует", "ok"))));

Вторая = Новый Массив();
Вторая.Добавить("1.0.0");
Вторая.Добавить(Новый Структура("HTML", Набор.Тег().Отрисовать("снята")));

Строки = Новый Массив();
Строки.Добавить(Первая);
Строки.Добавить(Вторая);

HTML = Набор.Таблица().Отрисовать(Новый Структура("Подпись, Колонки, Строки",
	"Редакции пакета", Колонки, Строки));
```

## Пустая таблица

Без строк таблица не рисует пустую шапку — вместо неё печатаются слова из поля `Пусто`. Если их не задать, кит напишет «Ничего не найдено»; это верно только для поиска.

```живой Пустая — вместо строк слова
Колонки = Новый Массив();
Колонки.Добавить("Редакция");

HTML = Набор.Таблица().Отрисовать(Новый Структура("Колонки, Строки, Пусто",
	Колонки, Новый Массив(), "Редакций пока нет"));
```

На холсте у таблицы есть свой холст `Пусто()`. Его печатают вместо таблицы, когда записей нет, и туда кладут полноценное [пустое состояние](пустое-состояние).

```живой Узлом холста — вместо таблицы печатается её холст «пусто»
Таблица = Кит.Таблица();
Таблица.Добавить(Кит.Колонка("Редакция"));
Таблица.Добавить(Кит.Колонка("Дата"));
Таблица.Пусто().Добавить(Кит.ПустоеСостояние(Новый Структура("Заголовок, Пояснение",
	"Редакций пока нет", "Первая появится здесь после публикации.")));

HTML = Таблица.Рендер();
```

## Разворот

Подробности записи, которые не влезают в колонки, печатаются разворотом — строкой под записью во всю ширину таблицы. Запись и разворот читаются одной записью: разделителя между ними нет, и при наведении подсвечиваются обе строки.

```живой Разворот строки
Колонки = Новый Массив();
Колонки.Добавить("Редакция");
Колонки.Добавить("Дата");

Первая = Новый Структура("Ячейки, Разворот",
	СтрРазделить("1.1.0,2026-07-29", ","),
	"<p class=""muted"">Исправлен разбор дат в отчёте за период.</p>");

Вторая = Новый Массив();
Вторая.Добавить("1.0.0");
Вторая.Добавить("2026-06-02");

Строки = Новый Массив();
Строки.Добавить(Первая);
Строки.Добавить(Вторая);

HTML = Набор.Таблица().Отрисовать(Новый Структура("Колонки, Строки", Колонки, Строки));
```

На холсте разворот — второй холст записи: `Запись.Разворот()`. Пустой разворот не печатается вовсе.

```живой Разворот узлом холста
Таблица = Кит.Таблица();
Таблица.Добавить(Кит.Колонка("Редакция"));
Таблица.Добавить(Кит.Колонка("Дата"));

Запись = Таблица.Добавить(Кит.Запись());
Запись.Добавить(Кит.Ячейка()).Добавить(Кит.Текст("1.1.0"));
Запись.Добавить(Кит.Ячейка()).Добавить(Кит.Текст("2026-07-29"));
Запись.Разворот().Добавить(Кит.Примечание("Исправлен разбор дат в отчёте за период."));

HTML = Таблица.Рендер();
```

## Карточками на телефоне

`Кит.Таблица("карточками")` на экране уже 720 пикселей печатает каждую запись карточкой. Шапки у карточки нет, поэтому ячейка сама несёт подпись своей колонки — приглушённой строкой над значением. Сузьте окно, чтобы увидеть это на образце.

Подписи нет у первой, заглавной ячейки, у ячейки с меню строки и у пустой ячейки. Пустая ячейка на узком экране вовсе не занимает места. Колонка, чьи значения называют себя сами («занято 12 КБ из 100», плашка «действует»), отказывается от подписи явно — `БезПодписиВЗаписи()`.

```живой Карточками — на телефоне ячейка подписана колонкой
Таблица = Кит.Таблица("карточками");
Таблица.Добавить(Кит.Колонка("Редакция"));
Таблица.Добавить(Кит.Колонка("Дата"));
Таблица.Добавить(Кит.Колонка("Состояние").БезПодписиВЗаписи());
Таблица.Добавить(Кит.Колонка("Объём").БезПодписиВЗаписи());

Первая = Таблица.Добавить(Кит.Запись());
Первая.Добавить(Кит.Ячейка()).Добавить(Кит.Текст("1.1.0"));
Первая.Добавить(Кит.Ячейка()).Добавить(Кит.Текст("2026-07-29"));
Первая.Добавить(Кит.Ячейка()).Добавить(Кит.Плашка("действует"));
Первая.Добавить(Кит.Ячейка("величина")).Добавить(Кит.Текст("занято 12 КБ из 100"));

Вторая = Таблица.Добавить(Кит.Запись());
Вторая.Добавить(Кит.Ячейка()).Добавить(Кит.Текст("1.0.0"));
Вторая.Добавить(Кит.Ячейка());
Вторая.Добавить(Кит.Ячейка()).Добавить(Кит.Плашка("снята"));
Вторая.Добавить(Кит.Ячейка("величина")).Добавить(Кит.Текст("занято 9 КБ из 100"));

HTML = Таблица.Рендер();
```

Угадывать, называет ли значение себя само, кит не берётся: плашка бывает и состоянием, и названием. Решает разработчик экрана.

## Выделенная запись

`Кит.Запись("выделенная")` заливает строку цветом secondary-container. Так выделяют одну запись, ради которой список открыли: текущую редакцию, свою учётку.

```живой Выделенная запись — текущая редакция
Таблица = Кит.Таблица();
Таблица.Добавить(Кит.Колонка("Редакция"));
Таблица.Добавить(Кит.Колонка("Дата"));

Текущая = Таблица.Добавить(Кит.Запись("выделенная"));
Текущая.Добавить(Кит.Ячейка()).Добавить(Кит.Текст("1.1.0"));
Текущая.Добавить(Кит.Ячейка()).Добавить(Кит.Плашка(Новый Структура("Текст, Вид", "текущая", "accent")));

Прежняя = Таблица.Добавить(Кит.Запись());
Прежняя.Добавить(Кит.Ячейка()).Добавить(Кит.Текст("1.0.0"));
Прежняя.Добавить(Кит.Ячейка()).Добавить(Кит.Текст("2026-06-02"));

HTML = Таблица.Рендер();
```

## Узкий столбец и величины

Узкий столбец (`Кит.Колонка("", "узкая")`, `Кит.Ячейка("узкая")`) сжимается по содержимому и не переносится: значок, галочка, счётчик, кнопка строки. Освободившуюся ширину забирают соседи. Ячейка «величина» держит число с единицей одной строкой и приглушает его, а ячейка «столбиком» ставит приписку под значением.

```живой Узкий столбец, величина и ячейка столбиком
Таблица = Кит.Таблица();
Таблица.Добавить(Кит.Колонка("Документ"));
Таблица.Добавить(Кит.Колонка("Размер"));
Таблица.Добавить(Кит.Колонка("", "узкая"));

Запись = Таблица.Добавить(Кит.Запись());
Ячейка = Запись.Добавить(Кит.Ячейка("столбиком"));
Ячейка.Добавить(Кит.Текст("Сводный отчёт"));
Ячейка.Добавить(Кит.Примечание("обновлён вчера"));
Запись.Добавить(Кит.Ячейка("величина")).Добавить(Кит.Текст("128 КБ"));
Запись.Добавить(Кит.Ячейка("узкая")).Добавить(Кит.Кнопка(
	Новый Структура("Подпись, Вариант, Размер, Иконка, ТолькоИконка",
		"Скачать отчёт", "ссылка", "малый", "скачать", Истина)));

HTML = Таблица.Рендер();
```

В таблице карточками узкая ячейка растягивается на всю ширину карточки: иначе число встало бы столбиком по букве.

## Доступность

- Заголовок колонки печатается `<th scope="col">`: скринридер называет колонку при переходе по ячейкам.
- `Подпись` таблицы уходит в `<caption>` — это доступное имя таблицы. Дайте его, когда таблиц на экране несколько.
- Широкая таблица прокручивается внутри своей обёртки, а страница вбок не уезжает.
- Выделенная запись отличается только заливкой. Если выделение несёт смысл, повторите его словом: плашкой «текущая» или текстом в ячейке.
- У кнопки-значка в строке подпись обязательна: она называет действие в `aria-label`.

## Узлом холста

Таблицу из узлов — колонки, записи, ячейки с любыми элементами внутри — подробно разбирает страница [таблица деревом](таблица-деревом). Подпись таблицы на холсте задаёт метод `Подпись()`.

```живой Таблица с подписью узлом холста
Таблица = Кит.Таблица().Подпись("Редакции пакета");
Таблица.Добавить(Кит.Колонка("Редакция"));
Таблица.Добавить(Кит.Запись()).Добавить(Кит.Ячейка()).Добавить(Кит.Текст("1.1.0"));

HTML = Таблица.Рендер();
```
