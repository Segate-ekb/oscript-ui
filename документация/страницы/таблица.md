# Таблица

Таблица показывает записи строками, а их признаки колонками: версия, дата, состояние. Кит печатает настоящую `<table>` в обёртке с прокруткой. На телефоне такая таблица умеет перестраиваться в стопку карточек.

## Когда использовать

- Записей много, и их сравнивают по одним и тем же признакам.
- Человек ищет нужную строку глазами, пробегая по колонке.
- У каждой записи есть свои действия, и место им — в её строке.

Не берите таблицу для одной записи: её покажут [сводка](сводка) или пары «подпись — значение» из [списков](списки). Одно число, ради которого открыли экран, — это [плитка](плитка).

В дереве холста таблица собирается прямо из данных, как в 1С: таблица значений даёт колонки и записи, а подпись задаёт слово (см. [Язык узлов](язык-узлов) и [Таблица деревом](таблица-деревом)).

```живой Узлом холста — словами
Редакции = Новый ТаблицаЗначений;
Редакции.Колонки.Добавить("Редакция");
Редакции.Колонки.Добавить("Состояние");
Редакция = Редакции.Добавить();
Редакция.Редакция = "1.1.0";
Редакция.Состояние = Кит.Плашка("действует").Вид("ok");
Редакция = Редакции.Добавить();
Редакция.Редакция = "1.0.0";
Редакция.Состояние = Кит.Плашка("снята");

HTML = Кит.Таблица(Редакции).Подпись("Редакции отчёта").Рендер();
```

## Шапка и строки

Колонки — массив заголовков, строки — массивы ячеек. Ячейка-строка экранируется, поэтому значения из базы кладут в таблицу как есть.

```живой Шапка и строки
Колонки = Новый Массив();
Колонки.Добавить("Редакция");
Колонки.Добавить("Дата");

Первая = Новый Массив();
Первая.Добавить("1.0.0");
Первая.Добавить("2026-07-29");

Строки = Новый Массив();
Строки.Добавить(Первая);

HTML = Набор.Таблица().Отрисовать(Новый Структура("Колонки, Строки", Колонки, Строки));
```

Ячейка-структура с полем `HTML` несёт готовую разметку кита: плашку, кнопку, ссылку. Эта разметка доверенная и не экранируется — собирайте её только компонентами. `Подпись` печатается тегом `<caption>`: она называет таблицу и для глаза, и для скринридера.

```живой Подпись таблицы и плашка в ячейке
Колонки = Новый Массив();
Колонки.Добавить("Редакция");
Колонки.Добавить("Состояние");

Первая = Новый Массив();
Первая.Добавить("1.1.0");
Первая.Добавить(Новый Структура("HTML",
	Набор.Тег().Отрисовать(Новый Структура("Текст, Вид", "действует", "ok"))));

Вторая = Новый Массив();
Вторая.Добавить("1.0.0");
Вторая.Добавить(Новый Структура("HTML", Набор.Тег().Отрисовать("снята")));

Строки = Новый Массив();
Строки.Добавить(Первая);
Строки.Добавить(Вторая);

HTML = Набор.Таблица().Отрисовать(Новый Структура("Подпись, Колонки, Строки",
	"Редакции пакета", Колонки, Строки));
```

## Пустая таблица

Без строк таблица не рисует пустую шапку — вместо неё печатаются слова из поля `Пусто`. Если их не задать, кит напишет «Ничего не найдено»; это верно только для поиска.

```живой Пустая — вместо строк слова
Колонки = Новый Массив();
Колонки.Добавить("Редакция");

HTML = Набор.Таблица().Отрисовать(Новый Структура("Колонки, Строки, Пусто",
	Колонки, Новый Массив(), "Редакций пока нет"));
```

На холсте у таблицы есть свой холст `Пусто(д…)`. Его печатают вместо таблицы, когда записей нет, и туда кладут полноценное [пустое состояние](пустое-состояние).

```живой Узлом холста — вместо таблицы печатается её холст «пусто»
HTML = Кит.Таблица(Кит.Колонка("Редакция"), Кит.Колонка("Дата"))
	.Пусто(Кит.ПустоеСостояние("Первая появится здесь после публикации.")
		.Заголовок("Редакций пока нет")).Рендер();
```

## Разворот

Подробности записи, которые не влезают в колонки, печатаются разворотом — строкой под записью во всю ширину таблицы. Запись и разворот читаются одной записью: разделителя между ними нет, и при наведении подсвечиваются обе строки.

```живой Разворот строки
Колонки = Новый Массив();
Колонки.Добавить("Редакция");
Колонки.Добавить("Дата");

Первая = Новый Структура("Ячейки, Разворот",
	СтрРазделить("1.1.0,2026-07-29", ","),
	"<p class=""muted"">Исправлен разбор дат в отчёте за период.</p>");

Вторая = Новый Массив();
Вторая.Добавить("1.0.0");
Вторая.Добавить("2026-06-02");

Строки = Новый Массив();
Строки.Добавить(Первая);
Строки.Добавить(Вторая);

HTML = Набор.Таблица().Отрисовать(Новый Структура("Колонки, Строки", Колонки, Строки));
```

На холсте разворот — второй холст записи: `Запись.Разворот(д…)`. Пустой разворот не печатается вовсе.

```живой Разворот узлом холста
HTML = Кит.Таблица(
	Кит.Колонка("Редакция"),
	Кит.Колонка("Дата"),
	Кит.Запись(Кит.Ячейка("1.1.0"), Кит.Ячейка("2026-07-29"))
		.Разворот(Кит.Примечание("Исправлен разбор дат в отчёте за период."))).Рендер();
```

## Карточками на телефоне

`Кит.Таблица().Вид("карточками")` на экране уже 720 пикселей печатает каждую запись карточкой. Шапки у карточки нет, поэтому ячейка сама несёт подпись своей колонки — приглушённой строкой над значением. Сузьте окно, чтобы увидеть это на образце.

Подписи нет у заглавной ячейки (по умолчанию первой), у ячейки с меню строки и у пустой ячейки. Пустая ячейка на узком экране вовсе не занимает места. Колонка, чьи значения называют себя сами («занято 12 КБ из 100», плашка «действует»), отказывается от подписи явно — `БезПодписиВЗаписи()`.

```живой Карточками — на телефоне ячейка подписана колонкой
HTML = Кит.Таблица(
	Кит.Колонка("Редакция"),
	Кит.Колонка("Дата"),
	Кит.Колонка("Состояние").БезПодписиВЗаписи(),
	Кит.Колонка("Объём").БезПодписиВЗаписи(),
	Кит.Запись(
		Кит.Ячейка("1.1.0"),
		Кит.Ячейка("2026-07-29"),
		Кит.Ячейка(Кит.Плашка("действует")),
		Кит.Ячейка("занято 12 КБ из 100").Вид("величина")),
	Кит.Запись(
		Кит.Ячейка("1.0.0"),
		Кит.Ячейка(),
		Кит.Ячейка(Кит.Плашка("снята")),
		Кит.Ячейка("занято 9 КБ из 100").Вид("величина"))).Вид("карточками").Рендер();
```

Угадывать, называет ли значение себя само, кит не берётся: плашка бывает и состоянием, и названием. Решает разработчик экрана.

### Заглавная ячейка и меню строки

Карточку узнают по одной ячейке — имени проекта, участника, документа. Эта ячейка печатается первой строкой карточки и крупнее остальных, шрифтом title-medium. По умолчанию заглавная — первая колонка. Если имя стоит в ряду не первым, колонку называет слово `.Заглавная()`: на широком экране порядок колонок задаёт шапка, а в карточке имя всё равно встаёт наверх.

Ячейка с [меню строки](меню) встаёт в правый верхний угол карточки, напротив заглавной. Так шестерёнка не теряется среди значений. Пункты меню на телефоне, как и прежде, выезжают листом от нижнего края окна.

```живой Заглавная колонка и меню строки — сузьте окно до телефона
HTML = Кит.Таблица(
	Кит.Колонка("Вошёл"),
	Кит.Колонка("Участник").Заглавная(),
	Кит.Колонка("Роль").БезПодписиВЗаписи(),
	Кит.Колонка("Проектов").Вид("узкая"),
	Кит.Колонка().Вид("узкая"),
	Кит.Запись(
		Кит.Ячейка("сегодня"),
		Кит.Ячейка("Анна Смирнова"),
		Кит.Ячейка(Кит.Плашка("владелец").Вид("accent")),
		Кит.Ячейка("4").Вид("узкая"),
		Кит.Ячейка(Кит.Меню("Действия над «Анна Смирнова»",
			Кит.ПунктМеню("Открыть", "/участники/7"),
			Кит.ПунктМеню("Права", "/участники/7/права").Иконка("замок"))).Вид("узкая")),
	Кит.Запись(
		Кит.Ячейка("в марте"),
		Кит.Ячейка("Борис Ким"),
		Кит.Ячейка(Кит.Плашка("участник")),
		Кит.Ячейка("1").Вид("узкая"),
		Кит.Ячейка(Кит.Меню("Действия над «Борис Ким»",
			Кит.ПунктМеню("Открыть", "/участники/9"),
			Кит.ПунктМеню("Права", "/участники/9/права").Иконка("замок"))).Вид("узкая")))
	.Вид("карточками").Рендер();
```

В разметке заглавная ячейка несёт класс `cell-title`, ячейка с меню — `cell-menu`. Оба класса печатаются только у таблицы карточками. У обычной таблицы есть шапка, и её разметка не меняется.

## Выделенная запись

`Кит.Запись().Вид("выделенная")` заливает строку цветом secondary-container. Так выделяют одну запись, ради которой список открыли: текущую редакцию, свою учётку.

```живой Выделенная запись — текущая редакция
HTML = Кит.Таблица(
	Кит.Колонка("Редакция"),
	Кит.Колонка("Дата"),
	Кит.Запись(
		Кит.Ячейка("1.1.0"),
		Кит.Ячейка(Кит.Плашка("текущая").Вид("accent"))).Вид("выделенная"),
	Кит.Запись(Кит.Ячейка("1.0.0"), Кит.Ячейка("2026-06-02"))).Рендер();
```

## Узкий столбец и величины

Узкий столбец (`Кит.Колонка().Вид("узкая")`, `Кит.Ячейка().Вид("узкая")`) сжимается по содержимому и не переносится: значок, галочка, счётчик, кнопка строки. Освободившуюся ширину забирают соседи. Ячейка «величина» держит число с единицей одной строкой и приглушает его, а ячейка «столбиком» ставит приписку под значением.

```живой Узкий столбец, величина и ячейка столбиком
HTML = Кит.Таблица(
	Кит.Колонка("Документ"),
	Кит.Колонка("Размер"),
	Кит.Колонка().Вид("узкая"),
	Кит.Запись(
		Кит.Ячейка("Сводный отчёт", Кит.Примечание("обновлён вчера")).Вид("столбиком"),
		Кит.Ячейка("128 КБ").Вид("величина"),
		Кит.Ячейка(Кит.Кнопка("Скачать отчёт").Ссылкой().Малая().Иконка("скачать").ТолькоИконка())
			.Вид("узкая"))).Рендер();
```

В таблице карточками узкая ячейка растягивается на всю ширину карточки: иначе число встало бы столбиком по букве.

## Доступность

- Заголовок колонки печатается `<th scope="col">`: скринридер называет колонку при переходе по ячейкам.
- `Подпись` таблицы уходит в `<caption>` — это доступное имя таблицы. Дайте его, когда таблиц на экране несколько.
- Широкая таблица прокручивается внутри своей обёртки, а страница вбок не уезжает.
- Выделенная запись отличается только заливкой. Если выделение несёт смысл, повторите его словом: плашкой «текущая» или текстом в ячейке.
- У кнопки-значка в строке подпись обязательна: она называет действие в `aria-label`.

## Узлом холста

Таблицу из узлов — колонки, записи, ячейки с любыми элементами внутри — и таблицу из данных (`Кит.Таблица(ТаблицаЗначений | Массив)`) подробно разбирает страница [таблица деревом](таблица-деревом). Подпись таблицы на холсте задаёт слово `.Подпись(…)`.

```живой Таблица с подписью узлом холста
HTML = Кит.Таблица(
	Кит.Колонка("Редакция"),
	Кит.Запись(Кит.Ячейка("1.1.0"))).Подпись("Редакции пакета").Рендер();
```
