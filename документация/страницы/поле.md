# Поле формы

Поле формы принимает от человека значение: строку, число, пароль, выбор из списка или отметку флажком. Внешне это залитое текстовое поле Material 3 с подписью внутри и линией снизу.

## Когда использовать

- Человек вводит значение, которое уйдёт на сервер с формой.
- Нужно выбрать один вариант из списка, где вариантов больше двух-трёх.
- Нужно отметить согласие или признак, который можно включить, — флажком.

Не берите поле для «включено — выключено» в настройках: для этого есть [тумблер](тумблер). Для отбора списка — [форма отбора](форма-отбора). Значение, заданное конфигурацией и не правимое в интерфейсе, показывает [поле из конфига](поле-из-конфига).

В дереве холста поле собирается словами: имя и метка позицией, тип — словом `.ТипЗначения(…)` значением системы типов или выводится из `.Значение(…)` (см. [Язык узлов](язык-узлов)).

```живой Узлом холста — словами
HTML = Кит.Холст(
	Кит.Поле("имя", "Имя проекта").Значение("main").Подсказка("латиница и дефис"),
	Кит.Поле("лимит", "Лимит, МБ").ТипЗначения(Тип("Число")),
	Кит.Поле("скрыт", "Скрыть из списка").Значение(Истина)).Рендер();
```

## Как оно выглядит

Поле — контейнер surface-container-highest высотой 56 пикселей со скруглёнными верхними углами и линией-индикатором снизу. Подпись (`Метка`) лежит внутри контейнера. В фокусе линия растёт от середины к краям цветом primary, а подпись окрашивается им же.

Подпись плавает. У пустого поля без фокуса она стоит на месте значения во весь кегль, у заполненного или в фокусе — уменьшается и поднимается к верхнему краю. Пустоту отмечает скрипт кита атрибутом `data-empty`: он следит за вводом, сбросом формы и автозаполнением. Без скрипта атрибута нет, и подпись всегда стоит наверху — законченный вид, а не сломанный.

Опускается подпись только у полей, где значение — текст: строка, пароль, число, многострочное. Выбор, дата и файл всегда что-то показывают, и подпись у них всегда наверху.

`Подсказка` и `Ошибка` — вспомогательный текст под контейнером, с отступом 16 пикселей.

```живой Текст с подсказкой
HTML = Набор.Поле().Отрисовать(Новый Структура("Имя, Метка, Значение, Подсказка",
	"имя", "Имя проекта", "main", "латиница и дефис"));
```

```живой Пустое поле с примером значения — пример виден в фокусе
HTML = Набор.Поле().Отрисовать(Новый Структура("Имя, Метка, Плейсхолдер",
	"почта", "Почта для уведомлений", "имя@пример.рф"));
```

## Типы

`Тип` выбирает управление: «текст» (по умолчанию), «пароль», «число», «многострочное», «выбор», «флажок», «файл». Любой другой допустимый `type` HTML уходит как есть: `email`, `url`, `date`. Тип подбирает клавиатуру телефона и проверку браузера, поэтому выбирайте его по смыслу значения. В дереве холста тип задаёт слово `.ТипЗначения(…)`: `Тип("Число")`, `Тип("Булево")`, `Тип("Дата")` или прежняя строка типа.

```живой Пароль — с подсказкой менеджеру паролей
HTML = Набор.Поле().Отрисовать(Новый Структура("Имя, Метка, Тип, Автозаполнение",
	"пароль", "Пароль", "пароль", "new-password"));
```

`Автозаполнение` печатается атрибутом `autocomplete`. Без него менеджер паролей подставит в форму нового пароля старую пару.

```живой Число
HTML = Набор.Поле().Отрисовать(Новый Структура("Имя, Метка, Тип, Значение",
	"лимит", "Лимит, МБ", "число", "0"));
```

```живой Дата — тип HTML как есть
HTML = Набор.Поле().Отрисовать(Новый Структура("Имя, Метка, Тип",
	"срок", "Срок", "date"));
```

### Многострочное

Многострочное поле — `<textarea>` высотой от двух строк, которое человек растягивает вниз. Берите его для описаний и комментариев.

```живой Многострочное
HTML = Набор.Поле().Отрисовать(Новый Структура("Имя, Метка, Тип, Значение",
	"описание", "Описание", "многострочное", "текст"));
```

### Выбор

Выбор — выпадающий список со своим шевроном справа. Варианты — массив структур `Значение, Подпись`; выбран тот, чьё значение совпало со `Значением` поля, или тот, у кого стоит `Выбрано`.

```живой Выбор
Варианты = Новый Массив();
Варианты.Добавить(Новый Структура("Значение, Подпись", "локальный", "Локальный"));
Варианты.Добавить(Новый Структура("Значение, Подпись", "внешний", "Внешний"));

HTML = Набор.Поле().Отрисовать(Новый Структура("Имя, Метка, Тип, Значение, Варианты",
	"тип", "Тип проекта", "выбор", "внешний", Варианты));
```

Вариант с пустым значением допустим: он означает «не выбрано» или «все». `value` у варианта печатается всегда, поэтому пустой вариант приезжает на сервер пустой строкой, а не своей подписью.

```живой Выбор с пустым вариантом
Варианты = Новый Массив();
Варианты.Добавить(Новый Структура("Значение, Подпись", "", "Все события"));
Варианты.Добавить(Новый Структура("Значение, Подпись", "доступ.выдан", "Доступ: выдан"));
Варианты.Добавить(Новый Структура("Значение, Подпись", "доступ.отозван", "Доступ: отозван"));

HTML = Набор.Поле().Отрисовать(Новый Структура("Имя, Метка, Тип, Варианты",
	"событие", "Событие", "выбор", Варианты));
```

### Флажок

Флажок — коробка 18 пикселей слева и подпись справа обычным текстом: плавающей подписи у него нет. Отмеченный заливается цветом primary. Подсказка встаёт под подписью, а не сбоку.

```живой Флажок
HTML = Набор.Поле().Отрисовать(Новый Структура("Имя, Метка, Тип, Отмечено",
	"скрыт", "Скрыть из списка", "флажок", Истина));
```

```живой Флажок с подсказкой
HTML = Набор.Поле().Отрисовать(Новый Структура("Имя, Метка, Тип, Подсказка",
	"рассылка", "Присылать сводку по почте", "флажок", "раз в неделю, по понедельникам"));
```

Отмеченный флажок отправляет `Значение`, а если оно пусто — «1». Снятый не отправляет ничего; если серверу нужен явный «0», берите [тумблер](тумблер).

## Состояния

### Ошибка

`Ошибка` красит линию, подпись и курсор цветом ошибки и печатает сообщение под полем. Пишите, что исправить, а не только что не так.

```живой С ошибкой
HTML = Набор.Поле().Отрисовать(Новый Структура("Имя, Метка, Ошибка",
	"имя", "Имя проекта", "Имя занято"));
```

С `Ид` поле получает `id`, подпись — `for`, а сообщение об ошибке — свой идентификатор, на который поле ссылается из `aria-describedby`. Тогда скринридер на фокусе прочтёт и подпись, и причину отказа.

```живой Ошибка, связанная с полем через Ид
HTML = Набор.Поле().Отрисовать(Новый Структура("Ид, Имя, Метка, Значение, Ошибка",
	"проект-имя", "имя", "Имя проекта", "main", "Имя занято — выберите другое"));
```

### Обязательное и только для чтения

`Обязательное` ставит атрибут `required`: браузер не отправит форму с пустым полем. `ТолькоЧтение` оставляет поле в форме и в отправке, но править не даёт.

```живой Обязательное
HTML = Набор.Поле().Отрисовать(Новый Структура("Имя, Метка, Обязательное",
	"имя", "Имя проекта", Истина));
```

```живой Только для чтения — значение уходит с формой
HTML = Набор.Поле().Отрисовать(Новый Структура("Имя, Метка, Значение, ТолькоЧтение",
	"ключ", "Ключ проекта", "PRJ-12", Истина));
```

### Заблокированное

Заблокированное поле — витрина значения: оно не правится и не отправляется, поэтому `Имя` ему не нужно. Контейнер и текст приглушены.

```живой Заблокированное — витрина значения
HTML = Набор.Поле().Отрисовать(Новый Структура("Метка, Значение, Заблокировано",
	"Каталог данных", "/var/lib/приложение", Истина));
```

## Проверка

Поле проверяется трижды одними и теми же правилами: браузер — атрибутами (`required`, `pattern`, `minlength`, `maxlength`, `min`, `max`, `type=url` и `email`), скрипт кита — текстом под полем ещё до отправки, сервер — при разборе [объявленной формы](формы-деревом). Источник правил один — слова поля; второй копии в скрипте или в обработчике нет.

### Когда использовать

- Правило известно заранее: формат адреса и почты, длина имени, пределы числа, шаблон ключа. Скажите его словом поля — человек узнает об ошибке, уходя из поля, а не после перезагрузки.
- Ответ знает только сервер: имя занято, ключ уже выдан. Слово `ПроверкаНаСервере(Адрес)` спросит его, пока человек ещё в форме.

Не проверяйте до отправки то, что зависит от других полей или прав: это работа обработчика формы, и его отказ ляжет под поле тем же путём.

### Слова и тексты

| Слово | Что печатает поле | Текст отказа — ключ словаря |
|---|---|---|
| `Обязательное()` | `required` | `form.error.required` |
| `ТипЗначения("url")`, `ТипЗначения("email")` | `type=url`, `type=email` | `form.error.url`, `form.error.email` |
| `ТипЗначения(Тип("Число"))` | `type=number` | `form.error.number` |
| `Пределы(Мин, Макс)` | `min`, `max` | `form.error.min`, `form.error.max` (`%1` — предел) |
| `Длина(Мин, Макс)` | `minlength`, `maxlength` | `form.error.minlength`, `form.error.maxlength` (`%1` — длина) |
| `Шаблон(Образец)` | `pattern` | `form.error.pattern` |
| `ПроверкаНаСервере(Адрес)` | `data-check` | текст ответа сервера |

Слова `Длина`, `Шаблон` и `ПроверкаНаСервере` включают проверку до отправки сами. Прежним ограничениям — обязательности, типу почты и адреса, пределам — её включает слово `ПроверкаДоОтправки()`: без него такое поле печатается как раньше, байт в байт, и отказ показывает браузер своим пузырём.

Поле с проверкой несёт тексты отказов разметкой: признак `data-error-<вид>` на каждое своё ограничение — `required`, `type`, `number`, `pattern`, `minlength`, `maxlength`, `min`, `max`. Текстов в скрипте нет: словарь один у сервера и у браузера, поэтому отказ до отправки звучит теми же словами, что и отказ сервера после неё. Ключ, которого словарь не знает, печатается маркером `[?ключ]`.

```живой Проверка до отправки — словами поля
HTML = Кит.Форма("/образец-проверки",
	Кит.Поле("name", "Имя проекта").Ид("proverka-name").Обязательное().Длина(2, 30)
		.Шаблон("[a-z0-9\-]+").ПроверкаНаСервере("/образец-проверки/имя")
		.Подсказка("латиница, цифры и дефис; alpha и beta заняты"),
	Кит.Поле("site", "Сайт проекта").Ид("proverka-site").ТипЗначения("url").ПроверкаДоОтправки(),
	Кит.Поле("limit", "Участников, не больше").Ид("proverka-limit").ТипЗначения(Тип("Число"))
		.Пределы(1, 50).ПроверкаДоОтправки(),
	Кит.Кнопка("Создать проект").Основная()).Вид("столбик").Токен("образец").Рендер();
```

Наберите в образце «пример.рф» в адресе и нажмите «Создать проект»: форма не уйдёт, а под полем встанет «Нужен адрес страницы целиком». Наберите «alpha» в имени — через полсекунды сервер этого сайта ответит, что имя занято. Тот же образец с тихой отправкой и тостом ответа — на [странице с сервером](/образец-проверки).

`Шаблон` браузер читает по правилам атрибута `pattern` — с флагом `v`: значение совпадает с выражением целиком, а дефис внутри класса экранируется (`[a-z0-9\-]+`). Негодное выражение останавливает сборку там, где его объявили.

### Что делает скрипт

- Попытка отправить форму с негодным полем: вместо пузыря браузера текст отказа ложится в `field__error` этого поля — туда же, куда сервер печатает свой, — поле получает `aria-invalid="true"` и ссылку на текст из `aria-describedby`, фокус встаёт на первое негодное поле.
- Уход из поля, в котором что-то набрали: та же проверка, без отправки. Нетронутое поле на уходе молчит.
- Исправленное поле снимает отказ сразу, на вводе.
- `ПроверкаНаСервере`: когда человек перестал набирать (полсекунды тишины) или ушёл из поля, скрипт спрашивает `GET Адрес?имя=значение`. Ответ `200` — свободно, `409` — занято, и текст ответа становится отказом: он держит форму, пока значение не сменят. Сеть и другие ответы молчат — занятость проверит обработчик при отправке.

Без скрипта форма работает целиком: негодное не пускает браузер, а то, что знает только сервер, отбивает обработчик формы — методом `Отбить` объявленной формы или словом `Ошибка` поля. Отказ сервера после тихой отправки морфится в те же места: тот же `field__error`, тот же `aria-invalid`.

```bsl
// обработчик POST: те же ограничения разбирает объявление, занятость — домен
Итог = Объявление.Разобрать(Присланное);
Если Итог.Принято И Проекты.Занято(Итог.Значения.Получить("name")) Тогда
	Объявление.Отбить("name", СтрШаблон("Имя «%1» уже занято", Итог.Значения.Получить("name")));
КонецЕсли;

// адрес проверки: 200 — свободно, 409 с текстом — занято
Ответ.УстановитьТипКонтента("txt");
Ответ.УстановитьСостояние(?(Занято, 409, 200));
Ответ.ТелоТекст = ?(Занято, "Имя уже занято — выберите другое", "");
```

```делайте Правило — словом поля: браузер, скрипт и сервер судят одинаково
HTML = Кит.Поле("name", "Имя проекта").Длина(2, 30).Шаблон("[a-z0-9\-]+")
	.Подсказка("латиница, цифры и дефис").Рендер();
```

```не-делайте Правило только в подсказке: человек узнает о нём после перезагрузки
HTML = Кит.Поле("name", "Имя проекта")
	.Подсказка("от 2 до 30 символов: латиница, цифры и дефис").Рендер();
```

### Доступность проверки

- Текст отказа — `role="alert"`: скринридер читает его сразу, как только он появился.
- Поле с отказом — `aria-invalid="true"`; с `Ид` оно ссылается на текст отказа из `aria-describedby`, не теряя других ссылок.
- После неудачной попытки отправить фокус встаёт на первое негодное поле.
- Отказ не держится на цвете: красная линия дублируется текстом под полем.

## Доступность

- Подпись связана с полем всегда: вложением в `<label>`, а с `Ид` — ещё и атрибутом `for`.
- Поле с ошибкой несёт `aria-invalid="true"`; сообщение печатается с `role="alert"` и читается сразу. С `Ид` поле ссылается на сообщение из `aria-describedby`.
- Флажок — настоящий `<input type="checkbox">`: пробел, фокус и состояние даёт браузер.
- Без `Метки` поле немо для скринридера: плейсхолдер подписью не считается. Метку задавайте всегда.
- Незаблокированное поле без `Имени` кит не соберёт: браузер не отправил бы его значение.

## Узлом холста

На [холсте](холст) поле кладут в форму; как собрать форму целиком — на странице [Формы деревом](формы-деревом).

```живой Поле узлом дерева
HTML = Кит.Поле("имя", "Имя проекта").Значение("main").Рендер();
```

## Модель

Класс зовётся `ПолеФормы`: имя `Поле` занято библиотекой decorator. В наборе компонентов он доступен как `Набор.Поле()`. Структура с этими полями — прежний вид модели: в дереве холста те же поля пишут слова `Кит.Поле`, а поле `Тип` — слово `ТипЗначения`.

```справка Кит.Поле
```

```справка ПолеФормы
```

Слова проверки до отправки (выпуск 0.12) — у поля холста и у описания поля объявленной формы:
