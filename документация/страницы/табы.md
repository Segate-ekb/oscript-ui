# Вкладки

Вкладки переключают соседние виды одного объекта: описание, редакции, связи. Каждая вкладка — отдельная страница со своим адресом, а полоса — обычный список ссылок, поэтому вкладку можно открыть в новом окне, отправить ссылкой и вернуть кнопкой «назад».

## Когда использовать

- У объекта несколько видов одного уровня, и человек переходит между ними туда и обратно.
- Каждый вид достаточно велик, чтобы занять свою страницу: список редакций, журнал, связи.
- Видов немного — от двух до пяти-шести, и подпись каждого укладывается в одно-два слова.

Не берите вкладки для разделов, которых много или которые вложены друг в друга, — для этого есть [дерево разделов](дерево-разделов). Шаги, которые проходят по порядку, показывает [проводник](проводник), а длинный список по страницам — [пагинация](пагинация).

## Полоса вкладок

Это основные вкладки Material 3: подпись шрифтом title-small, под активной вкладкой — индикатор цвета primary толщиной 3 пикселя со скруглёнными верхними углами. Активную вкладку отмечает сервер полем `Активна`; панель содержимого под полосой рисует сам контроллер страницы.

```живой Вкладки страницы объекта
Вкладки = Новый Массив();
Вкладки.Добавить(Новый Структура("Подпись, Адрес, Активна",
	"Описание", "/документы/отчёт", Истина));
Вкладки.Добавить(Новый Структура("Подпись, Адрес, Счётчик",
	"Редакции", "/документы/отчёт/редакции", 12));
Вкладки.Добавить(Новый Структура("Подпись, Адрес", "Связи", "/документы/отчёт/связи"));

HTML = Набор.Табы().Отрисовать(Новый Структура("Вкладки, Заголовок",
	Вкладки, "Разделы объекта"));
```

`Счётчик` печатается плашкой рядом с подписью: сколько записей ждёт на той вкладке. У активной вкладки плашка залита цветом primary.

## С иконками

Иконка стоит перед подписью и повторяет её смысл. Ставьте иконки всем вкладкам полосы или никому: половина значков выглядит как недосмотр.

```живой Иконка и подпись
Вкладки = Новый Массив();
Вкладки.Добавить(Новый Структура("Подпись, Адрес, Иконка, Активна",
	"Настройки", "/пулы/основной", "шестерёнка", Истина));
Вкладки.Добавить(Новый Структура("Подпись, Адрес, Иконка, Счётчик",
	"История", "/пулы/основной/история", "история", 4));
Вкладки.Добавить(Новый Структура("Подпись, Адрес, Иконка",
	"Ключи", "/пулы/основной/ключи", "ключ"));

HTML = Набор.Табы().Отрисовать(Новый Структура("Вкладки, Заголовок",
	Вкладки, "Разделы пула"));
```

## Индикатор едет между страницами

Каждая вкладка — отдельный документ, и всё же индикатор не прыгает, а скользит со старой вкладки на новую, как у Tabs в MUI. Это делает переход между документами (View Transitions): скрипт кита `oscript-ui.js` называет индикатор именем перехода, когда человек уходит по вкладке того же ряда, а лист кита задаёт ему кривую и длительность движения Material. Сама страница меняется сразу, без наплыва: движется только индикатор.

Браузер без View Transitions и страница без скрипта просто открывают новую вкладку с уже подчёркнутым индикатором — работает всё, кроме скольжения. Переход по чужой ссылке, не из полосы, остаётся обычным: индикатор путешествует, только если человек пришёл вкладкой.

## Вкладки дома настроек

Значение `Класс` = «настройки» снимает у полосы верхний отступ: так вкладки встают вплотную под шапку секции в [доме настроек](дом-настроек). Другие значения класса компонент отбрасывает — в атрибут `class` попадает только известное.

```живой Полоса в доме настроек
Вкладки = Новый Массив();
Вкладки.Добавить(Новый Структура("Подпись, Адрес, Активна",
	"Общие", "/настройки", Истина));
Вкладки.Добавить(Новый Структура("Подпись, Адрес", "Доступ", "/настройки/доступ"));

HTML = Набор.Табы().Отрисовать(Новый Структура("Вкладки, Класс, Заголовок",
	Вкладки, "настройки", "Разделы настроек"));
```

## Пустая полоса и вкладка без адреса

Пустой список вкладок не печатает ничего: полоса из одной рамки ничего не переключает.

```живой Пустой список — ничего
HTML = Набор.Табы().Отрисовать(Новый Структура("Вкладки", Новый Массив()));
```

Вкладка без `Адреса` — ошибка разработчика, и кит отказывается её печатать: такую вкладку нельзя ни открыть ссылкой, ни вернуть «назад». Адрес с опасной схемой (`javascript:`) вкладку не роняет: она остаётся видна, но перестаёт быть ссылкой.

```живой Вкладка без адреса — исключение с объяснением
Вкладки = Новый Массив();
Вкладки.Добавить(Новый Структура("Подпись, Адрес, Активна",
	"Описание", "/документы/отчёт", Истина));
Вкладки.Добавить(Новый Структура("Подпись", "Связи"));

Попытка
	HTML = Набор.Табы().Отрисовать(Новый Структура("Вкладки", Вкладки));
Исключение
	HTML = Набор.Тост().Отрисовать(Новый Структура("Текст, Вид",
		ИнформацияОбОшибке().Описание, "ошибка"));
КонецПопытки;
```

## Доступность

- Полоса печатается `<nav>` с `aria-label`: по умолчанию «Разделы страницы», своё имя задаёт поле `Заголовок`. Назовите полосу, если на странице есть другая навигация.
- Активная вкладка несёт `aria-current="page"`, остальные — ничего: значение `"false"` скринридеры читают по-разному, а отсутствие атрибута однозначно.
- Вкладки — ссылки, а не `role="tab"`: каждая ведёт на свою страницу, и клавиатура ходит по ним табуляцией, как по любым ссылкам.
- Иконка вкладки декоративна (`aria-hidden`), имя вкладки — её подпись. Счётчик читается числом после подписи, поэтому выбирайте подпись, с которой число понятно («Редакции 12»).
- Фокус с клавиатуры виден всегда; рябь от нажатия скрипт не показывает, если в системе включено «уменьшить движение».

## Узлом холста

На [холсте](холст) полоса вкладок — узел рода «вкладки». Его кладут под шапку объекта, перед содержимым активной вкладки.

```живой Вкладки узлом дерева
Вкладки = Новый Массив();
Вкладки.Добавить(Новый Структура("Подпись, Адрес, Активна",
	"Описание", "/документы/отчёт", Истина));
Вкладки.Добавить(Новый Структура("Подпись, Адрес, Счётчик",
	"Редакции", "/документы/отчёт/редакции", 12));
Вкладки.Добавить(Новый Структура("Подпись, Адрес", "Связи", "/документы/отчёт/связи"));

HTML = Кит.Табы(Новый Структура("Вкладки", Вкладки)).Рендер();
```
