# Блок команды

Блок команды показывает то, что человек скопирует и вставит в терминал: команду установки, строку подключения, ключ. Кнопка «Копировать» рядом забирает текст целиком, без риска недовыделить.

## Когда использовать

- Человек должен выполнить команду у себя: установить пакет, отправить релиз, подключить зеркало.
- Нужно отдать строку, которую набирать руками долго и ошибочно: токен, адрес, ключ.

Не берите блок для кода, который читают, а не вставляют: для этого есть [текст и код](текст). Значение настройки, которое задано снаружи и меняется в конфиге, показывает [поле из конфига](поле-из-конфига).

В дереве холста блок собирается словами: команда позицией, пояснение и надпись кнопки — цепочкой (см. [Язык узлов](язык-узлов)).

```живой Узлом холста — словами
HTML = Кит.БлокКоманды("приложение отправить отчёт-1.0.0")
	.Пояснение("Выполните в каталоге проекта:").Рендер();
```

## Команда с копированием

Строка — самая короткая модель: кит сам поймёт её как `Команда`. Текст печатается моноширинным шрифтом на заливке surface-container-highest, кнопка копирования стоит справа.

```живой Команда с копированием
HTML = Набор.БлокКоманды().Отрисовать("приложение установить отчёт");
```

Кнопку оживляет скрипт страницы по атрибуту `data-copy`: в нём лежит тот же текст, что и в блоке. Без скрипта блок остаётся читаемым, и команду можно выделить мышью.

## С пояснением

`Пояснение` — строка над блоком: где и когда выполнять. Она приглушена и не копируется вместе с командой.

```живой С пояснением — где выполнять
HTML = Набор.БлокКоманды().Отрисовать(Новый Структура("Команда, Пояснение",
	"приложение отправить отчёт-1.0.0", "Выполните в каталоге проекта:"));
```

## Без копирования

`БезКопирования` убирает кнопку. Это нужно, когда блок — пример формата, а не готовая команда, или когда рядом уже есть способ забрать значение.

```живой Без кнопки копирования
HTML = Набор.БлокКоманды().Отрисовать(Новый Структура("Команда, БезКопирования",
	"приложение установить отчёт", Истина));
```

Надпись кнопки меняется полем `Подпись`, если «Копировать» не подходит по смыслу.

```живой Своя надпись кнопки
HTML = Набор.БлокКоманды().Отрисовать(Новый Структура("Команда, Подпись",
	"https://хаб.пример/зеркало/отчёт.git", "Копировать адрес"));
```

## Несколько строк

Перевод строки в команде сохраняется: блок держит многострочный сниппет, а кнопка остаётся у первой строки.

```живой Сниппет из двух строк
HTML = Набор.БлокКоманды().Отрисовать(
	"export APP_STORAGE_ROOT=/var/lib/приложение" + Символы.ПС
	+ "приложение запустить");
```

## Гайдлайны

```делайте Команда без приглашения оболочки — вставил и выполнил
HTML = Набор.БлокКоманды().Отрисовать("приложение установить отчёт");
```

```не-делайте Знак «$» в команде: вставленная, она упадёт
HTML = Набор.БлокКоманды().Отрисовать("$ приложение установить отчёт");
```

```делайте Шаги — отдельными блоками, каждый со своим пояснением
HTML = Набор.БлокКоманды().Отрисовать(Новый Структура("Команда, Пояснение",
	"приложение установить отчёт", "1. Установите пакет:"))
	+ Набор.БлокКоманды().Отрисовать(Новый Структура("Команда, Пояснение",
	"приложение запустить отчёт", "2. Запустите:"));
```

```не-делайте Несколько шагов одним блоком через «&&»: сбой в середине не виден
HTML = Набор.БлокКоманды().Отрисовать(
	"приложение установить отчёт && приложение запустить отчёт");
```

```делайте Пояснение говорит, где выполнять
HTML = Набор.БлокКоманды().Отрисовать(Новый Структура("Команда, Пояснение",
	"приложение отправить отчёт-1.0.0", "Выполните в каталоге проекта:"));
```

```не-делайте Пояснение пересказывает команду
HTML = Набор.БлокКоманды().Отрисовать(Новый Структура("Команда, Пояснение",
	"приложение отправить отчёт-1.0.0", "Команда отправки отчёта:"));
```

## Доступность

- Команда печатается в `<code>` и экранируется: в блок можно отдать любой текст.
- Кнопка копирования — настоящая `<button type="button">` с видимой надписью: её читает скринридер, её нажимают с клавиатуры, и форму она не отправляет.
- Пустую команду кит не печатает, а кидает исключение: рамка с кнопкой, копирующей пустоту, никому не нужна.

## Узлом холста

```живой Блок команды узлом дерева
HTML = Кит.БлокКоманды("приложение установить отчёт").Рендер();
```

## Модель

Поля модели — из комментария в исходнике компонента. Структура с этими полями — прежний вид модели: в дереве холста те же поля пишут слова `Кит.БлокКоманды`.

```справка Кит.БлокКоманды
```

```справка БлокКоманды
```

```словарь компонент:команда
```
