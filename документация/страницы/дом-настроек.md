# Дом настроек

Единый каркас всех экранов настроек: объект, дерево разделов, секции и панель сохранения. Дом решает, что показать, каркас — как.

## Когда использовать

- У объекта — проекта, пула, учётной записи — есть настройки, и их больше одной формы.
- Настройки делятся на разделы: общее, доступ, ключи, история.
- Каждая группа полей сохраняется отдельно и проверяется отдельно.

Для одной короткой формы дом не нужен: хватит [полей](поле) и [кнопки](кнопка) в карточке.

## Устройство

Слева — разделы дома деревом, справа — секции текущего раздела. Каждая секция с `Действие` печатается своей формой со своей панелью сохранения: секция — единица переноса, у неё своя проверка и свой POST.

```живой Разделы, секции и шторка узкого экрана
Разделы = Новый Массив();
Разделы.Добавить(Настройки.Раздел("Общее", "/настройки", "шестерёнка", Истина));
Разделы.Добавить(Настройки.Раздел("Доступ", "/настройки/доступ", "замок"));
Разделы.Добавить(Настройки.Раздел("Ключи", "/настройки/ключи", "ключ"));
Разделы.Добавить(Настройки.Раздел("История", "/настройки/история", "история"));

Секции = Новый Массив();
Секции.Добавить(Настройки.Секция("Имя проекта", "Видно всем участникам",
	Набор.Поле().Отрисовать(Новый Структура("Имя, Метка, Значение",
		"имя", "Имя", "альфа"))));

HTML = Настройки.Отрисовать(Новый Структура(
	"Ключ, Заголовок, Объект, Пояснение, Разделы, Секции",
	"project", "Настройки", "альфа", "Что видит участник проекта",
	Разделы, Секции));
```

На телефоне колонка разделов встаёт над секциями. Если у инсталляции есть [единое меню](единое-меню), разделы дома уезжают туда, а колонка прячется: два списка одних и тех же разделов подряд не нужны.

```живой Дом без разделов — ни колонки, ни шторки
Секции = Новый Массив();
Секции.Добавить(Настройки.Секция("Единственная секция", "",
	"<p>прятать нечего: разделов у дома нет</p>"));

HTML = Настройки.Отрисовать(Новый Структура("Ключ, Заголовок, Секции",
	"project", "Настройки", Секции));
```

## Секция с формой

Задайте секции `Действие` — адрес POST — и `Токен` CSRF, и она станет формой с панелью сохранения внизу. Поля секции дозаполняются у результата `Настройки.Секция(...)`: структура открытая.

```живой Секция сохраняется своей формой
Секция = Настройки.Секция("Описание", "Короткий текст под именем проекта",
	Набор.Поле().Отрисовать(Новый Структура("Имя, Метка, Тип, Значение",
		"описание", "Описание", "многострочное", "Пакеты команды аналитики")));
Секция.Действие = "/настройки/описание";
Секция.Токен = "токен-из-сессии";
Секция.ПояснениеПанели = "Изменения увидят все участники";

Секции = Новый Массив();
Секции.Добавить(Секция);
HTML = Настройки.Отрисовать(Новый Структура("Ключ, Заголовок, Секции",
	"project", "Настройки", Секции));
```

```живой Опасная секция
Секция = Настройки.Секция("Удаление", "Проект и все его пакеты будут удалены",
	Набор.ОпаснаяЗона().Отрисовать(Новый Структура("Заголовок, Пояснение, Подтверждение",
		"Удалить проект", "Отменить это нельзя.",
		Новый Структура("Имя, Образец", "подтверждение", "альфа"))));
Секция.Опасная = Истина;
Секция.БезПанели = Истина;

Секции = Новый Массив();
Секции.Добавить(Секция);
HTML = Настройки.Отрисовать(Новый Структура("Ключ, Заголовок, Секции",
	"project", "Настройки", Секции));
```

## Гайдлайны

```делайте Одна секция — одна тема и своя кнопка сохранения
Секция = Настройки.Секция("Имя проекта", "", Набор.Поле().Отрисовать(
	Новый Структура("Имя, Метка, Значение", "имя", "Имя", "альфа")));
Секция.Действие = "/настройки/имя";
Секция.Токен = "т";
Секции = Новый Массив();
Секции.Добавить(Секция);
HTML = Настройки.Отрисовать(Новый Структура("Ключ, Заголовок, Секции", "project", "", Секции));
```

```не-делайте Все поля дома одной формой: ошибка в одном поле откатывает остальные
Тело = Набор.Поле().Отрисовать(Новый Структура("Имя, Метка", "имя", "Имя"))
	+ Набор.Поле().Отрисовать(Новый Структура("Имя, Метка", "ключ", "Ключ доступа"))
	+ Набор.Поле().Отрисовать(Новый Структура("Имя, Метка", "почта", "Почта для писем"));
Секция = Настройки.Секция("Всё сразу", "", Тело);
Секция.Действие = "/настройки";
Секция.Токен = "т";
Секции = Новый Массив();
Секции.Добавить(Секция);
HTML = Настройки.Отрисовать(Новый Структура("Ключ, Заголовок, Секции", "project", "", Секции));
```

## Доступность

- Колонка разделов — навигация с подписью из словаря инсталляции (`settings.frame.nav.title`); текущий раздел помечен `aria-current`.
- Секция — `<section>` с заголовком: скринридер ходит по секциям, как по главам.
- Ключ дома пишется латиницей: он уходит в атрибут `data-house`, а имена атрибутов кит пропускает только из `[a-z0-9-]`.
