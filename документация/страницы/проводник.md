# Проводник

Проводник ведёт человека по шагам многошаговой задачи — чаще всего первой настройки: создать учётную запись, выпустить ключ, сделать первый документ. Сверху строка «Пройдено 1 из 3», под ней шаги карточками: пройденный отмечен галочкой, текущий выделен обводкой и ведёт к делу ссылкой.

## Когда использовать

- Задача складывается из нескольких шагов, и человеку важно видеть, сколько осталось.
- Шаги делаются на разных страницах, а проводник собирает их в одном месте — в кабинете, на пустом экране нового проекта.
- Выполнен ли шаг, знает сервер: компонент только показывает то, что посчитала доменная служба.

Не берите проводник для соседних видов одного объекта — им место во [вкладках](табы). Одно действие на пустом экране — это [пустое состояние](пустое-состояние) с кнопкой, а не проводник из одного шага.

## Шаги и прогресс

Шаг — карточка Material с обводкой. Пройденный шаг узнаётся значком цвета primary, текущий — обводкой primary и лёгкой заливкой. У текущего шага есть ход к делу: `Адрес` и `ПодписьСсылки` печатают ссылку под заголовком.

```живой Шаги и прогресс
Шаги = Новый Массив();
Шаги.Добавить(Новый Структура("Заголовок, Пояснение, Выполнен, Текущий",
	"Создать учётную запись", "Мастер закрывается после первой записи", Истина, Ложь));
Шаги.Добавить(Новый Структура("Заголовок, Выполнен, Текущий, Адрес, ПодписьСсылки",
	"Выпустить ключ доступа", Ложь, Истина, "/кабинет/ключи", "Мои ключи"));
Шаги.Добавить(Новый Структура("Заголовок, Выполнен, Текущий",
	"Создать первый документ", Ложь, Ложь));

HTML = Набор.Проводник().Отрисовать(Новый Структура("Шаги", Шаги));
```

Прогресс «Пройдено N из M» компонент считает сам по полю `Выполнен`. Шаг, отмеченный и выполненным, и текущим, считается выполненным: текущим бывает только то, что ещё не сделано.

## Тело шага

Под заголовком шага можно положить свою разметку — `ТелоHTML`: команду для терминала, короткий список, форму из одной кнопки. Разметка вставляется как есть, поэтому кладите туда только то, что собрал сам код, а не ввод пользователя.

```живой Шаг с командой внутри
Команда = Набор.БлокКоманды().Отрисовать(Новый Структура("Команда",
	"opm install oscript-ui"));

Шаги = Новый Массив();
Шаги.Добавить(Новый Структура("Заголовок, Выполнен", "Создать проект", Истина));
Шаги.Добавить(Новый Структура("Заголовок, Пояснение, Текущий, ТелоHTML",
	"Поставить кит", "Выполните команду в каталоге проекта", Истина, Команда));
Шаги.Добавить(Новый Структура("Заголовок", "Нарисовать первый экран"));

HTML = Набор.Проводник().Отрисовать(Новый Структура("Шаги", Шаги));
```

## Пустой список

Шагов нет — компонент печатает приглушённую строку из поля `Пусто`. Без него не печатается ничего.

```живой Без шагов — заглушка
HTML = Набор.Проводник().Отрисовать(Новый Структура("Шаги, Пусто",
	Новый Массив(), "Шагов пока нет"));
```

## Доступность

- Шаги — нумерованный список `<ol>`: скринридер называет число шагов и номер каждого.
- Прогресс напечатан текстом «Пройдено 1 из 3», а не только галочками и цветом.
- Значок шага декоративен (`aria-hidden`), поэтому состояние шага, которое важно услышать, называйте и словами — в пояснении («Готово», «Ждёт подтверждения»).
- Ход к делу — обычная ссылка с подписью. Подпись по умолчанию «Перейти» ничего не называет: задавайте `ПодписьСсылки`.

HTML = Кит.Проводник(Новый Структура("Шаги", Шаги)).Рендер();
