# Словарь родов

Все роды узлов холста в одной таблице: каким тегом печатается род, принимает ли он детей и какие виды знает. Таблица собирается из кода кита при каждом показе страницы, поэтому не отстаёт от него.

## Род, вид, контейнер

- **Род** — что это за узел. Род задаёт тег и правила печати: ряд — `div`, запись — `tr`, свойство — пара `dt` и `dd`. Род выбирают функцией кита: `Кит.Ряд` даёт род «ряд».
- **Вид** — оформление узла из закрытого набора его рода, словом `.Вид(…)` (у ряда — первым аргументом). Вид — не имя CSS-класса: класс за пределы кита не выходит, а неизвестный вид останавливает сборку сразу. «—» в таблице значит «без вида».
- **Контейнер** — принимает ли род детей. Лист дерева (текст, картинка, мета, готовое, раздел) печатает себя целиком. Компонент принимает детей ровно тогда, когда у него есть слот.
- **«Только дети»** в колонке тега — род без своего тега. Холст и шаблон печатают одних детей, свойство — пару тегов `dt` и `dd`, текст — экранированную строку, компонент и готовое — свою разметку целиком, раздел — строку колонки разделов своего дома.

Род и признак холста можно спросить у самого узла: `Род()` и `ЭтоХолст()`.

```живой Род, вид и холст — у самого узла
Узлы = Новый Массив();
Узлы.Добавить(Кит.Холст());
Узлы.Добавить(Кит.Ряд("выбор"));
Узлы.Добавить(Кит.Текст("строка"));
Узлы.Добавить(Кит.Кнопка("Создать"));
Узлы.Добавить(Кит.Карточка("Проекты"));
Узлы.Добавить(Кит.Секция("Ключи"));

Роды = Новый ТаблицаЗначений;
Роды.Колонки.Добавить("Род");
Роды.Колонки.Добавить("Вид");
Роды.Колонки.Добавить("Холст");
Для Каждого Узел Из Узлы Цикл
	Строка_ = Роды.Добавить();
	Строка_.Род = Кит.Код(Узел.Род());
	Строка_.Вид = Узел.Свойства().Вид;
	Строка_.Холст = ?(Узел.ЭтоХолст(), "да", "нет");
КонецЦикла;

HTML = Кит.Таблица(Роды).Рендер();
```

У компонента в таблице стоит «нет»: так про род в целом. Детей принимает только компонент со слотом — карточка, опасная зона, шапка объекта, плашка, сетка. Виды компонента — имена компонентов кита, их видно в `Дерево()`.

## Правила вложения

Большинство родов принимают любых детей. Строгие роды печатают только своих — узел чужого рода исчез бы с экрана молча, поэтому кит останавливает сборку на `Добавить`.

| Родитель | Принимает только |
|---|---|
| `документ` | `голова`, `тело` |
| `голова` | `титул`, `мета`, `ресурс`, `стиль`, `скрипт` |
| `титул` | `текст` |
| `таблица` | `колонка`, `запись` |
| `запись` | `ячейка` |
| `список` | `пункт` |
| `свойства` | `свойство` |
| `дом` | `секция`, `раздел` |
| `шаги` | `шаг` |
| `реестр` | `запись-реестра` |

Строка на месте ребёнка — тоже узел, рода «текст», поэтому в строгий род она не ложится. В форму строка не кладётся вовсе: токен — словом `.Токен(…)`, текст — узлом `Кит.Текст()`. `Кит.Ничего()` — тот же холст, поэтому и он подчиняется этим правилам: в запись его не положить. Подробно — на странице [Холст и узлы](холст).

## Второй холст

Шесть родов и карточка держат второй холст — место для содержимого, которое печатается не там, где дети. С аргументами слово наполняет второй холст и возвращает сам узел, без аргументов — отдаёт холст.

| Род | Второй холст | Где печатается |
|---|---|---|
| `раскрывашка` | `Шапка(…)` | свёрнутой строкой перед телом |
| `запись` | `Разворот(…)` | строкой под записью во всю ширину; пустой не печатается |
| `таблица` | `Пусто(…)` | вместо таблицы, когда записей нет; строка — примечание вида «пусто» |
| `компонент[карточка]` | `Действия(…)` | рядом действий под телом карточки |
| `реестр` | `Пусто(…)` | вместо списка, когда записей нет; строка — пояснение пустого состояния |
| `запись-реестра` | `Действия(…)` | справа от свёрнутой строки, вне её; третий холст `Кнопки(…)` — меню ⚙ и кнопки внизу тела |
| `окно` | `Действия(…)` | рядом действий внизу окна, под телом; на телефоне — прилипшим к низу листа |

У других родов второго холста нет. Вызов `Шапка()` у записи — исключение, которое называет, как второй холст называется у этого рода. У таблицы из данных `Разворот(ИмяКолонки)` — не холст, а имя колонки, чьё значение печатается разворотом.

```живой Второй холст другого рода — исключение
Попытка
	Кит.Запись().Шапка();
Исключение
	HTML = Кит.Примечание(КраткоеПредставлениеОшибки(ИнформацияОбОшибке())).Рендер();
КонецПопытки;
```
