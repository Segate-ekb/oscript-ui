# Списки и пары

Список перечисляет равнозначное, свойства показывают пары «имя — значение». Оба рода строгие: в список кладут только пункты, в свойства — только свойства.

## Когда что брать

- **Список** — несколько равнозначных строк без порядка важности: источники, требования к полю, шаги без номеров.
- **Свойства** — сведения об объекте парами: «Создан — вчера», «Размер — 430 МБ».

Не берите список для записей, у которых есть колонки, — для этого есть [таблица](таблица-деревом). Сводку одной записи списка со знаками состояния собирает компонент [«Сводка»](сводка).

## Список

Список печатается тегом `ul`, пункт — `li`. Пункт — холст: в него кладут текст, ссылку, машинное значение.

```живой Список и пункты
Перечень = Кит.Список();
Перечень.Добавить(Кит.Пункт()).Добавить(Кит.Текст("первый"));

Второй = Перечень.Добавить(Кит.Пункт());
Второй.Добавить(Кит.Ссылка("/документы")).Добавить(Кит.Текст("второй, ссылкой"));

HTML = Перечень.Рендер();
```

Вид «сноска» — мелкий приглушённый список под полем. Им перечисляют требования, которые человек прочтёт перед вводом.

```живой Список-сноска под полем
Перечень = Кит.Список("сноска");
Перечень.Добавить(Кит.Пункт()).Добавить(Кит.Текст("только латиница и дефис"));
Перечень.Добавить(Кит.Пункт()).Добавить(Кит.Текст("не длиннее 64 символов"));

HTML = Перечень.Рендер();
```

Список из данных собирается циклом: пункт на каждое значение.

```живой Список из массива
Перечень = Кит.Список();
Для Каждого Имя Из СтрРазделить("main,отчёт,архив-2024", ",") Цикл
	Перечень.Добавить(Кит.Пункт()).Добавить(Кит.Код(Имя));
КонецЦикла;

HTML = Перечень.Рендер();
```

## Свойства

Свойства печатаются списком определений `dl`. Имя свойства приходит подписью и экранируется, значение собирается детьми. Своего тега у свойства нет: оно печатается парой `dt` и `dd`.

```живой Свойства — пары «имя — значение»
Свойства = Кит.Свойства();
Свойства.Добавить(Кит.Свойство("Создан")).Добавить(Кит.Текст("вчера"));
Свойства.Добавить(Кит.Свойство("Размер")).Добавить(Кит.Код("430 МБ"));

HTML = Свойства.Рендер();
```

Значение свойства — холст, поэтому в нём бывает плашка, ссылка или несколько узлов.

```живой Значение собрано из нескольких узлов
Свойства = Кит.Свойства();
Свойства.Добавить(Кит.Свойство("Состояние")).Добавить(
	Кит.Плашка(Новый Структура("Текст, Вид", "активен", "ok")));

Владелец = Свойства.Добавить(Кит.Свойство("Владелец"));
Владелец.Добавить(Кит.Ссылка("/люди/7")).Добавить(Кит.Текст("Анна Смирнова"));

HTML = Свойства.Рендер();
```

## Гайдлайны

```делайте Пары «имя — значение» — свойствами: имена выровнены в колонку
Свойства = Кит.Свойства();
Свойства.Добавить(Кит.Свойство("Создан")).Добавить(Кит.Текст("вчера"));
Свойства.Добавить(Кит.Свойство("Размер")).Добавить(Кит.Код("430 МБ"));
HTML = Свойства.Рендер();
```

```не-делайте Пары строкой в пунктах списка: имя и значение не различить
Перечень = Кит.Список();
Перечень.Добавить(Кит.Пункт()).Добавить(Кит.Текст("Создан: вчера"));
Перечень.Добавить(Кит.Пункт()).Добавить(Кит.Текст("Размер: 430 МБ"));
HTML = Перечень.Рендер();
```

```делайте Перечень — списком: скринридер называет число пунктов
Перечень = Кит.Список("сноска");
Перечень.Добавить(Кит.Пункт()).Добавить(Кит.Текст("только латиница и дефис"));
Перечень.Добавить(Кит.Пункт()).Добавить(Кит.Текст("не длиннее 64 символов"));
HTML = Перечень.Рендер();
```

```не-делайте Перечень примечаниями подряд: для скринридера это просто абзацы
Холст = Кит.Холст();
Холст.Добавить(Кит.Примечание("— только латиница и дефис"));
Холст.Добавить(Кит.Примечание("— не длиннее 64 символов"));
HTML = Холст.Рендер();
```

## Доступность

- Список печатается `ul` и `li`: скринридер объявляет «список, два пункта» и даёт перейти к следующему.
- Свойства печатаются `dl`, `dt` и `dd`: имя и значение связаны разметкой, а не только выравниванием.
- Кит не даст положить в список не пункт, а в свойства — не свойство: такой ребёнок исчез бы с экрана, и сборка останавливается исключением.
