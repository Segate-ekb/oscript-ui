# Тост

Тост сообщает итог действия: «Сохранено», «Не удалось отправить», «Лимит почти исчерпан». В ките это сообщение в потоке страницы, как Alert у MUI: тональная плашка цвета статуса со значком, которую сервер печатает там, где о результате нужно сказать, — обычно над формой после отправки.

## Когда использовать

- Человек только что отправил форму, и нужно сказать, чем кончилось: сохранено, отклонено, принято в работу.
- На странице есть состояние, о котором стоит предупредить: лимит, просроченный ключ, режим только для чтения.
- Ошибка касается всей формы, а не одного поля: сервер недоступен, запись изменил кто-то другой.

Не берите тост для ошибки одного поля — она печатается под самим [полем](поле). Состояние записи, которое видно всегда, показывает [плашка](плашка). Необратимое действие предупреждает [опасная зона](опасная-зона), а не тост после того, как всё уже удалено.

## Виды

Вид задаёт цвет, значок и роль сообщения. Он принимается и по-английски (`ok`, `warn`, `err`, `info`), и по-русски («успех», «предупреждение», «ошибка»); незнакомое значение станет нейтральным «info».

Успех — вид по умолчанию. Строку вместо структуры кит понимает как текст успеха.

```живой Успех
HTML = Набор.Тост().Отрисовать("Сохранено");
```

Предупреждение — ничего не сломалось, но скоро сломается или требует внимания.

```живой Предупреждение
HTML = Набор.Тост().Отрисовать(Новый Структура("Текст, Вид",
	"Проект почти исчерпал лимит", "warn"));
```

В дереве холста тост — узел `Кит.Уведомление`: текст позицией, вид, заголовок, крест и тревога — словами `Вид`, `Заголовок`, `Закрываемый`, `Тревога` (см. [Язык узлов](язык-узлов)).

```живой Узлом холста — словами
HTML = Кит.Уведомление("Проект почти исчерпал лимит").Вид("warn")
	.Заголовок("Лимит хранилища").Рендер();
```

Ошибка — действие не выполнено. Только этот вид объявляется скринридеру сразу, прерывая текущее чтение.

```живой Ошибка
HTML = Набор.Тост().Отрисовать(Новый Структура("Текст, Вид", "Не сохранено", "err"));
```

Сведения — нейтральное сообщение о том, что происходит: запущен процесс, письмо отправлено.

```живой Сообщение с заголовком
HTML = Набор.Тост().Отрисовать(Новый Структура("Текст, Заголовок, Вид",
	"Синхронизация запущена", "Синхронизация", "info"));
```

`Заголовок` печатается полужирным перед текстом. Он нужен, когда текст длинный и сначала важно сказать, о чём речь.

```живой Русские имена видов
HTML = Набор.Тост().Отрисовать(Новый Структура("Текст, Вид",
	"Ключ истекает через три дня", "предупреждение"))
	+ Набор.Тост().Отрисовать(Новый Структура("Текст, Заголовок, Вид",
	"Сервер сборки не отвечает. Изменения не потеряны — повторите позже.",
	"Сборка не запущена", "ошибка"));
```

## Закрываемый тост

`Закрываемый` печатает крест справа — кнопку с `data-close` и подписью «Закрыть». По нажатию скрипт кита гасит тост и убирает его со страницы, как Snackbar у MUI. Без скрипта крест ничего не делает, поэтому важное сообщение не прячьте только за ним.

```живой С крестом
HTML = Набор.Тост().Отрисовать(Новый Структура("Текст, Вид, Закрываемый",
	"Приглашение отправлено", "ok", Истина));
```

Тост появляется въездом снизу с кривой emphasized-decelerate. Если в системе включено «уменьшить движение», он просто появляется на месте.

## Тост из ответа

После [тихой отправки](формы-деревом) страница не перезагружается, и тост, который сервер напечатал в ответе, мог бы лечь где-то выше экрана — человек не узнал бы, что сохранилось. Поэтому скрипт кита, положив ответ на страницу, поднимает новые тосты из потока вниз экрана, как Snackbar у Material, и показывает их по одному: каждый — 5 секунд, потом тост гаснет и встаёт следующий. Пока на тосте мышь или фокус, время стоит. Крест закрывает раньше. Новый — тот, которого на странице до ответа не было: тост, который уже стоял в потоке и пришёл в ответе тем же (постоянное предупреждение, образец на этой странице), остаётся на месте, и смена темы его не трогает.

Серверу для этого ничего нового не нужно: он кладёт тост в ответ обычным узлом `Кит.Уведомление` там, где печатал его и раньше. Без скрипта тост остаётся на странице, где его напечатал сервер, и никуда не уходит.

```живой Тост в ответе — обычный узел над формой
HTML = Кит.Холст(
	Кит.Уведомление("Проект «my-project» создан"),
	Кит.Форма("/проекты", Кит.Поле("name", "Имя проекта").Обязательное(),
		Кит.Кнопка("Создать проект").Основная()).БезПерезагрузки().Токен("т0кен-сессии")).Рендер();
```

Тост с ролью `alert` — вид «ошибка» или слово `Тревога()` — скрипт не поднимает и не закрывает: он остаётся на своём месте, пока человек не закроет его крестом или следующий ответ сервера не уберёт его. Ошибку, которую не успели прочесть, нельзя прятать по таймеру.

```живой Тревога — role="alert" при любом виде
HTML = Кит.Уведомление("Квота проекта исчерпана: новые файлы не примутся")
	.Вид("warn").Заголовок("Квота").Тревога().Закрываемый().Рендер();
```

Поднятый тост скрипт отмечает признаком `data-toast-live`: `wait` — ждёт очереди и не виден, `show` — виден внизу экрана, `gone` — гаснет. Морфинг следующего ответа такой тост не трогает. Живой образец с сервером — [форма нового проекта](/образец-проверки): создайте два проекта подряд, и тосты встанут в очередь.

```делайте Ошибку — тревогой: она дождётся человека
HTML = Кит.Уведомление("Не сохранено: сервер сборки не отвечает").Вид("err").Закрываемый().Рендер();
```

```не-делайте Важное предупреждение обычным тостом: после тихой отправки он уйдёт через 5 секунд
HTML = Кит.Уведомление("Ключ доступа истекает завтра — продлите его").Вид("warn").Рендер();
```

## Гайдлайны

```делайте Текст называет итог: что именно произошло
HTML = Набор.Тост().Отрисовать("Профиль сохранён");
```

```не-делайте Пустое «Успешно!»: человек не знает, что удалось
HTML = Набор.Тост().Отрисовать("Операция выполнена успешно!");
```

```делайте Ошибка — видом ошибки: красным и с role="alert"
HTML = Набор.Тост().Отрисовать(Новый Структура("Текст, Вид",
	"Не удалось сохранить: сервер не отвечает", "err"));
```

```не-делайте Ошибка зелёным тостом: глаз читает «всё хорошо»
HTML = Набор.Тост().Отрисовать(Новый Структура("Текст, Вид",
	"Не удалось сохранить: сервер не отвечает", "ok"));
```

```делайте Один тост на итог действия
HTML = Набор.Тост().Отрисовать(Новый Структура("Текст, Вид",
	"Не сохранено: проверьте два поля ниже", "err"));
```

```не-делайте Стопка тостов про каждое поле: им место у самих полей
HTML = Набор.Тост().Отрисовать(Новый Структура("Текст, Вид", "Имя не заполнено", "err"))
	+ Набор.Тост().Отрисовать(Новый Структура("Текст, Вид", "Почта не заполнена", "err"))
	+ Набор.Тост().Отрисовать(Новый Структура("Текст, Вид", "Не сохранено", "err"));
```

## Доступность

- Ошибка печатается с `role="alert"`: скринридер объявляет её сразу. Остальные виды — `role="status"`: их прочтут, не прерывая человека.
- Значок вида декоративен (`aria-hidden`), смысл несут текст и роль. Цвет — лишь второй носитель смысла: «Не сохранено» должно быть понятно и без красного.
- Крест закрытия — кнопка с `aria-label="Закрыть"`; его поведение — забота скрипта страницы.
- Слово `Тревога()` даёт `role="alert"` тосту любого вида: важное предупреждение объявляется сразу. Такой тост скрипт из ответа сам не закрывает.
- Тост из ответа тихой отправки виден 5 секунд, и пока на нём мышь или фокус, время стоит: человек успевает дочитать и дотянуться до креста.
- Текст экранируется: сообщение с ввода пользователя разметкой не станет.

## Узлом холста

На [холсте](холст) тост — узел рода «уведомление», а функция холста так и называется: `Кит.Уведомление`.

```живой Тост узлом дерева
HTML = Кит.Уведомление("Сохранено").Вид("ok").Рендер();
```
