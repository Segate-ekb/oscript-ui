# Форма отбора

Форма отбора сужает список: поле подстроки и кнопка, а при нужде — несколько полей. Она отправляется методом GET, поэтому отбор живёт в адресе: его можно обновить, сохранить закладкой и отправить ссылкой.

## Когда использовать

- Поиск по списку или таблице: имя, часть имени, логин.
- Фильтр журнала по нескольким условиям: событие, кто, с какой даты.

Не берите форму отбора для того, что меняет данные на сервере: GET не несёт токена CSRF, и правка через него — дыра. Для таких форм есть `Кит.Форма` (см. [Формы деревом](формы-деревом)). Переключение соседних видов одного объекта — это [вкладки](табы), а не отбор.

## Поле и кнопка

Обязательны `Действие` — адрес, куда уходит GET, — и `Кнопка`, её подпись. Поле по умолчанию называется `q`; другое имя параметра задаёт `Имя`.

Поле и кнопка стоят в строку: поле занимает всё свободное место, кнопка держится по центру его контейнера, что бы ни печаталось под полем.

```живой Поле и кнопка
HTML = Набор.ФормаОтбора().Отрисовать(Новый Структура("Действие, Метка, Кнопка",
	"/настройки/проекты", "Отбор по имени проекта", "Отобрать"));
```

## Сохранение остального отбора

Отправка GET-формы заменяет запрос в адресе целиком. Если список уже отобран по проекту, поиск по подстроке этот отбор потеряет. `СкрытыеПоля` — массив `Имя, Значение` — везут остальные параметры вместе с подстрокой.

`Значение` — текущая подстрока: после отправки человек видит в поле то, что искал. `Плейсхолдер` — пример, что вводить. `Иконка` ставится в кнопку.

```живой С сохранением GET-отбора
Скрытые = Новый Массив();
Скрытые.Добавить(Новый Структура("Имя, Значение", "проект", "main"));

HTML = Набор.ФормаОтбора().Отрисовать(
	Новый Структура("Действие, Метка, Значение, Плейсхолдер, Кнопка, Иконка, СкрытыеПоля",
		"/документы", "Поиск", "отчёт", "Имя документа или его часть",
		"Найти", "поиск", Скрытые));
```

## Несколько полей

`Поля` — массив моделей [поля формы](поле). Если он задан, одиночное поле подстроки не печатается: форма состоит из этих полей и кнопки. Годятся любые типы поля — выбор, текст, дата.

```живой Несколько полей отбора
Варианты = Новый Массив();
Варианты.Добавить(Новый Структура("Значение, Подпись", "", "Все события"));
Варианты.Добавить(Новый Структура("Значение, Подпись", "доступ.выдан", "Доступ: выдан"));

Поля = Новый Массив();
Поля.Добавить(Новый Структура("Имя, Метка, Тип, Варианты",
	"type", "Событие", "выбор", Варианты));
Поля.Добавить(Новый Структура("Имя, Метка, Плейсхолдер", "who", "Кто", "Логин"));
Поля.Добавить(Новый Структура("Имя, Метка, Тип", "since", "С даты (UTC)", "date"));

HTML = Набор.ФормаОтбора().Отрисовать(Новый Структура("Действие, Кнопка, Иконка, Поля",
	"/настройки/журнал", "Показать", "поиск", Поля));
```

Пустой вариант выбора («Все события») отправляет пустую строку: сервер читает её как «без отбора по событию».

## Гайдлайны

```делайте Метка говорит, по чему ищем, плейсхолдер — пример
HTML = Набор.ФормаОтбора().Отрисовать(Новый Структура("Действие, Метка, Плейсхолдер, Кнопка, Иконка",
	"/документы", "Имя документа", "например, отчёт", "Найти", "поиск"));
```

```не-делайте Безымянное поле: непонятно, по имени ищем или по автору
HTML = Набор.ФормаОтбора().Отрисовать(Новый Структура("Действие, Кнопка",
	"/документы", "Найти"));
```

```делайте Кнопка — глагол того, что произойдёт
HTML = Набор.ФормаОтбора().Отрисовать(Новый Структура("Действие, Метка, Кнопка, Иконка",
	"/настройки/журнал", "Логин", "Показать", "поиск"));
```

```не-делайте Кнопка «ОК»
HTML = Набор.ФормаОтбора().Отрисовать(Новый Структура("Действие, Метка, Кнопка",
	"/настройки/журнал", "Логин", "ОК"));
```

```делайте Поиск помнит остальной отбор скрытыми полями
Скрытые = Новый Массив();
Скрытые.Добавить(Новый Структура("Имя, Значение", "проект", "main"));

HTML = Набор.ФормаОтбора().Отрисовать(Новый Структура("Действие, Метка, Кнопка, СкрытыеПоля",
	"/документы", "Имя документа", "Найти", Скрытые));
```

```не-делайте Поиск без скрытых полей: выбранный проект сбросится
HTML = Набор.ФормаОтбора().Отрисовать(Новый Структура("Действие, Метка, Кнопка",
	"/документы", "Имя документа", "Найти"));
```

## Доступность

- Форма — настоящий `<form method="get">`: отбор работает без скрипта, Enter в поле отправляет форму.
- Поле — [поле формы](поле) с подписью в `<label>`; без `Метки` скринридер не назовёт поле. Задавайте её всегда.
- Кнопка — [кнопка](кнопка) отправки с видимой подписью.
- Форма без `Действия` не собирается: кит кидает исключение, а не отправляет отбор «куда-то».

## Узлом холста

На [холсте](холст) готовая строка поиска — `Кит.СтрокаПоиска(Модель)`: модель та же, что у компонента. От рода `Кит.ФормаОтбора(Действие, Вид)` она отличается тем, что собрана целиком: род даёт пустую GET-форму, в которую поля кладут узлами.

```живой Строка поиска узлом дерева
HTML = Кит.СтрокаПоиска(Новый Структура("Действие, Метка, Кнопка",
	"/документы", "Поиск", "Найти")).Рендер();
```

Своя раскладка отбора собирается из рода: пустая GET-форма, поля и кнопка — её дети.

```живой Род «форма-отбора» — форма из узлов
Форма = Кит.ФормаОтбора("/документы", "строкой");
Форма.Добавить(Кит.Поле(Новый Структура("Имя, Метка", "q", "Имя документа")));
Форма.Добавить(Кит.Поле(Новый Структура("Имя, Метка", "автор", "Автор")));
Форма.Добавить(Кит.Кнопка(Новый Структура("Подпись, Иконка", "Найти", "поиск")));

HTML = Форма.Рендер();
```

## Модель

Поля модели — из комментария в исходнике компонента.

```справка ФормаОтбора
```

```справка Кит.СтрокаПоиска
```

```словарь компонент:поиск
```
