# Каркас документа

Роды документа собирают страницу целиком: объявление типа, голову с заглавием и ресурсами, тело с лендмарками. Обычно их печатает [каркас страницы](каркас-страницы), а свой каркас из них собирают, когда нужна страница без шапки и меню хаба.

## Документ, голова и тело

Документ — корень страницы. Он печатает `<!DOCTYPE html>` и `<html>` с языком и темой — это два первых аргумента, — а детьми принимает только голову и тело.

Тема ставится атрибутом `data-theme` ещё до листа стилей. Иначе страница на мгновение покажется в чужих цветах.

```разметкой Документ целиком: голова и тело
HTML = Кит.Документ("ru", "тёмная",
	Кит.Голова(Кит.Титул("Проекты")),
	Кит.Тело(Кит.Основное().Вид("полоса"))).Рендер();
```

Пустой язык не печатается вовсе: `lang=""` для скринридера хуже, чем отсутствие атрибута.

## Голова

Голова — то, чего человек не видит. В неё кладут только титул, мета, ресурс, стиль и скрипт; заголовок или абзац туда не попадут.

Кодировка стоит в голове первой: до неё браузер читает байты вслепую.

```разметкой Объявления головы
HTML = Кит.Голова(
	Кит.Кодировка("utf-8"),
	Кит.Мета("viewport", "width=device-width, initial-scale=1")).Рендер();
```

Свойства карточки ссылки (Open Graph) объявляются отдельной функцией: у них атрибут `property`, а не `name`. Адреса в карточке краулер ждёт абсолютными.

```разметкой Свойства карточки ссылки
HTML = Кит.Голова(
	Кит.МетаСвойство("og:title", "Проекты"),
	Кит.МетаСвойство("og:image", "https://пример.рф/проекты.png")).Рендер();
```

Ресурс — лист стилей, иконка вкладки, иконка домашнего экрана. Ресурс без адреса не печатается: `<link>` в никуда браузер всё равно запросил бы.

```разметкой Ресурсы: лист стилей и иконка вкладки
HTML = Кит.Голова(
	Кит.Ресурс("stylesheet", "/static/app.css", "text/css"),
	Кит.Ресурс("icon", "/static/знак.svg", "image/svg+xml", "32x32"),
	Кит.Ресурс("icon", "")).Рендер();
```

## Стиль и скрипт

Стиль — правила, которые должны приехать вместе с разметкой, а не отдельным запросом. Так каркас кладёт токены темы. Правила печатаются как есть: внутри `<style>` HTML-экранирование не защищает, а ломает.

```разметкой Палитра инлайном
HTML = Кит.Стиль("токены-темы", ":root { --layout-width: 1280px; }").Рендер();
```

Скрипт кита всегда отложенный (`defer`): разбор разметки он не останавливает, а порядок исполнения сохраняет. Скрипт без адреса не печатается.

```разметкой Отложенный скрипт
HTML = Кит.Скрипт("/static/app.js").Рендер();
```

## Лендмарки

Тело делится на ориентиры, по которым скринридер прыгает одной клавишей: шапка, навигация, основное, подвал. Основное на странице одно — то, ради чего её открыли.

Вид лендмарка — слово `.Вид(…)` — его оформление в каркасе: «страницы» у шапки и подвала, «полоса» у основного (колонка по центру), «верхняя» у навигации (ряд ходов в шапке). Без вида лендмарк печатается голым тегом.

```разметкой Страница из лендмарков
HTML = Кит.Тело(
	Кит.Шапка(
		Кит.Навигация().Вид("верхняя").Подпись("Основная навигация")).Вид("страницы"),
	Кит.Основное().Вид("полоса"),
	Кит.Подвал().Вид("страницы")).Рендер();
```

Обратите внимание: подпись у навигации сейчас не печатается. Доступное имя (`aria-label`) из подписи кит ставит только ряду.

## Гайдлайны

```делайте Один узел «основное» на страницу
HTML = Кит.Тело(
	Кит.Шапка().Вид("страницы"),
	Кит.Основное(Кит.Примечание("Содержимое экрана")).Вид("полоса"),
	Кит.Подвал().Вид("страницы")).Рендер();
```

```не-делайте Несколько «основных»: скринридер не знает, куда прыгать
HTML = Кит.Тело(
	Кит.Основное(Кит.Примечание("Список")).Вид("полоса"),
	Кит.Основное(Кит.Примечание("Подробности")).Вид("полоса")).Рендер();
```

```делайте Свой каркас — только когда каркас страницы не подходит
Документ = Кит.Документ("ru", "",
	Кит.Голова(Кит.Кодировка("utf-8"), Кит.Титул("Печать счёта")),
	Кит.Тело(Кит.Основное(Кит.Примечание("Страница для печати без шапки и меню"))));
HTML = Кит.Код(Документ.Дерево()).Вид("блочный").Рендер();
```

```не-делайте Голова без кодировки и заглавия
Документ = Кит.Документ("ru", "",
	Кит.Голова(),
	Кит.Тело(Кит.Основное(Кит.Примечание("Вкладка без имени"))));
HTML = Кит.Код(Документ.Дерево()).Вид("блочный").Рендер();
```

## Доступность

- Язык документа (`lang`) задаёт произношение скринридера и переносы слов. Передавайте его всегда.
- Титул — имя вкладки и первое, что скринридер объявит на странице. Называйте экран, а не приложение.
- Лендмарки печатаются своими тегами (`header`, `nav`, `main`, `footer`), поэтому роли им ставить не нужно.
