# Полоса заполнения

Полоса заполнения показывает долю занятого от предела: хранилище, квота, лимит запросов. Это показание, а не орган управления: мышью её не двигают, и скрипт ей не нужен. В Material это линейный индикатор — дорожка толщиной 4 пикселя и заливка цветом роли.

## Когда использовать

- У ресурса есть предел, и важно, сколько до него осталось.
- Человеку нужно заметить приближение к пределу раньше, чем случится отказ.
- В строке таблицы нужно показать заполнение каждой записи — для этого есть компактный вариант.

Не берите полосу для хода длительной операции — она не меняется сама и не анимирует ожидание. Число без предела показывает [плитка](плитка).

## Доля и подпись

`Процент` — число, `Метка` — что заполняется, `Подпись` — абсолютные величины рядом с процентом. Величины форматирует вызывающий: компонент не знает единиц.

```живой Нейтральная
HTML = Набор.ПолосаЗаполнения().Отрисовать(
	Новый Структура("Процент, Метка, Подпись",
		42, "Заполнение хранилища", "430 из 1024 МБ"));
```

При нуле заливка не печатается вовсе. При малой ненулевой доле виден хотя бы просвет: полоса не притворяется пустой, когда что-то уже занято.

```живой Пусто
HTML = Набор.ПолосаЗаполнения().Отрисовать(
	Новый Структура("Процент, Метка, Подпись",
		0, "Заполнение хранилища", "0 из 1024 МБ"));
```

```живой Просвет у малой доли
HTML = Набор.ПолосаЗаполнения().Отрисовать(
	Новый Структура("Процент, Метка, Подпись",
		3, "Заполнение хранилища", "31 из 1024 МБ"));
```

Ширина заливки идёт ступенями по 5 % и округляется вниз: индикатор предела не вправе преувеличивать остаток. Точный процент остаётся в тексте.

## Тон по проценту

Если `Вид` не задан, кит выводит его из процента. С 75 % полоса становится цветом предупреждения, с 90 % — цветом ошибки.

```живой Предупреждение с 75 %
HTML = Набор.ПолосаЗаполнения().Отрисовать(
	Новый Структура("Процент, Метка, Подпись",
		78, "Заполнение хранилища", "799 из 1024 МБ"));
```

```живой Тревога с 90 %
HTML = Набор.ПолосаЗаполнения().Отрисовать(
	Новый Структура("Процент, Метка, Подпись",
		94, "Заполнение хранилища", "963 из 1024 МБ"));
```

Больше 100 % — переполнение. Полоса заполнена целиком, а истинный процент остаётся в подписи.

```живой Переполнение
HTML = Набор.ПолосаЗаполнения().Отрисовать(
	Новый Структура("Процент, Метка, Подпись",
		137, "Заполнение хранилища", "1403 из 1024 МБ"));
```

## Вид задан явно

`Вид` («ok», «warn», «err») отменяет тон по проценту. Задавайте его, когда смысл обратный: заполненность — это хорошо, например доля пройденной проверки.

```живой Вид задан явно
HTML = Набор.ПолосаЗаполнения().Отрисовать(
	Новый Структура("Процент, Метка, Подпись, Вид",
		42, "Заполнение хранилища", "430 из 1024 МБ", "ok"));
```

## Компактная

Компактная полоса — для ячейки таблицы: строки с текстом под ней нет, остаётся одна дорожка. Метка и подпись при этом не пропадают — они в доступном имени.

```живой Компактная — для ячейки таблицы
HTML = Набор.ПолосаЗаполнения().Отрисовать(
	Новый Структура("Процент, Метка, Подпись, Компактная",
		61, "Заполнение хранилища", "625 из 1024 МБ", Истина));
```

```живой Компактная полоса в таблице
Таблица = Кит.Таблица();
Таблица.Добавить(Кит.Колонка("Проект"));
Таблица.Добавить(Кит.Колонка("Хранилище"));
Таблица.Добавить(Кит.Колонка("Занято"));

Запись = Таблица.Добавить(Кит.Запись());
Запись.Добавить(Кит.Ячейка()).Добавить(Кит.Текст("Альфа"));
Запись.Добавить(Кит.Ячейка()).Добавить(Кит.ПолосаЗаполнения(
	Новый Структура("Процент, Метка, Подпись, Компактная",
		61, "Хранилище проекта «Альфа»", "625 из 1024 МБ", Истина)));
Запись.Добавить(Кит.Ячейка("величина")).Добавить(Кит.Текст("625 из 1024 МБ"));

HTML = Таблица.Рендер();
```

## Гайдлайны

```делайте Рядом с процентом — абсолютные величины
HTML = Набор.ПолосаЗаполнения().Отрисовать(
	Новый Структура("Процент, Метка, Подпись",
		78, "Заполнение хранилища", "799 из 1024 МБ"));
```

```не-делайте Только процент: неясно, много это или мало
HTML = Набор.ПолосаЗаполнения().Отрисовать(
	Новый Структура("Процент, Метка", 78, "Заполнение"));
```

```делайте Тон по проценту: у предела полоса тревожит сама
HTML = Набор.ПолосаЗаполнения().Отрисовать(
	Новый Структура("Процент, Метка, Подпись",
		94, "Заполнение хранилища", "963 из 1024 МБ"));
```

```не-делайте Зелёный у самого предела: цвет врёт о запасе
HTML = Набор.ПолосаЗаполнения().Отрисовать(
	Новый Структура("Процент, Метка, Подпись, Вид",
		94, "Заполнение хранилища", "963 из 1024 МБ", "ok"));
```

## Доступность

- Дорожка печатается с `role="progressbar"` и `aria-valuemin`, `aria-valuemax`, `aria-valuenow`. При переполнении `aria-valuenow` держится на 100, а истинный процент — в доступном имени.
- `Метка` обязательна: без неё кит бросает исключение. Метка, процент и подпись собираются в один `aria-label`, и скринридер читает полосу одной фразой: «Заполнение хранилища: 42%, 430 из 1024 МБ».
- Цвет — второй носитель смысла: процент всегда напечатан текстом или звучит в доступном имени.
- В компактной полосе текста на экране нет. Назовите в метке, чьё это заполнение, — в таблице соседние полосы иначе прозвучат одинаково.

## Узлом холста

```живой Полоса узлом дерева
HTML = Кит.ПолосаЗаполнения(Новый Структура("Процент, Метка, Подпись",
	42, "Заполнение хранилища", "430 из 1024 МБ")).Рендер();
```
