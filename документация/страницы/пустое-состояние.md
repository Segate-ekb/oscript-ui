# Пустое состояние

Пустое состояние встаёт на место списка, в котором нет ни одной записи: значок, заголовок, объяснение и призыв к действию. Оно отвечает, почему здесь пусто и что сделать, чтобы появилось. Без единого слова объяснения кит его не печатает.

## Когда использовать

- В списке пока нет записей: проект только создан, документов ещё нет.
- Отбор или поиск ничего не нашёл, и нужно подсказать, как его ослабить.
- У объекта нет какой-то части — описания, связей, — и место под неё не должно выглядеть сломанным.

Не берите пустое состояние для места, которого на экране быть не должно, — его просто не рисуют, см. [Ничего и Холст](#ничего-и-холст) ниже. Об ошибке загрузки сообщает [тост](тост) или [страница ошибки](страница-ошибки).

## С призывом к действию

Лучшее пустое состояние объясняет, что здесь будет, и даёт кнопку, чтобы это сделать. `Действие` — модель компонента [кнопка](кнопка).

```живой С призывом к действию
HTML = Набор.ПустоеСостояние().Отрисовать(
	Новый Структура("Заголовок, Пояснение, Иконка, Действие",
		"В проекте пока нет документов",
		"Создайте первый документ — он появится здесь сразу.",
		"куб",
		Новый Структура("Подпись, Адрес, Иконка",
			"Как опубликовать", "/кабинет/публикация", "скачать")));
```

В дереве холста пустое состояние собирается словами: пояснение позицией, заголовок и значок — словами, действие — узлом кнопки (см. [Язык узлов](язык-узлов)).

```живой Узлом холста — словами
HTML = Кит.ПустоеСостояние("Создайте первый документ — он появится здесь сразу.")
	.Заголовок("В проекте пока нет документов").Иконка("куб")
	.Действие(Кит.Кнопка("Как опубликовать").Адрес("/кабинет/публикация").Иконка("скачать"))
	.Рендер();
```

## Только объяснение

Строка вместо модели — только пояснение под значком «инфо». Так пишут, когда сделать ничего нельзя, но пустоту нужно назвать.

```живой Только объяснение
HTML = Набор.ПустоеСостояние().Отрисовать("У этой редакции нет описания.");
```

## Компактное

Компактное пустое состояние — для узкой колонки или ячейки таблицы: меньше отступы и значок.

```живой Компактное — для колонки
HTML = Набор.ПустоеСостояние().Отрисовать(Новый Структура("Пояснение, Компактное",
	"Связей нет", Истина));
```

## Ничего и Холст

Иногда на экране показывать нечего, и никакого объяснения там не нужно: блока просто не должно быть. Тогда возвращают `Кит.Ничего()` — узел, который печатается пустой строкой.

```живой Кит.Ничего() не печатает ничего
HTML = Кит.Ничего().Рендер();
```

`Кит.Холст()` печатается так же, пока пуст, но смысл у него обратный. Холст — корень куска экрана: его наполняют и печатают целиком. Ничего — место, где показывать нечего: его не наполняют, он и есть ответ.

```bsl
Функция БлокЧерновика(Знач Статья)

	Если Статья.Черновик Тогда
		Возврат Кит.Ничего();   // на странице этого места просто не будет
	КонецЕсли;

	Возврат Кит.Холст(          // а здесь собираем кусок экрана
		Кит.Заголовок(3, "Как читать"),
		Кит.Примечание(Статья.Пояснение).Вид("описание"));

КонецФункции
```

На `Возврат Кит.Ничего();` читатель останавливается: элемента здесь нет. На `Возврат Кит.Холст();` он пошёл бы вверх по функции искать, чем холст наполнили. `Ничего()` ложится всюду, где принимают холст, но не в обход правил вложения: в запись по-прежнему кладут ячейку, в таблицу — запись.

Пустое состояние и `Ничего()` — противоположности. Первое что-то показывает человеку, второе не показывает ничего.

## Гайдлайны

```делайте Объяснить, почему пусто и что сделать
HTML = Набор.ПустоеСостояние().Отрисовать(
	Новый Структура("Заголовок, Пояснение, Действие",
		"Ничего не найдено",
		"Уточните отбор или сбросьте его.",
		Новый Структура("Подпись, Вариант, Адрес", "Сбросить отбор", "вторичная", "/документы")));
```

```не-делайте «Нет данных»: неясно, сломалось или так и должно быть
HTML = Набор.ПустоеСостояние().Отрисовать("Нет данных");
```

```делайте Компактное — в узкой колонке
HTML = Набор.ПустоеСостояние().Отрисовать(Новый Структура("Пояснение, Компактное",
	"Связей нет", Истина));
```

```не-делайте Полное с кнопкой там, где действия нет
HTML = Набор.ПустоеСостояние().Отрисовать(
	Новый Структура("Заголовок, Пояснение, Действие",
		"Связей нет", "Связи появятся, когда на документ сошлются.",
		Новый Структура("Подпись, Адрес", "Обновить", "/документы")));
```

## Доступность

- Без `Заголовка` и `Пояснения` кит бросает исключение: пустой блок неотличим от несработавшей загрузки.
- Заголовок и пояснение — обычные абзацы текста, скринридер читает их по порядку.
- Значок декоративен: смысл несут слова.
- Кнопка действия — полноценная [кнопка](кнопка) или ссылка-кнопка, с подписью-глаголом.

## Узлом холста

```живой Пустое состояние узлом дерева
HTML = Кит.ПустоеСостояние("Уточните отбор.").Заголовок("Ничего не найдено").Рендер();
```

Пустое состояние вместо таблицы без записей кладут в её холст `Пусто()` — образец на странице [таблица](таблица).
