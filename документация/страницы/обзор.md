# oscript-ui

UI-кит для веб-приложений на чистом OneScript в облике Material Design 3. Экран собирается на сервере из готовых компонентов и печатается в HTML, который выглядит прилично без единой строки CSS от вас.

## Что это

Кит — набор компонентов, каркас страницы и тема. Экран собирается деревом узлов — [холстом](холст): позицией то, без чего узел бессмыслен, дальше дети, остальное — слова цепочкой (правила — на странице [Язык узлов](язык-узлов)). Дерево печатается одним вызовом. Компонент можно позвать и строкой: набор получает модель-структуру и сразу возвращает разметку.

```живой Экран из пяти компонентов
Проекты = Новый Массив();
Проекты.Добавить(Новый Структура("Имя, Состояние",
	Кит.Код("альфа"), Кит.Плашка("открытый").Вид("ok")));
Проекты.Добавить(Новый Структура("Имя, Состояние",
	Кит.Код("отчёт"), Кит.Плашка("устаревший").Вид("warn")));

Таблица = Кит.Таблица(Проекты);
Таблица.Колонка("Имя", "Имя");
Таблица.Колонка("Состояние", "Состояние");

HTML = Кит.Холст(
	Кит.СтрокаПоиска("/проекты").Метка("Поиск").Кнопка("Найти", "поиск"),
	Таблица,
	Кит.Пагинация("/проекты", 1, 3)).Рендер();
```

## Три обещания кита

- **Выглядит готовым из коробки.** Базовый лист кита оформляет каждый класс, который кит печатает. Тест следит, чтобы ни один компонент не приехал к вам голым.
- **Работает без скрипта.** Формы отправляются, меню и окна открываются движком браузера, раскрывашки раскрываются. Скрипт кита добавляет движение — рябь, плавающую подпись поля, — но страница без него законченная.
- **Переопределяется штатно.** Свой лист встаёт вторым в каскаде, свой файл статики вытесняет одноимённый файл кита, свой акцент перекрашивает всю схему. Библиотеку трогать не нужно.

## Как читать документацию

У каждой страницы компонента одинаковое устройство: зачем он, когда его брать, варианты с живыми образцами, правила «делайте и не делайте», доступность и модель.

Образцы на этих страницах не картинки. Код под образцом исполняется при каждом показе страницы, и образец нарисован ровно им. Скопируйте код кнопкой справа, вставьте к себе — получите то же самое.

> **Совет.** Переключите тему в шапке и выберите свой акцент на странице [Цвет и тема](цвет). Вся документация, образцы в том числе, перекрасится: это тот же механизм, что работает в вашем приложении.
