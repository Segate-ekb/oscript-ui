# Пагинация

Пагинация делит длинный список на страницы: «Назад» слева, «Вперёд» справа, между ними — где человек сейчас. Адреса страниц собирает сам компонент из основы списка и параметров отбора, поэтому поиск и фильтр не теряются при переходе.

## Когда использовать

- Список длиннее, чем разумно отдать одним ответом: журнал, документы, участники.
- Порядок записей устойчив, и «страница 3» означает одно и то же при повторном заходе.
- Список отфильтрован, и отбор должен пережить переход на следующую страницу.

Не берите пагинацию для разделов одного объекта — для этого есть [вкладки](табы) и [дерево разделов](дерево-разделов). Если записей нет вовсе, покажите [пустое состояние](пустое-состояние), а не навигацию по нулю страниц.

## Число страниц известно

Задайте `Страница`, `ВсегоСтраниц` и `Основа` — путь списка. Посередине стоит «Страница 3 из 7», по краям — шаги в виде кнопок Material с обводкой.

```живой Середина списка
HTML = Набор.Пагинация().Отрисовать(Новый Структура("Страница, ВсегоСтраниц, Основа",
	3, 7, "/документы"));
```

В дереве холста пагинация собирается словами: основа, страница и число страниц позицией, отбор и подписи шагов — словами (см. [Язык узлов](язык-узлов)).

```живой Узлом холста — словами
HTML = Кит.Пагинация("/документы", 2, 4).Параметры("q", "отчёт").Рендер();
```

На краях списка лишний шаг не печатается: с первой страницы назад идти некуда, с последней — вперёд.

```живой Первая страница — без «Назад»
HTML = Набор.Пагинация().Отрисовать(Новый Структура("Страница, ВсегоСтраниц, Основа",
	1, 7, "/документы"));
```

```живой Последняя страница — без «Вперёд»
HTML = Набор.Пагинация().Отрисовать(Новый Структура("Страница, ВсегоСтраниц, Основа",
	7, 7, "/документы"));
```

Номер вне диапазона компонент поправляет сам: «страница 0» станет первой, «страница 40 из 7» — седьмой.

Одна страница — навигации нет вовсе: переходить некуда.

```живой Одна страница — навигации нет
HTML = Набор.Пагинация().Отрисовать(Новый Структура("Страница, ВсегоСтраниц, Основа",
	1, 1, "/документы"));
```

## Сколько записей: «41–60 из 137»

Знаете, сколько записей в списке после отбора, — скажите словами `Всего` и `НаСтранице` (размер страницы). Рядом с номером страницы встанет диапазон: какие записи на экране и сколько их всего. Число страниц кит посчитает сам, если его не передали позицией; последняя страница кончается последней записью, а не полной страницей. Текст диапазона — ключ словаря `pagination.of` (`%1–%2 из %3`).

```живой Диапазон записей
HTML = Кит.Пагинация("/проекты", 3).Всего(137).НаСтранице(20).Рендер();
```

```живой Последняя страница — до последней записи
HTML = Кит.Пагинация("/проекты", 7).Всего(137).НаСтранице(20).Рендер();
```

Одного числа мало: без размера страницы диапазон не посчитать, и он не печатается. Все записи на одной странице — навигации нет, как и прежде.

## Без перезагрузки

Слово `БезПерезагрузки()` делает ссылки страниц тихими: у каждой — признак `data-quiet`, тот же, что у [тихой формы](формы-деревом). Скрипт кита берёт страницу запросом в фоне и кладёт ответ на место: список меняется, а прокрутка и фокус остаются. Адрес вкладки уходит в её историю, поэтому «Назад» браузера возвращает прежнюю страницу — тоже без перезагрузки и на ту же прокрутку. Номер страницы объявлен живой областью (`aria-live="polite"`): скринридер прочтёт «Страница 2 из 7» сам.

```живой Тихие ссылки страниц
HTML = Кит.Пагинация("/проекты", 2).Всего(137).НаСтранице(20)
	.Параметры("q", "бета").БезПерезагрузки().Рендер();
```

Сервер ничего нового не учит: он отвечает на адрес страницы тем же, чем ответил бы браузеру, — всей страницей списка. Без скрипта это обычные ссылки. Вместе со [строкой поиска](форма-отбора) и [сортировкой колонки](таблица-деревом) пагинация собирает список, который листается и отбирается на месте, — живой образец с сервером: [список проектов](/образец-списка).

## Отбор переживает переход

`Параметры` — пары `Имя, Значение`, которые войдут в адрес каждой страницы. Значения кодируются для URL, пустые пары пропускаются. Без этого вторая страница поиска показала бы весь список.

```живой С сохранением отбора
Отбор = Новый Массив();
Отбор.Добавить(Новый Структура("Имя, Значение", "q", "отчёт"));

HTML = Набор.Пагинация().Отрисовать(
	Новый Структура("Страница, ВсегоСтраниц, Основа, Параметры",
		2, 4, "/документы", Отбор));
```

Имя параметра страницы по умолчанию — `page`. Если список уже занял это имя, задайте своё полем `Параметр`. Подписи шагов меняются полями `ПодписьНазад` и `ПодписьВперёд`.

```живой Свой параметр и подписи шагов
HTML = Набор.Пагинация().Отрисовать(
	Новый Структура("Страница, ВсегоСтраниц, Основа, Параметр, ПодписьНазад, ПодписьВперёд",
		2, 5, "/журнал", "p", "Раньше", "Позже"));
```

## Число страниц неизвестно

Сосчитать строки бывает дороже, чем их показать. Тогда вместо `ВсегоСтраниц` передайте `ЕстьСледующая`: выбрали на одну запись больше, чем помещается, — значит, дальше есть. Посередине печатается только номер страницы, без «из».

```живой Число страниц неизвестно, дальше есть
HTML = Набор.Пагинация().Отрисовать(Новый Структура("Страница, ЕстьСледующая, Основа",
	1, Истина, "/настройки/журнал"));
```

«Назад» печатается по номеру текущей страницы: с третьей страницы вернуться можно, даже если дальше пусто.

```живой Число страниц неизвестно, дальше пусто
HTML = Набор.Пагинация().Отрисовать(Новый Структура("Страница, ЕстьСледующая, Основа",
	3, Ложь, "/настройки/журнал"));
```

## Основа обязательна

Без `Основы` ссылки страниц вели бы относительно текущего адреса, а с опасной схемой (`javascript:`) — исполняли бы код. Компонент отказывает в обоих случаях, и проверка стоит раньше всего остального: забытая основа всплывёт и на коротком списке из одной страницы.

```живой Пустая основа — исключение с объяснением
Попытка
	HTML = Набор.Пагинация().Отрисовать(Новый Структура("Страница, ВсегоСтраниц", 1, 1));
Исключение
	HTML = Набор.Тост().Отрисовать(Новый Структура("Текст, Вид",
		ИнформацияОбОшибке().Описание, "ошибка"));
КонецПопытки;
```

```делайте Число страниц не знаете — так и скажите: ЕстьСледующая

```


## Доступность

- Навигация печатается `<nav>` с `aria-label` «Постраничная навигация»; своё имя — поле `Заголовок`.
- Шаги — ссылки с `rel="prev"` и `rel="next"`: браузер и поисковик понимают, что это соседние страницы одного списка.
- Состояние «Страница 3 из 7» напечатано текстом, а не только видом шагов. Стрелки-значки декоративны: имя шага — его подпись.
- Шаг, которого нет, не печатается вовсе, а не блокируется: мёртвой ссылки клавиатура не встретит.
- Со словом `БезПерезагрузки` состояние «Страница 3 из 7» — живая область (`aria-live="polite"`): страница сменилась без перезагрузки, и скринридер скажет об этом сам. Фокус остаётся на нажатом шаге.
- Диапазон «41–60 из 137» напечатан текстом рядом с состоянием; живой областью он не объявлен, чтобы скринридер не читал смену дважды.

## Узлом холста

На [холсте](холст) пагинация — узел рода «страницы». Ставьте его сразу под [таблицей](таблица) списка.

```живой Пагинация узлом дерева
HTML = Кит.Пагинация("/документы", 2, 5).Рендер();
```
