# Формы деревом

Форма в дереве бывает двух видов. Род формы — пустая `form`, в которую кладут поля и кнопки узлами. Объявленная форма знает свои поля сама: печатает их, разбирает пришедшее и возвращает человеку отказ вместе с набранным.

## Когда что брать

- **Род формы** — форма из одной-двух кнопок, отбор списка, переключатель, форма, состав которой собирает экран.
- **Объявленная форма** — форма, которую сервер разбирает: создание и правка объекта, настройки. Поля объявлены один раз, и отрисовка с разбором не могут разойтись в именах.

Готовую строку поиска с полем и кнопкой печатает компонент [«Форма отбора»](форма-отбора), отдельное поле — компонент [«Поле формы»](поле).

## Четыре рода формы

Роды формы отличаются не оформлением, а тем, чем защищён отправленный запрос. Раскладка у всех общая: вид «столбик», «строкой», «меню» (форма внутри пункта меню), «переключатель».

Форма вошедшего отправляет POST и без CSRF-токена не собирается: форма без него выглядит рабочей, а получает 403. Токен встаёт скрытым полем первым ребёнком.

```живой Форма вошедшего — токен встаёт первым ребёнком
Форма = Кит.Форма("/проекты", "т0кен-сессии", "строкой");
Форма.Добавить(Кит.Поле(Новый Структура("Имя, Метка", "имя", "Имя проекта")));
Форма.Добавить(Кит.Кнопка(Новый Структура("Подпись, Вариант", "Создать", "основная")));

HTML = Форма.Рендер();
```

Форма посетителя без сессии — вход, регистрация, запрос ссылки на смену пароля. Токена у неё нет, потому что его неоткуда взять: токен живёт в сессии.

```живой Форма посетителя без сессии
Форма = Кит.ФормаБезСессии("/вход", "столбик");
Форма.Добавить(Кит.Поле(Новый Структура("Имя, Метка", "почта", "Почта")));
Форма.Добавить(Кит.Кнопка(Новый Структура("Подпись, Вариант", "Войти", "основная")));

HTML = Форма.Рендер();
```

Форма отбора идёт GET и на сервере ничего не меняет. Отправленный отбор виден в адресе, и им можно поделиться ссылкой — в этом его смысл.

```живой Форма отбора — GET, ничего не меняет
Форма = Кит.ФормаОтбора("/документы", "строкой");
Форма.Добавить(Кит.Поле(Новый Структура("Имя, Метка", "q", "Поиск")));
Форма.Добавить(Кит.Кнопка(Новый Структура("Подпись, Вариант", "Найти", "вторичная")));

HTML = Форма.Рендер();
```

Форма без токена — у отправителя сессия есть, но сервер токена не спрашивает: цена подделки запроса — неудобство, а не ущерб. Так переключают тему и выходят.

```живой Форма, у которой сервер токена не спрашивает
Форма = Кит.ФормаБезТокена("/оформление", "переключатель");
Форма.Добавить(Кит.Кнопка(Новый Структура("Подпись, Вариант, Иконка, ТолькоИконка",
	"Переключить тему", "ссылка", "луна", Истина)));

HTML = Форма.Рендер();
```

Форма, которая несёт файлы, объявляет это методом `СФайлами()`. Без него браузер отправит вместо файла одно его имя.

```разметкой Форма с файлами
Форма = Кит.Форма("/пакеты", "т0кен-сессии", "столбик").СФайлами();
Форма.Добавить(Кит.Поле(Новый Структура("Имя, Метка, Тип", "архив", "Архив пакета", "файл")));

HTML = Форма.Рендер();
```

## Объявленная форма

Объявление берут у желудя `Формы`: `Формы.Новая()`. Поля перечисляют цепочкой `Поле(Ключ, Метка, Вид, Свойства)`. Из ключа выводится атрибут `name`, и разбор зовёт ту же функцию, что отрисовка.

Вид поля — «строка», «число», «флажок», «секрет», «многострочное» или «выбор». Свойства — обязательность, подсказка, пределы числа, варианты выбора, умолчание.

```живой Объявленная форма — состав знает она сама
Объявление = Формы.Новая();
Объявление.Поле("имя", "Имя проекта", "строка",
	Новый Структура("Обязательное, Подсказка", Истина, "латиница и дефис"));
Объявление.Поле("описание", "Описание", "многострочное");

HTML = Кит.ОбъявленнаяФорма(Объявление, Новый Структура("имя", "main"),
	"/проекты", "т0кен-сессии", "столбик").Рендер();
```

Второй аргумент — действующие значения по ключам полей. Их печатают в полях, пока человек ещё ничего не набрал.

## Проверка полей

`Разобрать` берёт тело запроса, приводит значения к видам полей и проверяет ограничения. Флажок становится булевым, число — числом. Поле только на чтение из запроса не берётся вовсе: подделанное значение не сохранится и не попадёт на экран.

Отказ возвращает ту же форму: под полем текст отказа, в поле — то, что человек набрал. Секрет не возвращается никогда.

```живой Отказ возвращает форму с набранным
Объявление = Формы.Новая();
Объявление.Поле("имя", "Имя проекта", "строка", Новый Структура("Обязательное", Истина));
Объявление.Поле("квота", "Квота, ГБ", "число", Новый Структура("Мин, Макс", 1, 100));

Присланное = Новый Соответствие();
Присланное.Вставить("имя", "");
Присланное.Вставить("квота", "500");
Итог = Объявление.Разобрать(Присланное);

HTML = Кит.ОбъявленнаяФорма(Объявление, Неопределено,
	"/проекты", "т0кен-сессии", "столбик").Рендер();
```

Текстов отказов у кита нет: он берёт их из словаря интерфейса инсталляции по ключам `form.error.required`, `form.error.number`, `form.error.min`, `form.error.max` и `form.error.choice`. Ключ, которого словарь не знает, печатается маркером `[?ключ]` — так пропуск виден сразу, а не прячется за пустой строкой. Словарь этого сайта ключей отказов не объявляет, поэтому в образце выше видны маркеры.

Отказ, который видит только домен (имя занято, пул закрыт), приходит в форму тем же путём — методом `Отбить`.

```живой Отказ домена
Объявление = Формы.Новая();
Объявление.Поле("имя", "Имя проекта");

Присланное = Новый Соответствие();
Присланное.Вставить("имя", "main");
Итог = Объявление.Разобрать(Присланное);
Если Итог.Принято Тогда
	Объявление.Отбить("имя", "Проект с таким именем уже есть");
КонецЕсли;

HTML = Кит.ОбъявленнаяФорма(Объявление, Неопределено,
	"/проекты", "т0кен-сессии", "столбик").Рендер();
```

## Кат и рамка

Подряд идущие поля с одной подписью `Кат` уходят под общую раскрывашку, с одним видом `Рамка` — в общую область. Это объявляют у полей, а не собирают вокруг них руками.

```живой Редкие настройки под раскрывашкой
Объявление = Формы.Новая();
Объявление.Поле("имя", "Имя проекта");
Объявление.Поле("ветка", "Ветка по умолчанию", "строка",
	Новый Структура("Кат, Умолчание", "Дополнительно", "main"));
Объявление.Поле("архив", "В архиве", "флажок", Новый Структура("Кат", "Дополнительно"));

HTML = Кит.ОбъявленнаяФорма(Объявление, Неопределено,
	"/проекты", "т0кен-сессии", "столбик").Рендер();
```

## Форма окном

Та же объявленная форма печатается модальным окном: кнопка открытия и `dialog`, который места не занимает, пока не открыт. Открытие, закрытие по Esc и удержание фокуса делает браузер, скрипта нет.

```живой Та же форма окном поверх экрана
Объявление = Формы.Новая();
Объявление.Поле("имя", "Имя проекта");

Окно = Новый Структура("Заголовок, Открывашка, Отправка",
	"Новый проект", "Создать проект", "Создать");

HTML = Кит.Окно(Объявление, Новый Структура(), "/проекты", "т0кен-сессии", Окно).Рендер();
```

Кнопка открытия не сработает в старом браузере, поэтому у экрана должна оставаться серверная дорога: адрес, по которому страница приходит с открытым окном (`Открыта` в свойствах окна). Им же отбитая форма возвращается человеку.

## Гайдлайны

```делайте Форма, которая меняет данные, — с токеном сессии
Форма = Кит.Форма("/проекты/7/удалить", "т0кен-сессии");
Форма.Добавить(Кит.Кнопка(Новый Структура("Подпись, Вариант", "Удалить", "опасная")));
HTML = Форма.Рендер();
```

```не-делайте ФормаБезТокена на удалении: сервер ответит 403
Форма = Кит.ФормаБезТокена("/проекты/7/удалить");
Форма.Добавить(Кит.Кнопка(Новый Структура("Подпись, Вариант", "Удалить", "опасная")));
HTML = Форма.Рендер();
```

```делайте Отбор списка — формой отбора: запрос виден в адресе
Форма = Кит.ФормаОтбора("/документы", "строкой");
Форма.Добавить(Кит.Поле(Новый Структура("Имя, Метка", "q", "Поиск")));
Форма.Добавить(Кит.Кнопка(Новый Структура("Подпись, Вариант", "Найти", "вторичная")));

```

```не-делайте Отбор POST-формой: результат не открыть ссылкой и не обновить

```

## Доступность

- Поля объявленной формы печатаются компонентом [«Поле формы»](поле): метка связана с полем, отказ — с полем через описание.
- Окно называет себя скринридеру заголовком: без заголовка оно не соберётся.
- Форма без адреса действия не печатается: запрос ушёл бы на текущую страницу молча и не туда.
- Род формы не подставляет подписей сам: каждому полю нужна метка, кнопке-значку — подпись.
