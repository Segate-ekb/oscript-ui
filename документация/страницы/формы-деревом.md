# Формы деревом

Форма в дереве бывает двух видов. Род формы — пустая `form`, в которую кладут поля и кнопки узлами. Объявленная форма знает свои поля сама: печатает их, разбирает пришедшее и возвращает человеку отказ вместе с набранным.

## Когда что брать

- **Род формы** — форма из одной-двух кнопок, отбор списка, переключатель, форма, состав которой собирает экран.
- **Объявленная форма** — форма, которую сервер разбирает: создание и правка объекта, настройки. Поля объявлены один раз, и отрисовка с разбором не могут разойтись в именах.

Готовую строку поиска с полем и кнопкой печатает компонент [«Форма отбора»](форма-отбора), отдельное поле — компонент [«Поле формы»](поле).

## Четыре рода формы

Роды формы отличаются не оформлением, а тем, чем защищён отправленный запрос. Раскладка у всех общая — словом `.Вид(…)`: «столбик», «строкой», «меню» (форма внутри пункта меню), «переключатель». Поля и кнопки — дети формы аргументами.

Форма вошедшего отправляет POST со скрытым полем CSRF первым. Токен задаётся словом `.Токен(…)` — у самой формы или у предка: форма ищет его у себя и дальше вверх по дереву. Без токена форма не печатается: она выглядела бы рабочей, а получала 403. Строка внутри формы не принимается вовсе — прежде вторым аргументом шёл токен, и строкой он напечатался бы на экране.

```живой Форма вошедшего — токен словом, поле CSRF встаёт первым
HTML = Кит.Форма("/проекты",
	Кит.Поле("имя", "Имя проекта"),
	Кит.Кнопка("Создать").Основная()).Токен("т0кен-сессии").Вид("строкой").Рендер();
```

Форма посетителя без сессии — вход, регистрация, запрос ссылки на смену пароля. Токена у неё нет, потому что его неоткуда взять: токен живёт в сессии.

```живой Форма посетителя без сессии
HTML = Кит.ФормаБезСессии("/вход",
	Кит.Поле("почта", "Почта").ТипЗначения("email"),
	Кит.Кнопка("Войти").Основная()).Вид("столбик").Рендер();
```

Форма отбора идёт GET и на сервере ничего не меняет. Отправленный отбор виден в адресе, и им можно поделиться ссылкой — в этом его смысл.

```живой Форма отбора — GET, ничего не меняет
HTML = Кит.ФормаОтбора("/документы",
	Кит.Поле("q", "Поиск"),
	Кит.Кнопка("Найти").Вторичная()).Вид("строкой").Рендер();
```

Форма без токена — у отправителя сессия есть, но сервер токена не спрашивает: цена подделки запроса — неудобство, а не ущерб. Так переключают тему и выходят.

```живой Форма, у которой сервер токена не спрашивает
HTML = Кит.ФормаБезТокена("/оформление",
	Кит.Кнопка("Переключить тему").Ссылкой().Иконка("луна").ТолькоИконка())
	.Вид("переключатель").Рендер();
```

Форма, которая несёт файлы, объявляет это словом `СФайлами()`. Без него браузер отправит вместо файла одно его имя.

```разметкой Форма с файлами
HTML = Кит.Форма("/документы", Кит.Поле("архив", "Архив документов").Файл())
	.Токен("т0кен-сессии").Вид("столбик").СФайлами().Рендер();
```

## Адрес и токен у контекста

Адрес раздела и токен на экране задаются один раз — у [дома настроек](дом-настроек) или у холста экрана, — а форма берёт их у ближайшего предка:

- `Кит.Форма("", …)` уходит на адрес контекста — текущего раздела дома;
- `Кит.Форма("revoke", …)` — на `раздел/revoke`;
- `Кит.Форма("/x", …)` — на свой адрес; так же адрес с `?` и `#` в начале.

Форма с относительным адресом без дома вокруг не печатается: запрос ушёл бы на текущую страницу молча и не туда. Форма вошедшего без токена ни у себя, ни у предков — тоже.

```живой Формы берут адрес у раздела дома, токен — у дома
Дом = Кит.ДомНастроек("Настройки", "/проекты/альфа/настройки", "т0кен-сессии",
	Кит.Секция("Ключи доступа",
		Кит.Ряд("действия",
			Кит.Форма("", Кит.Кнопка("Выпустить ключ").Основная()),
			Кит.Форма("7/revoke", Кит.Кнопка("Отозвать ключ 7").Опасная()))));
Дом.Раздел("Ключи", "ключи").Текущий();

HTML = Дом.Рендер();
```

```живой Относительный адрес без контекста — исключение
Попытка
	Кит.Форма("revoke", Кит.Кнопка("Отозвать")).Токен("т").Рендер();
Исключение
	HTML = Кит.Примечание(КраткоеПредставлениеОшибки(ИнформацияОбОшибке())).Рендер();
КонецПопытки;
```

## Тип поля

Тип поля задаётся словом `.ТипЗначения(…)` значением системы типов OneScript — тем же, что у реквизита в 1С. Имя слова не «Тип»: оно в OneScript занято самой системой типов.

| Значение | Поле |
|---|---|
| `Тип("Строка")` | текст |
| `Тип("Число")` | `type="number"` |
| `Тип("Булево")` | флажок |
| `Тип("Дата")` | `type="date"` |
| `ОписаниеТипов("Число", КвалификаторыЧисла(7, 2))` | `step="0.01"`, `max="99999.99"`; без дробной части — `step="1"` |
| `ОписаниеТипов("Строка", , КвалификаторыСтроки(50))` | `maxlength="50"` |
| `КвалификаторыДаты(ЧастиДаты.Дата \| ДатаВремя \| Время)` | `date` \| `datetime-local` \| `time` |
| строка: «email», «url», «пароль», «файл», «многострочное», «выбор», «флажок», «число», «текст» | прежний тип модели |

Без явного типа он выводится из значения: число — числовое поле, Булево — отмеченный или снятый флажок, дата — поле даты в формате ввода `ГГГГ-ММ-ДД`. Явный тип старше выведенного. Не-типы остаются словами: `.Многострочное()`, `.Секрет()`, `.Файл()`, `.Вариант(Значение, Подпись)` — первый вариант делает поле выбором.

```разметкой Тип описанием типов, выводом из значения и словом
HTML = Кит.ФормаБезТокена("/отчёт",
	Кит.Поле("сумма", "Сумма, ₽").ТипЗначения(
		Новый ОписаниеТипов("Число", Новый КвалификаторыЧисла(9, 2))),
	Кит.Поле("с", "С даты").Значение(Дата(2024, 3, 1)),
	Кит.Поле("итоги", "Показать итоги").Значение(Истина),
	Кит.Поле("формат", "Формат").Вариант("pdf", "PDF").Вариант("csv", "CSV").Значение("csv"))
	.Вид("столбик").Рендер();
```

## Без перезагрузки

Форма, помеченная `БезПерезагрузки()`, уходит запросом в фоне, и страница не перезагружается. Ответ сервера скрипт кита кладёт на текущую страницу на место. Узел, который не изменился, остаётся тем же узлом, поэтому не прыгает прокрутка, не теряется фокус, раскрытые раскрывашки остаются раскрытыми, а бегунок тумблера доезжает своей анимацией.

```разметкой Форма без перезагрузки — тот же адрес и метод, один признак
HTML = Кит.Форма("/настройки/почта",
	Кит.Тумблер("сбои", "Письма о сбоях").Включено().СохранятьСразу(),
	Кит.ПанельСохранения())
	.Токен("т0кен-сессии").Вид("столбик").БезПерезагрузки().Рендер();
```

Сервер для такой формы ничего нового не делает и отвечает тем же, чем ответил бы браузеру:

- **Сохранил — перенаправляет обратно на страницу** (POST, затем 303, затем GET). Форма сбрасывается к тому, что пришло с сервера: поле комментария пустеет, тумблер стоит так, как его запомнил сервер. Перенаправление на другой адрес тоже работает: страница сменится без перезагрузки, адрес вкладки — вместе с ней.
- **Не принял — отдаёт страницу с ошибками** (4xx). Введённое человеком остаётся в полях, подсказки об ошибках встают рядом.

Пока ответ в пути, форма помечена `aria-busy`. Две отправки подряд уходят по очереди, каждая со своими данными, а на страницу ложится только последний ответ. Если что-то пошло не так (нет сети, ответ — не страница, у новой страницы другие листы или скрипты), форма уходит обычной навигацией: страница перезагрузится, как и без скрипта.

Так в этой документации работают [переключатель темы](каркас-страницы) в шапке и [выбор акцента](оформление).

> **Совет.** Скрипт инсталляции, который оживляет элементы при загрузке страницы, слушает событие `oscript-ui:update` на `document`: после тихой отправки по нему оживляют новые элементы.

Не помечайте так форму, которая отдаёт файл или уводит на чужой сайт, например вход через провайдера. Такому ответу место во вкладке, а не на текущей странице.

## В окне

Форма в [окне](окно) уходит без перезагрузки так же, как любая тихая форма, — сервер отвечает тем же, что и браузеру. Скрипт кита только смотрит, где стояла форма:

- **Сохранил — перенаправляет.** Окно закрывается, страница ложится по ответу на место, и фокус встаёт на элемент, который сервер пометил словом `Фокус()` (признак `data-focus`), — обычно на только что созданную запись. Человек видит результат там, где начинал, и клавиатура продолжает с него. Без пометки фокус возвращается на кнопку, которой окно открыли.
- **Не принял — 4xx.** Ответ несёт ту же страницу с этим же окном, напечатанным открытым (`Открыто()`), и отказами у полей. Скрипт берёт из ответа только окно и кладёт его содержимое в открытое: введённое на месте, подсказки рядом, фокус на первом отбитом поле, остальная страница не тронута.

```разметкой Окно-форма и запись, которую сервер пометил фокусом
Окно = Кит.Окно("Новый проект", Кит.Поле("name", "Название").Обязательное())
	.Форма("/проекты").БезПерезагрузки().Якорь("novyi-proekt")
	.Действия(Кит.Кнопка("Создать").Основная());
HTML = Кит.Холст(
	Кит.Кнопка("Новый проект").Открывает(Окно),
	Кит.Таблица(Кит.Колонка("Проект"),
		Кит.Запись(Кит.Ячейка("альфа")),
		Кит.Запись(Кит.Ячейка("дельта")).Фокус()),
	Окно).Токен("т0кен-сессии").Рендер();
```

Признак тихой отправки у окна-формы печатается на `<form>`, а не на `<dialog>`: словом `БезПерезагрузки()` помечают само окно. Форма, которая стоит в окне вне его формы (кнопка [подтверждения](подтверждение) с атрибутом `form`), закрывает окно своей кнопки по тем же правилам.

Без скрипта форма окна уходит обычным POST, и приходит страница целиком: удача — список с новой записью, отказ — страница с окном, напечатанным открытым. Образец с настоящим сервером — [список проектов](/образец-окон).

## Объявленная форма

Объявление берут у желудя `Формы`: `Формы.Новая()`. `Поле(Ключ, Метка)` объявляет поле и отдаёт его описание — оно настраивается словами, как узел холста: `ТипЗначения`, `Пределы(Мин, Макс)`, `Обязательное`, `ТолькоЧтение`, `Подсказка`, `Источник`, `Пример`, `Автозаполнение`, `Умолчание`, `Вариант(Значение, Подпись)`, `Кат`, `Рамка`, `Многострочное`, `Секрет`, а проверку до отправки — `Длина(Мин, Макс)`, `Шаблон(Образец)`, `ПроверкаНаСервере(Адрес)`, `ПроверкаДоОтправки` (раздел «Проверка» страницы [Поле](поле)). Следующее `Поле` у описания объявляет следующее поле того же объявления — цепочка не рвётся. Из ключа выводится атрибут `name`, и разбор зовёт ту же функцию, что отрисовка.

Прежний вызов `Поле(Ключ, Метка, Вид, Свойства)` — вид «строка», «число», «флажок», «секрет», «многострочное», «выбор», «дата» и структура свойств — работает как раньше и печатает то же самое.

```живой Объявленная форма — состав знает она сама
Объявление = Формы.Новая();
Объявление.Поле("имя", "Имя проекта").Обязательное().Подсказка("латиница и дефис")
	.Поле("описание", "Описание").Многострочное()
	.Поле("квота", "Квота, ГБ").ТипЗначения(Тип("Число")).Пределы(1, 100);

HTML = Кит.ОбъявленнаяФорма(Объявление, Новый Структура("имя, квота", "main", 20),
	"/проекты", "т0кен-сессии", "столбик").Рендер();
```

Второй аргумент — действующие значения по ключам полей. Их печатают в полях, пока человек ещё ничего не набрал; дата печатается в формате ввода.

## Проверка полей

`Разобрать` берёт тело запроса, приводит значения к объявленным типам и проверяет ограничения. Флажок становится Булево, число — Числом, дата — Датой. Поле только на чтение из запроса не берётся вовсе: подделанное значение не сохранится и не попадёт на экран.

Отказ возвращает ту же форму: под полем текст отказа, в поле — то, что человек набрал. Секрет не возвращается никогда.

```живой Отказ возвращает форму с набранным
Объявление = Формы.Новая();
Объявление.Поле("имя", "Имя проекта").Обязательное()
	.Поле("квота", "Квота, ГБ").ТипЗначения(Тип("Число")).Пределы(1, 100);

Присланное = Новый Соответствие();
Присланное.Вставить("имя", "");
Присланное.Вставить("квота", "500");
Итог = Объявление.Разобрать(Присланное);

HTML = Кит.ОбъявленнаяФорма(Объявление, Неопределено,
	"/проекты", "т0кен-сессии", "столбик").Рендер();
```

Текстов отказов у кита нет: он берёт их из словаря интерфейса инсталляции по ключам `form.error.required`, `form.error.number`, `form.error.min`, `form.error.max`, `form.error.choice` и `form.error.date`, а ограничения проверки до отправки — по ключам `form.error.minlength`, `form.error.maxlength` (`%1` — длина), `form.error.pattern`, `form.error.email` и `form.error.url`. Ключ, которого словарь не знает, печатается маркером `[?ключ]` — так пропуск виден сразу, а не прячется за пустой строкой.

Разбор судит строку теми же ограничениями, что поле печатает браузеру: вид «email» и «url» (`ТипЗначения("email")`), `Длина`, `Шаблон` — совпадение целиком и с учётом регистра, как у атрибута `pattern`. Без скрипта браузер не отправит негодное, а сервер не примет подделанное — и скажет теми же словами, что скрипт до отправки.

Отказ, который видит только домен (имя занято, проект закрыт), приходит в форму тем же путём — методом `Отбить`.

```живой Отказ домена
Объявление = Формы.Новая();
Объявление.Поле("имя", "Имя проекта");

Присланное = Новый Соответствие();
Присланное.Вставить("имя", "main");
Итог = Объявление.Разобрать(Присланное);
Если Итог.Принято Тогда
	Объявление.Отбить("имя", "Проект с таким именем уже есть");
КонецЕсли;

HTML = Кит.ОбъявленнаяФорма(Объявление, Неопределено,
	"/проекты", "т0кен-сессии", "столбик").Рендер();
```

## Кат и рамка

Подряд идущие поля с одной подписью `Кат` уходят под общую раскрывашку, с одним видом `Рамка` — в общую область. Это объявляют у полей, а не собирают вокруг них руками.

```живой Редкие настройки под раскрывашкой
Объявление = Формы.Новая();
Объявление.Поле("имя", "Имя проекта")
	.Поле("ветка", "Ветка по умолчанию").Умолчание("main").Кат("Дополнительно")
	.Поле("архив", "В архиве").ТипЗначения(Тип("Булево")).Кат("Дополнительно");

HTML = Кит.ОбъявленнаяФорма(Объявление, Неопределено,
	"/проекты", "т0кен-сессии", "столбик").Рендер();
```

## Форма окном

Та же объявленная форма печатается модальным окном: кнопка открытия и `dialog`, который места не занимает, пока не открыт. Открытие, закрытие по Esc и удержание фокуса делает браузер, скрипта нет.

```живой Та же форма окном поверх экрана
Объявление = Формы.Новая();
Объявление.Поле("имя", "Имя проекта");

Окно = Новый Структура("Заголовок, Открывашка, Отправка",
	"Новый проект", "Создать проект", "Создать");

HTML = Кит.Окно(Объявление, Новый Структура(), "/проекты", "т0кен-сессии", Окно).Рендер();
```

Кнопка открытия не сработает в старом браузере, поэтому у экрана должна оставаться серверная дорога: адрес, по которому страница приходит с открытым окном (`Открыта` в свойствах окна). Им же отбитая форма возвращается человеку.

Это окно печатается той же рамкой, что [окно со слотами](окно), и в дереве оно — узел рода «окно»: кнопка открывает его словом `Открывает(узел)`. Разметка — прежняя, байт в байт.

## Гайдлайны

```делайте Форма, которая меняет данные, — с токеном сессии
HTML = Кит.Форма("/проекты/7/удалить", Кит.Кнопка("Удалить").Опасная())
	.Токен("т0кен-сессии").Рендер();
```

```не-делайте ФормаБезТокена на удалении: сервер ответит 403
HTML = Кит.ФормаБезТокена("/проекты/7/удалить", Кит.Кнопка("Удалить").Опасная()).Рендер();
```

## Доступность

- Поля объявленной формы печатаются компонентом [«Поле формы»](поле): метка связана с полем, отказ — с полем через описание.
- Окно называет себя скринридеру заголовком: без заголовка оно не соберётся.
- Форма без адреса действия не печатается: запрос ушёл бы на текущую страницу молча и не туда.
- Род формы не подставляет подписей сам: каждому полю нужна метка, кнопке-значку — подпись.
