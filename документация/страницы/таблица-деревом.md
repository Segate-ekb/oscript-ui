# Таблица деревом

Таблица деревом собирается из узлов: колонки и записи кладут в таблицу, ячейки — в запись, а в ячейку — что угодно: код, плашку, ссылку, кнопку. Разметку таблицы, прокрутку и вид на телефоне кит печатает сам.

## Когда использовать

- Записи с одинаковыми полями, которые сравнивают по колонкам: проекты, пакеты, ключи.
- В ячейке нужно больше, чем строка: плашка состояния, ссылка, два этажа значения, меню строки.
- Список длинный и должен читаться на телефоне — вид «карточками».

Не берите таблицу для сведений об одном объекте — для этого есть [свойства](списки). Модель компонента «Таблица», собранного одной структурой, описана на странице [Таблица](таблица).

## Колонки, записи, ячейки

Порядок рода строгий: в таблицу кладут колонки и записи, в запись — только ячейки. Ячейка — холст. Запись с узлом другого рода кит не соберёт: такой узел исчез бы с экрана молча.

У записи есть второй холст — `Разворот()`. Он печатается отдельной строкой под записью во всю ширину таблицы. Пустой разворот не печатается.

```живой Колонки, запись, ячейка и разворот
Таблица = Кит.Таблица();
Таблица.Добавить(Кит.Колонка("Имя"));
Таблица.Добавить(Кит.Колонка("Признак"));

Запись = Таблица.Добавить(Кит.Запись());
Запись.Добавить(Кит.Ячейка()).Добавить(Кит.Код("значение"));
Запись.Добавить(Кит.Ячейка()).Добавить(
	Кит.Плашка(Новый Структура("Текст, Вид", "готово", "ok")));
Запись.Разворот().Добавить(Кит.Примечание("разворот печатается во всю ширину"));

HTML = Таблица.Рендер();
```

Записи из данных собираются циклом: запись на объект, ячейка на колонку.

```живой Таблица из массива данных
Таблица = Кит.Таблица();
Таблица.Добавить(Кит.Колонка("Имя"));
Таблица.Добавить(Кит.Колонка("Состояние"));
Таблица.Добавить(Кит.Колонка("Обновлён"));

Проекты = Новый Массив();
Проекты.Добавить(Новый Структура("Имя, Состояние, Обновлён",
	"альфа", Новый Структура("Текст, Вид", "открытый", "ok"), "вчера"));
Проекты.Добавить(Новый Структура("Имя, Состояние, Обновлён",
	"отчёт", Новый Структура("Текст, Вид", "устаревший", "warn"), "в марте"));

Для Каждого Проект Из Проекты Цикл
	Запись = Таблица.Добавить(Кит.Запись());
	Запись.Добавить(Кит.Ячейка()).Добавить(Кит.Код(Проект.Имя));
	Запись.Добавить(Кит.Ячейка()).Добавить(Кит.Плашка(Проект.Состояние));
	Запись.Добавить(Кит.Ячейка()).Добавить(Кит.Текст(Проект.Обновлён));
КонецЦикла;

HTML = Таблица.Рендер();
```

## Пустая таблица

Таблица без записей печатает вместо себя свой холст `Пусто()`. Пустая шапка над пустым телом — рамка, в которой человеку нечего прочесть.

```живой Пустая таблица отвечает словами
Таблица = Кит.Таблица();
Таблица.Добавить(Кит.Колонка("Имя"));
Таблица.Пусто().Добавить(Кит.Примечание("Ничего не найдено"));

HTML = Таблица.Рендер();
```

Когда пустой список — первый экран и человеку есть что сделать, положите в `Пусто()` компонент [«Пустое состояние»](пустое-состояние) с действием.

```живой Пустое состояние с действием вместо таблицы
Таблица = Кит.Таблица();
Таблица.Добавить(Кит.Колонка("Имя"));
Таблица.Пусто().Добавить(Кит.ПустоеСостояние(Новый Структура("Заголовок, Пояснение, Действие",
	"Проектов пока нет", "Создайте первый — он появится здесь.",
	Новый Структура("Подпись, Адрес, Иконка", "Создать проект", "/проекты/новый", "плюс"))));

HTML = Таблица.Рендер();
```

## Виды записи, колонки и ячейки

Выделенная запись залита цветом: одна строка списка отвечает на вопрос, ради которого список открыли («проект по умолчанию»). Узкая колонка и узкая ячейка сжимаются по содержимому — под значок, галочку, счётчик.

```живой Выделенная запись и узкий столбец
Таблица = Кит.Таблица();
Таблица.Добавить(Кит.Колонка("", "узкая"));
Таблица.Добавить(Кит.Колонка("Имя"));

Своя = Таблица.Добавить(Кит.Запись("выделенная"));
Своя.Добавить(Кит.Ячейка("узкая")).Добавить(
	Кит.Иконка(Новый Структура("Имя, Подпись", "закладка", "Выбор по умолчанию")));
Своя.Добавить(Кит.Ячейка()).Добавить(Кит.Текст("выделенная строка"));

Чужая = Таблица.Добавить(Кит.Запись());
Чужая.Добавить(Кит.Ячейка("узкая"));
Чужая.Добавить(Кит.Ячейка()).Добавить(Кит.Текст("обычная строка"));

HTML = Таблица.Рендер();
```

Ячейка «величина» — число с единицей: не переносится и приглушена. Ячейка «столбиком» — два этажа: значение и приписка под ним.

```живой Величина — число с единицей
Таблица = Кит.Таблица();
Таблица.Добавить(Кит.Колонка("Пакет"));
Таблица.Добавить(Кит.Колонка("Размер"));

Запись = Таблица.Добавить(Кит.Запись());
Запись.Добавить(Кит.Ячейка()).Добавить(Кит.Код("архив-2024"));
Запись.Добавить(Кит.Ячейка("величина")).Добавить(Кит.Текст("430 МБ"));

HTML = Таблица.Рендер();
```

```живой Ячейка столбиком — два этажа значения
Таблица = Кит.Таблица("карточками");
Таблица.Добавить(Кит.Колонка("Документ"));

Ячейка = Таблица.Добавить(Кит.Запись()).Добавить(Кит.Ячейка("столбиком"));
Ячейка.Добавить(Кит.Надпись("название")).Добавить(Кит.Текст("отчёт"));
Ячейка.Добавить(Кит.Надпись("пояснение")).Добавить(Кит.Текст("обновлён вчера"));

HTML = Таблица.Рендер();
```

## Таблица карточками

Вид «карточками» на узком экране (до 720 пикселей) печатает запись карточкой. Шапки у неё нет, поэтому ячейка сама несёт подпись своей колонки. Подписи нет у первой, заглавной ячейки, у пустой и у ячейки с меню строки.

Колонка, чьи значения называют себя сами («занято 12 КБ из 100», плашка «активна»), от подписи отказывается методом `БезПодписиВЗаписи()`. Угадывать это по значению кит не берётся. Сузьте окно, чтобы увидеть карточки.

```живой Карточками на узком экране
Таблица = Кит.Таблица("карточками");
Таблица.Добавить(Кит.Колонка("Имя"));
Таблица.Добавить(Кит.Колонка("Состояние")).БезПодписиВЗаписи();
Таблица.Добавить(Кит.Колонка("Обновлён"));

Запись = Таблица.Добавить(Кит.Запись());
Запись.Добавить(Кит.Ячейка()).Добавить(Кит.Код("альфа"));
Запись.Добавить(Кит.Ячейка()).Добавить(
	Кит.Плашка(Новый Структура("Текст, Вид", "активна", "ok")));
Запись.Добавить(Кит.Ячейка()).Добавить(Кит.Текст("вчера"));

HTML = Таблица.Рендер();
```

## Гайдлайны

```делайте Пустая выдача — словами в Пусто()
Таблица = Кит.Таблица();
Таблица.Добавить(Кит.Колонка("Имя"));
Таблица.Добавить(Кит.Колонка("Состояние"));
Таблица.Пусто().Добавить(Кит.Примечание("По запросу «бета» ничего не найдено", "пусто"));
HTML = Таблица.Рендер();
```

```не-делайте Таблица без Пусто(): на месте списка не остаётся ничего
Таблица = Кит.Таблица();
Таблица.Добавить(Кит.Колонка("Имя"));
Таблица.Добавить(Кит.Колонка("Состояние"));
HTML = Таблица.Рендер();
```

```делайте Машинное значение в ячейке — кодом, состояние — плашкой
Таблица = Кит.Таблица();
Таблица.Добавить(Кит.Колонка("Имя"));
Таблица.Добавить(Кит.Колонка("Состояние"));
Запись = Таблица.Добавить(Кит.Запись());
Запись.Добавить(Кит.Ячейка()).Добавить(Кит.Код("архив-2024"));
Запись.Добавить(Кит.Ячейка()).Добавить(Кит.Плашка(Новый Структура("Текст, Вид", "устарел", "warn")));
HTML = Таблица.Рендер();
```

```не-делайте Всё простым текстом: имя, состояние и пояснение сливаются
Таблица = Кит.Таблица();

Таблица.Добавить(Кит.Колонка("Состояние"));
Запись = Таблица.Добавить(Кит.Запись());
Запись.Добавить(Кит.Ячейка()).Добавить(Кит.Текст("архив-2024"));

```

## Доступность

- Колонка печатается `th scope="col"`: скринридер называет заголовок колонки перед каждой ячейкой.
- Подпись таблицы (`Таблица.Подпись("…")`) печатается `caption` — именем таблицы для скринридера.
- Колонку без подписи (узкую, под значок) называет содержимое ячеек: значку дайте подпись, она станет его доступным именем.
- Таблица обёрнута прокруткой: широкая таблица не ломает страницу на узком экране.
