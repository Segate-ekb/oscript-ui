# Таблица деревом

Таблица деревом собирается из данных, как в 1С, или из узлов: колонки и записи кладут в таблицу, ячейки — в запись, а в ячейку — что угодно: код, плашку, ссылку, кнопку. Разметку таблицы, прокрутку и вид на телефоне кит печатает сам.

## Когда использовать

- Записи с одинаковыми полями, которые сравнивают по колонкам: проекты, участники, ключи.
- В ячейке нужно больше, чем строка: плашка состояния, ссылка, два этажа значения, меню строки.
- Список длинный и должен читаться на телефоне — вид «карточками».

Не берите таблицу для сведений об одном объекте — для этого есть [свойства](списки). Модель компонента «Таблица», собранного одной структурой, описана на странице [Таблица](таблица).

## Таблица из данных

`Кит.Таблица(Данные)` собирает таблицу сама. Данные — таблица значений: колонки и их заголовки берутся из неё (заголовок колонки, по умолчанию её имя), записи — её строки, ячейка — свойство строки по имени колонки.

```живой Таблица из таблицы значений
Ключи = Новый ТаблицаЗначений;
Ключи.Колонки.Добавить("Имя");
Ключи.Колонки.Добавить("Префикс");
Ключи.Колонки.Добавить("Обращений", , "Обращений за месяц");
Ключи.Колонки.Добавить("Действие");

Ключ = Ключи.Добавить();
Ключ.Имя = "ноутбук";
Ключ.Префикс = Кит.Код("api_7f2c");
Ключ.Обращений = 1204;
Ключ.Действие = Кит.ФормаБезТокена("/ключи/7/отзыв", Кит.Кнопка("Отозвать").Опасная().Малая());

Ключ = Ключи.Добавить();
Ключ.Имя = "сборка";
Ключ.Префикс = Кит.Код("api_91ab");
Ключ.Обращений = 0;

HTML = Кит.Таблица(Ключи).Пусто("Ключей пока нет.").Рендер();
```

Что печатается в ячейке:

- строка — текст (экранируется);
- узел — узел; несколько узлов кладут `Кит.Холст(…)`;
- число — без разделителя групп;
- `Неопределено` и `""` — пустая ячейка.

Дату и Булево кит не форматирует: в каком виде их показать, решает экран. Такое значение останавливает печать исключением, и оно называет колонку.

```живой Дата в ячейке — исключение с именем колонки
Данные = Новый Массив();
Данные.Добавить(Новый Структура("Имя, Создан", "отчёт", Дата(2024, 3, 5)));
Таблица = Кит.Таблица(Данные);
Таблица.Колонка("Имя", "Имя");
Таблица.Колонка("Создан", "Создан");

Попытка
	Таблица.Рендер();
Исключение
	HTML = Кит.Примечание(КраткоеПредставлениеОшибки(ИнформацияОбОшибке())).Рендер();
КонецПопытки;
```

Данные — массив структур или соответствий: у записи-структуры нет порядка полей, поэтому колонки объявляются словом `.Колонка(Ключ, Заголовок)` в порядке вызовов. Без объявленных колонок такая таблица не печатается. У таблицы значений слово `Колонка` находит её колонку и даёт переопределить заголовок и вид.

```живой Таблица из массива: колонки словами
Участники = Новый Массив();
Участники.Добавить(Новый Структура("Имя, Роль, Вошёл", "анна",
	Кит.Плашка("владелец").Вид("accent"), "сегодня"));
Участники.Добавить(Новый Структура("Имя, Роль, Вошёл", "борис", "участник", "в марте"));

Таблица = Кит.Таблица(Участники).Вид("карточками");
Таблица.Колонка("Имя", "Участник");
Таблица.Колонка("Роль", "Роль").БезПодписиВЗаписи();
Таблица.Колонка("Вошёл", "Последний вход");

HTML = Таблица.Рендер();
```

Колонку, которую показывать не нужно, снимает слово `.Когда(Ложь)` — вместе с ячейками под ней.

### Разворот из данных

`.Разворот(ИмяКолонки)` называет колонку, чьё значение печатается не ячейкой, а строкой под записью во всю ширину таблицы. Пустое значение разворота не даёт.

```живой Колонка разворота — строкой под записью
Заявки = Новый ТаблицаЗначений;
Заявки.Колонки.Добавить("Документ");
Заявки.Колонки.Добавить("Автор");
Заявки.Колонки.Добавить("Сведения");

Заявка = Заявки.Добавить();
Заявка.Документ = Кит.Код("отчёт-2024");
Заявка.Автор = "анна";
Заявка.Сведения = Кит.Примечание("Годовой отчёт: 14 страниц, три приложения.");

Заявка = Заявки.Добавить();
Заявка.Документ = Кит.Код("план-q2");
Заявка.Автор = "борис";

HTML = Кит.Таблица(Заявки).Разворот("Сведения").Рендер();
```

## Колонки, записи, ячейки

Таблица собирается и узлами. Порядок рода строгий: в таблицу кладут колонки и записи, в запись — только ячейки. Ячейка — холст. Запись с узлом другого рода (и со строкой) кит не соберёт: такой узел исчез бы с экрана молча.

У записи есть второй холст — разворот, слово `Разворот(д…)`. Он печатается отдельной строкой под записью во всю ширину таблицы. Пустой разворот не печатается.

```живой Колонки, запись, ячейка и разворот
HTML = Кит.Таблица(
	Кит.Колонка("Имя"),
	Кит.Колонка("Признак"),
	Кит.Запись(
		Кит.Ячейка(Кит.Код("значение")),
		Кит.Ячейка(Кит.Плашка("готово").Вид("ok")))
		.Разворот(Кит.Примечание("разворот печатается во всю ширину"))).Рендер();
```

Таблица из данных печатается этим же кодом: по строкам данных кит собирает те же записи и ячейки, поэтому разметка у обеих одна, байт в байт.

## Пустая таблица

Таблица без записей печатает вместо себя содержимое слова `Пусто(…)`. Строка становится примечанием вида «пусто», узлы кладутся как есть. Пустая шапка над пустым телом — рамка, в которой человеку нечего прочесть.

```живой Пустая таблица отвечает словами
HTML = Кит.Таблица(Кит.Колонка("Имя")).Пусто("Ничего не найдено").Рендер();
```

Когда пустой список — первый экран и человеку есть что сделать, положите в `Пусто(…)` компонент [«Пустое состояние»](пустое-состояние) с действием.

```живой Пустое состояние с действием вместо таблицы
HTML = Кит.Таблица(Кит.Колонка("Имя"))
	.Пусто(Кит.ПустоеСостояние("Создайте первый — он появится здесь.")
		.Заголовок("Проектов пока нет")
		.Действие(Кит.Кнопка("Создать проект").Адрес("/проекты/новый").Иконка("плюс")))
	.Рендер();
```

## Виды записи, колонки и ячейки

Выделенная запись залита цветом: одна строка списка отвечает на вопрос, ради которого список открыли («проект по умолчанию»). Узкая колонка и узкая ячейка сжимаются по содержимому — под значок, галочку, счётчик. В таблице из данных узкая колонка сужает и свои ячейки.

```живой Выделенная запись и узкий столбец
HTML = Кит.Таблица(
	Кит.Колонка().Вид("узкая"),
	Кит.Колонка("Имя"),
	Кит.Запись(
		Кит.Ячейка(Кит.Иконка("закладка").Подпись("Выбор по умолчанию")).Вид("узкая"),
		Кит.Ячейка("выделенная строка")).Вид("выделенная"),
	Кит.Запись(
		Кит.Ячейка().Вид("узкая"),
		Кит.Ячейка("обычная строка"))).Рендер();
```

Ячейка «величина» — число с единицей: не переносится и приглушена. Ячейка «столбиком» — два этажа: значение и приписка под ним.

```живой Величина — число с единицей
HTML = Кит.Таблица(
	Кит.Колонка("Документ"),
	Кит.Колонка("Размер"),
	Кит.Запись(
		Кит.Ячейка(Кит.Код("архив-2024")),
		Кит.Ячейка("430 МБ").Вид("величина"))).Рендер();
```

```живой Ячейка столбиком — два этажа значения
HTML = Кит.Таблица(
	Кит.Колонка("Документ"),
	Кит.Запись(Кит.Ячейка(
		Кит.Надпись("отчёт").Вид("название"),
		Кит.Надпись("обновлён вчера").Вид("пояснение")).Вид("столбиком")))
	.Вид("карточками").Рендер();
```

## Таблица карточками

Вид «карточками» на узком экране (до 720 пикселей) печатает запись карточкой. Шапки у неё нет, поэтому ячейка сама несёт подпись своей колонки. Подписи нет у заглавной ячейки, у пустой и у ячейки с меню строки.

Заглавная ячейка стоит первой строкой карточки и крупнее остальных: по ней запись узнают. По умолчанию это первая колонка, другую называет слово `.Заглавная()` у колонки. У таблицы из данных это слово колонки из `Таблица.Колонка(Ключ)`. Ячейка с меню строки встаёт в правый верхний угол карточки, а лист с пунктами меню на телефоне выезжает снизу, как и раньше.

Колонка, чьи значения называют себя сами («занято 12 КБ из 100», плашка «активна»), от подписи отказывается словом `БезПодписиВЗаписи()`. Угадывать это по значению кит не берётся. Сузьте окно, чтобы увидеть карточки.

```живой Карточками на узком экране
HTML = Кит.Таблица(
	Кит.Колонка("Имя"),
	Кит.Колонка("Состояние").БезПодписиВЗаписи(),
	Кит.Колонка("Обновлён"),
	Кит.Запись(
		Кит.Ячейка(Кит.Код("альфа")),
		Кит.Ячейка(Кит.Плашка("активна").Вид("ok")),
		Кит.Ячейка("вчера"))).Вид("карточками").Рендер();
```

```живой Заглавная колонка из данных и меню строки
Проекты = Новый ТаблицаЗначений;
Проекты.Колонки.Добавить("Обновлён");
Проекты.Колонки.Добавить("Имя", , "Проект");
Проекты.Колонки.Добавить("Действия", , "");

Проект = Проекты.Добавить();
Проект.Обновлён = "вчера";
Проект.Имя = "Альфа";
Проект.Действия = Кит.Меню("Действия над «Альфа»",
	Кит.ПунктМеню("Открыть", "/проекты/альфа"),
	Кит.ПунктМеню("Участники", "/проекты/альфа/участники"));

Таблица = Кит.Таблица(Проекты).Вид("карточками");
Таблица.Колонка("Имя").Заглавная();
Таблица.Колонка("Действия").Вид("узкая");

HTML = Таблица.Рендер();
```

```делайте Таблица из данных: колонки и записи кит собирает сам
Проекты = Новый ТаблицаЗначений;
Проекты.Колонки.Добавить("Имя");
Проекты.Колонки.Добавить("Состояние");
Проект = Проекты.Добавить();
```

```не-делайте Цикл записей руками там, где хватает данных: шума больше, смысла столько же
	Запись = Таблица.Добавить(Кит.Запись());
	Запись.Добавить(Кит.Ячейка()).Добавить(Кит.Код(Имя));
	Запись.Добавить(Кит.Ячейка()).Добавить(Кит.Плашка("открытый").Вид("ok"));
КонецЦикла;
Таблица.Пусто().Добавить(Кит.Примечание("Проектов нет.").Вид("пусто"));
```

## Доступность

- Колонка печатается `th scope="col"`: скринридер называет заголовок колонки перед каждой ячейкой.
- Подпись таблицы (`Таблица.Подпись("…")`) печатается `caption` — именем таблицы для скринридера.
- Колонку без подписи (узкую, под значок) называет содержимое ячеек: значку дайте подпись, она станет его доступным именем.
- Таблица обёрнута прокруткой: широкая таблица не ломает страницу на узком экране.
