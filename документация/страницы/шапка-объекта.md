# Шапка объекта

Шапка объекта — первый экран его страницы: имя заголовком `<h1>`, значок и подпись вида, плашки состояния, описание, ряд меты и главное действие. Каким бывает объект, кит не знает: значок, подпись вида и слаг приходят в модели.

## Когда использовать

- У объекта есть своя страница: проект, документ, группа, пакет.
- Человеку нужно сразу понять, что перед ним, в каком оно состоянии и что с ним можно сделать.
- У объекта есть одно главное действие — команда установки, «Настройки», «Опубликовать».

Не берите шапку объекта для страницы-списка или раздела настроек — там нужен [заголовок страницы](заголовок-страницы). Запись внутри списка показывает [сводка](сводка).

## Полная шапка

`Имя` обязательно. `Иконка` стоит перед именем, `Подпись` — вид объекта мелко рядом. Под ними идут `Плашки`, `Описание`, `Мета` и `Команда` — [блок команды](блок-команды) с копированием.

```живой Со значком, подписью и командой
Плашки = Новый Массив();
Плашки.Добавить(Новый Структура("Текст, Вид", "внешний", "accent"));
Плашки.Добавить(Новый Структура("Текст, Вид", "устаревший", "warn"));

Мета = Новый Массив();
Мета.Добавить(Новый Структура("Подпись, Значение, Значок",
	"автор", "а.иванова", "аккаунт"));
Мета.Добавить(Новый Структура("Подпись, Значение", "срок", "бессрочно"));
Мета.Добавить(Новый Структура("Подпись, Адрес",
	"источник", "https://пример.рф/источник"));

HTML = Набор.ШапкаОбъекта().Отрисовать(
	Новый Структура("Имя, Вид, Иконка, Подпись, Описание, Плашки, Мета, Команда",
		"отчёт", "document", "куб", "документ", "Сводный отчёт за период",
		Плашки, Мета, "приложение установить отчёт"));
```

`Вид` — слаг объекта для атрибута `data-kind`: строчная латиница, цифры и дефис. Своего оформления у вида нет, атрибут нужен листу и скриптам инсталляции. Слаг с другими символами в разметку не попадает.

## Другой объект

Другой объект — другой значок, подпись и слаг. Шапка та же: кит не держит словаря видов.

```живой Другой объект — другой значок
Плашки = Новый Массив();
Плашки.Добавить(Новый Структура("Текст, Вид", "внешний", "accent"));

HTML = Набор.ШапкаОбъекта().Отрисовать(
	Новый Структура("Имя, Вид, Иконка, Подпись, Плашки",
		"альфа", "project", "куб", "проект", Плашки));
```

## Признак у имени

`Признаки` — значки сразу за именем, в той же строке заголовка: подписан, закреплён, проверен. Это свойство самого имени, поэтому место ему — у имени, а не среди плашек состояния. Значок размером с букву стоит по средней линии и держится за последний символ имени: на новую строку один он не уходит.

```живой С признаком у имени — значок, а не плашка
Признаки = Новый Массив();
Признаки.Добавить(Новый Структура("Иконка, Подпись",
	"замок", "Выпуск подписан ключом издателя"));

HTML = Набор.ШапкаОбъекта().Отрисовать(
	Новый Структура("Имя, Иконка, Подпись, Признаки",
		"годовой-отчёт", "куб", "документ", Признаки));
```

Подпись признака обязательна: без неё кит бросает исключение. Признак с неизвестным глифом не печатается.

## Действия

`Действия` — кнопки справа от имени; на узком экране они переносятся под него. Это доверенная разметка, собранная компонентом [кнопка](кнопка).

```живой Без значка и подписи, с действием
Действия = Набор.Кнопка().Отрисовать(Новый Структура("Подпись, Вариант, Иконка, Адрес",
	"Настройки", "вторичная", "шестерёнка", "/настройки/проекты"));

HTML = Набор.ШапкаОбъекта().Отрисовать(Новый Структура("Имя, Действия",
	"группа-разработки", Действия));
```

## Гайдлайны

```делайте Одно главное действие, остальные легче
Действия = Набор.Кнопка().Отрисовать(Новый Структура("Подпись, Вариант", "Настройки", "вторичная"))
	+ Набор.Кнопка().Отрисовать(Новый Структура("Подпись, Иконка", "Опубликовать", "стрелка"));

HTML = Набор.ШапкаОбъекта().Отрисовать(Новый Структура("Имя, Подпись, Действия",
	"годовой-отчёт", "документ", Действия));
```

```не-делайте Ряд основных кнопок: шапка спорит сама с собой
Действия = Набор.Кнопка().Отрисовать("Настройки")
	+ Набор.Кнопка().Отрисовать("Опубликовать")
	+ Набор.Кнопка().Отрисовать("Скачать");

HTML = Набор.ШапкаОбъекта().Отрисовать(Новый Структура("Имя, Подпись, Действия",
	"годовой-отчёт", "документ", Действия));
```

```делайте Признак имени — значком с подписью у имени
Признаки = Новый Массив();
Признаки.Добавить(Новый Структура("Иконка, Подпись", "замок", "Подписан ключом издателя"));

Плашки = Новый Массив();
Плашки.Добавить(Новый Структура("Текст, Вид", "устаревший", "warn"));

HTML = Набор.ШапкаОбъекта().Отрисовать(Новый Структура("Имя, Признаки, Плашки",
	"годовой-отчёт", Признаки, Плашки));
```

```не-делайте Признак плашкой среди состояний: смешаны «что это» и «как оно»
Плашки = Новый Массив();
Плашки.Добавить(Новый Структура("Текст, Вид", "подписан", "ok"));
Плашки.Добавить(Новый Структура("Текст, Вид", "устаревший", "warn"));

HTML = Набор.ШапкаОбъекта().Отрисовать(Новый Структура("Имя, Плашки",
	"годовой-отчёт", Плашки));
```

```делайте Описание — одна фраза о том, что это
HTML = Набор.ШапкаОбъекта().Отрисовать(Новый Структура("Имя, Подпись, Описание",
	"отчёт", "документ", "Сводный отчёт за период"));
```

```не-делайте Описание в абзац: первый экран уходит на чтение
HTML = Набор.ШапкаОбъекта().Отрисовать(Новый Структура("Имя, Подпись, Описание",
	"отчёт", "документ", "Этот документ содержит сводный отчёт за выбранный период, "
	+ "собранный из всех проектов, в которых вы участвуете, с учётом прав доступа, "
	+ "фильтров и настроек, сохранённых в вашем профиле, и обновляется каждую ночь."));
```

## Доступность

- Имя печатается `<h1>`. На странице объекта это единственный `<h1>`: другие заголовки — второго уровня и ниже.
- Шапка печатается `<header>` с классом `objhead`.
- Признак у имени — значок с `role="img"` и `<title>` из подписи: это и доступное имя, и всплывающая подсказка.
- Значок перед именем и значки меты декоративны. В мете подпись звучит скрытым текстом, как в [ряду меты](ряд-меты).
- Без `Имени` кит шапку не соберёт: страница объекта осталась бы без заголовка.

## Узлом холста

На [холсте](холст) действия шапки кладут детьми узла.

```живой Узлом дерева — действия кладут детьми
Шапка = Кит.ШапкаОбъекта(Новый Структура("Имя, Подпись", "отчёт", "документ"));
Шапка.Добавить(Кит.Кнопка(Новый Структура("Подпись, Вариант",
	"Настройки", "вторичная")));

HTML = Шапка.Рендер();
```
