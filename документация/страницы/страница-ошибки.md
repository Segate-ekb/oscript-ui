# Страница ошибки

Страница ошибки — тело ответа, когда показать запрошенное нельзя: «не найдено», «нет доступа», «сервер не справился». Крупно стоит код состояния HTTP, под ним — приглушённое пояснение, что случилось и куда идти дальше. Шапку, тему и статику вокруг добавляет [каркас страницы](каркас-страницы), как у любой другой страницы.

## Когда использовать

- Запрошенного объекта нет: 404.
- Объект есть, но этому человеку его видеть нельзя: 403.
- Сервер не смог ответить, и человеку нужно сказать об этом по-человечески: 500, 503.

Не берите страницу ошибки, когда объект есть, но пуст, — это [пустое состояние](пустое-состояние). Ошибка отправки формы показывается [тостом](тост) над той же формой, а не отдельной страницей: введённое не должно пропасть.

## Код и пояснение

`Код` — целое от 100 до 599, оно печатается заголовком первого уровня. `Сообщение` — абзац под ним.

```живой 404
HTML = Набор.СтраницаОшибки().Отрисовать(Новый Структура("Код, Сообщение",
	404, "Объект не найден"));
```

Пояснение необязательно. Без него остаётся один код — так бывает, когда объяснять причину отказа значит раскрыть лишнее.

```живой 403 без пояснения
HTML = Набор.СтраницаОшибки().Отрисовать(Новый Структура("Код", 403));
```

Компонент только печатает тело. Состояние ответа ставит контроллер — тот же код, что на странице: страница «404» с ответом 200 обманет и поисковик, и мониторинг.

```bsl
Ответ.УстановитьСостояниеНеНайдено();
Ответ.ТелоТекст = Каркас.Страница("Не найдено", Набор.СтраницаОшибки().Отрисовать(
	Новый Структура("Код, Сообщение", 404, "Такой страницы нет")), Контекст);
```

## Пояснение со ссылкой

`СообщениеHTML` — пояснение своей разметкой, обычно со ссылкой туда, где искать дальше. Оно задаётся вместо `Сообщение` и вставляется как есть: собирайте его кодом, а не из адреса запроса.

```живой 404 с ходом к списку
HTML = Набор.СтраницаОшибки().Отрисовать(Новый Структура("Код, СообщениеHTML",
	404, "Документ мог быть удалён или переехать. Вернитесь <a href=""/документы"">к списку документов</a>."));
```

```живой 503 — сервер на обслуживании
HTML = Набор.СтраницаОшибки().Отрисовать(Новый Структура("Код, Сообщение",
	503, "Идёт обновление. Через несколько минут всё заработает — данные не пострадают."));
```

Код вне 100..599 или не целый — ошибка разработчика, и кит отказывается печатать такую страницу.

```живой Код 42 — исключение с объяснением
Попытка
	HTML = Набор.СтраницаОшибки().Отрисовать(Новый Структура("Код", 42));
Исключение
	HTML = Набор.Тост().Отрисовать(Новый Структура("Текст, Вид",
		ИнформацияОбОшибке().Описание, "ошибка"));
КонецПопытки;
```

## Гайдлайны

```делайте Пояснение по-человечески и с ходом дальше
HTML = Набор.СтраницаОшибки().Отрисовать(Новый Структура("Код, СообщениеHTML",
	404, "Проекта нет — возможно, его удалили. <a href=""/проекты"">Все проекты</a>."));
```

```не-делайте Пояснение языком сервера: человеку нечего с ним делать
HTML = Набор.СтраницаОшибки().Отрисовать(Новый Структура("Код, Сообщение",
	500, "Поле объекта не обнаружено (Ссылка) at Модуль.ПолучитьПроект(), строка 214"));
```

```делайте Отказ в доступе говорит, к кому идти
HTML = Набор.СтраницаОшибки().Отрисовать(Новый Структура("Код, Сообщение",
	403, "У вас нет доступа к этому пулу. Попросите владельца пула добавить вас в участники."));
```

```не-делайте Отказ, который винит человека
HTML = Набор.СтраницаОшибки().Отрисовать(Новый Структура("Код, Сообщение",
	403, "Доступ запрещён! Вы не имеете права здесь находиться."));
```

## Доступность

- Код печатается `<h1>`: это первый и главный заголовок страницы, скринридер начнёт с него.
- `Сообщение` экранируется — адрес запроса или текст исключения, попавший в пояснение, разметкой не станет. `СообщениеHTML` не экранируется, поэтому его собирают только из своих строк.
- Код в заголовке понятен не всем. Где можно, пусть пояснение называет ситуацию словами («Страницы нет», «Нет доступа»), а не повторяет одно число.
- Заголовок вкладки браузера задаёт каркас (первый параметр `Каркас.Страница`): пишите в него слова, а не код.

## Узлом холста

На [холсте](холст) тело отказа — узел рода «отказ».

```живой Страница ошибки узлом дерева
HTML = Кит.СтраницаОшибки(Новый Структура("Код, Сообщение",
	404, "Объект не найден")).Рендер();
```
