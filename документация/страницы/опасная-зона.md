# Опасная зона

Опасная зона — красная рамка вокруг необратимого действия: удалить проект, отозвать публикацию, сбросить ключи. Внутри — заголовок со значком предупреждения, пояснение, поле подтверждения и опасная кнопка. Действие не случится с первого клика: человек сначала вводит образец, например имя проекта.

## Когда использовать

- Действие нельзя отменить: данные пропадут, ссылки сломаются, ключи перестанут работать.
- Ошибка дорого стоит, и лишние три секунды на ввод имени — честная цена.
- Действие живёт в настройках объекта, отдельной секцией внизу страницы.

Не берите опасную зону для действий, которые можно отменить, — там хватит [кнопки](кнопка) и [тоста](тост) с итогом. Удаление строки в списке, которое восстанавливается из корзины, — пункт [меню](меню) строки, а не зона.

## Удаление с подтверждением

`Подтверждение` обязательно: `Имя` — имя поля, значение которого сверит сервер, `Образец` — что нужно ввести. Образец печатается в метке поля («Введите «main» для подтверждения») и подсказкой внутри поля, но не значением: иначе подтверждение свелось бы к лишнему клику.

```живой Удаление проекта
HTML = Набор.ОпаснаяЗона().Отрисовать(
	Новый Структура("Заголовок, Пояснение, Подтверждение",
		"Удаление проекта",
		"Проект и все его документы будут удалены безвозвратно. Отменить это нельзя.",
		Новый Структура("Имя, Образец, Подсказка",
			"подтверждение", "main",
			"Введите имя проекта ровно так, как оно написано выше")));
```

Поле подтверждения обязательное и с выключенным автозаполнением: браузер не подставит образец сам. Проверка на клиенте — только удобство. Гарантия — сервер, который сравнивает присланное значение с образцом и без совпадения ничего не удаляет.

Свою метку поля задаёт `Метка` в подтверждении. Без образца метка по умолчанию — «Подтвердите необратимое действие».

## Своя кнопка

Кнопка по умолчанию — «Удалить» с корзиной. Свою задают полем `Кнопка` моделью [кнопки](кнопка); вариант у неё всё равно будет «опасная», что бы ни пришло.

```живой Своя кнопка — вид навязан опасным
HTML = Набор.ОпаснаяЗона().Отрисовать(
	Новый Структура("Заголовок, Подтверждение, Кнопка",
		"Отзыв публикации",
		Новый Структура("Имя, Образец", "подтверждение", "1.0.0"),
		Новый Структура("Подпись, Иконка", "Отозвать публикацию", "закрыть")));
```

## Тело над подтверждением

`Тело` — своя разметка между пояснением и полем: список того, что пропадёт, ссылка на экспорт. Она вставляется как есть, поэтому собирайте её кодом, а не из ввода пользователя.

```живой Что пропадёт — списком в теле
Тело = "<ul><li>12 документов и их редакции</li><li>3 ключа доступа</li>"
	+ "<li>Публичные ссылки на проект</li></ul>";

HTML = Набор.ОпаснаяЗона().Отрисовать(
	Новый Структура("Заголовок, Пояснение, Тело, Подтверждение, Кнопка",
		"Удаление проекта",
		"Вместе с проектом исчезнет всё, что в нём лежит:",
		Тело,
		Новый Структура("Имя, Метка, Образец", "подтверждение",
			"Имя проекта для подтверждения", "main"),
		Новый Структура("Подпись, Иконка", "Удалить проект", "корзина")));
```

## Формы зона не печатает

Зона живёт внутри формы секции настроек: вложенная `<form>` — невалидный HTML. Поэтому ни формы, ни токена CSRF компонент не печатает — их даёт секция [дома настроек](дом-настроек) или форма, в которую вы зону положили.

Без подтверждения с именем поля зона не собирается: красная рамка вокруг кнопки — оформление, а не защита.

```живой Зона без подтверждения — исключение с объяснением
Попытка
	HTML = Набор.ОпаснаяЗона().Отрисовать(Новый Структура("Заголовок", "Удаление проекта"));
Исключение
	HTML = Набор.Тост().Отрисовать(Новый Структура("Текст, Вид",
		ИнформацияОбОшибке().Описание, "ошибка"));
КонецПопытки;
```

## Гайдлайны

```делайте Образец — то, что вводят осознанно: имя проекта
HTML = Набор.ОпаснаяЗона().Отрисовать(Новый Структура("Заголовок, Подтверждение",
	"Удаление проекта", Новый Структура("Имя, Образец", "подтверждение", "отчёты-2026")));
```

```не-делайте Образец «да»: его вводят не глядя, как жмут «ОК»
HTML = Набор.ОпаснаяЗона().Отрисовать(Новый Структура("Заголовок, Подтверждение",
	"Удаление проекта", Новый Структура("Имя, Образец", "подтверждение", "да")));
```

```делайте Пояснение говорит, что пропадёт и что отменить нельзя
HTML = Набор.ОпаснаяЗона().Отрисовать(Новый Структура("Заголовок, Пояснение, Подтверждение",
	"Сброс ключей",
	"Все выпущенные ключи перестанут работать сразу. Сборки, которые ими пользуются, упадут.",
	Новый Структура("Имя, Образец", "подтверждение", "сбросить")));
```

```не-делайте Без пояснения: человек не знает цену действия
HTML = Набор.ОпаснаяЗона().Отрисовать(Новый Структура("Заголовок, Подтверждение",
	"Сброс ключей", Новый Структура("Имя, Образец", "подтверждение", "сбросить")));
```

```делайте Кнопка называет действие
HTML = Набор.ОпаснаяЗона().Отрисовать(Новый Структура("Заголовок, Подтверждение, Кнопка",
	"Отзыв публикации", Новый Структура("Имя, Образец", "подтверждение", "1.0.0"),
	Новый Структура("Подпись, Иконка", "Отозвать версию 1.0.0", "закрыть")));
```

```не-делайте Кнопка «ОК»: не ясно, что случится по нажатию
HTML = Набор.ОпаснаяЗона().Отрисовать(Новый Структура("Заголовок, Подтверждение, Кнопка",
	"Отзыв публикации", Новый Структура("Имя, Образец", "подтверждение", "1.0.0"),
	Новый Структура("Подпись", "ОК")));
```

## Доступность

- Заголовок зоны — `<h3>`, он виден в списке заголовков страницы и предупреждает ещё до кнопки. Значок рядом декоративен.
- Поле подтверждения — обычное поле формы кита: `<label>` оборачивает поле, поэтому метка с образцом и есть его имя, а подсказка стоит внутри той же метки и читается вместе с ней. Поле помечено `required`.
- Образец стоит и в метке, и плейсхолдером. Плейсхолдер исчезает при вводе, метка — нет: сверяться есть с чем до последней буквы.
- Красная рамка и цвет кнопки — второй носитель смысла. Опасность называют слова: заголовок, пояснение и подпись кнопки.
- Кнопка — та же опасная [кнопка](кнопка) кита со всеми её свойствами доступности.

## Узлом холста

На [холсте](холст) зона — узел рода «зона». Её тело собирается детьми узла: поле `Тело` в модели не задают.

```живой Узлом дерева — тело кладут детьми
Зона = Кит.ОпаснаяЗона(Новый Структура("Заголовок, Подтверждение",
	"Удаление проекта", Новый Структура("Имя, Образец", "подтверждение", "main")));
Зона.Добавить(Кит.Примечание("Отменить это нельзя."));

HTML = Зона.Рендер();
```
