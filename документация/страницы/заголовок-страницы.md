# Заголовок страницы

Заголовок страницы говорит, о чём экран: `<h1>` и, по желанию, приглушённый абзац-пояснение под ним. Он же озаглавливает блок внутри страницы — тогда это `<h2>`.

## Когда использовать

- У экрана-списка или раздела настроек нужно название: «Управление проектами», «Внешние источники».
- Под названием стоит одна фраза: что здесь делают или что здесь лежит.
- Длинную страницу делят блоки, и у каждого свой заголовок второго уровня.

Не берите заголовок страницы для страницы одного объекта — у неё есть [шапка объекта](шапка-объекта) с плашками, метой и действиями. Заголовок блока с рамкой и действиями даёт [карточка](карточка).

## Заголовок страницы

Строка вместо модели — это просто `<h1>`.

```живой h1 страницы
HTML = Набор.ЗаголовокСтраницы().Отрисовать("Управление проектами");
```

## С пояснением

`Пояснение` печатается приглушённым абзацем под заголовком. Пишите его одной фразой: что человек делает на этом экране.

```живой h1 с пояснением
HTML = Набор.ЗаголовокСтраницы().Отрисовать(Новый Структура("Заголовок, Пояснение",
	"Внешние источники", "Синхронизация чужих данных в это приложение"));
```

Пояснение со ссылкой или кодом передают полем `ПояснениеHTML` вместо `Пояснение`. Это доверенная разметка, и собирать её нужно компонентами кита.

```живой Пояснение с разметкой
HTML = Набор.ЗаголовокСтраницы().Отрисовать(Новый Структура("Заголовок, ПояснениеHTML",
	"Ключи доступа", "Ключ передают в заголовке <code>Authorization</code>."));
```

## Заголовок блока

`Уровень` 2 печатает `<h2>` — заголовок блока внутри страницы. Других уровней компонент не печатает: всё, кроме 2, становится 1.

```живой h2 блока
HTML = Набор.ЗаголовокСтраницы().Отрисовать(Новый Структура("Заголовок, Уровень",
	"Документы проекта", 2));
```

## Примечание отдельно

`Примечание` печатает такой же приглушённый абзац без заголовка. Так ставят оговорку под формой или списком. Пустой текст не печатается вовсе.

```живой Примечание отдельно
HTML = Набор.ЗаголовокСтраницы().Примечание(
	"Ключ показывается один раз — сохраните его сразу.");
```

## Гайдлайны

```делайте Один h1 на странице, блоки — h2
HTML = Набор.ЗаголовокСтраницы().Отрисовать("Управление проектами")
	+ Набор.ЗаголовокСтраницы().Отрисовать(Новый Структура("Заголовок, Уровень", "Открытые", 2))
	+ Набор.ЗаголовокСтраницы().Отрисовать(Новый Структура("Заголовок, Уровень", "Архив", 2));
```

```не-делайте h1 у каждого блока: оглавление страницы плоское
HTML = Набор.ЗаголовокСтраницы().Отрисовать("Управление проектами")
	+ Набор.ЗаголовокСтраницы().Отрисовать("Открытые")
	+ Набор.ЗаголовокСтраницы().Отрисовать("Архив");
```

```делайте Пояснение добавляет то, чего нет в заголовке
HTML = Набор.ЗаголовокСтраницы().Отрисовать(Новый Структура("Заголовок, Пояснение",
	"Внешние источники", "Синхронизация чужих данных в это приложение"));
```

```не-делайте Пояснение повторяет заголовок
HTML = Набор.ЗаголовокСтраницы().Отрисовать(Новый Структура("Заголовок, Пояснение",
	"Внешние источники", "На этой странице показаны внешние источники"));
```

## Доступность

- Заголовок — настоящий `<h1>` или `<h2>`: по ним скринридер строит оглавление страницы и прыгает между блоками.
- Пустой `Заголовок` кит не печатает и бросает исключение: пустой `<h1>` скринридер прочтёт как безымянный раздел.
- Уровень выбирают по месту в оглавлении, а не по размеру шрифта. Не прыгайте с `<h1>` на `<h3>`.
- Пояснение — обычный абзац после заголовка, его читают сразу за ним.

## Узлом холста

```живой Заголовок узлом дерева
HTML = Кит.ЗаголовокСтраницы(Новый Структура("Заголовок, Пояснение",
	"Управление проектами", "Все проекты инсталляции")).Рендер();
```

Заголовки любого уровня, с первого по шестой, на холсте даёт `Кит.Заголовок(Уровень)` — см. [текст и значения](текст).
